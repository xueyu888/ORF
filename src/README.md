# 代码目录

## 接口访问约定

前端数据统一通过同源 `/api` 请求后端接口。
前端不直接写死后端域名或端口，开发和生产环境由代理或网关转发到实际后端服务。

## 数据事实源约定

业务数据以后端数据库为唯一事实源。
前端新增、编辑、删除、排序、状态切换等业务写操作，必须先调用 API；API 成功后，再用接口返回结果或重新拉取 `/api/tasks-page` 更新页面状态。
API 失败时，不更新业务状态，只给出失败提示。
`localStorage` 只能保存主题、折叠状态、筛选条件等纯界面偏好，不能保存业务数据。

业务代码必须由仓库文档驱动，不能直接通过 AI 会话临时修改。
