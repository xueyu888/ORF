# ORF 系统框架

## 核心理念

- 目标导向：所有工作围绕明确目标展开。
- 结果导向：关注可验证结果，不奖励单纯忙碌。
- 数据驱动：用悬赏指标、证据和证伪报告判断结果。
- 不确定性导向：奖励把不确定性变成确定性的能力。

## 基础流程

```text
设定悬赏目标
→ 拆解悬赏指标
→ 申请挑战 / 征召
→ 确认挑战者
→ 目标确认期
→ 目标冻结
→ 执行任务
→ 提交战利品
→ 目标验收
→ 积分结算
```

指挥官是业务称呼，权限系统中等同管理员。

## 核心规则

- 挑战者绑定到目标，不绑定到指标。
- 目标冻结默认冻结目标下所有指标。
- 战利品在目标层级提交，用于证明指标完成或有效证伪。
- 完成时间按战利品提交时间判断。
- 任务和子任务只表示执行进度，不自动触发验收或结算。

## 积分规则

```text
目标总分 = 已验收悬赏指标不确定性分之和
目标结算积分 = 目标总分 × 完成系数
成员积分 = 目标结算积分 × 贡献比例 + 悬赏指标定义分
```

个人贡献比例由目标级匿名互评确定。详细规则见：

- [积分结算规则.md](../rules/积分结算规则.md)
- [贡献评价与积分分配规则.md](../rules/贡献评价与积分分配规则.md)
