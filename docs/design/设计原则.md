# ORF系统框架

## 接口访问约定

前端数据统一通过同源 `/api` 请求后端接口，例如 `/api/tasks`。
前端不直接写死后端域名或端口，开发和生产环境由代理或网关转发到实际后端服务。

## 核心理念：
1. **目标导向**：所有的工作都应该围绕着明确的目标展开，确保每个任务都为实现目标服务。
2. **结果导向**：关注结果而不是过程，确保每个任务的完成都能为目标的实现做出贡献。
3. **数据驱动**：通过数据来评估目标的完成度，确保评估的客观性和准确性。这里的数据主要是悬赏指标的完成度和证伪报告。
4. **不确定性导向**：ORF 奖励的是把不确定性变成确定性的能力。


## 基础概念：
1. **目标**：一个明确的方向
2. **悬赏指标**：衡量目标完成度的标准，要能够可观测，可衡量，有明确的截止日期，并且具有挑战性
3. **任务**：为了完成目标而需要完成的具体工作

## 基础流程：
1. **目标设定**：主管设定目标和悬赏指标，明确截止日期
2. **悬赏指标来源**：悬赏指标可以由主管定义，也可以由成员提出候选悬赏指标并由主管采纳。
3. **悬赏指标领取**：主管定义的悬赏指标由成员申请挑战并由主管确认；成员提出的候选悬赏指标被采纳后，提出人有 2 小时优先挑战权，放弃或超时后进入公共池。
4. **悬赏指标确认**：挑战者接受后进入确认期；确认期按剩余时间的 30% 计算，以半天为单位四舍五入，最短半天，最长 9 天。
5. **ORF重估**：在确认期内，主管和挑战者共同评估悬赏指标是否仍然成立，必要时调整悬赏指标、调整时间或推翻目标。
6. **悬赏指标冻结**：确认期结束且确认通过后，悬赏指标进入冻结状态，不再调整，直到完成、未完成或证伪。
7. **目标验收**：主管根据验收标准、交付结果和证伪报告进行完成评级，并计算积分。

## 积分规则

ORF 的积分由不确定性分、悬赏指标定义分和完成系数组成。悬赏指标定义分奖励把目标拆成有效悬赏指标；悬赏指标被完成或有效证伪时，按不确定性分和完成系数结算。

**悬赏指标定义分 = 2**

**结算积分 = 不确定性分 × 完成系数**

**成员积分 = 悬赏指标定义分 + 负责悬赏指标的结算积分**

完成分不额外乘以 10；按时完成的完成系数为 100%，完成分等于不确定性分。

积分不是按工作量、耗时或主观辛苦程度计算，而是奖励把不确定性转化为确定性的结果。

### 1. 不确定性分

不确定性分用于评估悬赏指标的交付不确定性。等级越高，代表路径越不清晰、依赖越复杂、验证成本越高，完成后的价值也越高。

系统落地时，不确定性等级直接使用下表五档。已有数据需要在迁移或验收时重新评级。

| 等级 | 不确定性分 | 判断标准 |
| --- | ---: | --- |
| 入门 | 10 | 路径非常清楚，有现成方案可以参考。大部分悬赏指标的不确定性分默认为 10。 |
| 进阶 | 30 | 方向清楚，有成熟参考方案，不需要创造新方法。但复杂度明显更高。 |
| 破局 | 90 | 没有现成答案，需要定义新的判断标准、评估口径、业务规则或验证方法，并通过实际数据证明可行。 |
| 渡劫 | 270 | 关键假设本身不确定，可能推翻原目标；需要跨业务、数据、模型、产品多方验证，失败概率高。 |
| 飞升 | 810 | 需要形成行业级、平台级或方法论级突破，完成后显著改变现有能力边界。 |


### 2. 悬赏指标定义分

悬赏指标定义分固定为 2 分，在正式悬赏指标完成或有效证伪后发放给悬赏指标定义人。悬赏指标定义分不随不确定性等级变化，也不受完成系数、完成时间或后续执行人影响。

成员提出的候选悬赏指标被主管采纳时不立即发放定义分；只有该悬赏指标最终完成或有效证伪后，才给定义人发放 2 分。


### 3. 完成系数

完成系数用于评估最终结果。完成必须通过验收；证伪或推翻目标必须形成证伪报告，不能只基于口头说明。

| 结果 | 系数 | 说明 |
| --- | ---: | --- |
| 按时完成 | 100% | 截止前通过验收 |
| 延期完成 | 50% | 超过截止时间后通过验收 |
| 按时悬赏指标证伪 | 100% | 截止前提交证伪报告，证明悬赏指标在原理上无法达成 |
| 延期悬赏指标证伪 | 50% | 超过截止时间后提交证伪报告，完成悬赏指标证伪 |
| 重估阶段内目标推翻 | 100% | 在重估阶段内提交证伪报告，证明目标本身不成立 |

| 主动放弃 | 0% | 无有效证据，主动放弃 |
| 超预期完成 | 150% | 明显超过验收标准 |


字段说明：
- **结果**：悬赏指标最终状态，包括完成、未完成、悬赏指标证伪、评估窗口内目标推翻和主动放弃。
- **系数**：最终积分的乘数。
- **说明**：判断该结果状态的验收标准。

### 4. 特殊说明

1. **悬赏指标证伪**：如果通过数据、实验或明确外部约束证明悬赏指标在原理上无法达成，并提交证伪报告，视为有效交付；没有证伪报告，不计为有效交付。
2. **目标推翻**：目标推翻只能发生在评估窗口内。
3. **目标优先级调整**：仅调整优先级、延期或暂缓执行，不属于目标推翻，也不触发证伪积分。
4. **评估窗口后处理**：评估窗口结束后，不再认定目标推翻，只能按悬赏指标证伪、完成或未完成处理。
5. **主动放弃**：没有有效证据支撑，或没有提交证伪报告，只是主观放弃，完成系数为 0%。
