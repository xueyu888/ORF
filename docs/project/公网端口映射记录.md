## 配置提醒

1. 稳定入口优先使用 `8443`，这是常见 HTTPS 备用端口，截图里没有占用，地址 `https://orf-xueyu.duckdns.org:8443` 也容易记。
2. 只有公网 IP、没有域名时也可以做 HTTPS 反向代理；区别在于证书来源。若使用本地 bootstrap CA 或自签 IP 证书，手机需要先信任对应 CA 证书；若要浏览器默认信任，需要申请公网可信的 IP 地址证书。
3. 生产或长期手机访问不要直接暴露 `5173`；用 `8443` 上的 HTTPS 反向代理服务前端，并把 `/api`、`/health`、`/settings/backgrounds` 转发到 `127.0.0.1:8787`。
4. Let's Encrypt 已支持公网 IP 地址证书，但 IP 证书是短期证书，需要自动续期；Certbot 申请 IP 证书时需要让 ACME challenge 能从公网访问。当前 `80` 的路由器映射已存在，但本机 `80` 只有在证书验证流程启动 `acme-http-gateway` 时才应监听。
5. 如果临时暴露 `15173 -> 5173`，需要把 Ory 的 `allowed_origins`、`allowed_return_urls` 和 ORF 的 `ORF_APP_URL` 按实际公网访问地址同步调整，否则登录回跳和浏览器凭据可能失败。
6. 如果使用稳定 HTTPS 入口，`ORF_APP_URL` 应指向 `https://orf-xueyu.duckdns.org:8443`，`CORS_ORIGIN` 应包含这个同源入口；若所有 API 都由同源反向代理转发，浏览器侧不会直接访问 `8787`。
7. 如果当前浏览器通过 VPN 访问 DuckDNS，DuckDNS 页面自动识别的 IP 可能是 VPN 出口。ORF 域名应手动填服务器路由器的公网 IP，或用本仓库脚本读取 `ORF_PUBLIC_IP` 更新。
8. 路由器映射只需要 TCP，不需要 UDP。HTTP、HTTPS、SSE、WebSocket 和 Vite HMR 都走 TCP。
9. 局域网成员访问 `125.70.13.137:18443/19443` 可能触发 NAT 回流失败；共享包 LAN 模式应写入 `https://199.199.199.8:18443` 和 `https://199.199.199.8:19443`，对应 public-gateway bootstrap 证书 SAN 必须同时包含 `125.70.13.137` 和 `199.199.199.8`。

## 本机部署命令

服务器本机运行 `.env` 需要包含本地/LAN 运行入口，避免路由器 NAT 回环导致 `orf up` 失败：

```text
ORF_PUBLIC_IP=125.70.13.137
ORF_PUBLIC_GATEWAY_CERT_EXTRA_IPS=199.199.199.8
DATABASE_URL=postgresql://<user>:<password>@199.199.199.8:5432/orf?sslmode=verify-full&sslrootcert=<root.crt>&options=-csearch_path%3Dorf_current%2Cpublic
ORF_WEB_EXTERNAL_PORT=8443
ORF_DUCKDNS_DOMAIN=orf-xueyu.duckdns.org
ORF_DUCKDNS_TOKEN=<DuckDNS token>
ORF_DUCKDNS_PROPAGATION_SECONDS=120
ORY_PUBLIC_URL=http://127.0.0.1:4433
OBJECT_STORAGE_ENDPOINT=http://127.0.0.1:9000
ORF_APP_URL=https://orf-xueyu.duckdns.org:8443
CORS_ORIGIN=http://127.0.0.1:5173,http://localhost:5173,https://orf-xueyu.duckdns.org:8443
```

远程成员机器手工接入共享基础设施时，依赖入口使用公网地址：

```text
DATABASE_URL=postgresql://<user>:<password>@125.70.13.137:54321/orf?sslmode=verify-full&sslrootcert=<root.crt>&options=-csearch_path%3Dorf_current%2Cpublic
ORY_PUBLIC_URL=https://125.70.13.137:18443
OBJECT_STORAGE_ENDPOINT=https://125.70.13.137:19443
```

刷新 DuckDNS A 记录：

```bash
npm run infra:public:duckdns:update
```

准备并启动公网网关：

```bash
npm run infra:public:up
```

签发 DuckDNS 域名证书：

```bash
npm run infra:public:domain-cert:issue
```

续期：

```bash
npm run infra:public:domain-cert:renew
```

安装每日自动续期任务：

```bash
npm run infra:public:domain-cert:install-renewal
```
