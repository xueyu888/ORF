# ORF 任务管理页面

## 1. 页面目标

ORF 任务管理页面用于在同一个工作区管理目标、指标、任务、子任务的执行关系，并支持团队视图、个人视图和 ORF 流程状态切换。

页面目标是让团队在 ORF 重估和目标冻结过程中，清楚看到每个目标的可验证进展、负责人、完成状态和任务推进情况。

## 2. 组件结构

### 2.1 组件树

```text
ORFTaskPage
├─ AppSidebar
└─ MainContent
   ├─ ProcessPanel
   │  └─ ProcessStep[4]
   ├─ TeamDashboard
   │  └─ DashboardMetricCard[4]
   ├─ ListToolbar
   │  ├─ OrfTabs
   │  │  ├─ TeamTab
   │  │  └─ PersonalTab
   │  └─ Filters
   └─ ObjectiveTableList
      └─ GoalCard
         ├─ GoalInfoRow
         └─ MetricList
            └─ MetricItem
               ├─ MetricRow
               └─ TaskList
                  └─ TaskRow
                     └─ SubtaskRow
```

### 2.2 组件职责

| 组件 | 职责 |
| --- | --- |
| `ORFTaskPage` | 页面容器 |
| `AppSidebar` | 全局侧边栏，支持宽侧栏和窄侧栏两种状态。 |
| `MainContent` | 页面主内容区域 |
| `ProcessPanel` | 顶部任务管理流程卡，横向展示 4 个步骤。 |
| `ProcessStep` | 单个流程步骤，支持已完成、进行中、待确认三种视觉状态。 |
| `OrfTabs` | 团队和个人标签页切换。 |
| `TeamDashboard` | 团队视图顶部仪表盘，仅团队标签页展示。 |
| `DashboardMetricCard` | 单个指标卡，左侧环形图标，右侧指标数值和说明。 |
| `ListToolbar` | 目标列表上方的工具条，左侧放团队 / 个人标签，右侧放周期和筛选控件。 |
| `ObjectiveTableList` | 目标表格卡列表容器。 |
| `GoalCard` | 目标表格卡，目标不可折叠，内部承载指标行和任务行。 |
| `GoalInfoRow` | 目标摘要行，展示目标标题、状态、头像、截止日期和进度。 |
| `MetricList` | 目标内的指标列表容器。 |
| `MetricItem` | 单个指标块，包含指标行和该指标下的任务列表。 |
| `MetricRow` | 指标行，支持展开和折叠。 |
| `TaskList` | 指标下的任务列表容器。 |
| `TaskRow` | 任务行，展示任务标题、执行人、状态、更新时间和进度。 |
| `SubtaskRow` | 子任务行。 |

## 3. 页面布局

### 3.1 整体布局

页面从左到右分为两块：

| 区域 | 说明 |
| --- | --- |
| 左侧 | `AppSidebar`，固定显示，高度占满页面。 |
| 右侧 | `MainContent`，从上到下展示页面内容。 |

`MainContent` 内部顺序必须固定：

1. `ProcessPanel`
2. `TeamDashboard`，仅团队标签页显示
3. `ListToolbar`
4. `ObjectiveTableList`

`AppShell` 顶部栏展示当前页面标题，任务页内部只在流程卡片左上展示 `任务管理`。

### 3.2 标签页布局

| 标签页 | 顺序 | 展示内容 |
| --- | --- | --- |
| 团队 | 第 1 个 | 团队目标列表 + `TeamDashboard` |
| 个人 | 第 2 个 | 当前成员相关目标列表 |

规则：

- 默认选中团队标签页。
- 点击团队标签页时，显示团队目标列表和 `TeamDashboard`。
- 点击个人标签页时，显示当前成员相关目标列表，并隐藏 `TeamDashboard`。

### 3.3 团队仪表盘布局

`TeamDashboard` 位于团队标签页顶部。

布局要求：

- 使用 4 张独立圆角指标卡。
- 使用白色背景、浅灰边框和轻微阴影。
- 桌面端一行 4 张，窄屏自动换行。
- 每张卡片左侧是环形进度图标，右侧是大号数字和说明文字。
- 仪表盘由 4 张独立指标卡组成，每张卡片独立展示边框、圆角和内容。

饼图内容：

| 饼图 | 内容 |
| --- | --- |
| 饼 1 | 展示整个团队目前完成目标中所有指标的百分比，用分数表示。 |
| 饼 2 | TODO |
| 饼 3 | TODO |
| 饼 4 | TODO |

### 3.4 目标布局

`GoalList` 内可以有多个 `GoalCard`。

规则：

- 多个 `GoalCard` 纵向排列。
- `GoalCard` 是目标的最外层大框。
- `GoalCard` 不可折叠。
- `GoalCard` 内部从上到下排列：
  1. `GoalInfoRow`
  2. `MetricList`
- `GoalInfoRow` 是目标表格卡首行，左侧为目标图标和标题，中间为成员头像与日期，右侧为进度条和百分比。
- `GoalInfoRow` 与后续行之间使用 1px 浅灰分割线。

### 3.5 指标布局

`MetricList` 内可以有多个 `MetricItem`。

规则：

- `MetricItem` 位于 `GoalCard` 内部。
- 多个 `MetricItem` 纵向排列。
- `MetricItem` 可以折叠，默认展开。
- `MetricItem` 使用 `MetricRow` 表格行结构，不做独立卡片。
- `MetricRow` 字段从左到右为：指标标题、负责人、完成状态、更新时间、进度。
- 指标展开时，下方展示该指标关联的 `TaskList`。
- 指标折叠时，只保留指标行。

### 3.6 任务布局

`TaskTree` 内展示任务和子任务。

规则：

- 任务和子任务字段结构接近，统一使用表格行密度展示。
- 任务可以折叠，默认展开。
- 子任务挂在任务下。
- 每深入一层，左侧缩进增加一级。
- 任务和子任务使用浅灰短连接线展示层级关系。
- 子任务暂不强制继续折叠，后续是否开放作为 TODO 保留。

## 5. 状态规则

### 5.1 标签页状态

`tab` 取值：

| 取值 | 含义 |
| --- | --- |
| `team` | 团队 |
| `personal` | 个人 |

规则：

- 默认选中 `team`。
- `team` 展示 `TeamDashboard`。
- `personal` 不展示 `TeamDashboard`。

### 5.2 ORF 流程状态

`flowStatus` 取值和推进顺序：

| 顺序 | 取值 | 页面含义 |
| --- | --- | --- |
| 1 | `goal_setting` | 目标设定 |
| 2 | `metric_claiming` | 指标领取 |
| 3 | `orf_review` | ORF 重估 |
| 4 | `frozen` | 目标冻结，代表主管已确认 |

规则：

- 流程必须按顺序推进。
- 上一个状态完成后，才能进入下一个状态。
- `goal_setting`、`metric_claiming`、`orf_review` 完成并经主管确认后，进入下一步。
- `frozen` 是最终状态。
- 目标进入 `frozen` 时，表示目标冻结已经由主管确认完成。
- 顶部流程条必须展示 4 张步骤卡，步骤之间用右箭头连接。
- 当前步骤使用青绿色描边和浅青背景；已完成步骤使用青绿色圆形勾选；未开始步骤使用浅灰编号。

### 5.3 冻结状态

目标冻结前：

- `GoalCard` 整体背景偏灰。
- 表示目标仍处于未冻结状态。

目标冻结后：

- `GoalCard` 背景恢复白色。
- 表示主管已经确认目标冻结，目标进入硬验收状态。

核心原则：

> 允许早期识别不确定性，禁止后期拿不确定性当借口。

### 5.4 折叠状态

| 对象 | 是否可折叠 | 默认状态 |
| --- | --- | --- |
| 目标 | 不可折叠 | 固定展开 |
| 指标 | 可折叠 | 默认展开 |
| 任务 | 可折叠 | 默认展开 |
| 子任务 | 暂不强制 | TODO |

### 5.5 完成状态

完成状态统一显示在标题左侧。

建议图标：

| 状态 | 图标 |
| --- | --- |
| 已完成 | `check-circle` |
| 未完成 | `circle` |
| 展开 | `chevron-down` |
| 折叠 | `chevron-right` |

## 6. 交互规则

### 6.1 标签页切换

点击团队标签页：

- 显示团队目标列表。
- 显示 `TeamDashboard`。

点击个人标签页：

- 显示当前成员相关目标列表。
- 隐藏 `TeamDashboard`。

### 6.2 指标展开和折叠

点击指标左侧展开图标：

- 如果当前指标已展开，则收起该指标下的任务。
- 如果当前指标已收起，则展开该指标下的任务。

### 6.3 任务展开和折叠

点击任务左侧展开图标：

- 如果当前任务已展开，则收起该任务下的子任务。
- 如果当前任务已收起，则展开该任务下的子任务。

### 6.4 完成图标展示

| 对象 | 完成后展示 |
| --- | --- |
| 目标 | 目标标题左侧显示勾选图标。 |
| 指标 | 指标标题左侧显示勾选图标。 |
| 任务 | 任务标题左侧显示勾选图标。 |
| 子任务 | 子任务标题左侧显示勾选图标。 |

### 6.5 流程推进

流程推进由主管确认触发。

主管确认后：

- 当前状态标记为完成。
- 如果存在下一步，页面进入下一个流程状态。
- 当主管确认 `orf_review` 完成后，页面直接进入 `frozen`。
- `frozen` 本身就是确认后的最终状态。

## 7. 权限规则

主管拥有全部界面的全部权限。

成员权限：

| 流程状态 | 成员权限 |
| --- | --- |
| 目标设定 | 查看 |
| 指标领取 | 查看 |
| ORF 重估 | 查看、编辑 |
| 目标冻结 | 查看 |

补充规则：

- 只有主管可以确认流程状态完成。
- 只有主管可以推动流程进入下一个状态。
- 成员只有在 ORF 重估阶段可以编辑。

### 8.2 全局侧边栏视觉风格

侧边栏参考 tability / Squarepoint 风格，整体使用青绿色系，不使用当前黑紫色侧栏。

侧边栏配色：

| 用途 | 颜色要求 |
| --- | --- |
| 主背景 | 深青绿色，接近 `#075856` / `#085f5e` |
| 顶部品牌区背景 | 更深青绿色，接近 `#064f4f` |
| 当前工作区高亮背景 | 偏亮青绿色块，接近 `#2a6f6d` |
| 当前选中菜单项背景 | 深青绿色高亮，接近 `#064b4b` |
| 分割线 | 比背景略深的青绿色线，接近 `rgba(0, 0, 0, 0.18)` |
| 图标颜色 | 浅青色，接近 `#74d2d6` |
| 主要文字 | 白色或接近白色，接近 `#f4fbfb` |
| 次级文字和分组标题 | 浅青灰，接近 `#b7d8d8` |

侧边栏布局：

- 宽侧栏宽度约 `280px`。
- 窄图标侧栏宽度约 `88px`。
- 顶部是品牌区：左侧深色小方形 logo + 产品名，右侧设置图标。
- 品牌区下面是工作区 / 组织入口。
- 工作区 / 组织入口高度高于普通菜单项，使用较亮青绿色背景。
- 菜单按分组展示。
- 分组标题使用全大写小字和较大字距，例如 `WORK`、`REPORTS`、`ORG`。
- 菜单项为整行点击区域。
- 菜单项左侧显示图标，右侧显示文字。
- 图标颜色比正文更亮。
- 当前选中菜单项使用深色块高亮。
- 当前选中菜单项左侧不需要额外竖线。
- 菜单项和分组之间使用 `1px` 分割线。
- 不使用卡片阴影。
- 窄侧栏模式只保留居中的图标按钮。

### 8.3 盒模型

#### AppSidebar

宽侧栏：

- 宽度约 `280px`。
- 左侧固定显示。
- 高度占满页面。

窄侧栏：

- 宽度约 `88px`。
- 只保留居中的图标按钮。
- 背景和高亮色沿用同一套青绿色规范。

侧边栏内部顺序：

1. 顶部品牌区
2. 工作区 / 组织入口
3. 菜单分组
4. 菜单项

#### GoalCard

盒模型要求：

- 使用圆角卡片。
- 边框为 `1px` 浅灰色实线。
- 背景默认为白色。
- 未冻结状态背景偏灰。
- 内部有适当 padding。
- 多个 `GoalCard` 之间保持垂直间距。
- 目标摘要行高度约 `58px`，正文行高度约 `42px` 到 `50px`。
- 右侧进度统一使用短横向进度条 + 百分比。

#### MetricItem

盒模型要求：

- 不需要做成独立大卡片。
- 使用行结构或轻量块结构。
- 与其他指标之间用浅灰分割线或留白区分。
- 左侧与 `GoalCard` 内容区域对齐。
- 指标下的任务相对指标向右缩进。
- 指标行不显示大色块，完成状态使用圆形勾选 / 空心圆 / 进行中圆点。

#### TaskNode

盒模型要求：

- 任务行保持紧凑。
- 同级任务纵向排列。
- 每深入一层，左侧缩进增加。
- 使用浅灰色树形连接线表示父子关系。
- 任务行之间可以使用浅灰分割线或留白。
- 任务行左侧根据层级增加缩进，后续列保持纵向对齐。
- 任务行支持整行浅青色选中 / 完成底色。
