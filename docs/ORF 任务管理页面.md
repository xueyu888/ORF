# ORF 任务管理页面

## 1. 页面目标

ORF 任务管理页面用于在同一个工作区管理目标、指标、任务、子任务的执行关系，并支持团队视图、个人视图和 ORF 流程状态切换。

页面目标是让团队在 ORF 重估和目标冻结过程中，清楚看到每个目标的可验证进展、负责人、完成状态和任务推进情况。

## 2. 组件结构

### 2.1 组件树

```text
ORFTaskPage
├─ AppSidebar
└─ MainContent
   ├─ ProcessPanel
   │  └─ ProcessStep[]
   ├─ TeamDashboard
   │  └─ DashboardMetricCard[]
   ├─ ListToolbar
   │  ├─ OrfTabs
   │  ├─ CycleControl
   │  └─ FilterButton
   └─ GoalCard[]
      ├─ GoalInfoRow
      └─ MetricItem[]
         ├─ MetricInfoRow
         └─ TaskItem[]
            └─ SubtaskItem[]
```

### 2.2 组件职责

| 组件 | 职责 |
| --- | --- |
| `ORFTaskPage` | 页面容器 |
| `AppSidebar` | 全局侧边栏，支持宽侧栏和窄侧栏两种状态。 |
| `MainContent` | 页面主内容区域 |
| `ProcessPanel` | 顶部任务管理流程卡，横向展示 4 个步骤。 |
| `ProcessStep` | 单个流程步骤，支持已完成、进行中、待确认三种视觉状态。 |
| `OrfTabs` | 团队和个人标签页切换。 |
| `TeamDashboard` | 团队视图顶部仪表盘，仅团队标签页展示。 |
| `DashboardMetricCard` | 单个指标卡，左侧环形图标，右侧指标数值和说明。 |
| `ListToolbar` | 目标列表上方的工具条，左侧放团队 / 个人标签，右侧放周期和筛选控件。 |
| `CycleControl` | 周期控件，默认展示当前周期，点击后展示周期选项。 |
| `FilterButton` | 筛选入口，点击后展示筛选面板。 |
| `GoalCard` | 单个目标表格卡，目标不可折叠，内部承载目标摘要和指标。 |
| `GoalInfoRow` | 目标摘要行，展示目标标题、状态、头像、截止日期和进度。 |
| `MetricItem` | 单个指标块，代表一个指标，包含指标信息行和该指标下的任务。 |
| `MetricInfoRow` | 指标顶部信息行，展示指标标题、负责人、完成状态、更新时间和进度，并支持展开和折叠。 |
| `TaskItem` | 单个任务项，展示任务标题、执行人、状态、更新时间和进度，并支持展开和折叠。 |
| `SubtaskItem` | 单个子任务项，沿用任务项字段结构。 |

## 4. 状态规则

### 4.1 标签页状态

`tab` 取值：

| 取值 | 含义 |
| --- | --- |
| `team` | 团队 |
| `personal` | 个人 |

规则：

- 默认选中 `team`。
- `team` 展示 `TeamDashboard`。
- `personal` 不展示 `TeamDashboard`。

### 4.2 ORF 流程状态

`flowStatus` 取值和推进顺序：

| 顺序 | 取值 | 页面含义 |
| --- | --- | --- |
| 1 | `goal_setting` | 目标设定 |
| 2 | `metric_claiming` | 指标领取 |
| 3 | `orf_review` | ORF 重估 |
| 4 | `frozen` | 目标冻结，代表主管已确认 |

规则：

- 流程必须按顺序推进。
- 上一个状态完成后，才能进入下一个状态。
- `goal_setting`、`metric_claiming`、`orf_review` 完成并经主管确认后，进入下一步。
- `frozen` 是最终状态。
- 目标进入 `frozen` 时，表示目标冻结已经由主管确认完成。
- 顶部流程条必须展示 4 张步骤卡，步骤之间用右箭头连接。
- 当前步骤使用青绿色描边和浅青背景；已完成步骤使用青绿色圆形勾选；未开始步骤使用浅灰编号。

### 4.3 冻结状态

目标冻结前：

- `GoalCard` 整体背景偏灰。
- 表示目标仍处于未冻结状态。

目标冻结后：

- `GoalCard` 背景恢复白色。
- 表示主管已经确认目标冻结，目标进入硬验收状态。

核心原则：

> 允许早期识别不确定性，禁止后期拿不确定性当借口。

### 4.4 折叠状态

| 对象 | 是否可折叠 | 默认状态 |
| --- | --- | --- |
| 目标 | 不可折叠 | 固定展开 |
| 指标 | 可折叠 | 默认展开 |
| 任务 | 可折叠 | 默认展开 |
| 子任务 | 暂不强制 | TODO |

### 4.5 完成状态

完成状态统一显示在标题左侧。

建议图标：

| 状态 | 图标 |
| --- | --- |
| 已完成 | `check-circle` |
| 未完成 | `circle` |
| 展开 | `chevron-down` |
| 折叠 | `chevron-right` |

## 5. 交互规则

### 5.1 标签页切换

点击团队标签页：

- 显示团队目标列表。
- 显示 `TeamDashboard`。

点击个人标签页：

- 显示当前成员相关目标列表。
- 隐藏 `TeamDashboard`。

### 5.2 指标展开和折叠

点击指标左侧展开图标：

- 如果当前指标已展开，则收起该指标下的任务。
- 如果当前指标已收起，则展开该指标下的任务。

### 5.3 任务展开和折叠

点击任务左侧展开图标：

- 如果当前任务已展开，则收起该任务下的子任务。
- 如果当前任务已收起，则展开该任务下的子任务。

### 5.4 完成图标展示

| 对象 | 完成后展示 |
| --- | --- |
| 目标 | 目标标题左侧显示勾选图标。 |
| 指标 | 指标标题左侧显示勾选图标。 |
| 任务 | 任务标题左侧显示勾选图标。 |
| 子任务 | 子任务标题左侧显示勾选图标。 |

### 5.5 流程推进

流程推进由主管确认触发。

主管确认后：

- 当前状态标记为完成。
- 如果存在下一步，页面进入下一个流程状态。
- 当主管确认 `orf_review` 完成后，页面直接进入 `frozen`。
- `frozen` 本身就是确认后的最终状态。

## 6. 权限规则

主管拥有全部界面的全部权限。

成员权限：

| 流程状态 | 成员权限 |
| --- | --- |
| 目标设定 | 查看 |
| 指标领取 | 查看 |
| ORF 重估 | 查看、编辑 |
| 目标冻结 | 查看 |

补充规则：

- 只有主管可以确认流程状态完成。
- 只有主管可以推动流程进入下一个状态。
- 成员只有在 ORF 重估阶段可以编辑。

| 次级文字和分组标题 | 浅青灰，接近 `#b7d8d8` |

侧边栏布局：

- 宽侧栏宽度约 `280px`。
- 窄图标侧栏宽度约 `88px`。
- 顶部是品牌区：左侧深色小方形 logo + 产品名，右侧设置图标。
- 品牌区下面是工作区 / 组织入口。
- 工作区 / 组织入口高度高于普通菜单项，使用较亮青绿色背景。
- 菜单按分组展示。
- 分组标题使用全大写小字和较大字距，例如 `WORK`、`REPORTS`、`ORG`。
- 菜单项为整行点击区域。
- 菜单项左侧显示图标，右侧显示文字。
- 图标颜色比正文更亮。
- 当前选中菜单项使用深色块高亮。
- 当前选中菜单项左侧不需要额外竖线。
- 菜单项和分组之间使用 `1px` 分割线。
- 不使用卡片阴影。
- 窄侧栏模式只保留居中的图标按钮。

### 7.3 盒模型

#### AppSidebar

宽侧栏：

- 宽度约 `280px`。
- 左侧固定显示。
- 高度占满页面。

窄侧栏：

- 宽度约 `88px`。
- 只保留居中的图标按钮。
- 背景和高亮色沿用同一套青绿色规范。

侧边栏内部顺序：

1. 顶部品牌区
2. 工作区 / 组织入口
3. 菜单分组
4. 菜单项

#### GoalCard

盒模型要求：

- 使用圆角卡片。
- 边框为 `1px` 浅灰色实线。
- 背景默认为白色。
- 未冻结状态背景偏灰。
- 内部有适当 padding。
- 多个 `GoalCard` 之间保持垂直间距。
- 目标摘要行高度约 `58px`，正文行高度约 `42px` 到 `50px`。
- 右侧进度统一使用短横向进度条 + 百分比。

#### MetricItem

盒模型要求：

- 不需要做成独立大卡片。
- 使用行结构或轻量块结构。
- 与其他指标之间用浅灰分割线或留白区分。
- 左侧与 `GoalCard` 内容区域对齐。
- 指标下的任务相对指标向右缩进。
- 指标行不显示大色块，完成状态使用圆形勾选 / 空心圆 / 进行中圆点。

#### TaskItem / SubtaskItem

盒模型要求：

- 任务行保持紧凑。
- 同级任务纵向排列。
- 每深入一层，左侧缩进增加。
- 使用浅灰色树形连接线表示父子关系。
- 任务行之间可以使用浅灰分割线或留白。
- 任务行左侧根据层级增加缩进，后续列保持纵向对齐。
- 任务行支持整行浅青色选中 / 完成底色。
