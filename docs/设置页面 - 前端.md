# 设置页面 - 前端

本文只定义前端实现契约。设置业务边界以 [设置边界规则.md](./rules/设置边界规则.md) 为唯一事实源。

## 1. 目标路由

| 页面 | 路由 | 入口 | 可见范围 | 职责 |
|---|---|---|---|---|
| 个人设置 | `/settings` | 侧边栏用户区齿轮入口 | 所有 `active` 用户 | 当前用户偏好和账号信息展示。 |
| 系统设置 | `/settings/system` | 侧边栏管理区入口 | `admin` | 全站默认视觉、登录页背景、系统背景资源和策略。 |

当前实现：`/settings` 已承载个人设置，`/settings/system` 已承载系统视觉设置；旧的单一 `settings` 语义不再作为新入口使用。

## 2. 显隐契约

| 显隐点 | 目标 key | 可见范围 | 路由 |
|---|---|---|---|
| 个人设置入口 | `nav.personalSettings` | `all` | `/settings` |
| 个人设置页面访问 | `page.personalSettings` | `all` | `/settings` |
| 系统设置入口 | `nav.systemSettings` | `admin` | `/settings/system` |
| 系统设置页面访问 | `page.systemSettings` | `admin` | `/settings/system` |

实现要求：

- 组件只能通过 `canShowFrontend()` 和 `canShowFrontendPath()` 判断入口和页面显隐。
- 不能用同一个 `settings` key 同时表达个人设置和系统设置。
- 前端隐藏系统设置入口只是体验优化，后端仍必须拒绝非管理员系统写入。

## 3. 个人设置页面契约

个人设置只读写当前用户事实源。

必须包含：

| 设置项 | 前端行为 |
|---|---|
| 账号信息 | 展示姓名、邮箱、角色、状态；当前不提供自助改名。 |
| 默认进入页面 | 只能选择当前用户可访问的登录后页面。 |
| 侧边栏偏好 | 保存当前用户自己的展开、折叠或密度偏好。 |
| 通知展示偏好 | 保存当前用户自己的通知展示方式。 |
| 登录后应用背景 | 后续接入个人偏好；当前 AppShell 使用系统默认应用背景。 |
| 个人背景上传 | 后续在系统策略允许时展示；上传只写入当前用户资源。 |

禁止包含：

- 登录页背景配置。
- 系统默认应用背景配置。
- 系统背景资源上传、删除、启用、禁用。
- 成员、角色、权限或全局策略写入。

个人背景展示和回退规则不在本文重复定义，必须引用设置边界规则中的唯一解析规则。

## 4. 系统设置页面契约

系统设置只读写系统事实源。

当前应承接现有视觉设置能力：

| 设置项 | 前端行为 |
|---|---|
| 登录页背景 | 管理 `login_background`，只允许管理员写入。 |
| 系统默认应用背景 | 管理登录后默认背景；前端使用规范场景 `app_background`。 |
| 系统背景资源 | 管理系统背景上传、默认选择和配置。 |
| 个人背景策略 | 管理是否允许个人上传、大小限制、数量限制等策略。 |

禁止包含：

- 当前用户个人偏好。
- 当前用户个人背景上传入口。
- 把管理员个人偏好保存为系统默认。

## 5. 前端状态归属

| 状态 | 归属 | 说明 |
|---|---|---|
| `personalPreferences` | 当前用户 | 默认页面、侧边栏、通知和个人背景偏好。 |
| `personalBackgroundList` | 当前用户 | 当前用户上传的个人背景。 |
| `systemAppBackgroundList` | 系统只读资源 | 已登录用户可选择的系统应用背景。 |
| `systemVisualSettings` | 系统配置 | 登录页背景、系统默认应用背景和系统背景策略。 |
| 页面选中态、loading、错误提示 | 当前页面临时状态 | 不作为业务事实源。 |

状态不变量：

- 个人设置保存成功只能更新当前用户偏好。
- 系统设置保存成功只能更新系统配置。
- 打开时切换、定时切换的运行时位置不写入系统配置或个人偏好。

## 6. 当前落地状态

1. `SettingsPage` 是系统设置页，路由为 `/settings/system`。
2. `PersonalSettingsPage` 是个人设置页，路由为 `/settings`。
3. 显隐 key 已拆成 `personalSettings` 和 `systemSettings`。
4. 登录后背景已使用规范场景 `app_background`；后端仍兼容读取旧 `sidebar_background` 资源。
5. 后续个人偏好数据流必须继续按本文和设置边界规则接入，不能复用系统设置写接口。
