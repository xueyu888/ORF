# 设置页面 - 前端

本文只定义前端实现契约。设置业务边界以 [设置边界规则.md](./rules/设置边界规则.md) 为唯一事实源。

设置页的视觉层级、主题、控件几何、背景消费和响应式验收统一遵守 [ORF 前端视觉系统.md](./design/ORF%20前端视觉系统.md)。

## 1. 目标路由

| 页面 | 路由 | 入口 | 可见范围 | 职责 |
|---|---|---|---|---|
| 个人设置 | `/settings` | 侧边栏用户头像菜单 | 所有 `active` 用户 | 当前用户偏好和账号信息展示。 |
| 系统设置 | `/system/settings` | 系统管理页内子页面 | `admin` | 全站默认视觉、登录页背景、系统背景资源、聊天/反馈附件设置和策略。 |

当前实现：`/settings` 承载个人设置；系统级能力统一进入 `/system`，再由 `/system/members`、`/system/permissions`、`/system/settings` 分别承载成员、权限和系统设置。

## 2. 显隐契约

| 显隐点 | 目标 key | 可见范围 | 路由 |
|---|---|---|---|
| 个人设置入口 | `nav.personalSettings` | `all` | `/settings` |
| 个人设置页面访问 | `page.personalSettings` | `all` | `/settings` |
| 系统管理入口 | `nav.systemManagement` | `admin` | `/system` |
| 系统管理页面访问 | `page.systemManagement` | `admin` | `/system` |
| 系统成员页面访问 | `page.systemMembers` | `admin` | `/system/members` |
| 系统权限页面访问 | `page.systemPermissions` | `admin` | `/system/permissions` |
| 系统设置页面访问 | `page.systemSettings` | `admin` | `/system/settings` |

实现要求：

- 组件只能通过 `canShowFrontend()` 和 `canShowFrontendPath()` 判断入口和页面显隐。
- 不能用同一个 `settings` key 同时表达个人设置和系统设置。
- 前端隐藏系统管理入口只是体验优化，后端仍必须拒绝非管理员系统写入。

## 3. 个人设置页面契约

个人设置只读写当前用户事实源。少数本机客户端能力可以在个人设置页展示，但只能读写本机系统事实源，不进入个人设置接口、系统设置接口或服务端业务数据。

必须包含：

| 设置项 | 前端行为 |
|---|---|
| 账号信息 | 展示姓名、邮箱、角色、状态；当前不提供自助改名。 |
| 默认进入页面 | 只能选择当前用户可访问的登录后页面。 |
| 侧边栏偏好 | 保存当前用户自己的展开、折叠和桌面展开宽度；拖拽宽度由 AppShell 写入同一份个人偏好，不建立本地第二事实源。 |
| 通知展示偏好 | 保存当前用户自己的通知展示方式。 |
| 全局外观 | 复用已有 `personalPreferences.chatTheme` 兼容字段保存亮色/暗色，由 AppShell 统一投射到顶部栏、侧边栏、聊天和全部页面；本轮不新增后端字段，高对比度继续作为正交显示偏好。 |
| 界面显示 | 保存当前用户自己的工作台缩放、界面字号、内容字号、界面密度和高对比度偏好。 |
| 工作区布局 | 仅保留当前用户个人偏好兼容字段；当前前端不提供独立设置表单，AppShell 也不再用它恢复聊天目标/行动项工作区。 |
| Win11 开机自启 | 可在个人设置页展示；只有已安装 Win11 客户端可操作。读写 Windows 登录项，首次提示是否看过只保存在 Electron 本机 `userData`。 |
| 个人头像 | 上传、替换、删除或查看当前用户自己的头像原图；未上传或图片加载失败时继续使用姓名首字母占位。 |
| 个人皮肤工作台 | 管理当前用户的登录页、顶部栏、侧边栏和全部页面内容区皮肤；聊天、资源和个人设置分别使用独立页面槽位。每个槽位可选择系统图或本人上传图，并通过整图取景框独立保存取景中心、背景放大和蒙层强度。编辑器中固定取景框代表最终槽位，图片层只能按原图比例等比缩放和平移；`zoom=100%` 表示 cover 后刚好铺满，不能露底，不能拉伸变形，也不能保留第二套预览坐标。 |
| 个人背景上传 | 按当前槽位上传，只写入当前用户资源，不进入系统背景资源库。 |
| 社区背景分享 | 个人图片上传完成后提供一次明确的可选分享确认，用户也可以稍后从个人图片执行分享或撤回。分享创建独立社区副本；撤回只隐藏社区入口，界面不得暗示会删除个人原图或已被使用的社区文件。 |

禁止包含：

- 系统默认皮肤配置。
- 全站默认字号、缩放、密度或高对比度配置。
- 系统背景资源上传、删除、启用、禁用。
- 成员、角色、权限或全局策略写入。

个人背景展示和回退规则不在本文重复定义，必须引用设置边界规则中的唯一解析规则。

侧边栏用户区规则：

- 全局搜索入口统一放在 AppShell 顶部栏，侧边栏用户区不承载搜索入口。
- 用户头像和用户名区域打开用户菜单。
- 用户菜单包含 `个人设置` 和 `退出登录`；当前用户有头像时包含 `查看头像`。
- 侧边栏头像菜单只负责入口聚合，不写入用户头像事实源或个人偏好。

## 4. 系统设置页面契约

系统设置只读写系统事实源。

当前应承接现有视觉设置能力：

| 设置项 | 前端行为 |
|---|---|
| 系统皮肤工作台 | 管理 `login_background`、`topbar_background`、`sidebar_background` 和全部 `page_*_background` 的系统默认图、切换模式、摆放参数和蒙层强度；聊天、资源和个人设置均提供独立且生效的页面皮肤槽位。编辑预览以整张图片为画布，固定取景框代表最终槽位，取景框比例来自运行态槽位尺寸，图片层按原图比例等比缩放和平移，不能保留第二套预览坐标模型；顶部栏这类超宽槽位在编辑器中允许取景框横向溢出预览面板，但裁剪数学仍以真实槽位比例为准。页面槽位保存时可选择当前页面、全部页面或部分页面作为本次写入目标。登录页、顶部栏、侧边栏和页面内容区的运行态渲染必须走同一个固定 frame 背景槽位组件。 |
| 系统背景资源 | 图库按系统作用域共享展示，登录页、顶部栏、侧边栏和页面内容区都能选择同一张系统图片；上传入口记录来源槽位用于资源归档。 |
| 个人背景策略 | 管理是否允许个人上传、大小限制、数量限制等策略。 |
| 聊天附件上限 | 管理聊天允许上传的最大附件大小；不能超过基础设施承载上限。 |
| 反馈附件总上限 | 管理单条反馈原始报告全部附件的总大小；默认 2GiB，不能超过基础设施承载上限。 |

禁止包含：

- 当前用户个人偏好。
- 当前用户个人背景上传入口。
- 把管理员个人偏好保存为系统默认。

## 5. 前端状态归属

| 状态 | 归属 | 说明 |
|---|---|---|
| `personalPreferences` | 当前用户 | 全局外观、默认页面、侧边栏、通知、个人显示、个人皮肤和页面视图筛选偏好。 |
| `personalPreferences.chatTheme` | 当前用户 | 现有兼容字段，只允许 `light`、`dark`；AppShell 在前端将其投射为全局语义颜色 token，不改变服务端接口。认证前读取最近一次服务端确认的本机缓存，缓存缺失时为亮色；识别用户后优先使用按 `userId` 隔离的最后确认值并由服务端校准。 |
| `personalPreferences.display` | 当前用户 | 工作台缩放、界面字号、内容字号、界面密度和高对比度；AppShell 统一投射为 CSS token，桌面端工作台缩放通过 Electron 窗口缩放派生。 |
| `personalPreferences.filterPreferences` | 当前用户 | 长期页面筛选偏好，按页面视图 key 保存当前用户主动选择的筛选槽位；只保存筛选值，不保存业务对象、权限结果、URL 深链、当前选中行、菜单开关、搜索浮层或 loading 状态。页面进入时可用它恢复默认工作视图；URL 查询参数、哈希直达目标或一次性创建入口优先级更高，不能被记忆筛选挡住。 |
| `personalPreferences.workspaceLayout` | 当前用户 | 兼容旧可分离工作区布局偏好；当前前端不读取或写入，不保存业务对象、筛选条件或定位高亮。 |
| `personalPreferences.backgrounds[scene]` | 当前用户 | 当前用户某个皮肤槽位的图片选择、切换模式、`crops[imageId]` 取景参数和 `material` 材质偏好；取景参数为 `centerX`、`centerY`、`zoom`，`zoom` 范围为 `1..3`。材质偏好保存 `tone`、`exposure`、`overlayStrength`、`blurStrength`、`reduceTransparency`；两个强度字段都允许为 `0`，只缩放统一策略派生出的遮罩和模糊，不保存页面固定值。页面“应用页面”只决定一次保存写入哪些 `page_*_background`，不另存隐藏分组规则；聊天、资源和个人设置各自写入独立页面槽位。 |
| `localLoginBackgroundPreview` | 本机浏览器/客户端 | 当前用户保存个人登录页皮肤时生成的压缩预览；只用于登出页展示，不是服务端个人背景读取权限。 |
| Win11 开机自启 | Windows 登录项 | 由 Electron 主进程通过系统登录项接口读写；个人设置页和托盘菜单只通过桌面 IPC 触发，不写入服务端。 |
| 开机自启首次提示已处理 | Electron 本机 `userData` | 只控制是否再次弹出首次提示；不是业务偏好，也不代表 Windows 登录项当前状态。 |
| Windows 启动底色主题缓存 | Electron 本机 `userData` | 保存最近一次 `light` / `dark` 外观，只用于 BrowserWindow 创建和页面加载前底色，避免深色模式启动白闪；登录后的服务端个人偏好仍是外观事实源。 |
| `currentUser.avatarUrl` | 当前用户投影 | 由用户头像事实源派生，只用于展示，不保存到个人偏好。 |
| `personalBackgroundList[scene]` | 当前用户 | 当前用户在任一规范槽位上传的个人背景共享到当前用户自己的其它槽位；其他用户不可读写。 |
| `systemBackgroundList[scene]` | 系统只读资源 | 已登录用户可选择共享系统图库中的槽位皮肤；登录页系统背景可公开读取。 |
| `communityBackgroundList` | 当前 ORF 作用域 | 已登录用户可选择仍公开的社区副本；作者信息默认不返回。已撤回副本仅在当前用户已有槽位引用时继续出现在该用户的数据中。 |
| `communityBackgroundShare` | 当前 ORF 作用域的社区素材记录 | 保存社区副本、原个人图片引用、作者、创建时间和撤回时间；前端只消费匿名化的可选图片及当前用户自己的分享操作能力。 |
| `systemVisualSettings` | 系统配置 | 登录页、顶部栏、侧边栏、页面级皮肤和系统背景策略。 |
| `chatSettings` | 系统配置 | 聊天附件业务上限；聊天输入框只用它做上传前提示，后端仍做最终校验。 |
| `feedbackSettings` | 系统配置 | 单条反馈原始报告的附件总上限；新建反馈页只用于上传前提示，后端按同一设置对全部文件做最终聚合校验。 |
| 页面选中态、菜单开关、原图预览、上传中、图片加载失败、loading、错误提示 | 当前页面临时状态 | 不作为业务事实源。 |

状态不变量：

- 个人设置保存成功只能更新当前用户偏好。
- 全局外观保存成功只能更新既有 `personalPreferences.chatTheme` 兼容字段；页面、聊天、顶部栏和侧边栏只能消费其前端派生 token，不能另存亮暗主题，也不能要求新增服务端字段。
- 本机外观缓存只允许在个人偏好读取或保存成功后更新；加载态、请求失败、认证切换和内置默认值都不能写成用户已确认偏好。个人偏好读取使用 `no-store` 请求并对瞬时失败做有限重试，失败期间继续显示该用户最后确认值，不得把亮色默认值渲染成已选项。
- 界面显示保存成功只能更新 `personalPreferences.display`，不能写入系统设置或页面局部缓存。
- 页面筛选保存成功只能更新 `personalPreferences.filterPreferences[viewKey]`；筛选结果始终由业务数据、URL 当前视图状态和当前筛选偏好派生，不能把筛选后的列表、业务状态、权限结果或 URL 深链写入个人偏好。
- 兼容旧工作区布局写入时只能更新 `personalPreferences.workspaceLayout`，不能写入任务管理事实或系统设置；当前前端不主动写入该字段。
- Win11 开机自启保存成功只能更新 Windows 登录项，不能更新 `personalPreferences`、系统设置或后端业务数据。
- 个人头像保存成功只能更新当前用户头像事实和用户投影，不能写入个人偏好或系统设置。
- 个人皮肤保存成功只能更新 `personalPreferences.backgrounds[scene]`；登录页本机缓存只是展示缓存，不反向定义服务端事实。
- 个人图片上传和本机缓存不能自动分享；上传后的分享确认和稍后的分享按钮都必须由用户主动确认后才调用社区分享接口。
- 社区分享成功只创建或恢复独立社区副本，不把个人资源改成系统资源；撤回成功只让社区副本退出公共可选列表，当前用户个人图片和其他用户已有引用均保持不变。
- 登录后的顶部栏、侧边栏和页面背景使用统一持久缓存模块：以 `userId + scene + imageId` 隔离缓存已选图片，渲染快照同时以 `userId + scene` 标识，先用本机副本完成首帧，再由个人背景接口校准图片、取景和材质。服务端返回空配置时清除旧副本；缓存不可用时静默回退网络，不改变服务端配置、资源所有权或分享状态。
- 个人或系统背景保存、恢复默认和删除成功后统一失效该用户对应场景的前端快照与本机图片副本，再广播场景变更；因此当前场景和稍后才进入的场景都以新配置加载，不允许继续命中五分钟读缓存里的旧背景。
- 前端只读取和写入 `personalPreferences.backgrounds[scene]`，背景配置只消费完整 v4 的 `material + crops`；本机预览缓存不满足当前形状时按派生缓存失效处理，由服务端配置重建。
- 系统设置保存成功只能更新系统配置。
- 打开时切换、定时切换的运行时位置不写入系统配置或个人偏好。

## 6. 当前落地状态

1. `SettingsPage` 是系统管理内的系统设置页，路由为 `/system/settings`。
2. `PersonalSettingsPage` 是个人设置页，路由为 `/settings`。
3. 显隐 key 已拆成 `personalSettings`、`systemManagement` 和系统管理子页面 key。
4. 视觉皮肤已拆成登录页、顶部栏、侧边栏和全部页面级内容区槽位；聊天、资源和个人设置各有独立背景，规范槽位图片进入共享图库。
5. 个人默认进入页面、侧边栏默认状态、Toast 通知偏好、个人显示偏好和个人皮肤选择已走个人设置接口，不能复用系统设置写接口。
6. 个人头像入口在个人设置页账号信息区；上传、删除和原图预览只作用于当前登录用户，展示层统一使用用户头像组件并回退到首字母占位。
7. Win11 开机自启入口在个人设置页客户端能力区展示，并和托盘菜单共用 Electron 主进程登录项读写能力。
8. 侧边栏用户区通过头像菜单承载个人设置、退出登录和查看头像；全局搜索入口统一在顶部栏展示。
9. 界面显示区块读取和写入 `/api/settings/personal/preferences` 的 `display` 字段；设置页只收集输入，AppShell 统一应用派生 token。
10. 页面筛选偏好读取和写入 `/api/settings/personal/preferences` 的 `filterPreferences` 字段；每个页面只写自己的 `viewKey`，不能覆盖其它页面视图偏好。当前已接入 `challenge.plan` 和 `feedback.issueList`，旧本地筛选记忆只允许作为一次性迁移输入。
11. `/api/settings/personal/preferences` 仍兼容 `workspaceLayout` 字段，但 AppShell 当前不读取或写入它，也不恢复聊天目标/行动项工作区布局。
12. 聊天设置区块读取 `/api/settings/chat`，写入 `chat.attachmentMaxBytes`；页面展示基础设施承载上限，但不把 MinIO 或 Nginx 设置当作聊天业务规则。
13. 反馈设置区块读取 `/api/settings/feedback`，管理员写入 `feedback.attachmentMaxBytes`；新建反馈页读取同一接口展示并预校验附件总大小，服务端仍是最终事实源。
14. 全局外观继续读取和写入 `/api/settings/personal/preferences` 的既有 `chatTheme` 字段；AppShell 只在前端把它投射为全局外观。本机保留通用最后确认值和按用户隔离的最后确认值，用于认证前首帧及登录后请求恢复，服务端成功响应始终校准缓存。页面背景继续写入既有 `backgrounds[scene]` 映射，只新增聊天、资源和个人设置三个场景枚举，不新增偏好字段。
15. 个人背景工作台通过确认框显式创建社区副本，并允许作者撤回；社区图、系统图和个人图继续共用同一图库与槽位配置模型，不建立页面私有分享状态。
