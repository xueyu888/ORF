设置页
├── 设置导航栏
│   ├── 视觉设置入口
│   ├── 周期与团队入口
│   ├── 反馈分类入口
│   ├── ORF 规则入口
│   └── 存储入口
└── 设置详情栏

**设置入口**：设置导航栏中的一个个按钮
**设置详情**：设置详情栏中的每个区域，称作一个设置详情

> 当前只实现“视觉设置”。“周期与团队”“反馈分类”“ORF 规则”“存储”暂时只作为导航占位，不展开具体内容。

### 前端页面素材

设置页组件美工参考素材统一放在仓库根目录 `frontend-assets/` 下，本地保存，不提交 git。

`frontend-assets/` 只用于前端页面和组件的视觉参考，不作为登录页背景或侧边栏背景资源，不参与后端背景列表扫描。

### 登录页面背景设置

#### 布局

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 登录页面背景设置                                                      │
│ 自定义登录页面的背景。                                                 │
│                                                                      │
│ 背景上传     [上传图片]                                                │
│ 背景预览     ┌────────────────────────────────────────────────────┐  │
│             │  图片1  图片2  图片3  图片4  图片5  ...              │  │
│             │  横向滚动条                                         │  │
│             └────────────────────────────────────────────────────┘  │
│             [设为默认]                                                │
└──────────────────────────────────────────────────────────────────────┘
```

#### 触发源

| 触发源     | 所属区域   | 触发方式    | 触发事件                  | 是否触发接口 | 说明                |
| ------- | ------ | ------- | --------------------- | ------ | ----------------- |
| 页面初始化   | 页面整体   | 进入页面    | `onPageInit`          | 是      | 获取背景图片列表及当前默认背景图  |
| 上传图片按钮  | 背景上传区域 | 鼠标左键点击  | `onUploadButtonClick` | 否      | 唤起系统文件选择器         |
| 系统文件选择器 | 系统弹窗   | 选择图片并确认 | `onFileSelected`      | 是      | 校验文件类型后调用上传接口     |
| 系统文件选择器 | 系统弹窗   | 取消选择    | `onFileSelectCancel`  | 否      | 不改变页面状态           |
| 背景图片项   | 背景预览区域 | 鼠标左键单击  | `onBackgroundSelect`  | 否      | 设置当前选中的背景图片       |
| 设为默认按钮  | 背景预览区域 | 鼠标左键点击  | `onSetDefaultClick`   | 是      | 将当前选中的图片设置为默认背景   |
| 上传接口    | 系统响应   | 上传成功    | `onUploadSuccess`     | 否      | 新图片进入背景预览列表       |
| 上传接口    | 系统响应   | 上传失败    | `onUploadError`       | 否      | 展示上传失败提示          |
| 设置默认接口  | 系统响应   | 设置成功    | `onSetDefaultSuccess` | 否      | 更新默认背景标记          |
| 设置默认接口  | 系统响应   | 设置失败    | `onSetDefaultError`   | 否      | 保持原默认背景不变，并展示错误提示 |

#### 事件表

| 事件名                   | 触发来源       | 前置条件            | 主要动作                | 影响状态                                                     | 是否触发接口 |
| --------------------- | ---------- | --------------- | ------------------- | -------------------------------------------------------- | ------ |
| `onPageInit`          | 页面初始化      | 用户进入登录页面背景设置区域  | 请求背景图片列表和默认背景配置     | `backgroundList`、`defaultBackgroundId`、`listQueryStatus` | 是      |
| `onUploadButtonClick` | 上传图片按钮     | 页面未处于上传中状态      | 打开系统文件选择器，仅允许选择图片文件 | 无，或仅触发文件选择器                                              | 否      |
| `onFileSelected`      | 系统文件选择器    | 用户已选择图片文件       | 校验文件类型，调用上传接口       | `uploadStatus`、`uploadErrorMessage`                      | 是      |
| `onFileSelectCancel`  | 系统文件选择器    | 用户取消文件选择        | 不执行上传操作             | 无                                                        | 否      |
| `onUploadSuccess`     | 上传接口成功响应   | 上传接口返回成功        | 将新图片追加到背景预览列表       | `backgroundList`、`uploadStatus`                          | 否      |
| `onUploadError`       | 上传接口失败响应   | 上传接口返回失败或网络异常   | 记录错误信息              | `uploadStatus`、`uploadErrorMessage`                      | 否      |
| `onBackgroundSelect`  | 背景图片项      | 图片存在于背景列表中      | 设置当前选中图片            | `selectedBackgroundId`                                   | 否      |
| `onSetDefaultClick`   | 设为默认按钮     | 已选中图片，且当前未设置默认中 | 调用设置默认接口            | `setDefaultStatus`、`setDefaultErrorMessage`              | 是      |
| `onSetDefaultSuccess` | 设置默认接口成功响应 | 设置默认接口返回成功      | 更新默认背景 ID           | `defaultBackgroundId`、`setDefaultStatus`                 | 否      |
| `onSetDefaultError`   | 设置默认接口失败响应 | 设置默认接口返回失败或网络异常 | 记录错误信息，保持原默认背景不变    | `setDefaultStatus`、`setDefaultErrorMessage`              | 否      |

#### 状态变化表

##### 页面初始化流程

| 阶段          | 事件                  | 状态变化                                                                                                           | UI 表现                  |
| ----------- | ------------------- | -------------------------------------------------------------------------------------------------------------- | ---------------------- |
| 页面进入        | `onPageInit`        | `listQueryStatus = 'loading'`                                                                                  | 背景预览区域展示加载态            |
| 获取列表成功，列表非空 | `onPageInitSuccess` | `backgroundList = 接口返回图片列表`；`defaultBackgroundId = 接口返回默认图片 ID`；`listQueryStatus = 'success'`                  | 展示背景图片列表；默认图片展示“默认”标记  |
| 获取列表成功，列表为空 | `onPageInitSuccess` | `backgroundList = []`；`defaultBackgroundId = null`；`selectedBackgroundId = null`；`listQueryStatus = 'success'` | 展示空状态文案：`暂无背景图片，请先上传。` |
| 获取列表失败      | `onPageInitError`   | `listQueryStatus = 'error'`；`listQueryErrorMessage = 错误信息`                                                     | 展示加载失败提示，可选展示重试入口      |
##### 上传图片流程

| 阶段     | 事件                    | 前置条件                           | 状态变化                                                        | UI 表现               |
| ------ | --------------------- | ------------------------------ | ----------------------------------------------------------- | ------------------- |
| 点击上传按钮 | `onUploadButtonClick` | `uploadStatus !== 'uploading'` | 无业务状态变化                                                     | 唤起系统文件选择器           |
| 取消文件选择 | `onFileSelectCancel`  | 用户未选择文件                        | 无状态变化                                                       | 页面保持不变              |
| 确认选择图片 | `onFileSelected`      | 文件类型为图片                        | `uploadStatus = 'uploading'`；`uploadErrorMessage = null`    | 上传按钮可展示 loading 或禁用 |
| 上传成功   | `onUploadSuccess`     | 接口返回新图片信息                      | `backgroundList` 追加新图片；`uploadStatus = 'success'`           | 新图片立即出现在背景预览列表中     |
| 上传失败   | `onUploadError`       | 接口失败或网络异常                      | `uploadStatus = 'error'`；`uploadErrorMessage = 错误信息`        | 展示上传失败提示；原图片列表保持不变  |
| 文件类型非法 | `onFileValidateError` | 文件不是图片类型                       | `uploadStatus = 'error'`；`uploadErrorMessage = '仅支持上传图片文件'` | 展示文件类型错误提示          |

##### 选择背景图片流程

| 阶段      | 事件                   | 前置条件                            | 状态变化                               | UI 表现             |
| ------- | -------------------- | ------------------------------- | ---------------------------------- | ----------------- |
| 点击图片    | `onBackgroundSelect` | `backgroundList` 中存在该图片         | `selectedBackgroundId = 当前图片 ID`   | 当前图片展示选中态         |
| 点击另一张图片 | `onBackgroundSelect` | 已存在选中图片                         | `selectedBackgroundId` 更新为新图片 ID   | 原图片取消选中态，新图片展示选中态 |
| 图片列表为空  | -                    | `backgroundList.length === 0`   | `selectedBackgroundId = null`      | 不展示图片项，展示空状态      |
| 选中非默认图片后 | 状态推导 | `selectedBackgroundId !== null && selectedBackgroundId !== defaultBackgroundId` | `isSetDefaultButtonDisabled = false` | “设为默认”按钮变为可点击 |
| 选中当前默认图片 | 状态推导 | `selectedBackgroundId === defaultBackgroundId` | `isSetDefaultButtonDisabled = true` | “设为默认”按钮不可点击 |

##### 设置默认背景流程

| 阶段     | 事件                    | 前置条件          | 状态变化                                                                                  | UI 表现                       |
| ------ | --------------------- | ------------- | ------------------------------------------------------------------------------------- | --------------------------- |
| 初始状态   | -                     | 未选中图片         | `selectedBackgroundId = null`                                                         | “设为默认”按钮不可点击                |
| 选中非默认图片 | `onBackgroundSelect` | 用户点击非默认图片 | `selectedBackgroundId = 图片 ID` | “设为默认”按钮可点击 |
| 选中当前默认图片 | `onBackgroundSelect` | 用户点击当前默认图片 | `selectedBackgroundId = 图片 ID` | “设为默认”按钮不可点击 |
| 点击设为默认 | `onSetDefaultClick` | 已选中非默认图片，且未处于设置中 | `setDefaultStatus = 'setting'`；`setDefaultErrorMessage = null` | “设为默认”按钮 loading 或禁用，防止重复点击 |
| 设置成功   | `onSetDefaultSuccess` | 接口返回成功        | `defaultBackgroundId = selectedBackgroundId`；`setDefaultStatus = 'success'`           | 新默认图片展示“默认”标记，旧默认图片取消“默认”标记 |
| 设置失败   | `onSetDefaultError`   | 接口失败或网络异常     | `setDefaultStatus = 'error'`；`setDefaultErrorMessage = 错误信息`；`defaultBackgroundId` 不变 | 默认标记不变，展示设置失败提示             |

| 事件名 | 触发来源 | 前置条件 | 主要动作 | 影响状态 | 是否触发接口 |
|---|---|---|---|---|---|
| `onSidebarBackgroundInit` | 页面初始化 | 用户进入侧边栏背景设置区域 | 请求侧边栏背景图片列表和默认背景配置 | `sidebarBackgroundList`、`defaultSidebarBackgroundId`、`sidebarBackgroundListQueryStatus` | 是 |
| `onSidebarBackgroundUploadButtonClick` | 上传图片按钮 | 页面未处于上传中状态 | 打开系统文件选择器，仅允许选择图片文件 | 无，或仅触发文件选择器 | 否 |
| `onSidebarBackgroundFileSelected` | 系统文件选择器 | 用户已选择图片文件 | 校验文件类型，调用上传接口 | `sidebarBackgroundUploadStatus`、`sidebarBackgroundUploadErrorMessage` | 是 |
| `onSidebarBackgroundFileSelectCancel` | 系统文件选择器 | 用户取消文件选择 | 不执行上传操作 | 无 | 否 |
| `onSidebarBackgroundUploadSuccess` | 上传接口成功响应 | 上传接口返回成功 | 将新图片追加到侧边栏背景预览列表 | `sidebarBackgroundList`、`sidebarBackgroundUploadStatus` | 否 |
| `onSidebarBackgroundUploadError` | 上传接口失败响应 | 上传接口返回失败或网络异常 | 记录错误信息 | `sidebarBackgroundUploadStatus`、`sidebarBackgroundUploadErrorMessage` | 否 |
| `onSidebarBackgroundFileValidateError` | 文件校验 | 用户选择的文件不是图片类型 | 阻止上传，记录错误信息 | `sidebarBackgroundUploadStatus`、`sidebarBackgroundUploadErrorMessage` | 否 |
| `onSidebarBackgroundSelect` | 背景图片项 | 图片存在于侧边栏背景列表中 | 设置当前选中图片 | `selectedSidebarBackgroundId` | 否 |
| `onSidebarBackgroundSetDefaultClick` | 设为默认按钮 | 已选中图片，且当前未处于设置默认中 | 调用设置默认接口 | `sidebarBackgroundSetDefaultStatus`、`sidebarBackgroundSetDefaultErrorMessage` | 是 |
| `onSidebarBackgroundSetDefaultSuccess` | 设置默认接口成功响应 | 设置默认接口返回成功 | 更新默认侧边栏背景 ID | `defaultSidebarBackgroundId`、`sidebarBackgroundSetDefaultStatus` | 否 |
| `onSidebarBackgroundSetDefaultError` | 设置默认接口失败响应 | 设置默认接口返回失败或网络异常 | 记录错误信息，保持原默认背景不变 | `sidebarBackgroundSetDefaultStatus`、`sidebarBackgroundSetDefaultErrorMessage` | 否 |


#### 状态变化表

##### 页面初始化流程

| 阶段 | 事件 | 状态变化 | UI 表现 |
|---|---|---|---|
| 页面进入 | `onSidebarBackgroundInit` | `sidebarBackgroundListQueryStatus = 'loading'` | 侧边栏背景预览区域展示加载态 |
| 获取列表成功，列表非空 | `onSidebarBackgroundInitSuccess` | `sidebarBackgroundList = 接口返回图片列表`；`defaultSidebarBackgroundId = 接口返回默认图片 ID`；`sidebarBackgroundListQueryStatus = 'success'` | 展示侧边栏背景图片列表；默认图片展示“默认”标记 |
| 获取列表成功，列表为空 | `onSidebarBackgroundInitSuccess` | `sidebarBackgroundList = []`；`defaultSidebarBackgroundId = null`；`selectedSidebarBackgroundId = null`；`sidebarBackgroundListQueryStatus = 'success'` | 展示空状态文案：`暂无背景图片，请先上传。` |
| 获取列表失败 | `onSidebarBackgroundInitError` | `sidebarBackgroundListQueryStatus = 'error'`；`sidebarBackgroundListQueryErrorMessage = 错误信息` | 展示加载失败提示，可选展示重试入口 |

##### 上传图片流程

| 阶段 | 事件 | 前置条件 | 状态变化 | UI 表现 |
|---|---|---|---|---|
| 点击上传按钮 | `onSidebarBackgroundUploadButtonClick` | `sidebarBackgroundUploadStatus !== 'uploading'` | 无业务状态变化 | 唤起系统文件选择器 |
| 取消文件选择 | `onSidebarBackgroundFileSelectCancel` | 用户未选择文件 | 无状态变化 | 页面保持不变 |
| 确认选择图片 | `onSidebarBackgroundFileSelected` | 文件类型为图片 | `sidebarBackgroundUploadStatus = 'uploading'`；`sidebarBackgroundUploadErrorMessage = null` | 上传按钮可展示 loading 或禁用 |
| 上传成功 | `onSidebarBackgroundUploadSuccess` | 接口返回新图片信息 | `sidebarBackgroundList` 追加新图片；`sidebarBackgroundUploadStatus = 'success'` | 新图片立即出现在侧边栏背景预览列表中 |
| 上传失败 | `onSidebarBackgroundUploadError` | 接口失败或网络异常 | `sidebarBackgroundUploadStatus = 'error'`；`sidebarBackgroundUploadErrorMessage = 错误信息` | 展示上传失败提示；原图片列表保持不变 |
| 文件类型非法 | `onSidebarBackgroundFileValidateError` | 文件不是图片类型 | `sidebarBackgroundUploadStatus = 'error'`；`sidebarBackgroundUploadErrorMessage = '仅支持上传图片文件'` | 展示文件类型错误提示 |

##### 选择侧边栏背景图片流程

| 阶段 | 事件 | 前置条件 | 状态变化 | UI 表现 |
|---|---|---|---|---|
| 点击图片 | `onSidebarBackgroundSelect` | `sidebarBackgroundList` 中存在该图片 | `selectedSidebarBackgroundId = 当前图片 ID` | 当前图片展示选中态 |
| 点击另一张图片 | `onSidebarBackgroundSelect` | 已存在选中图片 | `selectedSidebarBackgroundId` 更新为新图片 ID | 原图片取消选中态，新图片展示选中态 |
| 图片列表为空 | - | `sidebarBackgroundList.length === 0` | `selectedSidebarBackgroundId = null` | 不展示图片项，展示空状态 |
| 选中非默认图片后 | 状态推导 | `selectedSidebarBackgroundId !== null && selectedSidebarBackgroundId !== defaultSidebarBackgroundId` | `isSetSidebarDefaultButtonDisabled = false` | “设为默认”按钮变为可点击 |
| 选中当前默认图片 | 状态推导 | `selectedSidebarBackgroundId === defaultSidebarBackgroundId` | `isSetSidebarDefaultButtonDisabled = true` | “设为默认”按钮不可点击 |

##### 设置默认侧边栏背景流程

| 阶段 | 事件 | 前置条件 | 状态变化 | UI 表现 |
|---|---|---|---|---|
| 初始状态 | - | 未选中图片 | `selectedSidebarBackgroundId = null` | “设为默认”按钮不可点击 |
| 选中非默认图片 | `onSidebarBackgroundSelect` | 用户点击非默认图片 | `selectedSidebarBackgroundId = 图片 ID` | “设为默认”按钮可点击 |
| 选中当前默认图片 | `onSidebarBackgroundSelect` | 用户点击当前默认图片 | `selectedSidebarBackgroundId = 图片 ID` | “设为默认”按钮不可点击 |
| 点击设为默认 | `onSidebarBackgroundSetDefaultClick` | 已选中非默认图片，且未处于设置中 | `sidebarBackgroundSetDefaultStatus = 'setting'`；`sidebarBackgroundSetDefaultErrorMessage = null` | “设为默认”按钮 loading 或禁用，防止重复点击 |
| 设置成功 | `onSidebarBackgroundSetDefaultSuccess` | 接口返回成功 | `defaultSidebarBackgroundId = selectedSidebarBackgroundId`；`sidebarBackgroundSetDefaultStatus = 'success'` | 新默认图片展示“默认”标记，旧默认图片取消“默认”标记 |
| 设置失败 | `onSidebarBackgroundSetDefaultError` | 接口失败或网络异常 | `sidebarBackgroundSetDefaultStatus = 'error'`；`sidebarBackgroundSetDefaultErrorMessage = 错误信息`；`defaultSidebarBackgroundId` 不变 | 默认标记不变，展示设置失败提示 |


#### 状态清单

| 状态名 | 作用域 | 类型 / 可选值 | 初始值 | 来源 | 是否可推导 | 触发变化的事件 | 影响 UI |
|---|---|---|---|---|---|---|---|
| `sidebarBackgroundList` | 页面 / 区域状态 | `SidebarBackgroundImage[]` | `[]` | 侧边栏背景列表接口、上传成功结果 | 否 | `onSidebarBackgroundInitSuccess`、`onSidebarBackgroundUploadSuccess` | 背景预览列表、空状态 |
| `selectedSidebarBackgroundId` | 区域状态 | `string \| null` | `null` | 用户点击图片 | 否 | `onSidebarBackgroundSelect` | 图片选中态、“设为默认”按钮可用状态 |
| `defaultSidebarBackgroundId` | 区域状态 | `string \| null` | `null` | 侧边栏背景列表接口、设置默认接口成功结果 | 否 | `onSidebarBackgroundInitSuccess`、`onSidebarBackgroundSetDefaultSuccess` | “默认”标记展示 |
| `sidebarBackgroundListQueryStatus` | 服务端请求状态 | `'idle' / 'loading' / 'success' / 'error'` | `'idle'` | 页面请求流程 | 否 | `onSidebarBackgroundInit`、`onSidebarBackgroundInitSuccess`、`onSidebarBackgroundInitError` | 背景预览加载态、错误态、正常列表 |
| `sidebarBackgroundListQueryErrorMessage` | 区域状态 | `string \| null` | `null` | 侧边栏背景列表接口失败结果 | 否 | `onSidebarBackgroundInitError` | 列表加载失败提示 |
| `sidebarBackgroundUploadStatus` | 上传流程状态 | `'idle' / 'uploading' / 'success' / 'error'` | `'idle'` | 上传流程 | 否 | `onSidebarBackgroundFileSelected`、`onSidebarBackgroundUploadSuccess`、`onSidebarBackgroundUploadError`、`onSidebarBackgroundFileValidateError` | 上传按钮 loading、上传失败提示 |
| `sidebarBackgroundUploadErrorMessage` | 区域状态 | `string \| null` | `null` | 文件校验失败或上传接口失败 | 否 | `onSidebarBackgroundFileValidateError`、`onSidebarBackgroundUploadError` | 上传错误提示 |
| `sidebarBackgroundSetDefaultStatus` | 设置默认流程状态 | `'idle' / 'setting' / 'success' / 'error'` | `'idle'` | 设置默认流程 | 否 | `onSidebarBackgroundSetDefaultClick`、`onSidebarBackgroundSetDefaultSuccess`、`onSidebarBackgroundSetDefaultError` | “设为默认”按钮 loading、设置失败提示 |
| `sidebarBackgroundSetDefaultErrorMessage` | 区域状态 | `string \| null` | `null` | 设置默认接口失败结果 | 否 | `onSidebarBackgroundSetDefaultError` | 设置默认失败提示 |

| `selectedSidebarBackground` | 推导状态 | `SidebarBackgroundImage \| null` | `null` | 根据 `selectedSidebarBackgroundId` 从 `sidebarBackgroundList` 查找 | 是 | 随 `sidebarBackgroundList`、`selectedSidebarBackgroundId` 变化 | 当前选中图片信息 |
| `isSetSidebarDefaultButtonDisabled` | 推导状态 | `boolean` | `true` | `!selectedSidebarBackgroundId || selectedSidebarBackgroundId === defaultSidebarBackgroundId || sidebarBackgroundSetDefaultStatus === 'setting'` | 是 | 随 `selectedSidebarBackgroundId`、`defaultSidebarBackgroundId`、`sidebarBackgroundSetDefaultStatus` 变化 | “设为默认”按钮禁用状态 |

| `isSidebarUploadButtonLoading` | 推导状态 | `boolean` | `false` | `sidebarBackgroundUploadStatus === 'uploading'` | 是 | 随 `sidebarBackgroundUploadStatus` 变化 | 上传按钮 loading 状态 |
