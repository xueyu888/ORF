设置页
├── 设置导航栏
│   ├── 视觉设置入口
│   ├── 周期与团队入口
│   ├── 反馈分类入口
│   ├── ORF 规则入口
│   └── 存储入口
└── 设置详情栏

**设置入口**：设置导航栏中的一个个按钮
**设置详情**：设置详情栏中的每个区域，称作一个设置详情

> 当前只实现“视觉设置”。“周期与团队”“反馈分类”“ORF 规则”“存储”暂时只作为导航占位，不展开具体内容。

### 前端页面素材

设置页组件美工参考素材统一放在仓库根目录 `frontend-assets/` 下，本地保存，不提交 git。

`frontend-assets/` 只用于前端页面和组件的视觉参考，不作为登录页背景或侧边栏背景资源，不参与后端背景列表扫描。

## 背景设置详情

### 布局

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 登录页面背景设置 / 侧边栏背景设置                                      │
│ 自定义对应区域的背景。                                                  │
│                                                        [上传图片]       │
│                                                                      │
│ 背景模式     [固定背景] [可切换背景]                                    │
│ 触发方式     [打开时切换] [定时切换]                                    │
│ 切换规则     [顺序切换] [随机切换]                                      │
│ 切换间隔     [10] [分钟]                                               │
│                                                                      │
│ 背景预览     ┌────────────────────────────────────────────────────┐  │
│             │  图片1  图片2  图片3  图片4  图片5  ...              │  │
│             │  横向滚动条                                         │  │
│             └────────────────────────────────────────────────────┘  │
│                                                        [设为默认]       │
└──────────────────────────────────────────────────────────────────────┘
```

布局要求：

| 区域 | 要求 |
|---|---|
| 背景模式、触发方式、切换规则、切换间隔 | 四行纵向排列，不额外加外框。 |
| 行标题 | 与“背景预览”左侧文字对齐。 |
| 控件 | 使用分段按钮、数字输入和单位下拉，视觉风格与当前设置页保持一致。 |
| 背景预览 | 横向滚动图片列表，只展示图片、选中态和“默认”标记，不展示文件名。 |
| 状态文案 | 不展示“已选中”或“未选中”文案；错误信息仍可在操作区展示。 |

### 配置模型

```ts
type BackgroundMode = 'fixed' | 'switchable'
type BackgroundSwitchTrigger = 'on_open' | 'interval'
type BackgroundSwitchOrder = 'sequential' | 'random'

type BackgroundSceneConfig = {
  mode: BackgroundMode
  fixedBackgroundId: string | null
  switchTrigger: BackgroundSwitchTrigger
  switchOrder: BackgroundSwitchOrder
  switchIntervalMinutes: number
}
```

| 字段 | UI 名称 | 说明 |
|---|---|---|
| `mode` | 背景模式 | `fixed` 为固定背景；`switchable` 为可切换背景。 |
| `fixedBackgroundId` | 固定背景 | 固定背景模式下展示的图片 ID。 |
| `switchTrigger` | 触发方式 | `on_open` 为打开时切换；`interval` 为定时切换。 |
| `switchOrder` | 切换规则 | `sequential` 为顺序切换；`random` 为随机切换。 |
| `switchIntervalMinutes` | 切换间隔 | 定时切换的间隔，单位分钟。 |

### 控件状态规则

| 条件 | 背景模式 | 触发方式 | 切换规则 | 切换间隔 | 设为默认 |
|---|---|---|---|---|---|
| `mode = fixed` | 可互动 | 不可互动 | 不可互动 | 不可互动 | 选中非固定背景时可点击 |
| `mode = switchable` 且 `switchTrigger = on_open` | 可互动 | 可互动 | 可互动 | 不可互动 | 不可点击 |
| `mode = switchable` 且 `switchTrigger = interval` | 可互动 | 可互动 | 可互动 | 可互动 | 不可点击 |
| 正在上传图片 | 可互动 | 按模式规则 | 按模式规则 | 按模式规则 | 按模式规则 |
| 正在保存配置 | 不可互动 | 不可互动 | 不可互动 | 不可互动 | 不可互动 |

说明：

- 固定背景模式下，用户点击图片后可以通过“设为默认”更新 `fixedBackgroundId`。
- 可切换背景模式下，图片列表用于参与切换和预览，不通过“设为默认”改变固定背景。
- 背景模式切换为 `fixed` 时，如果当前没有 `fixedBackgroundId`，前端使用当前选中图片作为固定背景；没有选中图片时使用列表第一张图片。
- 背景模式切换为 `switchable` 时，保留 `fixedBackgroundId`，用于用户切回固定背景时恢复固定选择。

### 触发源

| 触发源 | 所属区域 | 触发方式 | 触发事件 | 是否触发接口 | 说明 |
|---|---|---|---|---|---|
| 页面初始化 | 背景设置详情 | 进入设置页 | `onBackgroundInit` | 是 | 获取背景图片列表和背景策略配置。 |
| 背景模式控件 | 背景策略区域 | 鼠标左键点击 | `onModeChange` | 是 | 保存背景模式。 |
| 触发方式控件 | 背景策略区域 | 鼠标左键点击 | `onSwitchTriggerChange` | 是 | 保存触发方式。 |
| 切换规则控件 | 背景策略区域 | 鼠标左键点击 | `onSwitchOrderChange` | 是 | 保存切换规则。 |
| 切换间隔输入 | 背景策略区域 | 输入数字 | `onSwitchIntervalChange` | 否 | 只更新本地输入状态。 |
| 切换间隔输入 | 背景策略区域 | 失焦或回车 | `onSwitchIntervalCommit` | 是 | 保存切换间隔。 |
| 上传图片按钮 | 背景上传区域 | 鼠标左键点击 | `onUploadButtonClick` | 否 | 唤起系统文件选择器。 |
| 系统文件选择器 | 系统弹窗 | 选择图片并确认 | `onFileSelected` | 是 | 校验文件类型后调用上传接口。 |
| 系统文件选择器 | 系统弹窗 | 取消选择 | `onFileSelectCancel` | 否 | 不改变页面状态。 |
| 背景图片项 | 背景预览区域 | 鼠标左键单击 | `onBackgroundSelect` | 否 | 设置当前选中的背景图片。 |
| 设为默认按钮 | 背景预览区域 | 鼠标左键点击 | `onSetDefaultClick` | 是 | 固定背景模式下将当前选中的图片设为固定背景。 |
| 上传接口 | 系统响应 | 上传成功 | `onUploadSuccess` | 否 | 新图片进入背景预览列表。 |
| 上传接口 | 系统响应 | 上传失败 | `onUploadError` | 否 | 展示上传失败提示。 |
| 保存配置接口 | 系统响应 | 保存成功 | `onConfigSaveSuccess` | 否 | 更新背景策略配置。 |
| 保存配置接口 | 系统响应 | 保存失败 | `onConfigSaveError` | 否 | 恢复或保留原配置，并展示错误提示。 |

### 事件表

| 事件名 | 前置条件 | 主要动作 | 影响状态 | 是否触发接口 |
|---|---|---|---|---|
| `onBackgroundInit` | 用户进入视觉设置 | 请求背景图片列表和策略配置 | `backgroundList`、`backgroundConfig`、`fixedBackgroundId`、`listQueryStatus` | 是 |
| `onModeChange` | 未处于保存中 | 更新 `mode` 并保存配置 | `backgroundConfig`、`configSaveStatus` | 是 |
| `onSwitchTriggerChange` | `mode = switchable`，未处于保存中 | 更新 `switchTrigger` 并保存配置 | `backgroundConfig`、`configSaveStatus` | 是 |
| `onSwitchOrderChange` | `mode = switchable`，未处于保存中 | 更新 `switchOrder` 并保存配置 | `backgroundConfig`、`configSaveStatus` | 是 |
| `onSwitchIntervalChange` | `mode = switchable` 且 `switchTrigger = interval` | 更新本地输入值 | `switchIntervalInputValue` | 否 |
| `onSwitchIntervalCommit` | 间隔值合法，未处于保存中 | 更新 `switchIntervalMinutes` 并保存配置 | `backgroundConfig`、`configSaveStatus` | 是 |
| `onUploadButtonClick` | `uploadStatus !== 'uploading'` | 打开系统文件选择器 | 无 | 否 |
| `onFileSelected` | 用户已选择图片文件 | 校验文件类型，调用上传接口 | `uploadStatus`、`uploadErrorMessage` | 是 |
| `onFileSelectCancel` | 用户取消文件选择 | 不执行上传操作 | 无 | 否 |
| `onUploadSuccess` | 上传接口返回成功 | 将新图片追加到背景预览列表 | `backgroundList`、`selectedBackgroundId`、`uploadStatus` | 否 |
| `onUploadError` | 上传接口返回失败或网络异常 | 记录错误信息 | `uploadStatus`、`uploadErrorMessage` | 否 |
| `onBackgroundSelect` | 图片存在于背景列表中 | 设置当前选中图片 | `selectedBackgroundId` | 否 |
| `onSetDefaultClick` | `mode = fixed`，已选中非固定背景，未处于设置中 | 调用设置固定背景接口 | `setDefaultStatus`、`setDefaultErrorMessage` | 是 |
| `onSetDefaultSuccess` | 设置固定背景接口返回成功 | 更新 `fixedBackgroundId` | `backgroundConfig`、`fixedBackgroundId`、`setDefaultStatus` | 否 |
| `onSetDefaultError` | 设置固定背景接口失败或网络异常 | 记录错误信息，保持原固定背景不变 | `setDefaultStatus`、`setDefaultErrorMessage` | 否 |

### 状态变化表

#### 页面初始化流程

| 阶段 | 事件 | 状态变化 | UI 表现 |
|---|---|---|---|
| 页面进入 | `onBackgroundInit` | `listQueryStatus = 'loading'` | 背景预览区域展示加载态。 |
| 获取列表成功，列表非空 | `onBackgroundInitSuccess` | `backgroundList = 接口返回图片列表`；`backgroundConfig = 接口返回配置`；`fixedBackgroundId = config.fixedBackgroundId`；`listQueryStatus = 'success'` | 展示背景策略控件和背景图片列表；固定背景展示“默认”标记。 |
| 获取列表成功，列表为空 | `onBackgroundInitSuccess` | `backgroundList = []`；`fixedBackgroundId = null`；`selectedBackgroundId = null`；`listQueryStatus = 'success'` | 展示空状态文案：`暂无背景图片，请先上传。` |
| 获取列表失败 | `onBackgroundInitError` | `listQueryStatus = 'error'`；`listQueryErrorMessage = 错误信息` | 展示加载失败提示，可选展示重试入口。 |

#### 背景策略配置流程

| 阶段 | 事件 | 前置条件 | 状态变化 | UI 表现 |
|---|---|---|---|---|
| 切换为固定背景 | `onModeChange` | 用户点击“固定背景” | `backgroundConfig.mode = 'fixed'`；保存配置 | 触发方式、切换规则、切换间隔置灰不可互动。 |
| 切换为可切换背景 | `onModeChange` | 用户点击“可切换背景” | `backgroundConfig.mode = 'switchable'`；保存配置 | 触发方式、切换规则恢复可互动；切换间隔按触发方式判断。 |
| 选择打开时切换 | `onSwitchTriggerChange` | `mode = switchable` | `backgroundConfig.switchTrigger = 'on_open'`；保存配置 | 切换间隔置灰不可互动。 |
| 选择定时切换 | `onSwitchTriggerChange` | `mode = switchable` | `backgroundConfig.switchTrigger = 'interval'`；保存配置 | 切换间隔恢复可互动。 |
| 修改切换规则 | `onSwitchOrderChange` | `mode = switchable` | `backgroundConfig.switchOrder` 更新；保存配置 | 当前切换规则按钮高亮。 |
| 修改切换间隔 | `onSwitchIntervalChange` | `mode = switchable` 且 `switchTrigger = interval` | `switchIntervalInputValue` 更新 | 输入框展示新值，尚未保存。 |
| 提交切换间隔 | `onSwitchIntervalCommit` | 间隔值合法 | `backgroundConfig.switchIntervalMinutes` 更新；保存配置 | 保存成功后输入框保持提交值。 |
| 保存失败 | `onConfigSaveError` | 保存配置接口失败 | `configSaveStatus = 'error'`；`configSaveErrorMessage = 错误信息` | 展示保存失败提示，控件恢复可互动。 |

#### 上传图片流程

| 阶段 | 事件 | 前置条件 | 状态变化 | UI 表现 |
|---|---|---|---|---|
| 点击上传按钮 | `onUploadButtonClick` | `uploadStatus !== 'uploading'` | 无业务状态变化 | 唤起系统文件选择器。 |
| 取消文件选择 | `onFileSelectCancel` | 用户未选择文件 | 无状态变化 | 页面保持不变。 |
| 确认选择图片 | `onFileSelected` | 文件类型为图片 | `uploadStatus = 'uploading'`；`uploadErrorMessage = null` | 上传按钮展示 loading 或禁用。 |
| 上传成功 | `onUploadSuccess` | 接口返回新图片信息 | `backgroundList` 追加新图片；`selectedBackgroundId = 新图片 ID`；`uploadStatus = 'success'` | 新图片立即出现在背景预览列表中并展示选中态。 |
| 上传失败 | `onUploadError` | 接口失败或网络异常 | `uploadStatus = 'error'`；`uploadErrorMessage = 错误信息` | 展示上传失败提示；原图片列表保持不变。 |
| 文件类型非法 | `onFileValidateError` | 文件不是图片类型 | `uploadStatus = 'error'`；`uploadErrorMessage = '仅支持上传图片文件'` | 展示文件类型错误提示。 |

#### 选择背景图片流程

| 阶段 | 事件 | 前置条件 | 状态变化 | UI 表现 |
|---|---|---|---|---|
| 点击图片 | `onBackgroundSelect` | `backgroundList` 中存在该图片 | `selectedBackgroundId = 当前图片 ID` | 当前图片展示选中态。 |
| 点击另一张图片 | `onBackgroundSelect` | 已存在选中图片 | `selectedBackgroundId` 更新为新图片 ID | 原图片取消选中态，新图片展示选中态。 |
| 图片列表为空 | - | `backgroundList.length === 0` | `selectedBackgroundId = null` | 不展示图片项，展示空状态。 |
| 固定背景模式选中非固定图片 | 状态推导 | `mode = fixed` 且 `selectedBackgroundId !== fixedBackgroundId` | `isSetDefaultButtonDisabled = false` | “设为默认”按钮可点击。 |
| 固定背景模式选中固定图片 | 状态推导 | `mode = fixed` 且 `selectedBackgroundId === fixedBackgroundId` | `isSetDefaultButtonDisabled = true` | “设为默认”按钮不可点击。 |
| 可切换背景模式 | 状态推导 | `mode = switchable` | `isSetDefaultButtonDisabled = true` | “设为默认”按钮不可点击。 |

#### 设置固定背景流程

| 阶段 | 事件 | 前置条件 | 状态变化 | UI 表现 |
|---|---|---|---|---|
| 初始状态 | - | 未选中图片 | `selectedBackgroundId = null` | “设为默认”按钮不可点击。 |
| 选中非固定图片 | `onBackgroundSelect` | `mode = fixed`，用户点击非固定图片 | `selectedBackgroundId = 图片 ID` | “设为默认”按钮可点击。 |
| 点击设为默认 | `onSetDefaultClick` | `mode = fixed`，已选中非固定图片，且未处于设置中 | `setDefaultStatus = 'setting'`；`setDefaultErrorMessage = null` | “设为默认”按钮 loading 或禁用。 |
| 设置成功 | `onSetDefaultSuccess` | 接口返回成功 | `fixedBackgroundId = selectedBackgroundId`；`backgroundConfig.fixedBackgroundId = selectedBackgroundId`；`backgroundConfig.mode = 'fixed'`；`setDefaultStatus = 'success'` | 新固定背景展示“默认”标记，旧固定背景取消“默认”标记。 |
| 设置失败 | `onSetDefaultError` | 接口失败或网络异常 | `setDefaultStatus = 'error'`；`setDefaultErrorMessage = 错误信息`；`fixedBackgroundId` 不变 | 默认标记不变，展示设置失败提示。 |

### 状态清单

| 状态名 | 作用域 | 类型 / 可选值 | 初始值 | 来源 | 是否可推导 | 触发变化的事件 | 影响 UI |
|---|---|---|---|---|---|---|---|
| `backgroundList` | 设置详情状态 | `BackgroundImage[]` | `[]` | 背景列表接口、上传成功结果 | 否 | `onBackgroundInitSuccess`、`onUploadSuccess` | 背景预览列表、空状态。 |

## 背景展示规则

### 固定背景

| 场景 | 规则 |
|---|---|
| 登录页面 | 使用 `login_background` 的 `fixedBackgroundId` 对应图片。 |
| 侧边栏 | 使用 `sidebar_background` 的 `fixedBackgroundId` 对应图片。 |
| 固定图片不存在 | 使用当前场景图片列表第一张作为兜底。 |
| 图片列表为空 | 使用代码内置兜底背景。 |

### 打开时切换

| 切换规则 | 规则 |
|---|---|
| 顺序切换 | 每次打开登录页或进入系统时，按当前场景图片列表从左到右取下一张。 |
| 随机切换 | 每次打开登录页或进入系统时，从当前场景图片列表中随机取一张。 |

顺序切换的当前位置属于运行时状态，不写入 `settings.json`。前端使用 `localStorage` 保存，例如：

```text
orf.backgroundRotation.login_background.lastIndex
orf.backgroundRotation.sidebar_background.lastIndex
```

### 定时切换

| 切换规则 | 规则 |
|---|---|
| 顺序切换 | 页面打开后立即显示一张背景，并按 `switchIntervalMinutes` 从左到右轮换。 |
| 随机切换 | 页面打开后立即显示一张背景，并按 `switchIntervalMinutes` 随机轮换。 |

定时切换只在当前页面生命周期内运行。用户离开登录页或卸载侧边栏时，前端清理计时器。
