# 评论功能黑盒不确定性地图

## 1. 说明

本地图从用户目标、外部条件和可观察结果出发，不描述内部函数、内部状态变量或内部调用链。

## 2. 不确定性清单

| 编号 | 不确定性类型 | 黑盒问题 | 示例条件 | 可能失败表现 | 优先级 |
|---|---|---|---|---|---|
| U-001 | 展示不确定性 | 没有评论时，用户是否能理解当前为空 | 用户打开一个没有评论的对象 | 页面空白、误以为加载失败 | P0 |
| U-002 | 展示不确定性 | 有评论时，用户是否能看清作者、正文、时间和操作 | 对象已有多条评论 | 评论信息缺失、操作入口不清晰 | P0 |
| U-003 | 对象隔离不确定性 | 不同对象的评论是否会串在一起 | 两个对象标题相同或相似 | A 对象显示 B 对象评论 | P0 |
| U-004 | 输入不确定性 | 空评论是否会被提交 | 输入为空后提交 | 出现空评论 | P0 |
| U-005 | 输入不确定性 | 纯空白评论是否会被提交 | 输入空格、换行后提交 | 出现无意义评论 | P0 |
| U-006 | 输入不确定性 | 多行、emoji、符号是否正常处理 | 输入多行文本或 emoji | 内容丢失、乱码、提交失败 | P1 |
| U-007 | 输入不确定性 | 超长评论是否可控 | 输入很长正文 | 页面卡顿、布局破坏、无法操作 | P1 |
| U-008 | 安全不确定性 | 危险内容是否会执行 | 输入 script 或 HTML | 弹窗执行、DOM 被插入、页面异常 | P0 |
| U-009 | 状态不确定性 | 未登录用户是否被正确限制 | 未登录时尝试评论 | 成功发表评论或无提示失败 | P0 |
| U-010 | 权限不确定性 | 无权限用户是否被正确限制 | 用户无目标评论权限 | 成功评论、编辑或删除 | P0 |
| U-011 | 交互不确定性 | 合法评论提交后是否可见 | 用户输入合法评论并提交 | 评论未出现、出现到错误位置 | P0 |
| U-012 | 交互不确定性 | 重复点击提交是否产生重复评论 | 保存较慢时连续点击提交 | 出现多条重复评论 | P0 |
| U-013 | 回复不确定性 | 回复是否关联到正确评论 | 回复某条评论 | 回复显示到错误评论下 | P0 |
| U-014 | 回复不确定性 | 回复列表是否易于理解 | 一条评论有多条回复 | 回复顺序混乱、层级不清 | P1 |
| U-015 | 编辑不确定性 | 编辑评论是否只改变目标评论 | 用户编辑一条评论 | 其他评论被改、内容未更新 | P0 |
| U-016 | 编辑不确定性 | 编辑为空是否被阻止 | 用户清空正文并保存 | 评论变成空白 | P0 |
| U-017 | 删除不确定性 | 删除前是否有确认 | 用户点击删除 | 误删且无法取消 | P0 |
| U-018 | 删除不确定性 | 取消删除是否保持不变 | 用户取消确认框 | 评论消失或状态变化 | P0 |
| U-019 | 删除不确定性 | 删除外层评论时回复如何处理 | 外层评论下有回复 | 行为不符合规格或让用户困惑 | P1 |
| U-020 | 恢复不确定性 | 保存失败后用户能否恢复 | 外部保存失败或超时 | 输入丢失、按钮卡死、无法重试 | P0 |
| U-021 | 恢复不确定性 | 删除失败后数据是否一致 | 外部删除失败 | 用户以为删除成功但重新打开又出现 | P1 |
| U-022 | 持久化不确定性 | 关闭或刷新后评论是否还在 | 用户发表后刷新页面 | 评论丢失 | P0 |
| U-023 | 共享范围不确定性 | 评论是否需要跨设备或多人可见 | 用户换设备或其他成员查看 | 期望和实际不一致 | P1 |
| U-024 | 布局不确定性 | 小屏幕能否正常使用 | 手机宽度打开评论区 | 遮挡、溢出、无法点击按钮 | P1 |
| U-025 | 布局不确定性 | 长标题和长正文是否影响操作 | 对象标题很长、评论很长 | 按钮被挤出、内容重叠 | P1 |
| U-026 | 可访问性不确定性 | 关键操作是否可被识别和触发 | 使用键盘或辅助技术 | 按钮无名称、无法提交或关闭 | P2 |

## 3. 待确认不确定性

| 编号 | 问题 | 影响 |
|---|---|---|
| Q-001 | 评论是否必须跨浏览器、跨设备、多人共享 | 决定持久化和后端验收标准 |
| Q-002 | 未登录用户是否允许查看评论 | 决定只读场景用例 |
| Q-003 | 管理员是否可编辑或删除他人评论 | 决定权限用例 |
| Q-004 | 删除外层评论时回复如何处理 | 决定删除用例预期 |
| Q-005 | 评论最大长度是多少 | 决定边界输入用例 |
| Q-006 | 保存失败时是否必须有重试入口 | 决定失败恢复用例 |
