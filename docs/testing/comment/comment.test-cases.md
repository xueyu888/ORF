# 评论功能黑盒测试用例

## 1. 用例说明

所有用例采用 Given / When / Then。

用例来源是评论功能黑盒规格和不确定性地图，不来源于当前源码。

## 2. P0 用例

| 用例编号 | 测试目标 | Given | When | Then | 优先级 | 是否门禁 |
|---|---|---|---|---|---|---|
| CMT-BB-001 | 打开无评论对象 | 用户已登录且有查看权限；目标对象没有评论 | 用户打开该对象评论区 | 用户看到评论区、目标上下文、空状态和评论输入入口 | P0 | 是 |
| CMT-BB-002 | 打开有评论对象 | 用户已登录且有查看权限；目标对象已有评论 | 用户打开该对象评论区 | 用户看到已有评论的作者、正文、时间和可用操作 | P0 | 是 |
| CMT-BB-003 | 评论按对象隔离 | 用户有两个可评论对象 A 和 B；A 已有评论 | 用户打开 B 的评论区 | B 不显示 A 的评论 | P0 | 是 |
| CMT-BB-004 | 发表合法评论 | 用户已登录且有评论权限；评论区已打开 | 用户输入合法正文并提交 | 评论提交成功；新评论出现在当前对象评论区；输入区按规格清理 | P0 | 是 |
| CMT-BB-005 | 空评论不能提交 | 用户已登录且有评论权限；评论区已打开 | 用户不输入内容并提交 | 不产生新评论；用户可以继续输入 | P0 | 是 |
| CMT-BB-006 | 纯空白评论不能提交 | 用户已登录且有评论权限；评论区已打开 | 用户输入空格或换行并提交 | 不产生新评论；用户可以继续输入 | P0 | 是 |
| CMT-BB-007 | 重复提交不产生重复评论 | 用户已登录且有评论权限；输入了合法正文 | 用户快速连续触发提交 | 最多产生一条有效评论；界面不崩溃 | P0 | 是 |
| CMT-BB-008 | 回复外层评论 | 用户已登录且有评论权限；评论区有一条评论 | 用户对该评论输入回复并提交 | 回复成功；用户能从被回复评论处看到回复入口或回复内容 | P0 | 是 |
| CMT-BB-009 | 查看回复 | 用户已登录且有查看权限；一条评论下已有回复 | 用户打开该评论的回复区域 | 用户看到外层评论和其下回复；回复关系清晰 | P0 | 是 |
| CMT-BB-010 | 编辑自己的评论 | 用户已登录；评论区有自己发表的评论 | 用户编辑评论正文并保存 | 该评论展示为新正文；其他评论不受影响 | P0 | 是 |
| CMT-BB-011 | 编辑为空被阻止 | 用户已登录；正在编辑自己的评论 | 用户清空正文并保存 | 评论不变为空白；用户能继续编辑 | P0 | 是 |
| CMT-BB-012 | 删除前确认 | 用户已登录；评论区有自己可删除的评论 | 用户点击删除 | 系统要求用户确认删除 | P0 | 是 |
| CMT-BB-013 | 确认删除评论 | 用户已登录；删除确认已出现 | 用户确认删除 | 评论不再展示；评论数量相应变化 | P0 | 是 |
| CMT-BB-014 | 取消删除评论 | 用户已登录；删除确认已出现 | 用户取消删除 | 评论保持可见；内容和数量不变 | P0 | 是 |
| CMT-BB-015 | 危险内容不执行 | 用户已登录且有评论权限 | 用户输入 script 或 HTML 片段并提交 | 危险内容不执行；内容按安全方式展示或被拒绝 | P0 | 是 |
| CMT-BB-016 | 未登录用户不能进入评论页面 | 用户未登录 | 用户访问评论页面或尝试打开评论区 | 用户无法进入评论页面；不能查看、发表、编辑或删除评论；系统引导登录或展示未登录反馈 | P0 | 是 |
| CMT-BB-017 | 无权限用户不能操作 | 用户已登录但对目标对象无相应权限 | 用户尝试查看、发表、编辑或删除评论 | 操作不成功；不产生评论变化；用户看到权限反馈；评论权限跟随目标对象权限 | P0 | 是 |
| CMT-BB-018 | 刷新或重新打开后评论保留 | 用户已登录；已成功发表评论 | 用户刷新页面或关闭后重新打开同一对象评论区 | 已保存评论仍可见 | P0 | 是 |
| CMT-BB-019 | 评论跨用户可见 | 用户 A 已在某对象下成功发表评论；用户 B 有该对象查看权限 | 用户 B 打开同一对象评论区 | 用户 B 能看到用户 A 的评论 | P0 | 是 |
| CMT-BB-020 | 评论跨设备或浏览器可见 | 用户已在设备或浏览器 A 中成功发表评论 | 同一用户在设备或浏览器 B 打开同一对象评论区 | 已保存评论仍可见 | P0 | 是 |

## 3. P1 用例

| 用例编号 | 测试目标 | Given | When | Then | 优先级 | 是否门禁 |
|---|---|---|---|---|---|---|
| CMT-BB-021 | 多行评论 | 用户已登录且有评论权限 | 用户输入多行评论并提交 | 多行内容可读展示，不破坏评论区 | P1 | 是 |
| CMT-BB-022 | emoji 和特殊字符 | 用户已登录且有评论权限 | 用户输入 emoji、只包含 emoji 的正文、标点和中英文混排并提交 | 内容保存和展示正确，无乱码；只包含 emoji 的正文允许提交 | P1 | 是 |
| CMT-BB-023 | 500 字符评论可提交 | 用户已登录且有评论权限 | 用户输入 500 字符正文并提交 | 评论提交成功，内容完整展示或按安全布局展示 | P1 | 是 |
| CMT-BB-024 | 超过 500 字符评论不能提交 | 用户已登录且有评论权限 | 用户输入 501 字符或更长正文并提交 | 不产生新评论；用户看到长度超限反馈；页面不崩溃，核心操作仍可用 | P1 | 是 |
| CMT-BB-025 | URL 不自动链接 | 用户已登录且有评论权限 | 用户输入包含 URL 的正文并提交 | URL 作为普通文本展示，不自动变成可点击链接 | P1 | 是 |
| CMT-BB-026 | 回复多条评论 | 用户已登录；多条评论均可回复 | 用户分别回复不同评论 | 每条回复出现在正确评论下，不串回复 | P1 | 是 |
| CMT-BB-027 | 回复内层评论 | 用户已登录；某评论下已有回复 | 用户回复其中一条回复 | 用户能看出回复对象，回复关系不混乱 | P1 | 是 |
| CMT-BB-028 | 删除有回复的外层评论 | 用户已登录；外层评论下有回复 | 用户删除该外层评论并确认 | 外层评论和它下面的回复一起删除；评论数量相应变化 | P1 | 是 |
| CMT-BB-029 | 保存失败后可恢复并可重试 | 用户已登录；外部保存失败或超时 | 用户提交合法评论 | 用户看到失败反馈；输入不丢失或可恢复；功能不卡死；提供重试入口 | P1 | 是 |
| CMT-BB-030 | 删除失败后可恢复 | 用户已登录；外部删除失败或超时 | 用户确认删除评论 | 用户看到失败反馈；数据状态不误导用户 | P1 | 是 |
| CMT-BB-031 | 切换对象不串草稿 | 用户在 A 对象评论区输入未提交内容 | 用户切换到 B 对象评论区 | B 不显示 A 的已保存评论；草稿不会被误提交到 B | P1 | 是 |
| CMT-BB-032 | 小屏幕可操作 | 用户使用小屏幕设备 | 用户打开评论区并执行核心操作 | 评论区不明显溢出；提交、关闭、回复、编辑、删除可操作 | P1 | 是 |
| CMT-BB-033 | 长标题可用 | 目标对象标题很长 | 用户打开评论区 | 评论区仍能识别上下文，关键操作不被遮挡 | P1 | 是 |
| CMT-BB-034 | 评论数量准确 | 一个对象有评论和回复 | 用户查看对象评论入口和评论区 | 评论数量与规格定义的可见评论数量一致 | P1 | 是 |
| CMT-BB-035 | 登录过期处理 | 用户打开评论区后登录过期 | 用户尝试提交、编辑或删除 | 操作不成功；用户看到登录状态反馈；输入不被无故丢弃 | P1 | 是 |
| CMT-BB-036 | 编辑历史不可见 | 用户已登录；自己的一条评论已经被编辑过 | 用户查看该评论 | 用户只能看到当前正文，看不到编辑历史入口或历史版本 | P1 | 是 |

## 4. P2 用例

| 用例编号 | 测试目标 | Given | When | Then | 优先级 | 是否门禁 |
|---|---|---|---|---|---|---|
| CMT-BB-037 | 键盘可提交 | 用户已登录且有评论权限；输入合法正文 | 用户使用键盘快捷方式提交 | 评论按规格提交 | P2 | 否 |
| CMT-BB-038 | 关键操作有可访问名称 | 用户使用辅助技术 | 用户浏览评论区操作入口 | 关闭、提交、回复、编辑、删除等操作可被识别 | P2 | 否 |
| CMT-BB-039 | 管理员编辑他人评论 | 管理员打开包含他人评论的评论区 | 管理员编辑他人评论并保存 | 他人评论按管理员输入更新，其他评论不受影响 | P2 | 否 |
| CMT-BB-040 | 管理员删除他人评论 | 管理员打开包含他人评论的评论区 | 管理员删除他人评论并确认 | 他人评论按删除规则移除，评论数量相应变化 | P2 | 否 |

## 5. 已按规格确认的原待确认项

| 编号 | 已确认规则 | 影响的用例 |
|---|---|---|
| CFM-001 | 未登录用户无法进入评论页面 | CMT-BB-016 |
| CFM-002 | 删除外层评论时，它下面的回复一起删除 | CMT-BB-028 |
| CFM-003 | 评论最大长度为 500 字符 | CMT-BB-023、CMT-BB-024 |
| CFM-004 | 评论需要跨浏览器、跨设备、多人共享 | CMT-BB-019、CMT-BB-020 |
| CFM-005 | 管理员允许编辑和删除他人评论 | CMT-BB-039、CMT-BB-040 |
| CFM-006 | 评论权限跟随目标对象权限 | CMT-BB-017 |
| CFM-007 | 只包含 emoji 的评论允许提交 | CMT-BB-022 |
| CFM-008 | URL 不需要自动链接 | CMT-BB-025 |
| CFM-009 | 编辑历史不可见 | CMT-BB-036 |
| CFM-010 | 保存失败时需要重试入口 | CMT-BB-029 |
