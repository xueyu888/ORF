# 评论组件

## 目标

1. 绑定到目标、指标、任务或子任务。
2. 记录补充信息。
3. 支持编辑和删除。

## 组件结构

评论栏只有一个外框。历史评论是消息行，底部输入是输入行，不再渲染多个评论框 / 卡片。

```text
评论框 <CommentPanel>
├─ 评论消息行[] <CommentMessageRow>
│  └─ 头像 / 评论人名字 / 时间戳 / 评论内容 / 删除图标 / 编辑图标
└─ 底部输入行 <CommentComposer>
   └─ 头像 / 当前用户名字 / 输入框 / 灰色提示 / 发送图标
```

## 元素

| 元素 | 说明 |
| --- | --- |
| 评论框 | 页面上只出现一个外框 |
| 头像 | 评论人头像 |
| 评论人名字 | 当前评论作者 |
| 时间戳 | 评论创建时间 |
| 文本内容 | 评论正文 |
| 输入框 | 底部输入评论 |
| 删除图标 | 删除评论 |
| 编辑图标 | 编辑评论 |
| 发送图标 | 发送评论 |
| 评论入口图标 | 有评论时显示评论数量，点击打开当前块评论栏 |
| 灰色提示 | `添加评论...` / `Ctrl / Cmd + Enter 发送` |

## 状态

| 状态 | 显示 | 隐藏 |
| --- | --- | --- |
| 输入行 | 输入框、灰色提示、发送图标 | 删除图标、编辑图标、时间戳 |
| 消息行 | 文本内容、删除图标、编辑图标、时间戳 | 输入框、灰色提示、发送图标 |

## 交互

| 操作 | 结果 |
| --- | --- |
| 点击评论入口图标 | 打开 / 关闭当前块评论栏 |
| 输入评论 | 更新输入框内容 |
| 点击发送图标 | 发送评论 |
| `Ctrl / Cmd + Enter` | 发送评论 |
| 点击编辑图标 | 进入编辑 |
| 双击评论内容 | 进入编辑 |
| 点击删除图标 | 删除评论 |

## 排序

评论按时间倒序展示：最新在上，最旧在下。

## 暂不做

1. 点赞 / 表情反应。
2. 回复线程。
3. `@` 提及。
4. 图片 / 文件评论。
