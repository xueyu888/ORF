
## 任务评论的目标： 
1. 补充记录
2. 把氛围搞好

## 最小基：
1. 在空间上绑定某任务，记录相关内容
2. 评论可以被编辑和删除

### 涉及元素

**灰色文字提示1**：Ctrl / Cmd + Enter 发送
**灰色文字提示2**：添加评论...

评论框，时间戳，评论人，文本内容，删除键，编辑键
#### 状态：
**发送态**：显示灰色文字提示1和2，显示发送图标，隐藏删除图标和编辑图标
**展示态**：显示删除图标和编辑图标，隐藏发送图标，隐藏灰色文字提示1和2

发送态和展示态复用下面的页面布局：

-----------------------------------------------
头像 评论人名字                删除图标     时间戳
评论内容
灰色文字提示                            发送图标
-------------------------------------------------

## 原则：
1. 评论展示顺序原则：时间最新的在上面，时间最旧的在下面




1. 评论可以被点赞或表情反应，增加互动性
2. 可以回复评论，形成讨论线程
3. 评论可以被@提及相关人员，增加沟通效率
4. 评论内容支持文本、图片、文件等多种形式
