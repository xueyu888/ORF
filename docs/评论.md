# 评论组件

## 目标

1. 绑定到目标、指标、任务或子任务。
2. 记录补充信息。
3. 支持回复。
4. 支持编辑和删除。

## 回复区设计细则
1. 新增/发送评论的输入区应该永远固定在评论窗口底部。
2. 每条评论都拥有回复按钮。
3. 外层评论：
   外层评论是直接属于任务的一级评论。评论窗口默认展示外层评论列表。
   每条外层评论都可以被回复，并且可以进入它自己的回复详情。
4. 内层评论：
   内层评论是属于某条外层评论的回复列表。
   内层评论只保留一层，不再继续嵌套。
   回复内层评论时，新评论仍然加入当前外层评论的回复列表。
   回复内层评论后，新评论正文前显示回复对象：`回复xxx: 评论内容`。
5. 内层评论视图：
   当进入某条外层评论的回复详情时，当前外层评论固定显示在窗口顶部。
   该外层评论下方展示它所拥有的全部内层评论。
   如果不点击任何回复按钮，底部输入行默认回复当前顶部冻结外层评论，发送后创建新的内层评论。
6. 评论窗口：
   一个任务对应一个整体的评论窗口。
   评论窗口默认承载该任务下的外层评论列表。
   评论窗口可以从外层评论列表视图切换到某条外层评论的内层评论视图。
   无论当前处于哪个视图，新增/发送评论的输入区都固定在窗口底部。


## 组件结构

```
评论窗口 <CommentPanel>
├─ 绑定标题 <CommentContextTitle>
│  └─ 当前绑定的目标 / 指标 / 任务 / 子任务标题
│
├─ 当前视图区域 <CommentView>
│
│  ├─ 外层评论列表视图 <RootCommentListView>
│  │  └─ 外层评论消息行[] <RootCommentRow>
│  │     └─ 头像 / 评论人名字 / 时间戳 / 评论内容 / 回复按钮 / 共 x 条回复入口 / 删除图标 / 编辑图标
│  │
│  └─ 内层评论视图 <ReplyDetailView>
│     ├─ 顶部冻结外层评论 <FixedRootComment>
│     │  └─ 头像 / 评论人名字 / 时间戳 / 评论内容 / 回复按钮 / 删除图标 / 编辑图标
│     │
│     └─ 内层评论消息行[] <ReplyCommentRow>
│        └─ 头像 / 评论人名字 / 时间戳 / 回复对象标记 / 评论内容 / 回复按钮 / 删除图标 / 编辑图标
│
└─ 底部固定输入行 <CommentComposer>
   └─ 头像 / 当前用户名字 / 输入框 / 灰色提示 / 发送图标
```

## 元素

| 元素             | 说明                                                       |
| ---------------- | ---------------------------------------------------------- |
| 评论窗口         | 页面上只出现一个整体评论窗口，一个任务对应一个评论窗口     |
| 绑定标题         | 显示当前绑定的目标、指标、任务或子任务标题                 |
| 外层评论列表视图 | 评论窗口默认展示的视图，用于展示当前任务下的外层评论       |
| 外层评论消息行   | 直接属于任务的一级评论消息行                               |
| 内层评论视图     | 点击某条外层评论的“共 x 条回复”后进入的回复详情视图        |
| 顶部冻结外层评论 | 进入内层评论视图后，当前外层评论固定显示在顶部             |
| 内层评论消息行   | 属于某条外层评论的回复消息行                               |
| 头像             | 评论人头像                                                 |
| 评论人名字       | 当前评论作者                                               |
| 时间戳           | 评论创建时间                                               |
| 文本内容         | 评论正文                                                   |
| 回复按钮         | 每条外层评论和内层评论都拥有回复按钮                       |
| 回复对象标记     | 回复内层评论时显示为 `回复xxx:`，放在评论正文前             |
| 共 x 条回复入口  | 外层评论下方的回复入口，点击后进入该外层评论的内层评论视图 |
| 输入框           | 底部输入评论                                               |
| 删除图标         | 删除评论                                                   |
| 编辑图标         | 编辑评论                                                   |
| 发送图标         | 发送评论                                                   |
| 评论入口图标     | 有评论时显示评论数量，点击打开当前块评论窗口               |
| 灰色提示         | `添加评论...` / `Ctrl / Cmd + Enter 发送`                  |

## 状态

| 状态             | 显示                                                                              | 隐藏                                        |
| ---------------- | --------------------------------------------------------------------------------- | ------------------------------------------- |
| 外层评论列表视图 | 绑定标题、外层评论消息行列表、底部固定输入行                                      | 内层评论消息行列表、顶部冻结外层评论        |
| 内层评论视图     | 顶部冻结外层评论、内层评论消息行列表、底部固定输入行                              | 外层评论消息行列表                          |
| 输入行           | 头像、当前用户名字、输入框、灰色提示、发送图标                                    | 删除图标、编辑图标、时间戳                  |
| 外层评论消息行   | 头像、评论人名字、时间戳、文本内容、回复按钮、共 x 条回复入口、删除图标、编辑图标 | 输入框、灰色提示、发送图标                  |
| 内层评论消息行   | 头像、评论人名字、时间戳、文本内容、回复按钮、删除图标、编辑图标                  | 共 x 条回复入口、输入框、灰色提示、发送图标 |
| 顶部冻结外层评论 | 当前外层评论内容固定显示在内层评论视图顶部                                        | 其他外层评论                                |
| 选中消息行       | 当前评论消息行高亮                                                                | 其他消息行高亮                              |
| 默认输入状态     | 输入框用于发布新的外层评论                                                        | 回复目标提示                                |
| 内层默认输入状态 | 进入内层评论视图后，输入框默认回复顶部冻结外层评论                                | 回复目标提示                                |
| 回复外层评论状态 | 输入框用于回复某条外层评论                                                        | 默认输入提示                                |
| 回复内层评论状态 | 输入框用于回复某条内层评论，但新回复仍进入当前外层评论的内层评论列表              | 默认输入提示                                |

## 交互

| 操作                           | 结果                                                 |
| ------------------------------ | ---------------------------------------------------- |
| 点击评论入口图标               | 打开 / 关闭当前任务的评论窗口                        |
| 默认打开评论窗口               | 展示当前任务的外层评论列表视图                       |
| 点击评论消息行                 | 选中该评论，消息行高亮                               |
| 点击外层评论的回复按钮         | 底部输入行进入回复外层评论状态                       |
| 点击内层评论的回复按钮         | 底部输入行进入回复内层评论状态                       |
| 点击外层评论的“共 x 条回复”    | 进入该外层评论的内层评论视图                         |
| 进入内层评论视图               | 当前外层评论固定显示在顶部，下方展示它的全部内层评论 |
| 内层评论视图直接输入并发送     | 创建新的内层评论，挂到当前顶部冻结外层评论下         |
| 返回外层评论列表               | 从内层评论视图返回外层评论列表视图                   |
| 输入评论                       | 更新输入框内容                                       |
| 默认输入状态下点击发送图标     | 创建新的外层评论                                     |
| 回复外层评论状态下点击发送图标 | 创建新的内层评论，挂到该外层评论下                   |
| 回复内层评论状态下点击发送图标 | 创建新的内层评论，仍然挂到当前外层评论下，并显示 `回复xxx: 评论内容` |
| `Ctrl / Cmd + Enter`           | 按当前输入状态发送评论                               |
| 点击编辑图标                   | 进入编辑                                             |
| 双击评论内容                   | 进入编辑                                             |
| 点击删除图标                   | 删除评论                                             |

## 排序

外层评论:
评论按时间倒序展示：最新在上，最旧在下。

内层评论:
默认按时间顺序展示：最旧在上，最新在下。

## 暂不做

1. 点赞 / 表情反应。
2. `@` 提及。
3. 图片 / 文件评论。
