# ORF 任务管理页面 - 前端

本文档只记录前端展示规则、前端派生状态和组件定位。

后端返回字段、枚举和数据关系见 [ORF 任务管理页面 - 后端.md](./ORF%20任务管理页面%20-%20后端.md)。

## 0. 全局侧边栏

侧边栏当前只保留以下入口：

```text
Logo | ORF Flow | 折叠图标

work
- 计划
- 周复盘

report
- 反馈
- 统计

搜索

设置

当前登录人：头像 + 姓名
```

说明：

- `计划` 对应任务管理页。
- `反馈` 是单纯的反馈记录，不要求立即建立任务；未来反馈可能转化为工作目标。
- `统计` 用于统计历史目标完成情况和每个人的积分情况。
- 设置只作为底部图标入口，不放入普通菜单分组。
- 侧边栏必须支持折叠为图标栏；折叠态只显示图标，保留设置、菜单入口、搜索和当前登录人头像，图标需要提供可识别的 `title` / `aria-label`。

## 1. 层级结构

ORF 任务管理页固定四层结构：

```text
目标
└─ 指标
   └─ 任务
      └─ 子任务
```

目标框内的树形线条使用 `<HierarchyCell>` 和 `<HierarchyTreeOverlay>` 复用。所有层次化线条都必须使用这套样式。

树线样式规则：

- 竖线必须连续，不按单行切成断裂短线。
- 当前节点用圆角弯线连接到内容字段。
- 线条颜色固定为 `#d0d5dd`。
- 缩进步长固定为 `28px`。
- 目标行不画树线，指标行开始画树线。

| 层级 | 对象 | 树形深度 | 说明 |
| --- | --- | ---: | --- |
| 1 | 目标 | 0 | 目标行不画树形线，是树根。 |
| 2 | 指标 | 1 | 指标行开始画树形线。 |
| 3 | 任务 | 2 | 任务行向指标缩进一层。 |
| 4 | 子任务 | 3 | 子任务行向任务缩进一层。 |

实现约束：

- `<HierarchyCell depth={1}>` 只负责字段对齐，不画线。
- `<HierarchyCell depth={2}>` 开始画第一条分支线。
- `<HierarchyCell depth={3}>` 画祖先竖线和当前圆角分支。

## 2. 字段排列

### 目标行 `<ObjectivePanel>`

| 顺序 | 字段 | 数据 / 组件 | 前端展示规则 |
| --- | --- | --- | --- |
| 1 | 目标图标 | `<ObjectiveFlagIcon>` | 32×32 目标徽章，圆角 7px；未完成态用淡青绿底 `#eefaf7`、边框 `#9fd8cf`、旗子 `#2f9c89`；已完成态用透明底、灰边框 `#d6d6d3`、灰旗子 `#a7a7a7`。目标完成情况仍以进度条为准。 |
| 2 | 目标标题 | `objective.title` | 已完成时划线变灰。 |
| 3 | 目标风险标签 | `objective.status` | 显示正常 / 有风险。 |
| 4 | 负责人头像组 | `resultOwners` / `<AvatarStack>` | 来自目标下可见指标负责人。 |
| 5 | 日期 | `objectiveDue` 或 `reviewDue` | 优先显示任务截止日期。 |
| 6 | 目标进度条 | `objectiveProgress(...)` | 目标唯一的进度表达。 |

目标行左右两侧都不显示展开图标。

### 指标行 `<ResultBlock>`

| 顺序 | 字段 | 数据 / 组件 | 前端展示规则 |
| --- | --- | --- | --- |
| 1 | 树形线条 | `<HierarchyCell depth={1}>` | 表示指标属于上方目标。 |
| 2 | 展开图标 | `<ChevronDown>` / `<ChevronRight>` | 只表示指标下方任务展开 / 折叠。 |
| 3 | 指标图标 | `<MetricSquareIcon>` | 正方形颜色块，颜色表达指标状态。 |
| 4 | 指标标题 | `result.title` | 已完成时划线变灰。 |
| 5 | 负责人 | `result.owner` / `<PersonValue>` | 一个指标只显示一个负责人。 |
| 6 | 指标状态 | `indicatorStatus(result, tasks)` | 待办 / 进行中 / 待验收 / 已完成。 |
| 7 | 日期 | `updatedAt` | 指标相关任务、证据、反馈里的最近更新时间。 |

指标不显示进度条。

### 任务行 `<TaskRow>`

| 顺序 | 字段 | 数据 / 组件 | 前端展示规则 |
| --- | --- | --- | --- |
| 1 | 树形线条 | `<HierarchyCell depth={2}>` | 表示任务属于上方指标。 |
| 2 | 展开图标 | `<ChevronDown>` / `<ChevronRight>` | 只有存在子任务时显示；图标在任务勾选框左侧。 |
| 3 | 勾选框 | `<CompletionCheckbox>` / `<CompletionCircleIcon>` | 圆形勾选框，勾上后任务进入已完成。 |
| 4 | 任务标题 | `task.title` | 已完成时划线变灰。 |
| 5 | 负责人 | 无 | 任务不显示负责人；负责人只在指标行显示。 |
| 6 | 任务状态 | `task.status` / `<TaskStatusSelect>` | 只显示待办 / 进行中 / 已完成。 |
| 7 | 日期 | `task.updatedAt` | 任务最近更新时间。 |

任务不显示进度条，不显示负责人。任务可以折叠子任务。有子任务时，任务行树形横线连接到展开图标左侧；没有子任务时，树形横线连接到任务勾选框，避免展开图标占位形成视觉空档。

### 子任务行 `<SubtaskRow>`

| 顺序 | 字段 | 数据 / 组件 | 前端展示规则 |
| --- | --- | --- | --- |
| 1 | 树形线条 | `<HierarchyCell depth={3}>` | 表示子任务属于上方任务。 |
| 2 | 勾选框 | `<CompletionCheckbox>` / `<CompletionCircleIcon>` | 圆形勾选框，勾上后子任务进入已完成。 |
| 3 | 子任务标题 | `item.label` | 已完成时划线变灰。 |
| 4 | 负责人 | 无 | 子任务不显示负责人。 |
| 5 | 子任务状态 | `subtaskDisplayStatus(...)` | 待办 / 进行中 / 已完成。 |
| 6 | 日期 | `item.updatedAt` | 子任务最近更新时间。 |

子任务不显示进度条。任务到子任务的树形横线必须贴到子任务勾选框左边缘，不在图标前留空，也不穿过图标。

## 3. 前端派生状态

| 对象 | 展示状态 | 派生来源 |
| --- | --- | --- |
| 目标 | 无独立状态图标 | 只通过目标进度条表达完成情况。 |
| 指标 | 待办 / 进行中 / 待验收 / 已完成 | `indicatorStatus(result, tasks)`。 |
| 任务 | 待办 / 进行中 / 已完成 | `task.status` 归一化后显示。 |
| 子任务 | 待办 / 进行中 / 已完成 | `item.done` 和所在任务状态共同决定。 |

状态视觉规则：

- 完成态不要使用高饱和亮色强调；高亮颜色保留给待办、进行中、待验收、风险等仍需处理的状态。
- 状态标签：待办、进行中、待验收、风险、正常等未完成 / 需关注状态使用淡底色和 1px 边框增强扫视识别，不使用额外小圆点；已完成状态去掉底色，使用低强调灰色文字。
- 已完成：标题划线并变灰；已完成的目标、指标、任务、子任务行不增加整行灰底。
- 目标：保留旗子图标；目标完成情况仍以进度条为准，图标颜色不反向强调完成态。
- 指标：保留正方形颜色块，颜色表达状态。
- 任务、子任务：保留圆形勾选框，勾选框表达完成。
- 只有目标显示进度条；指标、任务、子任务不显示进度条。

## 4. 前端进度计算

目标进度由指标平均得到；指标下有任务时，指标进度由任务平均得到；任务下有子任务时，任务进度由子任务平均得到。

```text
s(待办) = 0
s(进行中) = 0.5
s(已完成) = 1

p(子任务) = s(子任务状态)

p(任务) =
  平均值(p(子任务[]))，如果任务下有子任务
  s(任务状态)，如果任务下没有子任务

p(指标) =
  平均值(p(任务[]))，如果指标下有任务
  指标自身完成率，如果指标下没有任务

p(目标) = 平均值(p(指标[]))

目标进度条 = round(p(目标) × 100%)
```

指标自身完成率由 `resultProgress(result)` 计算。
