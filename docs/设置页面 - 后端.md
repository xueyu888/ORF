# 设置页面 - 后端

## 1. 范围

当前仅实现“视觉设置”中的背景图片管理。

| 设置详情 | 后端场景值 | 说明 |
|---|---|---|
| 登录页面背景设置 | `login_background` | 管理登录页背景图片 |
| 侧边栏背景设置 | `sidebar_background` | 管理系统侧边栏背景图片 |

暂不实现：

- 周期与团队
- 反馈分类
- ORF 规则
- 存储

---

## 2. 核心能力

| 能力 | 说明 |
|---|---|
| 查询背景图片列表 | 返回指定场景下的图片列表和默认图片 |
| 上传背景图片 | 上传图片并保存为指定场景的背景图片 |
| 设置默认背景 | 将指定图片设置为该场景的默认背景 |

---

## 3. 数据模型

### 3.1 背景图片表：`visual_background_image`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | bigint / uuid | 是 | 背景图片 ID |
| `scene` | varchar | 是 | 背景场景：`login_background` / `sidebar_background` |
| `file_name` | varchar | 是 | 原始文件名 |
| `file_url` | varchar | 是 | 图片访问地址 |
| `file_key` | varchar | 是 | 文件存储路径或对象存储 key |
| `mime_type` | varchar | 是 | 文件类型 |
| `file_size` | bigint | 是 | 文件大小，单位 byte |
| `is_default` | boolean | 是 | 是否为当前场景默认图片 |
| `created_at` | datetime | 是 | 创建时间 |
| `created_by` | bigint / uuid | 否 | 上传人 ID |
| `updated_at` | datetime | 是 | 更新时间 |

### 3.2 `scene` 枚举

```ts
type VisualBackgroundScene =
  | 'login_background'
  | 'sidebar_background'
```

## 6. 接口详情

## 6.1 查询背景图片列表

### 接口

```http
GET /api/settings/visual/backgrounds?scene=login_background
```

### Query 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scene` | string | 是 | 背景场景 |

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "scene": "login_background",
    "defaultBackgroundId": "1001",
    "list": [
      {
        "id": "1001",
        "scene": "login_background",
        "fileName": "login-bg.png",
        "url": "https://example.com/uploads/login-bg.png",
        "mimeType": "image/png",
        "fileSize": 234567,
        "isDefault": true,
        "createdAt": "2026-05-07T10:00:00+08:00"
      }
    ]
  }
}
```

### 规则

| 场景 | 处理 |
|---|---|
| 图片列表为空 | 返回 `list: []`，`defaultBackgroundId: null` |
| 存在默认图片 | `defaultBackgroundId` 返回默认图片 ID |
| 不存在默认图片 | `defaultBackgroundId: null` |
| `scene` 非法 | 返回错误 |

---

## 6.2 上传背景图片

### 接口

```http
POST /api/settings/visual/backgrounds
Content-Type: multipart/form-data
```

### FormData 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scene` | string | 是 | 背景场景 |
| `file` | File | 是 | 图片文件 |

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": "1002",
    "scene": "login_background",
    "fileName": "new-bg.png",
    "url": "https://example.com/uploads/new-bg.png",
    "mimeType": "image/png",
    "fileSize": 345678,
    "isDefault": false,
    "createdAt": "2026-05-07T10:05:00+08:00"
  }
}
```

### 规则

| 规则 | 说明 |
|---|---|
| 文件类型 | 仅允许图片文件 |
| MIME 校验 | `image/jpeg`、`image/png`、`image/webp`、`image/gif` |
| 文件大小 | 默认不超过 `10MB` |
| 上传成功 | 写入数据库，返回新图片信息 |
| 上传失败 | 不写入数据库 |
| 是否自动设为默认 | 不自动设为默认，需调用设置默认接口 |

---

## 6.3 设置默认背景图片

### 接口

```http
PUT /api/settings/visual/backgrounds/{id}/default
```

### Path 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 背景图片 ID |

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": "1002",
    "scene": "login_background",
    "isDefault": true
  }
}
```

### 规则

| 规则 | 说明 |
|---|---|
| 图片不存在 | 返回错误 |
| 图片存在 | 将该图片设置为其所属 `scene` 的默认图片 |
| 同场景旧默认图片 | 自动取消默认 |
| 不同场景图片 | 不受影响 |
| 数据一致性 | 更新默认图片时需要使用事务 |

### 事务逻辑

```text
1. 根据 id 查询图片
2. 获取图片所属 scene
3. 将该 scene 下所有图片 is_default 更新为 false
4. 将当前图片 is_default 更新为 true
5. 提交事务
```

# 9. 错误码

| code | message | 说明 |
|---|---|---|
| `40001` | `invalid scene` | 非法背景场景 |
| `40002` | `file is required` | 未上传文件 |
| `40003` | `invalid file type` | 文件类型不合法 |
| `40004` | `file too large` | 文件超出大小限制 |
| `40401` | `background not found` | 背景图片不存在 |
| `50001` | `upload failed` | 文件上传失败 |
| `50002` | `set default failed` | 设置默认失败 |
