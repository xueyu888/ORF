# 设置页面 - 后端

## 1. 范围

当前仅实现“视觉设置”中的背景图片管理。

| 设置详情 | 后端场景值 | 说明 |
|---|---|---|
| 登录页面背景设置 | `login_background` | 管理登录页背景图片 |
| 侧边栏背景设置 | `sidebar_background` | 管理系统侧边栏背景图片 |

暂不实现：

- 周期与团队
- 反馈分类
- ORF 规则
- 存储

---

## 2. 核心能力

| 能力 | 说明 |
|---|---|
| 查询背景图片列表 | 扫描指定场景的 `default/` 和 `user/` 目录，返回图片列表和本地默认图片 |
| 上传背景图片 | 上传图片并保存到指定场景的 `user/` 目录 |
| 设置固定背景 | 将指定图片写入统一的本地设置文件 `public/settings/user/settings.json`，作为固定背景使用 |
| 保存背景策略 | 保存固定背景或可切换背景的显示策略 |

---

## 3. 资源目录与本地配置

### 3.1 背景资源目录

登录页面背景和侧边栏背景统一放在 `public/settings/backgrounds` 下管理。用户自己的设置配置统一放在 `public/settings/user/settings.json`。

```text
public/settings/
├── backgrounds/
│   ├── login_background/
│   │   ├── default/
│   │   │   └── 工程自带登录页背景图片
│   │   └── user/
│   │       └── 用户上传的登录页背景图片
│   └── sidebar_background/
│       ├── default/
│       │   └── 工程自带侧边栏背景图片
│       └── user/
│           └── 用户上传的侧边栏背景图片
└── user/
    └── settings.json
```

| 目录 | 说明 |
|---|---|
| `public/settings/backgrounds/login_background/default/` | 工程自带登录页背景图片，随代码提交。 |
| `public/settings/backgrounds/login_background/user/` | 用户上传登录页背景图片，本地保存，不提交 git。 |
| `public/settings/backgrounds/sidebar_background/default/` | 工程自带侧边栏背景图片，随代码提交。 |
| `public/settings/backgrounds/sidebar_background/user/` | 用户上传侧边栏背景图片，本地保存，不提交 git。 |
| `public/settings/user/settings.json` | 用户自己的本地设置配置，不提交 git。 |
| `public/settings/user/settings.json.example` | 本地设置文件结构样板，随代码提交。 |

`public/settings/backgrounds/*/user/` 保存用户上传图片，`public/settings/user/settings.json` 保存用户自己的设置配置。这些路径由 `.gitignore` 本地管理，不跟随分支合并变化。`settings.json.example` 只作为结构样板提交到仓库，后端写入背景策略时只更新 `settings.json`，不修改 `settings.json.example`。

### 3.2 本地设置文件

所有设置页的本地配置统一写入 `public/settings/user/settings.json`。

```json
{
  "visual": {
    "backgrounds": {
      "login_background": {
        "mode": "fixed",
        "fixedBackgroundId": "login_background/default/orf-login-sky-adventure.png",
        "switchTrigger": "on_open",
        "switchOrder": "random",
        "switchIntervalMinutes": 10
      },
      "sidebar_background": {
        "mode": "fixed",
        "fixedBackgroundId": "sidebar_background/default/orf-sidebar.png",
        "switchTrigger": "on_open",
        "switchOrder": "random",
        "switchIntervalMinutes": 10
      }
    }
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `visual.backgrounds.login_background` | `BackgroundSceneConfig` | 是 | 登录页面背景策略配置。 |
| `visual.backgrounds.sidebar_background` | `BackgroundSceneConfig` | 是 | 侧边栏背景策略配置。 |

`settings.json` 不存在时，后端使用 `settings.json.example` 的结构和内置兜底规则生成运行时配置。查询接口不主动创建 `settings.json`；只有用户执行“设为默认”时才写入真实的 `settings.json`。

### 3.3 背景策略配置结构

```ts
type BackgroundMode = 'fixed' | 'switchable'
type BackgroundSwitchTrigger = 'on_open' | 'interval'
type BackgroundSwitchOrder = 'sequential' | 'random'

type BackgroundSceneConfig = {
  mode: BackgroundMode
  fixedBackgroundId: string | null
  switchTrigger: BackgroundSwitchTrigger
  switchOrder: BackgroundSwitchOrder
  switchIntervalMinutes: number
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `mode` | `'fixed' / 'switchable'` | 是 | 背景模式。`fixed` 表示固定背景；`switchable` 表示可切换背景。 |
| `fixedBackgroundId` | string / null | 是 | 固定背景图片 ID。固定背景模式下使用该图片。 |
| `switchTrigger` | `'on_open' / 'interval'` | 是 | 可切换背景的触发方式。`on_open` 表示每次打开页面或进入系统时切换；`interval` 表示按时间间隔切换。 |
| `switchOrder` | `'sequential' / 'random'` | 是 | 可切换背景的切换规则。`sequential` 表示按图片列表顺序切换；`random` 表示随机切换。 |
| `switchIntervalMinutes` | number | 是 | 切换间隔，单位分钟。仅在 `mode = switchable` 且 `switchTrigger = interval` 时生效。 |

后端只保存背景策略配置，不计算运行时应该展示哪一张图片。登录页、侧边栏打开时切换、定时切换、顺序切换下标、随机选择等运行时行为由前端处理。

### 3.4 背景图片数据结构

背景图片列表由后端扫描 `default/` 和 `user/` 目录生成，不写入数据库。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 背景图片 ID，使用相对 key，例如 `login_background/default/a.png`。 |
| `scene` | string | 是 | 背景场景：`login_background` / `sidebar_background`。 |
| `fileName` | string | 是 | 文件名。 |
| `url` | string | 是 | 前端可访问的图片地址。 |
| `fileKey` | string | 是 | 相对 `public/settings/backgrounds` 的文件 key。 |
| `mimeType` | string | 是 | 文件类型。 |
| `fileSize` | number | 是 | 文件大小，单位 byte。 |
| `isDefault` | boolean | 是 | 是否为当前场景固定背景图片。 |
| `createdAt` | string | 否 | 文件创建时间。 |

### 3.5 `scene` 枚举

```ts
type BackgroundScene =
  | 'login_background'
  | 'sidebar_background'
```

## 6. 接口详情

## 6.1 查询背景图片列表

### 接口

```http
GET /api/settings/visual/backgrounds?scene=login_background
```

### Query 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scene` | string | 是 | 背景场景，只允许 `login_background` / `sidebar_background`。 |

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "scene": "login_background",
    "config": {
      "mode": "fixed",
      "fixedBackgroundId": "login_background/default/login-bg.png",
      "switchTrigger": "on_open",
      "switchOrder": "random",
      "switchIntervalMinutes": 10
    },
    "list": [
      {
        "id": "login_background/default/login-bg.png",
        "scene": "login_background",
        "fileName": "login-bg.png",
        "url": "/settings/backgrounds/login_background/default/login-bg.png",
        "fileKey": "login_background/default/login-bg.png",
        "mimeType": "image/png",
        "fileSize": 234567,
        "isDefault": true,
        "createdAt": "2026-05-07T10:00:00+08:00"
      }
    ]
  }
}
```

### 规则

| 场景 | 处理 |
|---|---|
| 查询图片 | 扫描 `public/settings/backgrounds/{scene}/default/` 和 `public/settings/backgrounds/{scene}/user/` 生成列表 |
| 默认配置 | 读取 `public/settings/user/settings.json` 中 `visual.backgrounds.{scene}` |
| 配置文件不存在 | 使用 `public/settings/user/settings.json.example` 的结构作为运行时配置，并从 `default/` 扫描结果中选择第一张图片作为 `fixedBackgroundId` 兜底；没有内置图时返回 `fixedBackgroundId: null` |
| 图片列表为空 | 返回 `list: []`，`config.fixedBackgroundId: null` |
| 存在固定背景图片 | `config.fixedBackgroundId` 返回固定背景图片 ID |
| 固定背景图片不存在 | `config.fixedBackgroundId: null` |
| `scene` 非法 | 返回错误 |

### 静态访问路径

响应中的 `url` 使用 `/settings/backgrounds/{scene}/{default 或 user}/{fileName}`。例如：

```text
URL: /settings/backgrounds/login_background/default/login-bg.png
磁盘路径: public/settings/backgrounds/login_background/default/login-bg.png
```

## 6.2 上传背景图片

### 接口

```http
POST /api/settings/visual/backgrounds
Content-Type: multipart/form-data
```

### FormData 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scene` | string | 是 | 背景场景 |
| `file` | File | 是 | 图片文件 |

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": "login_background/user/new-bg.png",
    "scene": "login_background",
    "fileName": "new-bg.png",
    "url": "/settings/backgrounds/login_background/user/new-bg.png",
    "fileKey": "login_background/user/new-bg.png",
    "mimeType": "image/png",
    "fileSize": 345678,
    "isDefault": false,
    "createdAt": "2026-05-07T10:05:00+08:00"
  }
}
```

### 规则

| 规则 | 说明 |
|---|---|
| 文件类型 | 仅允许图片文件 |
| MIME 校验 | `image/jpeg`、`image/png`、`image/webp`、`image/gif` |
| 文件大小 | 默认不超过 `10MB` |
| 上传目录 | 根据 `scene` 写入 `public/settings/backgrounds/{scene}/user/` |
| 文件命名 | 保留可读文件名，冲突时追加时间戳或短 ID，避免覆盖已有文件 |
| 上传成功 | 文件写入 `user/` 目录，返回新图片信息 |
| 上传失败 | 不写入文件；如果已写入但后续处理失败，需要删除本次写入文件 |
| 是否自动设为固定背景 | 不自动设为固定背景，需调用设置固定背景接口 |

---

## 6.3 设置固定背景图片

### 接口

```http
PUT /api/settings/visual/backgrounds/{id}/default
```

### Path 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 背景图片 ID，需要使用 `encodeURIComponent` 传入路径；例如 `login_background/default/a.png` 传为 `login_background%2Fdefault%2Fa.png`。 |

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": "login_background/user/new-bg.png",
    "scene": "login_background",
    "isDefault": true
  }
}
```

### 规则

| 规则 | 说明 |
|---|---|
| 图片不存在 | 返回错误 |
| 图片存在 | 将该图片 ID 写入 `public/settings/user/settings.json` 中对应场景的 `fixedBackgroundId`，并将 `mode` 写为 `fixed` |
| 同场景旧固定背景 | 被新的 `visual.backgrounds.{scene}.fixedBackgroundId` 覆盖 |
| 不同场景图片 | 不受影响 |
| 配置一致性 | 写入配置文件时先写临时文件，再原子替换 `settings.json` |

### 写入逻辑

```text
1. 根据 id 解析 scene 和文件路径
2. 校验图片位于该 scene 的 default/ 或 user/ 目录
3. 读取并更新 public/settings/user/settings.json 中对应 scene 的 mode 和 fixedBackgroundId
4. 写入 public/settings/user/settings.json.tmp
5. 将 settings.json.tmp 原子替换为 settings.json
6. 返回新的固定背景信息
```

## 6.4 保存背景策略配置

### 接口

```http
PUT /api/settings/visual/background-config
Content-Type: application/json
```

### 请求体

```json
{
  "scene": "login_background",
  "config": {
    "mode": "switchable",
    "fixedBackgroundId": "login_background/default/login-bg.png",
    "switchTrigger": "interval",
    "switchOrder": "sequential",
    "switchIntervalMinutes": 10
  }
}
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scene` | string | 是 | 背景场景，只允许 `login_background` / `sidebar_background`。 |
| `config.mode` | string | 是 | 背景模式，只允许 `fixed` / `switchable`。 |
| `config.fixedBackgroundId` | string / null | 是 | 固定背景图片 ID。 |
| `config.switchTrigger` | string | 是 | 触发方式，只允许 `on_open` / `interval`。 |
| `config.switchOrder` | string | 是 | 切换规则，只允许 `sequential` / `random`。 |
| `config.switchIntervalMinutes` | number | 是 | 切换间隔，单位分钟，最小 1。 |

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "scene": "login_background",
    "config": {
      "mode": "switchable",
      "fixedBackgroundId": "login_background/default/login-bg.png",
      "switchTrigger": "interval",
      "switchOrder": "sequential",
      "switchIntervalMinutes": 10
    }
  }
}
```

### 规则

| 规则 | 说明 |
|---|---|
| `scene` 非法 | 返回错误 |
| 配置枚举值非法 | 返回错误 |
| `switchIntervalMinutes` 小于 1 | 返回错误 |
| `fixedBackgroundId` 不为空但图片不存在 | 返回 `background not found` |
| `mode = fixed` | `fixedBackgroundId` 必须存在于该场景图片列表中 |
| `mode = switchable` | `fixedBackgroundId` 可以为空；前端按列表和切换策略决定展示图片 |
| 写入成功 | 更新 `public/settings/user/settings.json` 中 `visual.backgrounds.{scene}` |
# 7. 权限与本地化要求

| 接口 | 权限 |
|---|---|
| 查询背景图片列表 | 公开读取，登录页加载背景时也可调用 |
| 上传背景图片 | 登录用户 |
| 设置固定背景 | 登录用户 |
| 保存背景策略配置 | 登录用户 |

视觉设置是用户自己的本地设置，不作为团队共享配置写入数据库。用户上传图片保存在 `public/settings/backgrounds/*/user/`，背景策略配置保存在 `public/settings/user/settings.json`，并通过 `.gitignore` 保持本地化，避免合并分支后个人设置被其他人的配置覆盖。

# 8. 错误码

| code | message | 说明 |
|---|---|---|
| `40001` | `invalid scene` | 非法背景场景 |
| `40002` | `file is required` | 未上传文件 |
| `40003` | `invalid file type` | 文件类型不合法 |
| `40004` | `file too large` | 文件超出大小限制 |
| `40401` | `background not found` | 背景图片不存在 |
| `50001` | `upload failed` | 文件上传失败 |
| `50002` | `set default failed` | 设置固定背景失败 |
| `50003` | `save background config failed` | 保存背景策略配置失败 |
