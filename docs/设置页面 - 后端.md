# 设置页面 - 后端

本文只定义后端实现契约。设置业务边界以 [设置边界规则.md](./rules/设置边界规则.md) 为唯一事实源。

## 1. 目标边界

| 设置域 | 写入对象 | 写权限 | 事实源 |
|---|---|---|---|
| 个人设置 | 当前 session 用户 | 已激活登录用户本人 | 当前用户偏好和个人资源。 |
| 系统设置 | 全站配置和系统资源 | `admin` | 系统设置文件、系统背景资源和全局策略。 |

当前兼容：现有视觉背景接口和 `public/settings/user/*` 实际保存的是管理员维护的系统视觉配置。迁移时应把它们视为旧系统设置路径，不能解释为普通用户个人设置。

## 2. 数据所有权

后端模型必须能区分三类事实：

| 事实 | owner | 说明 |
|---|---|---|
| 系统视觉配置 | `system` | 登录页背景、系统默认应用背景、个人背景策略。 |
| 系统背景资源 | `system` | 管理员上传或工程内置的系统背景。 |
| 个人偏好和个人背景资源 | `userId` | 只属于当前用户本人。 |

背景场景：

| 场景 | 设置域 | 说明 |
|---|---|---|
| `login_background` | 系统设置 | 登录页背景；未登录可读取，只有管理员可写。 |
| `app_background` | 系统设置 + 个人设置 | 登录后应用背景；迁移期兼容旧 `sidebar_background`。 |

实现不变量：

- 登录页背景只能引用系统背景资源。
- 个人应用背景可以引用系统启用背景或当前用户自己的个人背景。
- 普通用户不能读取或写入其他用户个人背景。
- 个人背景上传不进入系统背景目录或系统默认资源池。

## 3. 存储边界

目标存储分层：

| 路径 | 归属 | 说明 |
|---|---|---|
| `public/settings/system/settings.json` | 系统 | 系统设置本地配置，不提交 git。 |
| `public/settings/system/settings.json.example` | 系统 | 系统设置样板，随代码提交。 |
| `public/settings/backgrounds/*/default/` | 系统 | 工程内置系统背景，随代码提交。 |
| `public/settings/backgrounds/*/system/` | 系统 | 管理员上传系统背景，本地保存，不提交 git。 |
| `public/settings/users/{userId}/backgrounds/app_background/` | 用户 | 当前用户个人应用背景，本地保存，不提交 git。 |

旧路径兼容：

- `public/settings/user/settings.json` 是旧系统视觉配置路径。
- `public/settings/backgrounds/*/user/` 是旧管理员上传系统背景路径。
- 迁移代码可以读取旧路径做兼容，但新个人设置不能继续写这些旧路径。

## 4. API 分组

目标 API 必须按作用域分组。

个人设置：

| 能力 | 权限 | 约束 |
|---|---|---|
| 读取当前用户偏好 | 已激活登录用户 | 不接受任意 `userId`。 |
| 保存当前用户偏好 | 已激活登录用户 | 只能写当前 session 用户。 |
| 读取当前用户可选应用背景 | 已激活登录用户 | 返回系统启用背景 + 本人个人背景。 |
| 上传当前用户个人背景 | 已激活登录用户且系统策略允许 | 写入当前用户个人目录。 |
| 删除当前用户个人背景 | 背景所有者本人 | 不能删除系统背景或他人背景。 |

系统设置：

| 能力 | 权限 | 约束 |
|---|---|---|
| 查询登录页系统背景 | 公开读取 | 只返回系统登录背景。 |
| 查询系统应用背景 | 已激活登录用户 | 只返回系统启用应用背景。 |
| 上传系统背景 | `admin` | 写入系统背景目录。 |
| 设置系统默认背景 | `admin` | 只能引用系统背景。 |
| 保存系统背景策略 | `admin` | 不能写入个人偏好。 |
| 保存个人背景策略 | `admin` | 只控制个人上传策略，不写个人资源。 |

旧接口兼容：

- 当前 `/api/settings/visual/*` 属于旧系统视觉接口。
- 拆分后可以保留兼容转发，但不能让它们变成个人设置接口。
- 新个人设置接口不得复用旧系统视觉写接口。

## 5. 权限不变量

- 未登录用户只能读取登录页需要的系统公开资源。
- 非管理员不能写系统设置、系统背景资源或系统默认背景。
- 个人设置写接口只能使用当前 session 用户作为写入对象。
- 所有背景引用都必须校验 owner 和 scene。
- 保存个人偏好时，不允许写入 `login_background`。
- 保存系统配置时，不允许引用个人背景资源。

## 6. 迁移步骤

1. 把现有视觉接口和文件路径标记为旧系统设置能力。
2. 增加系统设置命名空间，承接现有管理员背景配置能力。
3. 增加个人偏好和个人背景资源模型，owner 必须来自当前 session 用户。
4. 后端背景解析按设置边界规则实现：个人偏好优先，系统默认兜底。
5. 更新测试：系统背景写入继续验证 admin-only；新增个人背景正向用例。
