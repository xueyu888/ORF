# 设置页面 - 后端

本文只定义后端实现契约。设置业务边界以 [设置边界规则.md](./rules/设置边界规则.md) 为唯一事实源。

## 1. 目标边界

| 设置域 | 写入对象 | 写权限 | 事实源 |
|---|---|---|---|
| 个人设置 | 当前 session 用户 | 已激活登录用户本人 | 当前用户偏好和个人资源。 |
| 系统设置 | 全站配置和系统资源 | `admin` | 系统设置文件、系统背景资源、聊天设置和全局策略。 |
| 用户头像 | 当前 session 用户 | 已激活登录用户本人 | `users.avatar_*` 元数据和对象存储头像文件。 |

当前兼容：视觉背景接口属于系统设置能力；`public/settings/user/*` 只作为旧系统路径读取兼容，不能解释为普通用户个人设置。

## 2. 数据所有权

后端模型必须能区分三类事实：

| 事实 | owner | 说明 |
|---|---|---|
| 系统视觉配置 | `system` | 登录页、顶部栏、侧边栏和页面级皮肤默认值、个人背景策略。 |
| 聊天系统配置 | `system` | 聊天附件业务上限；基础设施上传上限只作为承载边界。 |
| 系统背景资源 | `system` | 管理员上传或工程内置的系统背景。 |
| 个人偏好和个人背景资源 | `userId` | 只属于当前用户本人；其中 `display` 保存显示偏好，`backgrounds[scene]` 保存各皮肤槽位选择、摆放和蒙层强度。 |
| 用户头像资源 | `userId` | 只允许本人上传、替换和删除；同作用域已激活用户可通过后端受控接口读取展示。 |

背景场景：

| 场景 | 设置域 | 说明 |
|---|---|---|
| `login_background` | 系统设置 + 个人设置 | 登录页背景；系统默认未登录可读，个人登录页只能登录后配置并在本机缓存预览。 |
| `topbar_background` | 系统设置 + 个人设置 | 登录后顶部栏皮肤。 |
| `sidebar_background` | 系统设置 + 个人设置 | 登录后侧边栏皮肤。 |
| `page_*_background` | 系统设置 + 个人设置 | 对应页面内容区皮肤。 |
| `app_background` | 兼容读取 | 旧 AppShell 单槽位；只作为顶部栏/侧边栏旧资源和旧偏好的兼容来源。 |

实现不变量：

- 登录页系统默认只能引用系统背景资源；个人登录页皮肤可以引用系统登录背景或当前用户自己的登录页背景。
- 个人槽位配置可以引用共享系统图库或当前用户自己的共享个人图库；其他用户个人图库不可读写。
- 图片文件、取景参数和蒙层参数分离：文件归资源目录，`crops[imageId]` 与 `overlayOpacity` 归槽位配置；`crops[imageId]` 保存 `centerX`、`centerY` 和 `zoom`，`zoom` 按 `1..3` 归一化并表示 cover 基础上的放大倍数，蒙层强度按 `0..1` 归一化。
- 普通用户不能读取或写入其他用户个人背景。
- 个人背景上传不进入系统背景目录或系统默认资源池。
- 未登录用户不能读取服务端个人背景文件；登录页个人化通过前端本机缓存预览闭环。

## 3. 存储边界

目标存储分层：

| 路径 | 归属 | 说明 |
|---|---|---|
| `public/settings/system/settings.json` | 系统 | 系统设置本地配置，不提交 git。 |
| `public/settings/system/settings.json.example` | 系统 | 系统设置样板，随代码提交。 |
| `public/settings/backgrounds/*/default/` | 系统 | 工程内置系统背景，随代码提交；规范槽位目录会合并成共享系统图库。 |
| `public/settings/backgrounds/{scene}/system/` | 系统 | 管理员上传系统背景，本地保存，不提交 git；上传来源保留为目录名，但图片可被其它规范槽位选择。 |
| `public/settings/users/{userId}/backgrounds/{scene}/` | 用户 | 当前用户个人背景，本地保存，不提交 git；上传来源保留为目录名，但图片可被当前用户自己的其它规范槽位选择。 |
| `users/{userId}/avatar/{timestamp}.{ext}` | 用户 | 当前用户头像对象存储 key；DB 只保存元数据，不暴露 key。 |

旧路径兼容：

- `public/settings/user/settings.json` 是旧系统视觉配置路径。
- `public/settings/backgrounds/*/user/` 是旧管理员上传系统背景路径。
- `public/settings/backgrounds/app_background/*` 和 `public/settings/users/{userId}/backgrounds/app_background/` 是旧 AppShell 单槽位路径，只兼容读取到顶部栏/侧边栏。
- 迁移代码可以读取旧路径做兼容，但新个人设置不能继续写这些旧路径。

## 4. API 分组

目标 API 必须按作用域分组。

个人设置：

| 能力 | 权限 | 约束 |
|---|---|---|
| 读取当前用户偏好 | 已激活登录用户 | 不接受任意 `userId`。 |
| 保存当前用户偏好 | 已激活登录用户 | 只能写当前 session 用户；`display` 字段按统一 schema 归一化，不能写系统默认。 |
| 读取当前用户某槽位可选皮肤 | 已激活登录用户 | 按 `scene` 返回共享系统图库 + 本人共享个人图库。 |
| 上传当前用户某槽位个人背景 | 已激活登录用户且系统策略允许 | 按上传入口的 `scene` 写入当前用户个人目录，但该图片会进入当前用户共享图库。 |
| 删除当前用户个人背景 | 背景所有者本人 | 不能删除系统背景或他人背景；删除后清理引用该图片的个人槽位。 |
| 上传当前用户头像 | 已激活登录用户 | 校验图片 MIME、真实文件头和大小，写入当前用户头像资源。 |
| 删除当前用户头像 | 已激活登录用户 | 只清空当前用户头像元数据并删除旧对象。 |

系统设置：

| 能力 | 权限 | 约束 |
|---|---|---|
| 查询登录页系统背景 | 公开读取 | 只返回系统登录背景。 |
| 查询非登录槽位系统皮肤 | 已激活登录用户 | 返回共享系统图库中可用于指定 `scene` 的系统皮肤。 |
| 上传系统背景 | `admin` | 按上传入口的 `scene` 写入系统背景目录，但该图片会进入共享系统图库。 |
| 保存系统背景策略 | `admin` | 只能引用系统背景，不能写入个人偏好。 |
| 保存个人背景策略 | `admin` | 只控制个人上传策略，不写个人资源。 |
| 查询聊天设置 | `admin` | 返回聊天附件业务上限和当前基础设施承载上限。 |
| 保存聊天设置 | `admin` | 只能写聊天附件业务上限，且不得超过基础设施承载上限。 |

当前接口兼容：

- 当前 `/api/settings/visual/*` 属于系统视觉接口。
- 可以保留旧 scene/scope 兼容转发，但不能让它们变成个人设置接口。
- 新个人设置接口不得复用旧系统视觉写接口。

## 5. 权限不变量

- 未登录用户只能读取登录页需要的系统公开资源。
- 非管理员不能写系统设置、系统背景资源或系统默认背景。
- 个人设置写接口只能使用当前 session 用户作为写入对象。
- 个人显示偏好只能写入当前用户偏好文件；工作台缩放、CSS token、DOM data 属性和桌面窗口缩放都是前端派生结果，不回写后端。
- 个人头像写接口只能使用当前 session 用户作为写入对象，不能接受任意 `userId`。
- 头像读取接口只能返回当前登录用户所在默认作用域内的用户头像；响应不暴露对象存储 key。
- 所有背景引用都必须校验 owner 和存储来源；任一规范槽位图片可用于任一规范槽位，旧 `app_background` 只能被顶部栏/侧边栏兼容读取。
- 保存个人偏好时允许写入 `login_background`，但该配置只属于当前用户；未登录页不能直接向后端读取它。
- 保存系统配置时，不允许引用个人背景资源。
- 旧 `appBackground` 字段只保留为读取旧个人偏好后的响应兼容投影；个人偏好写入必须使用 `backgrounds[scene]`，不能再通过旧单槽位字段同时改侧边栏和顶部栏。

## 6. 当前落地状态

1. 视觉接口已按系统设置能力收敛，并由独立 settings routes 注册。
2. 系统设置写入 `public/settings/system/settings.json`，读取兼容旧 `public/settings/user/settings.json`。
3. 规范场景是 `login_background`、`topbar_background`、`sidebar_background` 和 `page_*_background`；旧 `app_background` 只作为顶部栏/侧边栏兼容来源，不再作为新写入入口。
4. 规范系统上传 scope 是 `system`；旧 `user` scope 只作为旧管理员上传目录兼容读取。
5. 个人偏好接口写入当前 session 用户；`display` 字段统一保存工作台缩放、界面字号、内容字号、界面密度和高对比度。
6. 个人背景读取按 `scene` 返回共享系统图库和当前用户共享个人图库；其他用户个人背景不可读写。
7. 用户头像元数据写入 `users.avatar_*`，头像文件写入对象存储；`avatarUrl` 只作为用户和评论读模型派生字段返回。
8. 聊天附件上限写入系统设置的 `chat.attachmentMaxBytes`，默认 2GiB；`ORF_INFRA_UPLOAD_MAX_BYTES` 是基础设施承载上限，默认 10GiB，不反向定义聊天业务规则。
