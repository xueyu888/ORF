# 权限管理

## 结论

当前只用 Kratos。暂时不上 Keto、Hydra、Oathkeeper。


## 权限模型

```text
can(user, orf_stage, action, resource )
```

```text
user       当前用户
orf_stage  目标设定 / 指标领取 / ORF 重估 / 目标冻结
action     查看 / 编辑 / 创建
resource   目标 / 指标 / 任务 / 子任务
```

权限规则不写死，来自权限配置。

```text
role + orf_stage + resource -> actions[]
```

## 页面

| 页面             | 功能                       |
| ---------------- | -------------------------- |
| 注册登录页       | 注册 / 登录 / 找回密码     |
| 用户权限管理页面 | 配置角色、阶段、资源、操作 |

## 默认权限

管理员默认所有权限。

普通成员默认配置：

| ORF 阶段     | 普通成员权限                               |
| ------------ | ------------------------------------------ |
| 目标设定阶段 | 查看目标和指标                             |
| 指标领取阶段 | 查看目标和指标                             |
| ORF 重估阶段 | 编辑目标/指标/任务/子任务；创建任务/子任务 |
| 目标冻结阶段 | 查看目标/指标；创建/编辑任务/子任务        |

用户权限管理页面可修改以上配置。

## 当前架构

```text
Kratos：身份认证
业务库：角色、ORF 阶段、资源关系、权限配置
后端：Permission Service
```

```text
Frontend
  |
Backend API
  |
Auth Middleware：校验 Kratos Session，得到 user_id
  |
Permission Service：读取权限配置，执行 can(...)
  |
Business Service
```
