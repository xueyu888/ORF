# 积分自动计算规则

## 计分对象
积分按指标计算。
每个指标由管理员分配负责人并设定截止时间。
指标截止时间不得超过目标截止时间。

## 时间规则
resultStartAt = 指标分配时间
resultDueAt = 指标截止时间
objectiveDueAt = 目标截止时间
orfReestimateDueAt = resultStartAt + (resultDueAt - resultStartAt) × 30%
resultDueAt ≤ objectiveDueAt

## 积分公式
resultPoints = uncertaintyScore × completionMultiplier
memberPoints = sum resultPoints where result.owner = member

## 不确定性分
| 等级 | 分值 |
| --- | ---: |
| 入门 | 1 |
| 进阶 | 3 |
| 破局 | 9 |
| 渡劫 | 27 |
| 飞升 | 81 |

## 完成系数
| 结果 | 系数 | 判定 |
| --- | ---: | --- |
| 按时完成 | 100% | 自动 |
| 延期完成 | 50% | 自动 |
| 按时指标证伪 | 100% | 管理员确认 |
| 延期指标证伪 | 50% | 管理员确认 |
| 重估阶段内目标推翻 | 100% | 管理员确认 |
| 主动放弃 | 0% | 管理员确认 |
| 超预期完成 | 150% | 管理员确认 |

## 判定规则
按时完成：acceptedResult = completed, acceptedAt ≤ resultDueAt
延期完成：acceptedResult = completed, acceptedAt > resultDueAt
重估阶段内目标推翻：acceptedResult = goalInvalidated, acceptedAt ≤ orfReestimateDueAt

## 管理员评价接口
字段：acceptedResult, acceptedAt, acceptedBy, evaluationNote
acceptedResult：completed, falsified, goalInvalidated, abandoned, overExpected, rejected
