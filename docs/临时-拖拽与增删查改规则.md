# 临时 - 拖拽与增删查改规则

本文是讨论稿，暂不作为正式产品规则。

## 1. 基本结构

任务管理页固定四层：

```text
目标
└─ 指标
   └─ 任务
      └─ 子任务
```

所有新增、编辑、删除都不能破坏这个结构。

## 2. 拖拽规则

拖拽属于编辑操作，只用于调整位置或父对象，不等于删除后重新创建。

拖拽后的对象应保留原对象身份，包括标题、状态、评论、历史记录等信息。

| 对象 | 规则 |
| --- | --- |
| 目标 | 不支持拖拽。 |
| 指标 | 只能在同一目标内调整顺序，不支持移动到其他目标。 |
| 任务 | 可以在同一指标内调整顺序，也可以移动到其他指标下。 |
| 子任务 | 可以在同一任务内调整顺序，也可以移动到其他任务下。 |

层级转换规则：不允许对象之间转换。

## 3. 增删查改原则

所有操作都走统一权限模型：

```text
can(user, orf_stage, action, resource)
```

建议操作类型：

```text
查看 / 创建 / 编辑 / 删除
```

| 操作 | 原则 |
| --- | --- |
| 查看 | 只能查看有权限的对象。 |
| 创建 | 只能在有权限的层级下创建对象。 |
| 编辑 | 只能编辑有权限的对象和字段；拖拽调整位置或父对象也属于编辑。 |
| 删除 | 只能删除有权限的对象。 |

## 4. 新增规则

| 点击位置 | 新增内容 |
| --- | --- |
| 目标行 `+` | 在该目标下新增指标。 |
| 指标行 `+` | 在该指标下新增任务。 |
| 任务行 `+` | 在该任务下新增子任务。 |
| 子任务行 `+` | 在当前子任务下方新增同级子任务。 |

## 5. 编辑规则

| 对象 | 可编辑内容 |
| --- | --- |
| 目标 | 标题、状态等目标字段。 |
| 指标 | 标题、负责人、指标数值、状态等指标字段。 |
| 任务 | 标题、状态、完成情况等任务字段。 |
| 子任务 | 标题、完成情况等子任务字段。 |

拖拽调整对象顺序或父对象，属于编辑。

派生状态不直接编辑，例如目标进度、指标展示状态等，应由底层字段计算得到。

## 6. 删除规则

删除需要独立权限，不能因为有编辑权限就默认可以删除。

| 对象 | 删除原则 |
| --- | --- |
| 目标 | 默认只允许管理员删除。 |
| 指标 | 默认只允许管理员删除。 |
| 任务 | 有删除权限即可删除。 |
| 子任务 | 有删除权限即可删除。 |

删除有下级的对象时，前端需要二次确认，并明确提示受影响的下级对象数量；后端仍需校验删除权限和对象关系。


| 删除对象 | 影响 |
| --- | --- |
| 目标 | 会影响其下指标、任务、子任务。 |
| 指标 | 会影响其下任务、子任务。 |
| 任务 | 会影响其下子任务。 |
| 子任务 | 只影响自身。 |

## 7. 默认权限建议

| 阶段 | 普通成员建议权限 |
| --- | --- |
| 目标设定 | 查看目标、指标。 |
| 指标领取 | 查看目标、指标。 |
| ORF 重估 | 编辑目标、指标、任务、子任务；创建任务、子任务。 |
| 目标冻结 | 查看目标、指标；创建、编辑任务和子任务。 |

管理员默认拥有全部权限。
