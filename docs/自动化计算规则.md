
# 目标完成的自动化计算规则


## 目标

定义单个目标在冻结阶段后的自动化完成状态计算规则。

计算层级为：

```text
goal → ret → task → subtask
````

其中：

```text
goal 表示目标
ret 表示指标
task 表示任务
subtask 表示子任务
```

系统只自动计算：

```text
task
ret
goal
```

`subtask` 是最小状态输入，不再继续计算。

---

## 最小基

设单个目标为：

```text
g
```

目标 `g` 下的指标集合为：

```text
R = {r₁, r₂, ..., rₙ}, n ≥ 1
```

指标 `rᵢ` 下的任务集合为：

```text
Tᵢ = {tᵢ₁, tᵢ₂, ..., tᵢₘᵢ}, mᵢ ≥ 1
```

任务 `tᵢⱼ` 下的子任务集合为：

```text
Sᵢⱼ = {sᵢⱼ₁, sᵢⱼ₂, ..., sᵢⱼₖᵢⱼ}, kᵢⱼ ≥ 0
```

状态域为：

```text
B = {0, 1}
```

其中：

```text
1 = done
0 = undone
```

定义叶子状态函数：

```text
d(x) ∈ B
```

其中 `x` 只能是：

```text
没有 subtask 的 task
或 subtask
```

定义系统计算函数：

```text
C(x) ∈ B
```

其中 `x` 只能是：

```text
task
ret
goal
```

---

## 组合原则

### 1. task 的计算

对于任务 `tᵢⱼ`：

```text
C(tᵢⱼ) =
{
  d(tᵢⱼ),              kᵢⱼ = 0
  ∧ₗ d(sᵢⱼₗ),          kᵢⱼ > 0
}
```

即：

```text
task 没有 subtask 时，由 task 自身状态决定。
task 有 subtask 时，由全部 subtask 状态决定。
```

---

### 2. ret 的计算

对于指标 `rᵢ`：

```text
C(rᵢ) = ∧ⱼ C(tᵢⱼ)
```

即：

```text
ret done ⇔ ret 下所有 task done
```

---

### 3. goal 的计算

对于目标 `g`：

```text
C(g) = ∧ᵢ C(rᵢ)
```

即：

```text
goal done ⇔ goal 下所有 ret done
```

---

## 组合空间

单个目标的合法组合空间为：

```text
g
└── rᵢ, i = 1...n, n ≥ 1
    └── tᵢⱼ, j = 1...mᵢ, mᵢ ≥ 1
        └── sᵢⱼₗ, l = 1...kᵢⱼ, kᵢⱼ ≥ 0
```

约束为：

```text
goal 下至少有 1 个 ret
ret 下至少有 1 个 task
task 下可以有 0 个或多个 subtask
```

因此合法路径只有两类：

```text
goal → ret → task
```

和：

```text
goal → ret → task → subtask
```

最终计算式为：

```text
C(g) = ∧ᵢ ∧ⱼ F(tᵢⱼ)
```

其中：

```text
F(tᵢⱼ) =
{
  d(tᵢⱼ),              kᵢⱼ = 0
  ∧ₗ d(sᵢⱼₗ),          kᵢⱼ > 0
}
```
