# 积分自动计算规则

## 接口访问约定

前端数据统一通过同源 `/api` 请求后端接口，例如 `/api/tasks`。
前端不直接写死后端域名或端口，开发和生产环境由代理或网关转发到实际后端服务。

本文档记录积分自动计算的后端规则口径、字段和判定条件。

前端展示、交互和 UI 状态见 [积分自动计算规则 - 前端.md](../frontend/积分自动计算规则%20-%20前端.md)。

目标完成后的个人贡献比例和匿名互评规则见 [贡献评价与积分分配规则.md](./贡献评价与积分分配规则.md)。

业务文案中称为指挥官的采纳、确认和验收动作，权限上均按管理员处理。

## 计分对象
积分按目标协作结算。
目标总积分由目标下已验收悬赏指标的难度分相加得到。
个人积分不提前绑定到某个成员；目标验收后，按匿名互评得到的最终贡献比例分配。

每个悬赏指标由管理员确认挑战者并设定截止时间。
悬赏指标截止时间不得超过目标截止时间。
`Result.owner` 只表示当前挑战者或过程负责人，不等同最终积分归属。

悬赏指标定义分奖励把目标拆成有效悬赏指标，作为独立奖励结算，不进入目标总积分。

## 时间规则
resultStartAt = 悬赏指标分配时间
acceptedAt = 挑战者接受挑战时间
resultDueAt = 悬赏指标截止时间
objectiveDueAt = 目标截止时间
resultDueAt ≤ objectiveDueAt

悬赏指标确认期按 [ORF 游戏化流程设计.md](./ORF%20游戏化流程设计.md) 计算：

```text
剩余时间 = resultDueAt - acceptedAt
原始确认期 = 剩余时间 × 30%
确认期 = clamp(roundToHalfDay(原始确认期), 0.5 天, 9 天)
confirmationDueAt = acceptedAt + 确认期
```

## 积分公式
definitionPoints = 2

objectiveBasePoints = sum uncertaintyScore where result.acceptedResult in (completed, falsified)

objectiveSettlementPoints = objectiveBasePoints × objectiveCompletionMultiplier

memberSettlementPoints = objectiveSettlementPoints × contributionRatio(member)

memberPoints = sum definitionPoints where result.definer = member and result.acceptedResult in (completed, falsified)
  + memberSettlementPoints

## 不确定性分
| 等级 | 不确定性分 | 判断标准 |
| --- | ---: | --- |
| 入门 | 10 | 路径非常清楚，有现成方案可以参考。大部分悬赏指标的不确定性分默认为 10。 |
| 进阶 | 30 | 方向清楚，有成熟参考方案，不需要创造新方法。但复杂度明显更高。 |
| 破局 | 90 | 没有现成答案，需要定义新的判断标准、评估口径、业务规则或验证方法，并通过实际数据证明可行。 |
| 渡劫 | 270 | 关键假设本身不确定，可能推翻原目标；需要跨业务、数据、模型、产品多方验证，失败概率高。 |
| 飞升 | 810 | 需要形成行业级、平台级或方法论级突破，完成后显著改变现有能力边界。 |

## 悬赏指标定义分
悬赏指标定义分固定为 2 分。

悬赏指标定义分在正式悬赏指标完成或有效证伪后发放给悬赏指标定义人。

成员提出的候选悬赏指标被指挥官采纳时不立即发放定义分；只有该悬赏指标最终完成或有效证伪后，才给定义人发放 2 分。

悬赏指标定义分不随不确定性等级变化，也不受完成系数、完成时间或后续执行人影响。

如果候选悬赏指标被合并后采纳，由管理员在采纳或验收时确认悬赏指标定义分归属；未进入正式悬赏指标，或正式悬赏指标最终未完成且未有效证伪，不产生悬赏指标定义分。

## 完成分

完成分不额外乘以 10：

```text
目标完成分 = 目标总积分 × 完成系数
```

按时完成的完成系数为 100%，目标完成分等于目标总积分。

## 完成系数
| 结果 | 系数 | 判定 | 规则 |
| --- | ---: | --- | --- |
| 按时完成 | 100% | 自动 | acceptedResult = completed, acceptedAt ≤ resultDueAt |
| 延期完成 | 50% | 自动 | acceptedResult = completed, acceptedAt > resultDueAt |
| 按时悬赏指标证伪 | 100% | 管理员确认 |  |
| 延期悬赏指标证伪 | 50% | 管理员确认 |  |
| 重估阶段内目标推翻 | 100% | 管理员确认 |  |
| 主动放弃 | 0% | 管理员确认 |  |
| 超预期完成 | 150% | 管理员确认 |  |
