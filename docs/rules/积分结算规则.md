# 积分结算规则

## 计分对象

- 积分按悬赏目标结算。
- `Objective` 是积分分配对象。
- `Result` 只统计目标总分，不直接分配给个人。
- 目标参与成员来自 `Objective.challengers`。
- 个人贡献比例由目标级匿名互评产生，规则见 [贡献评价与积分分配规则.md](./贡献评价与积分分配规则.md)。

## 时间字段

| 字段 | 含义 |
| --- | --- |
| `Objective.acceptedAt` | 挑战者接受目标挑战时间 |
| `Objective.finalDueAt` | 目标截止时间 |
| `Objective.lootSubmittedAt` | 目标战利品提交时间 |

按时或延期只看 `lootSubmittedAt`，不看接受时间或验收时间。

重估和冻结状态见 [ORF 悬赏目标流程设计.md](./ORF%20悬赏目标流程设计.md)。

## 公式

```text
definitionPoints = 2

objectiveBasePoints =
  sum(result.uncertaintyScore)

objectiveSettlementPoints =
  objectiveBasePoints × objectiveCompletionMultiplier

memberSettlementPoints =
  objectiveSettlementPoints × contributionRatio(member)

memberPoints =
  sum(pointLedger.points where memberName = currentMember)
```

## 不确定性分

| 等级 | 分值 | 判断标准 |
| --- | ---: | --- |
| 入门 | 10 | 路径清楚，有现成方案 |
| 进阶 | 30 | 方向清楚，但复杂度更高 |
| 破局 | 90 | 需要定义新方法、新标准或新验证口径 |
| 渡劫 | 270 | 关键假设不确定，可能推翻原目标 |
| 飞升 | 810 | 平台级、行业级或方法论级突破 |

## 指标定义分

- 定义分规则保留为后续扩展，当前实现不单独发放定义分。
- 当前排行榜只读取 `pointLedger` 中的目标结算积分。

候选指标的优先参与规则未定，见 [ORF 悬赏目标流程设计.md](./ORF%20悬赏目标流程设计.md)。

## 完成系数

| 目标结果 | 系数 | 规则 |
| --- | ---: | --- |
| 按时完成 | 100% | `acceptedResult = completed` 且 `lootSubmittedAt <= finalDueAt` |
| 延期完成 | 50% | `acceptedResult = completed` 且 `lootSubmittedAt > finalDueAt` |
| 按时有效证伪 | 100% | `acceptedResult = falsified` 且 `lootSubmittedAt <= finalDueAt` |
| 延期有效证伪 | 50% | `acceptedResult = falsified` 且 `lootSubmittedAt > finalDueAt` |
| 目标被有效推翻 | 100% | `acceptedResult = overturned`，且指挥官确认目标本身不成立 |
| 主动放弃 | 0% | 无有效战利品或证伪报告 |
| 超预期完成 | 150% | 管理员确认明显超过验收标准 |

## 验收

目标验收时，管理员确认：

- 每个指标的验收结果。
- 目标结果由指标验收结论汇总；全部指标完成则目标完成。
- 匿名互评贡献结果；有分歧、缺评或申诉时由管理员处理。

任务和子任务勾选状态不计分，也不自动产生验收结果。排行榜读取后端生成的 `pointLedger`。
