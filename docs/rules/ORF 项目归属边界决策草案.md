# ORF 项目归属边界决策

## 文档状态

本文档记录当前已采纳的项目归属边界。项目不是目标生命周期的一部分，也不是权限、结算或数据隔离边界；它只是一层轻量归属容器，用来把同一个项目下的目标在挑战页聚合展示。

## 当前事实

- `Objective` 是悬赏、挑战、战利品和积分结算的核心对象。
- `Result` 是目标下的验收指标和计分基础。
- `Task` 是目标下的执行行动项，不归属于 `Result`。
- `Feedback` 绑定目标和指标，但不推进悬赏目标状态机。
- `pointLedger` 是公开积分结果，排行榜只读取后端结算后的积分流水。
- `team_id` 只表达底层默认作用域和存储隔离，不表达项目管理语义。
- `Project` 是轻量项目注册表，只保存项目身份和名称。
- `Objective.projectId` 是目标归属项目的唯一持久字段，可为空。

## 已采纳方案：可选项目归属

目标可以放进项目，也可以保持未归属。项目归属由指挥官操作，普通成员不能创建项目、移动目标归属或把目标移出项目。

### 状态链

```text
Project registry
-> Objective.projectId | null
-> 挑战页项目分组 / 未归属目标分组
-> Objective 下的 Result / Task / Loot / Comment 等仍按目标派生展示
```

### 唯一事实源

- 项目名称的事实源是 `Project.name`。
- 目标项目归属的事实源是 `Objective.projectId`。
- “未归属目标”是展示桶，不是真实项目，不写入 `Project`。
- `Result`、`Task`、`Feedback`、战利品、评论、消息和积分不保存项目字段，只从所属目标派生项目上下文。

### 不变量

- `Objective.projectId` 可以为空；无项目目标是合法状态。
- 目标引用不存在的项目时，读模型按未归属处理，避免旧数据阻塞展示。
- 项目归属只影响挑战页聚合展示，不改变目标生命周期状态机。
- 项目不是权限边界，不改变当前用户可见目标集合。
- 项目不是 `team_id`，不得复用团队表或默认作用域表达项目业务语义。
- 项目不是结算边界，不改变积分公式、排行榜事实源或公开积分流水。

## 前端契约

- `/tasks` 以项目为一级分组展示目标；没有项目的目标进入“未归属目标”分组。
- 已创建但暂无目标的项目也要显示，让指挥官可以直接往项目里添加目标。
- 原有“我的 / 全部”、周期、成员和状态筛选先决定可见目标集合，项目分组只对筛选后的目标做展示聚合。
- 指挥官可以在挑战页创建项目。
- 指挥官可以在目标行上把目标放入项目、移动到其他项目或移出项目。
- 指挥官可以删除项目；删除只移除 `Project` 注册表记录，项目下目标保留并回到“未归属目标”。
- 新建目标可以从项目分组发起并继承该项目，也可以从全局入口创建为未归属目标。
- 第一阶段不做 AppShell 全局项目切换器，不做项目成员、项目权限、项目归档、项目状态流或项目管理页面。

## 后端契约

- 新增 `projects` 表，项目归属名称只从该表读取。
- `objectives.project_id` 可空，并引用 `projects.id`；项目删除时目标归属置空。
- 创建项目、更新目标项目归属需要指挥官权限。
- 创建目标时允许传入 `projectId`，也允许为空。
- 创建目标时如果传入不存在或不属于当前作用域的 `projectId`，请求失败。
- 更新目标项目归属时如果传入不存在或不属于当前作用域的 `projectId`，请求失败。
- 删除项目时只删除项目注册表记录，引用该项目的目标必须置为未归属。
- 读模型必须返回 `projects` 与 `objectives`，前端用两者组合出项目分组。

## 暂不实现的内容

- 不把项目做成 AppShell 常驻上下文。
- 不把项目做成权限边界。
- 不做项目成员、项目角色、项目私有性或项目级可见性。
- 不做项目归档、恢复或项目状态流。
- 不把旧目标强制迁入“默认项目”。
- 不保存 `Objective.projectName` 或任何下游项目名称副本。
- 不用标题、标签、周期或 reason 文本模拟项目事实源。
- 不改变积分结算公式、匿名互评、本地结算服务或公开 `pointLedger` 的事实源边界。

## 后续可能扩展

只有当项目真的成为业务隔离边界时，才进入更重的 Project 方案：

- 项目级成员和角色。
- 项目级可见性和消息投递。
- 项目归档后的可读、可写和统计范围。
- 榜单、反馈收件箱和消息中心的项目筛选或项目上下文。

进入这些扩展前必须重新决策，因为它们会改变权限边界、读模型范围、消息投递、评论 mention、统计口径、测试数据隔离和旧数据迁移策略。
