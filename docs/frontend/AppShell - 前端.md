# AppShell - 前端说明

## 1. 页面目录

AppShell 是登录后页面共享的全局外壳。
当前文档只描述全局外壳 UI；业务对象的创建和编辑由对应业务页面承载。

注册成功但尚未审核通过的用户不进入 AppShell，只展示等待审核页。当前产品只有一个默认作用域，不提供团队切换入口。

### 1.1 页面关系

```text
ORF
└─ AppShell                    ← 当前文档
   ├─ 悬赏大厅
   ├─ 我的挑战
   ├─ 反馈
   ├─ 统计
   ├─ 成员管理
   ├─ 权限管理
   ├─ 系统设置
   └─ 用户区
      └─ 个人设置
```

## 2. 当前页页面结构

AppShell 由外壳背景层、侧边栏、顶部栏、页面内容出口和全局浮层组成。

### 2.1 页面结构示意图

```text
┌───────────────┬──────────────────────────────────────────────────────────────┐
│ Sidebar       │ Topbar                                                       │
│ 悬赏大厅      │ 当前路径              全局搜索        新建反馈*   新建目标* 消息 │
│ 我的挑战      ├──────────────────────────────────────────────────────────────┤
│ 反馈          │ PageOutlet                                                   │
│ 统计          │ 当前路由页面内容                                             │
│ 成员管理      │                                                              │
│ 权限管理      │                                                              │
│ 系统设置      │                                                              │
│ 用户区        ├──────────────────────────────────────────────────────────────┤
│               │ GlobalLayer                                                  │
│               │ CommandMenu / GlobalModals / Toasts           shown as needed │
└───────────────┴──────────────────────────────────────────────────────────────┘
```

`*` 悬赏大厅路由不展示顶部栏新建反馈；全局搜索和有权限的 `新建目标` 在所有 AppShell 页面展示。

### 2.2 页面区域说明

| 区域 | 含义 | 说明 |
| --- | --- | --- |
| `AppShellSkinLayers` | 外壳与内容皮肤层 | 侧边栏、顶部栏和当前页面内容区分别消费独立皮肤槽位；每个槽位先取当前用户个人偏好，缺省时回退系统默认；页面内容槽位按当前路由映射到页面级皮肤 |
| `DisplayPreferenceTokens` | 显示偏好投射层 | 使用当前用户个人显示偏好派生根字号、工作台缩放、内容字号、控件密度、行高和高对比度 token；页面和组件只消费 token，不各自保存显示规则 |
| `Sidebar` | 全局侧边栏 | 展示主要导航入口；底部用户区收纳个人设置和退出；管理区按权限展示系统管理 |
| `Topbar` | 顶部栏 | 展示当前路径和全局搜索入口；`新建目标` 按权限展示并跳转到挑战页创建入口 |
| `SystemBroadcastBanner` | 系统广播横幅 | 展示实时公共通知，例如新悬赏发布和兼容旧客户端的更新公告；点击跳转到关联对象，不替代聊天里的系统会话 |
| `ClientUpdateNotice` | 客户端更新提示 | 进入 AppShell 后立即检查客户端更新，之后每 10 分钟检查一次；收到 `client.update.available` 实时事件时立即补查一次；只消费更新检查结果，不改变消息事实源 |
| `PageOutlet` | 页面内容出口 | 展示当前路由页面 |
| `GlobalLayer` | 全局浮层 | 承载命令菜单、非目标创建类全局弹窗和 Toast |

## 3. 组件树与字段说明

本节说明 AppShell 由哪些组件组成，以及每个组件展示哪些字段。

### 3.1 组件树

```text
<AppShell>
├─ <AppShellSkinLayers>
├─ <DisplayPreferenceTokens>
├─ <Sidebar>
├─ <Topbar>
│  ├─ <BreadcrumbTitle>
│  ├─ <CommandSearchTrigger>
│  └─ <GlobalActions>
├─ <SystemBroadcastBanner>
├─ <ClientUpdateNotice>
├─ <PageOutlet>
└─ <GlobalLayer>
   ├─ <CommandMenu>
   ├─ <GlobalModals>
   └─ <Toasts>
```

### 3.2 通用组件字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<Sidebar>` | 导航项 | 页面入口 | 图标 + 文本 | 悬赏大厅、我的挑战、工作日志、聊天、反馈、统计、成员管理、权限管理、系统设置 |
| `<Sidebar>` | 用户区操作 | 用户菜单 | 用户头像 + 用户名 | 个人设置、关于与更新、退出；个人设置对所有 `active` 用户展示 |
| `<Topbar>` | `<BreadcrumbTitle>` | 当前路径 | 文本 | 根据当前路由展示 |
| `<Topbar>` | `<CommandSearchTrigger>` | 全局搜索入口 | 搜索按钮 | 所有 AppShell 页面展示 |
| `<Topbar>` | `<GlobalActions>` | 全局主操作 | 按钮组 | 有目标创建权限时展示 `新建目标` 并进入挑战页；非悬赏大厅页面且当前用户为 active 成员时展示 `新建反馈` |
| `<ClientUpdateNotice>` | 更新提示 | 客户端版本更新 | 页面内提示条 + 桌面首次提醒弹窗 | 运行中的 Win11 和 Android 客户端每 10 分钟检查一次；服务端发现带 Win11 安装包的新版本时会通过实时事件唤醒一次检查；移动端只展示页面流内提示，不使用全屏遮罩 |
| `<PageOutlet>` | 当前页面 | 当前路由内容 | 页面内容 | 由路由决定 |
| `<GlobalLayer>` | `<CommandMenu>` | 全局命令菜单 | 弹窗 | 按需出现 |
| `<GlobalLayer>` | `<GlobalModals>` | 全局业务弹窗 | 弹窗 | 承载反馈、指标、行动项、征召等浮层；不承载目标创建 |
| `<GlobalLayer>` | `<Toasts>` | 操作反馈 | Toast | 按需出现；移动端避让底部导航 |

### 3.3 当前页内容字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<CommandMenu>` | 搜索输入 | 搜索页面、动作和 ORF 对象 | 输入框 | 支持页面、新建目标动作、目标、指标、任务、反馈 |
| `<CommandMenu>` | 搜索结果 | 命中的页面、动作或对象 | 列表 | 页面和对象点击后跳转；动作点击后执行对应全局命令 |
| `<CommandMenu>` | 新建目标 | 创建目标入口 | 动作 | 跳转到 `/tasks` 的页面内创建入口 |
| `<GlobalModals>` | 新建反馈 | 创建反馈入口 | 弹窗 | 从顶部栏打开 |
| `<Toasts>` | 提示信息 | 操作结果反馈 | Toast | 自动消失 |

`/tasks/objectives/:objectiveId/loot` 的顶栏标题固定展示为 `目标战利品`；页面内容区再按当前状态展示 `提交战利品`、`提交匿名互评` 或 `验收战利品`。

## 4. 交互与状态

本节描述 AppShell 的核心 UI 交互和页面状态。

### 4.1 核心交互

| 交互 | 说明 |
| --- | --- |
| 切换页面 | 点击侧边栏导航进入对应页面 |
| 打开全局搜索 | 点击顶部栏搜索入口或使用快捷键打开命令菜单 |
| 搜索跳转 | 在命令菜单中选择页面或对象后跳转；选择动作时执行动作 |
| 新建目标 | 有目标创建权限时，点击顶部栏 `新建目标` 或命令菜单动作进入 `/tasks` 页面内创建入口 |
| 新建反馈 | 非悬赏大厅页面且当前用户为 active 成员时，点击顶部栏 `新建反馈` 打开全局弹窗 |
| 查看系统消息 | 进入聊天侧栏的 `系统公告` 或 `我的系统通知`；点击系统消息打开关联对象，或在消息内回复到目标评论 |
| 查看更新 | 客户端发现新版本时展示页面内提示；桌面端可额外出现首次提醒弹窗；移动端不使用全屏更新遮罩 |
| 打开个人设置 | 点击侧边栏用户菜单里的 `个人设置` 进入 `/settings`，管理当前用户偏好 |
| 调整界面显示 | 在个人设置中修改工作台缩放、界面字号、内容字号、界面密度或高对比度后，AppShell 立即重新派生全局显示 token；工作台缩放也支持全局快捷键快速调整，桌面端同步到当前窗口 |
| 打开系统管理 | 管理员点击侧边栏 `系统管理` 进入 `/system`，默认跳转到成员管理 |
| 打开系统设置 | 管理员在系统管理页切换到 `系统设置` 进入 `/system/settings` |
| 关闭浮层 | 点击遮罩、关闭按钮或完成操作后关闭浮层 |

### 4.2 页面状态

| 状态 | 说明 |
| --- | --- |
| 默认态 | 展示侧边栏、顶部栏和当前页面 |
| 命令菜单打开态 | 全局搜索弹窗打开 |
| 弹窗打开态 | 非目标创建类全局弹窗打开 |
| Toast 展示态 | 页面右侧展示操作反馈 |
| 客户端更新提示态 | 页面内容上方展示更新提示；桌面端可出现首次提醒弹窗，移动端保持在页面流中 |
| 系统会话态 | 聊天页打开 `系统公告` 或 `我的系统通知`，展示系统消息、已读/未读、打开目标和回复入口 |
| 注册待审核态 | 已登录但 `currentUser.status=pending`，展示等待审核说明，不加载业务页面 |
| 注册拒绝态 | 已登录但 `currentUser.status=rejected`，展示注册未通过说明，不加载业务页面 |
| 账号停用态 | 已登录但 `currentUser.status=disabled`，展示账号已停用说明，不加载业务页面 |

### 4.3 交互细则

| 交互 | 细则 |
| --- | --- |
| 全局搜索 | 所有 AppShell 页面在顶部栏展示搜索入口；侧边栏用户区不承载搜索入口 |
| 全局搜索 | 命令菜单可以搜索页面、动作、目标、指标、任务、反馈 |
| 全局操作 | `新建目标` 按权限展示但不拥有目标表单；`新建反馈` 仅在非悬赏大厅页面且当前用户为 active 成员时展示 |
| 系统消息入口 | 系统消息入口收敛到聊天页系统会话；不再提供顶部栏铃铛或独立消息页 |
| 路由标题 | 顶部标题根据当前路径生成 |
| 个人设置 | 侧边栏用户菜单对所有 `active` 用户展示；入口只管理当前用户偏好 |
| 显示偏好 | 工作台缩放、界面字号、内容字号、界面密度和高对比度来自当前用户 `personalPreferences.display`；Web 端工作台缩放合入根字号，桌面端工作台缩放交给 Electron 窗口缩放，其他显示 token 继续由 AppShell 应用 |
| 系统设置 | 只对管理员展示；入口管理系统默认和全局策略 |
| AppShell 皮肤 | 登录后侧边栏使用 `sidebar_background`，顶部栏使用 `topbar_background`，页面内容区按路由使用对应 `page_*_background`；每个槽位都先取当前用户个人偏好，缺省时回退系统默认；图库图片在规范槽位间共享，页面设置可一次保存到全部或部分页面；旧 `app_background` 只兼容回退到侧边栏和顶部栏，不再影响页面内容区；顶部栏、侧边栏和页面内容区统一由固定 frame 背景槽位组件渲染，`crops[imageId]` 的 `centerX`、`centerY` 和 `zoom` 只影响 frame 内 cover-crop 取景，`zoom=1` 表示刚好铺满且不能露底，不移动槽位本体 |
| 移动端全局提示 | 系统广播、客户端更新提示和 Toast 都是展示状态；移动端必须避让底部导航和主内容，不得用非用户主动打开的全屏遮罩挡住当前页面 |
