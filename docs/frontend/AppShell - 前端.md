## 2. 当前页页面结构

AppShell 由侧边栏、顶部栏、页面内容出口和全局浮层组成。

### 2.1 页面结构示意图

```text
┌───────────────┬──────────────────────────────────────────────────────────────┐
│ Sidebar       │ Topbar                                                       │
│ 计划          │ 当前路径              全局搜索        新建反馈    新建目标    │
│ 反馈          ├──────────────────────────────────────────────────────────────┤
│ 统计          │ PageOutlet                                                   │
│ 成员管理      │ 当前路由页面内容                                             │
│ 权限管理      │                                                              │
│ 设置          ├──────────────────────────────────────────────────────────────┤
│               │ GlobalLayer                                                  │
│               │ CommandMenu / GlobalModals / Toasts           shown as needed │
└───────────────┴──────────────────────────────────────────────────────────────┘
```

### 2.2 页面区域说明

| 区域 | 含义 | 说明 |
| --- | --- | --- |
| `Sidebar` | 全局侧边栏 | 展示主要导航入口 |
| `Topbar` | 顶部栏 | 展示当前路径、全局搜索入口和全局主操作 |
| `PageOutlet` | 页面内容出口 | 展示当前路由页面 |
| `GlobalLayer` | 全局浮层 | 承载命令菜单、全局弹窗和 Toast |

## 3. 组件树与字段说明

本节说明 AppShell 由哪些组件组成，以及每个组件展示哪些字段。

### 3.1 组件树

```text
<AppShell>
├─ <Sidebar>
├─ <Topbar>
│  ├─ <BreadcrumbTitle>
│  ├─ <CommandSearchTrigger>
│  └─ <GlobalActions>
├─ <PageOutlet>
└─ <GlobalLayer>
   ├─ <CommandMenu>
   ├─ <GlobalModals>
   └─ <Toasts>
```

### 3.2 通用组件字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<Sidebar>` | 导航项 | 页面入口 | 图标 + 文本 | 计划、反馈、统计、成员管理、权限管理、设置 |
| `<Topbar>` | `<BreadcrumbTitle>` | 当前路径 | 文本 | 根据当前路由展示 |
| `<Topbar>` | `<CommandSearchTrigger>` | 全局搜索入口 | 搜索按钮 | 打开命令菜单 |
| `<Topbar>` | `<GlobalActions>` | 全局主操作 | 按钮组 | 包含 `新建反馈`、`新建目标` |
| `<PageOutlet>` | 当前页面 | 当前路由内容 | 页面内容 | 由路由决定 |
| `<GlobalLayer>` | `<CommandMenu>` | 全局命令菜单 | 弹窗 | 按需出现 |
| `<GlobalLayer>` | `<GlobalModals>` | 全局新建弹窗 | 弹窗 | 按需出现 |
| `<GlobalLayer>` | `<Toasts>` | 操作反馈 | Toast | 按需出现 |

### 3.3 当前页内容字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<CommandMenu>` | 搜索输入 | 搜索页面和 ORF 对象 | 输入框 | 支持页面、目标、指标、任务、反馈 |
| `<CommandMenu>` | 搜索结果 | 命中的页面或对象 | 列表 | 点击后进入对应页面或对象 |
| `<GlobalModals>` | 新建目标 | 创建目标入口 | 弹窗 | 从顶部栏打开 |
| `<GlobalModals>` | 新建反馈 | 创建反馈入口 | 弹窗 | 从顶部栏打开 |
| `<Toasts>` | 提示信息 | 操作结果反馈 | Toast | 自动消失 |

## 4. 交互与状态

本节描述 AppShell 的核心 UI 交互和页面状态。

### 4.1 核心交互

| 交互 | 说明 |
| --- | --- |
| 切换页面 | 点击侧边栏导航进入对应页面 |
| 打开全局搜索 | 点击顶部栏搜索入口或使用快捷键打开命令菜单 |
| 搜索跳转 | 在命令菜单中选择页面或对象后跳转 |
| 新建目标 | 点击顶部栏 `新建目标` 打开全局弹窗 |
| 新建反馈 | 点击顶部栏 `新建反馈` 打开全局弹窗 |
| 关闭浮层 | 点击遮罩、关闭按钮或完成操作后关闭浮层 |

### 4.2 页面状态

| 状态 | 说明 |
| --- | --- |
| 默认态 | 展示侧边栏、顶部栏和当前页面 |
| 命令菜单打开态 | 全局搜索弹窗打开 |
| 弹窗打开态 | 全局新建弹窗打开 |
| Toast 展示态 | 页面右侧展示操作反馈 |

### 4.3 交互细则

| 交互 | 细则 |
| --- | --- |
| 全局搜索 | 搜索入口展示占位文案 `搜索目标、结果、任务、反馈...` |
| 全局搜索 | 命令菜单可以搜索页面、目标、指标、任务、反馈 |
| 全局操作 | `新建反馈` 和 `新建目标` 始终位于顶部栏右侧 |
| 路由标题 | 顶部标题根据当前路径生成 |
