# AppShell - 前端说明

## 1. 页面目录

AppShell 是登录后页面共享的全局外壳。
当前文档只描述全局外壳 UI。

注册成功但尚未审核通过的用户不进入 AppShell，只展示等待审核页。当前产品只有一个默认作用域，不提供团队切换入口。

### 1.1 页面关系

```text
ORF
└─ AppShell                    ← 当前文档
   ├─ 悬赏大厅
   ├─ 我的挑战
   ├─ 反馈
   ├─ 统计
   ├─ 成员管理
   ├─ 权限管理
   └─ 设置
```

## 2. 当前页页面结构

AppShell 由全局背景层、侧边栏、顶部栏、页面内容出口和全局浮层组成。

### 2.1 页面结构示意图

```text
┌───────────────┬──────────────────────────────────────────────────────────────┐
│ Sidebar       │ Topbar                                                       │
│ 悬赏大厅      │ 当前路径              全局搜索*       新建反馈*   新建目标* 消息 │
│ 我的挑战      ├──────────────────────────────────────────────────────────────┤
│ 反馈          │ PageOutlet                                                   │
│ 统计          │ 当前路由页面内容                                             │
│ 成员管理      │                                                              │
│ 权限管理      │                                                              │
│ 用户区        ├──────────────────────────────────────────────────────────────┤
│               │ GlobalLayer                                                  │
│               │ CommandMenu / GlobalModals / Toasts           shown as needed │
└───────────────┴──────────────────────────────────────────────────────────────┘
```

`*` 悬赏大厅路由不展示顶部栏全局搜索和新建反馈；有目标创建权限时仍展示 `新建目标`。

### 2.2 页面区域说明

| 区域 | 含义 | 说明 |
| --- | --- | --- |
| `AppShellBackground` | 全局背景层 | 使用侧边栏背景状态派生右侧延展背景；不作为设置页可选侧边栏图 |
| `Sidebar` | 全局侧边栏 | 展示主要导航入口；底部用户区收纳搜索、设置和退出 |
| `Topbar` | 顶部栏 | 展示当前路径；非悬赏大厅页面展示全局搜索入口；`新建目标` 按权限展示；消息入口常驻 |
| `PageOutlet` | 页面内容出口 | 展示当前路由页面 |
| `GlobalLayer` | 全局浮层 | 承载命令菜单、全局弹窗和 Toast |

## 3. 组件树与字段说明

本节说明 AppShell 由哪些组件组成，以及每个组件展示哪些字段。

### 3.1 组件树

```text
<AppShell>
├─ <AppShellBackground>
├─ <Sidebar>
├─ <Topbar>
│  ├─ <BreadcrumbTitle>
│  ├─ <CommandSearchTrigger>
│  └─ <GlobalActions>
│     └─ <NotificationBell>
├─ <PageOutlet>
└─ <GlobalLayer>
   ├─ <CommandMenu>
   ├─ <GlobalModals>
   └─ <Toasts>
```

### 3.2 通用组件字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<Sidebar>` | 导航项 | 页面入口 | 图标 + 文本 | 悬赏大厅、我的挑战、反馈、统计、成员管理、权限管理 |
| `<Sidebar>` | 用户区操作 | 次级全局操作 | 用户名 + 图标按钮 | 搜索、设置、退出；设置按权限展示 |
| `<Topbar>` | `<BreadcrumbTitle>` | 当前路径 | 文本 | 根据当前路由展示 |
| `<Topbar>` | `<CommandSearchTrigger>` | 全局搜索入口 | 搜索按钮 | 悬赏大厅不展示 |
| `<Topbar>` | `<GlobalActions>` | 全局主操作 | 按钮组 | 有目标创建权限时展示 `新建目标`；非悬赏大厅页面且有可见指标时展示 `新建反馈`；右侧常驻消息入口 |
| `<Topbar>` | `<NotificationBell>` | 系统消息入口 | 铃铛 + 未读数 + 浮层 | 点击展示最近消息，可进入完整消息页；不放入侧边栏主导航 |
| `<PageOutlet>` | 当前页面 | 当前路由内容 | 页面内容 | 由路由决定 |
| `<GlobalLayer>` | `<CommandMenu>` | 全局命令菜单 | 弹窗 | 按需出现 |
| `<GlobalLayer>` | `<GlobalModals>` | 全局新建弹窗 | 弹窗 | 按需出现 |
| `<GlobalLayer>` | `<Toasts>` | 操作反馈 | Toast | 按需出现 |

### 3.3 当前页内容字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<CommandMenu>` | 搜索输入 | 搜索页面、动作和 ORF 对象 | 输入框 | 支持页面、新建目标动作、目标、指标、任务、反馈 |
| `<CommandMenu>` | 搜索结果 | 命中的页面、动作或对象 | 列表 | 页面和对象点击后跳转；动作点击后执行对应全局命令 |
| `<GlobalModals>` | 新建目标 | 创建目标入口 | 弹窗 | 创建后进入我的挑战工作台，目标仍为候选状态 |
| `<GlobalModals>` | 新建反馈 | 创建反馈入口 | 弹窗 | 从顶部栏打开 |
| `<Toasts>` | 提示信息 | 操作结果反馈 | Toast | 自动消失 |

`/objectives/:objectiveId/loot` 的顶栏标题固定展示为 `目标战利品`；页面内容区再按当前状态展示 `提交战利品`、`提交匿名互评` 或 `验收战利品`。

## 4. 交互与状态

本节描述 AppShell 的核心 UI 交互和页面状态。

### 4.1 核心交互

| 交互 | 说明 |
| --- | --- |
| 切换页面 | 点击侧边栏导航进入对应页面 |
| 打开全局搜索 | 点击顶部栏搜索入口、侧边栏用户区搜索按钮或使用快捷键打开命令菜单 |
| 搜索跳转 | 在命令菜单中选择页面或对象后跳转；选择动作时执行动作 |
| 新建目标 | 有目标创建权限时，点击顶部栏 `新建目标` 或命令菜单动作打开全局弹窗；保存成功后进入我的挑战工作台 |
| 新建反馈 | 非悬赏大厅页面且当前数据中存在可见指标时，点击顶部栏 `新建反馈` 打开全局弹窗 |
| 查看消息 | 点击顶部栏铃铛查看最近消息；点击消息跳转到关联页面，点击“查看全部消息”进入完整消息页 |
| 关闭浮层 | 点击遮罩、关闭按钮或完成操作后关闭浮层 |

### 4.2 页面状态

| 状态 | 说明 |
| --- | --- |
| 默认态 | 展示侧边栏、顶部栏和当前页面 |
| 命令菜单打开态 | 全局搜索弹窗打开 |
| 弹窗打开态 | 全局新建弹窗打开 |
| Toast 展示态 | 页面右侧展示操作反馈 |
| 消息浮层态 | 顶部栏消息浮层打开，展示最近消息和全部已读入口 |
| 注册待审核态 | 已登录但 `currentUser.status=pending`，展示等待审核说明，不加载业务页面 |
| 注册拒绝态 | 已登录但 `currentUser.status=rejected`，展示注册未通过说明，不加载业务页面 |
| 账号停用态 | 已登录但 `currentUser.status=disabled`，展示账号已停用说明，不加载业务页面 |

### 4.3 交互细则

| 交互 | 细则 |
| --- | --- |
| 全局搜索 | 非悬赏大厅页面在顶部栏展示搜索入口；侧边栏用户区保留紧凑搜索按钮 |
| 全局搜索 | 命令菜单可以搜索页面、动作、目标、指标、任务、反馈 |
| 全局操作 | `新建目标` 按权限展示；`新建反馈` 仅在非悬赏大厅页面且当前数据中存在可见指标时展示 |
| 消息入口 | 消息是横切系统入口，放在顶部栏；侧边栏只保留主要业务页面 |
| 路由标题 | 顶部标题根据当前路径生成 |
| 视觉背景 | 侧边栏保持原始背景图；右侧延展背景属于 AppShell 外壳资源，不进入设置页背景扫描目录 |
