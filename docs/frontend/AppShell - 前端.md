# AppShell - 前端说明

## 1. 页面目录

AppShell 是登录后页面共享的全局外壳。

页面切换采用“路由模块预取 + 会话级读模型缓存 + 背景图片预热 + 后台失效刷新”。`src/routing/routeModules.ts` 是生产页面代码分包和预取的唯一注册表；侧边栏悬停、键盘聚焦、移动端触摸，以及登录后的空闲阶段会通过 `routePreload.ts` 同时准备页面模块和常用读模型。目标页有个性化背景时，预取链会选定并预热实际展示的图片本体，页面消费同一选择，不能只预取 URL 元数据后让大图在切页时才下载。pathname 只选择页面，不能触发用户、权限、通知或任务读模型的全局重新初始化；外壳布局和背景 scene 也只能消费已经确认的 pathname，导航意图不得提前把旧页面套入新页面布局，背景状态不得跨 scene 复用。

服务端 API 和数据库仍是业务事实源；`src/state/readModelCache.ts` 只保存当前登录用户会话内可丢弃的读模型投影。已有缓存必须立即渲染，过期或收到 `orf.read-model.invalidated` 后在后台刷新；只有当前会话从未取得过该读模型时才展示稳定骨架。退出登录或切换身份必须同时清空通用读模型缓存和聊天消息窗口缓存，禁止跨用户复用。
当前文档只描述全局外壳 UI；业务对象的创建和编辑由对应业务页面承载。

注册成功但尚未审核通过的用户不进入 AppShell，只展示等待审核页。当前产品只有一个默认作用域，不提供团队切换入口。

## 2. 当前页页面结构

AppShell 由外壳背景层、侧边栏、顶部栏、页面内容出口和全局浮层组成。

### 2.1 页面结构示意图

```text
┌───────────────┬──────────────────────────────────────────────────────────────┐
│ Sidebar       │ Topbar                                                       │
│ 悬赏大厅      │ 当前路径              全局搜索        新建反馈*   新建目标* 消息 │
│ 我的挑战      ├──────────────────────────────────────────────────────────────┤
│ 反馈          │ PageOutlet / 当前路由页面内容                                  │
│ 统计          │                                                              │
│ 聊天          │                                                              │
│ 成员管理      │                                                              │
│ 权限管理      │                                                              │
│ 系统设置      │                                                              │
│ 用户区        ├──────────────────────────────────────────────────────────────┤
│               │ GlobalLayer                                                  │
│               │ CommandMenu / GlobalModals / Toasts           shown as needed │
└───────────────┴──────────────────────────────────────────────────────────────┘
```

`*` 悬赏大厅路由不展示顶部栏新建反馈。全局搜索和有权限的 `新建目标` 在所有 AppShell 页面展示。

### 2.2 页面区域说明

| 区域 | 含义 | 说明 |
| --- | --- | --- |
| `AppShellSkinLayers` | 外壳与内容皮肤层 | 侧边栏、顶部栏和当前页面内容区分别消费独立皮肤槽位；每个槽位先取当前用户个人偏好，缺省时回退系统默认；页面内容槽位按当前路由映射到页面级皮肤 |
| `DisplayPreferenceTokens` | 显示偏好投射层 | 使用当前用户个人显示偏好派生根字号、工作台缩放、内容字号、控件密度、行高和高对比度 token；页面和组件只消费 token，不各自保存显示规则 |
| `PageOutlet` | 页面内容出口 | 直接渲染当前路由页面；聊天页不再承载目标/行动项右侧工作区，目标和行动项仍只在 `/tasks` 完整页处理 |
| `Sidebar` | 全局侧边栏 | 展示主要导航入口；底部用户区收纳个人设置和退出；管理区按权限展示系统管理 |
| `Topbar` | 顶部栏 | 展示当前路径和全局搜索入口；`新建目标` 按权限展示并跳转到挑战页创建入口 |
| `SystemBroadcastBanner` | 系统广播横幅 | 展示实时公共通知，例如新悬赏发布和兼容旧客户端的更新公告；点击跳转到关联对象，不替代聊天里的系统会话 |
| `ClientUpdateNotice` | 客户端更新提示 | 进入 AppShell 后立即检查客户端更新，之后每 10 分钟检查一次；收到 `client.update.available` 实时事件时立即补查一次；原生客户端按“已检查、已展示、开始安装、已运行新版”上报幂等更新收据，收据只观测发布覆盖，不改变版本清单或消息事实源 |
| `AttentionWorkbar` | 待我处理入口 | 展示由消息、系统通知、工作日志提醒和窗口状态派生的注意力摘要；只通过既有通知已读接口清理注意力状态，不创建通知、不改变业务状态、不替代聊天系统会话 |
| `PageOutlet` | 页面内容出口 | 展示当前路由页面 |
| `GlobalLayer` | 全局浮层 | 承载命令菜单、非目标创建类全局弹窗和 Toast |

## 3. 组件树与字段说明

本节说明 AppShell 由哪些组件组成，以及每个组件展示哪些字段。

### 3.1 组件树

```text
<AppShell>
├─ <AppShellSkinLayers>
├─ <DisplayPreferenceTokens>
├─ <Sidebar>
├─ <Topbar>
│  ├─ <BreadcrumbTitle>
│  ├─ <CommandSearchTrigger>
│  └─ <GlobalActions>
├─ <SystemBroadcastBanner>
├─ <ClientUpdateNotice>
├─ <AttentionWorkbar>
├─ <PageOutlet>
└─ <GlobalLayer>
   ├─ <CommandMenu>
   ├─ <GlobalModals>
   └─ <Toasts>
```

### 3.2 通用组件字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<Sidebar>` | 导航项 | 页面入口 | 图标 + 文本 | 悬赏大厅、我的挑战、工作日志、聊天、反馈、统计、成员管理、权限管理、系统设置 |
| `<Sidebar>` | 待我处理 | 注意力入口 | 图标 + 数字 + 摘要 | 仅在 `AttentionState.count > 0` 时展示 `urgent`、`flash`、`toast` 和需要响应的通知摘要；普通聊天总未读只进聊天入口和桌面红点 |
| `<Sidebar>` | 用户区操作 | 用户菜单 | 用户头像 + 用户名 | 个人设置、关于与更新、退出；个人设置对所有 `active` 用户展示 |
| `<Topbar>` | `<BreadcrumbTitle>` | 当前路径 | 文本 | 根据当前路由展示 |
| `<Topbar>` | `<CommandSearchTrigger>` | 全局搜索入口 | 搜索按钮 | 所有 AppShell 页面展示 |
| `<Topbar>` | `<GlobalActions>` | 全局主操作 | 按钮组 | 有目标创建权限时展示 `新建目标` 并进入挑战页；非悬赏大厅页面且当前用户为 active 成员时展示 `新建反馈` 并进入 `/feedback/new` |
| `<ClientUpdateNotice>` | 更新提示 | 客户端版本更新 | 页面内提示条 + 桌面首次提醒弹窗 | 运行中的 Win11 和 Android 客户端每 10 分钟检查一次；服务端发现带 Win11 安装包的新版本时会通过实时事件唤醒一次检查；移动端只展示页面流内提示，不使用全屏遮罩；原生客户端只有在提示实际渲染时才记录“已展示” |
| `<AttentionWorkbar>` | 待我处理 | 当前用户注意力摘要 | 侧边栏入口 + 轻量面板 | `count=0` 时不渲染；有待处理时入口展示数量，面板展示私聊、`@我`、关注话题回复、反馈指派、征召/加派、审核请求、工作日志欠账和数据同步冲突等摘要 |
| `<PageOutlet>` | 当前页面 | 当前路由内容 | 页面内容 | 由路由决定 |
| `<GlobalLayer>` | `<CommandMenu>` | 全局命令菜单 | 弹窗 | 按需出现 |
| `<GlobalLayer>` | `<GlobalModals>` | 全局业务弹窗 | 弹窗 | 承载指标、征召和加派等浮层；不承载目标创建或反馈创建 |
| `<GlobalLayer>` | `<Toasts>` | 操作反馈 | Toast | 按需出现；移动端避让底部导航；桌面端遇到页面内 docked side panel 时避让右侧面板 |

### 3.3 当前页内容字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<CommandMenu>` | 搜索输入 | 搜索页面、动作和 ORF 对象 | 输入框 | 支持页面、新建目标动作、目标、指标、任务、反馈 |
| `<CommandMenu>` | 搜索结果 | 命中的页面、动作或对象 | 列表 | 页面和对象点击后跳转；动作点击后执行对应全局命令 |
| `<CommandMenu>` | 新建目标 | 创建目标入口 | 动作 | 跳转到 `/tasks` 的页面内创建入口 |
| `/feedback/new` | 新建反馈 | 创建反馈入口 | 页面 | 从顶部栏或反馈列表进入 |
| `<AttentionWorkbar>` | 待处理项 | 需要当前用户注意的摘要 | 列表项 | 每条至少提供 `打开`；不得直接提供改变业务状态的 `已处理` 动作 |
| `<Toasts>` | 提示信息 | 操作结果反馈 | Toast | 自动消失 |

`/tasks/objectives/:objectiveId/loot` 的顶栏标题固定展示为 `目标战利品`；页面内容区再按当前状态展示 `提交战利品`、`提交匿名互评` 或 `验收战利品`。

## 4. 交互与状态

本节描述 AppShell 的核心 UI 交互和页面状态。

### 4.1 核心交互

| 交互 | 说明 |
| --- | --- |
| 切换页面 | 点击侧边栏导航进入对应页面 |
| 打开全局搜索 | 点击顶部栏搜索入口或使用快捷键打开命令菜单 |
| 搜索跳转 | 在命令菜单中选择页面或对象后跳转；选择动作时执行动作 |
| 新建目标 | 有目标创建权限时，点击顶部栏 `新建目标` 或命令菜单动作进入 `/tasks` 页面内创建入口 |
| 新建反馈 | 非悬赏大厅页面且当前用户为 active 成员时，点击顶部栏 `新建反馈` 进入 `/feedback/new` |
| 查看待我处理 | 点击侧边栏 `待我处理` 打开轻量面板；通知项点击后先标记该通知已读，再进入聊天系统消息或业务 `targetHref` |
| 查看系统消息 | 进入聊天侧栏的 `系统公告` 或 `我的系统通知`；点击系统消息打开关联对象，或在消息内回复到目标评论 |
| 打开目标或行动项链接 | 聊天消息里的 `/tasks#objective:*`、`/tasks#action:*`、`/tasks#subAction:*` 链接按普通站内链接进入 `/tasks` 完整页并由挑战页负责定位，不在聊天页打开右侧工作区 |
| 查看更新 | 客户端发现新版本时展示页面内提示；桌面端可额外出现首次提醒弹窗；移动端不使用全屏更新遮罩 |
| 打开个人设置 | 点击侧边栏用户菜单里的 `个人设置` 进入 `/settings`，管理当前用户偏好 |
| 调整界面显示 | 在个人设置中修改工作台缩放、界面字号、内容字号、界面密度或高对比度后，AppShell 立即重新派生全局显示 token；工作台缩放也支持全局快捷键快速调整，桌面端同步到当前窗口 |
| 打开系统管理 | 管理员点击侧边栏 `系统管理` 进入 `/system`，默认跳转到成员管理 |
| 打开系统设置 | 管理员在系统管理页切换到 `系统设置` 进入 `/system/settings` |
| 关闭浮层 | 点击遮罩、关闭按钮或完成操作后关闭浮层 |

### 4.2 页面状态

| 状态 | 说明 |
| --- | --- |
| 默认态 | 展示侧边栏、顶部栏和当前页面 |
| 命令菜单打开态 | 全局搜索弹窗打开 |
| 弹窗打开态 | 非目标创建类全局弹窗打开 |
| Toast 展示态 | 页面右侧展示操作反馈；如果当前页面打开 docked 右侧面板，桌面 Toast 向左避让该面板 |
| 客户端更新提示态 | 页面内容上方展示更新提示；桌面端可出现首次提醒弹窗，移动端保持在页面流中 |
| 待我处理态 | 有待处理时侧边栏展示 `AttentionState.count`，面板中强提醒置顶；只有普通聊天未读时入口不渲染；关闭面板不改变消息已读或业务状态，点击通知项或“全部已读”只改变通知已读状态 |
| 系统会话态 | 聊天页打开 `系统公告` 或 `我的系统通知`，展示系统消息、已读/未读、打开目标和回复入口 |
| 注册待审核态 | 已登录但 `currentUser.status=pending`，展示等待审核说明，不加载业务页面 |
| 注册拒绝态 | 已登录但 `currentUser.status=rejected`，展示注册未通过说明，不加载业务页面 |
| 账号停用态 | 已登录但 `currentUser.status=disabled`，展示账号已停用说明，不加载业务页面 |

### 4.3 交互细则

| 交互 | 细则 |
| --- | --- |
| 全局搜索 | 所有 AppShell 页面在顶部栏展示搜索入口；侧边栏用户区不承载搜索入口 |
| 全局搜索 | 命令菜单可以搜索页面、动作、目标、指标、任务、反馈 |
| 全局操作 | `新建目标` 按权限展示但不拥有目标表单；`新建反馈` 仅在非悬赏大厅页面且当前用户为 active 成员时展示 |
| 待我处理入口 | 入口属于 AppShell 注意力展示，不属于聊天事实源；数量和摘要由注意力系统从可处理聊天提醒、系统通知、工作日志提醒、当前路由和窗口状态派生；可处理聊天提醒由 `/api/chat/unread-summary` 的 `actionableMessageUnreadCount` 表达，覆盖私聊和 @我；普通聊天总未读只进入聊天入口和桌面 `badgeCount`；`count=0` 时不显示入口 |
| 待我处理动作 | 允许打开通知项并调用现有通知已读接口，允许“通知全部已读”；`标记已处理` 不属于注意力系统，必须回到业务页面完成 |
| 系统消息入口 | 系统消息入口收敛到聊天页系统会话；不再提供顶部栏铃铛或独立消息页 |
| 路由标题 | 顶部标题根据当前路径生成 |
| 个人设置 | 侧边栏用户菜单对所有 `active` 用户展示；入口只管理当前用户偏好 |
| 显示偏好 | 工作台缩放、界面字号、内容字号、界面密度和高对比度来自当前用户 `personalPreferences.display`；Web 端工作台缩放合入根字号，桌面端工作台缩放交给 Electron 窗口缩放，其他显示 token 继续由 AppShell 应用 |
| 工作区布局偏好 | `personalPreferences.workspaceLayout` 仅作为兼容字段保留；当前 AppShell 不读取或写入它，聊天页也不恢复目标/行动项右侧工作区 |
| 聊天目标工作区 | 当前前端已屏蔽聊天目标/行动项工作区入口和任务链接拦截；目标、行动项、子行动项的查看和修改统一回到 `/tasks` 完整页 |
| 系统设置 | 只对管理员展示；入口管理系统默认和全局策略 |
| AppShell 皮肤 | 登录后侧边栏使用 `sidebar_background`，顶部栏使用 `topbar_background`，页面内容区按路由使用对应 `page_*_background`；每个槽位都先取当前用户个人偏好，缺省时回退系统默认；图库图片在规范槽位间共享，页面设置可一次保存到全部或部分页面；旧 `app_background` 只兼容回退到侧边栏和顶部栏，不再影响页面内容区；顶部栏、侧边栏和页面内容区统一由固定 frame 背景槽位组件渲染，`crops[imageId]` 的 `centerX`、`centerY` 和 `zoom` 只影响 frame 内 cover-crop 取景，`zoom=1` 表示刚好铺满且不能露底，不移动槽位本体 |
| 页面切换 | 导航意图先预取目标页面代码、页面读模型和页面背景配置；已有读模型立即展示，后台刷新不得清空当前内容或替换为整页旋转图标；用户/权限只在身份建立或权限失效时刷新，通知由首次加载、实时事件和通知失效事件维护，任务读模型在登录后后台加载并由任务失效事件刷新 |
| 移动端全局提示 | 系统广播、客户端更新提示和 Toast 都是展示状态；移动端必须避让底部导航和主内容，不得用非用户主动打开的全屏遮罩挡住当前页面 |
| 移动端待我处理 | 移动端底部导航仅在 `AttentionState.count > 0` 时展示 `待办` 入口；普通聊天未读仍只显示在聊天入口角标；它复用注意力派生状态，不新增独立页面，最新项是通知时先标记已读，并避让底部导航 |
| 桌面端 Toast 避让 | Toast 是 AppShell 全局层，不归属某个业务页；当业务页存在占布局空间的右侧面板时，Toast 只能避让面板，不能覆盖面板保存、取消、评论等操作 |
