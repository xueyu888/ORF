# ORF 工作日志页面 - 前端

## 页面

`/work-logs` 承载工作日志页面。侧边栏显示“工作日志”，移动端底部导航也提供入口。

页面默认日期为今天，也支持前一天、后一天和日期选择。

## 结构

桌面端为双栏：

| 区域 | 职责 |
| --- | --- |
| 团队动态 | 读取当天团队工作日志活动流，只展示日志事实 |
| 我的日志 | 当前用户编辑自己当天多目标日志 |

移动端使用“填写 / 动态”分段切换，避免编辑器和活动流互相挤压。

## 编辑

- 日志正文复用 `OrfRichTextEditor`，保存 Markdown。
- 活动流正文复用 `OrfRichTextMarkdownViewer`。
- 页面不复用 `ChatComposer`，避免把频道、回复、typing、附件上传等聊天语义带入工作日志。
- 同一天同一目标只保留一条日志。
- 空白草稿不会保存；只有目标和正文都完整时才提交。

## 数据边界

- 页面通过 `/api/work-logs/*` 独立读写，不并入任务管理读模型。
- 目标选择只消费后端返回的可写目标列表。
- 团队动态由日志读模型派生，不反向定义日志契约。
- 保存成功后刷新当天团队动态，并关闭工作日志提醒横幅。
