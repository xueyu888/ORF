# ORF 提交战利品页 - 前端

## 页面定位

从我的挑战的目标行进入：

```text
/objectives/:objectiveId/loot
```

战利品提交发生在目标层级，不发生在单个悬赏指标层级。

## 页面字段

| 字段 | 说明 |
| --- | --- |
| 目标标题 | 只读展示 |
| 指标完成提醒 | 提醒战利品用于证明目标下指标完成或有效证伪 |
| 悬赏指标清单 | 展示指标标题、验收标准、难度和不确定性分 |
| 完成说明 | 必填，说明完成或证伪证据 |

## 交互

| 操作 | 结果 |
| --- | --- |
| 返回 / 取消 | 回到 `/tasks` |
| 提交 | 保存目标战利品，目标进入待验收 |

任务和子任务勾选完成不触发验收。只有目标战利品提交并通过指挥官验收后，才产生完成或结算结果。

后端契约见 [ORF 提交战利品 - 后端.md](../backend/ORF%20提交战利品%20-%20后端.md)。
