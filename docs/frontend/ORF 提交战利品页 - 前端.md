# ORF 提交战利品页 - 前端

## 页面定位

从我的挑战的目标行进入：

```text
/objectives/:objectiveId/loot
```

战利品提交发生在目标层级，不发生在单个指标层级。

## 页面字段

| 字段 | 说明 |
| --- | --- |
| 目标标题 | 只读展示 |
| 指标完成提醒 | 提醒战利品用于证明目标下指标完成或有效证伪 |
| 指标清单 | 展示指标标题、验收标准、难度和不确定性分 |
| 完成说明 | 必填，说明完成或证伪证据 |
| 自测报告 | 可选文本摘要，记录自测覆盖、复核结论或风险说明 |
| 匿名互评 | `submitted` 目标的普通成员挑战者填写挑战者贡献比例 |
| 验收指标 | 指挥官选择每个指标验收结论 |
| 互评结果 | 指挥官只读查看匿名互评汇总；分歧时处理贡献比例 |

## 交互

| 操作 | 结果 |
| --- | --- |
| 返回 / 取消 | 回到 `/tasks` |
| 提交 | 普通成员挑战者保存目标战利品，目标进入待验收 |
| 提交匿名互评 | 保存普通成员挑战者互评结果，等待指挥官验收 |
| 验收并结算 | 指标验收结论和匿名互评结果生成积分流水 |

任务和子任务勾选完成不触发验收。只有目标战利品提交并通过指挥官验收后，才产生完成或结算结果。
