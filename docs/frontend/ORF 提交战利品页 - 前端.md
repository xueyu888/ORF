# ORF 提交战利品页 - 前端

## 页面定位

从我的挑战的目标行进入：

```text
/tasks/objectives/:objectiveId/loot
```

战利品提交发生在目标层级，不发生在单个指标层级。

## 页面字段

| 字段 | 说明 |
| --- | --- |
| 目标标题 | 只读展示 |
| 指标完成提醒 | 提醒战利品用于证明目标下指标完成或有效证伪 |
| 指标清单 | 展示指标标题和只读指标详情；指标详情读取 `Result.detail`，不从评论或证据说明反推 |
| 完成说明 | 必填，说明完成或证伪证据 |
| 自测报告 | 可选文本摘要，记录自测覆盖、复核结论或风险说明 |
| 试验收 | `frozen` 目标的挑战者可用同一份完成说明、指标主张和自测摘要发起一次试验收；指挥官在同页反馈 |
| 匿名互评 | `accepted` 目标的普通成员挑战者按目标指标表提交贡献百分比，或填写弃权说明 |
| 验收指标 | 指挥官选择每个指标验收结论 |
| 互评结果 | 指挥官在 `accepted` 阶段查看提交状态、原始评分、偏离提醒，并确认最终结算比例 |

## 交互

| 操作 | 结果 |
| --- | --- |
| 返回 / 取消 | 回到 `/tasks` |
| 提交试验收 | 普通成员挑战者保存一次试验收请求，目标仍保持已冻结 |
| 提交试验收反馈 | 指挥官反馈“可正式提交”或“需补充”，不改变目标状态 |
| 提交 | 普通成员挑战者保存目标战利品，目标进入待验收 |
| 提交匿名互评 | 页面按指标权重自动汇总为目标级贡献比例，浏览器本地加密后提交到 ORF 同源代理，由 ORF 转发到共享结算服务；ORF 后端不保存原始互评 |
| 提交弃权说明 | 成员说明自己做了什么、为什么不了解整体贡献；弃权不参与贡献均值计算 |
| 确认验收 | 指挥官保存指标验收结论，验收通过时目标进入已验收；不通过时目标保持待验收 |
| 确认结算 | 指挥官确认最终贡献比例，生成积分流水，目标进入已结算 |

任务和子任务勾选完成不触发验收。只有目标战利品提交并通过指挥官验收后，才产生已验收结果；只有指挥官确认结算后，才写入积分流水。

试验收不是正式提交：它不生成 `objectiveLoot`，不写入 `lootSubmittedAt`，不进入 `submitted`，也不参与按时/延期判断。目标挑战者仍需点击“正式提交”提交战利品。

## 匿名互评输入规则

- 页面展示和输入单位是百分比，不是接口中的小数比例。
- 成员可选择提交评分或弃权说明。
- 提交评分时，页面以表格展示目标下的指标，指标行来自当前目标的 `Result` 读模型；列是当前目标挑战者，包括当前登录成员自己。
- 每个指标行都必须为每个目标挑战者填写一项，单元格初始值为 `0`，范围为 `0` 到 `100`；提交前校验同一指标行合计必须为 `100%`。
- 指标权重由当前指标分值派生：优先使用 `Result.uncertaintyScore` 参与目标基础分的权重；如果当前目标没有指标，则退回为一行“目标整体”；如果指标都没有有效分值，页面按指标等权汇总。
- 指标行展示当前指标难度等级和指标分，例如 `入门 · 指标分 10 · 权重 25%`。
- 页面底部实时展示目标最终贡献比例，计算口径是 `sum(指标权重 * 成员在该指标上的百分比)`。
- 指标级百分比是匿名互评原始明细的一部分；页面提交时同时加密提交目标级 `allocations` 和逐指标 `metricScores`。最终结算仍只使用目标级比例或指挥官确认后的公开比例。
- 页面按当前用户和目标在浏览器 `localStorage` 保存未提交草稿，路由切换、离开页面再返回或刷新页面时可临时恢复；服务器已提交评价仍以匿名互评服务器为事实源。进入页面后会通过 `/api/local-settlement/objectives/:objectiveId/reviews/current` 读取当前用户在该目标的服务器最新提交，并覆盖初始本机草稿；只有服务器没有提交时才继续展示本机草稿。历史旧提交如果没有 `metricScores`，只能提示最新目标级比例，不能还原每个指标行。
- 提交弃权时必须填写说明，简述自己大概做了什么，以及为什么无法判断其他人的贡献比例。
- 提交时前端从 ORF 同源代理读取共享结算服务公钥，用 WebCrypto 加密后提交到 `/api/local-settlement/objectives/:objectiveId/reviews`。
- 自评优先只用于一致性核查；当某个成员暂时只有自评数据时，页面会标注为“仅自评参考”。
- 指挥官结算时通过 `/api/local-settlement/objectives/:objectiveId/summary` 读取共享结算服务汇总，页面展示已评分、已弃权、未提交、每个 reviewer 的目标级评分、逐指标评分明细、相对当前原始均值偏离和超过 `10%` 的提醒。
- 缺评、弃权和超过 `10%` 的偏离都不阻止结算；指挥官确认最终贡献百分比且合计为 `100%` 后即可结算。

后端契约见 [ORF 提交战利品 - 后端.md](../backend/ORF%20提交战利品%20-%20后端.md)。
