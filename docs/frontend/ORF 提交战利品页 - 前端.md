# ORF 提交战利品页 - 前端

## 1. 页面定位

提交战利品页是挑战页的子页面，从悬赏行 `提交战利品` 进入。

| 页面 | 路由 | 入口 |
| --- | --- | --- |
| 提交战利品页 | `/tasks/bounties/:bountyId/loot` | 我的挑战中的悬赏行 |

## 2. 页面结构

```text
<LootSubmitPage>
├─ 返回挑战
└─ <LootForm>
   ├─ 悬赏标题
   ├─ 完成说明
   ├─ 取消
   └─ 提交
```

## 3. 字段

| 字段 | 说明 |
| --- | --- |
| 悬赏标题 | 只读展示当前悬赏 |
| 完成说明 | 必填，多行输入 |

## 4. 交互

| 操作 | 结果 |
| --- | --- |
| 返回挑战 | 回到 `/tasks` |
| 取消 | 回到 `/tasks` |
| 提交 | 保存战利品并回到 `/tasks` |

提交成功后，挑战页对应悬赏进入待验收状态。

后端契约见 [ORF 提交战利品 - 后端.md](../backend/ORF%20提交战利品%20-%20后端.md)。
