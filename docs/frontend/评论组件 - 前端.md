# 评论组件 - 前端

本文档记录 `src/features/challenge/comments/CommentPanel.tsx` 的展示和交互。

评论业务接口、权限和持久化规则见 [评论组件 - 后端.md](../backend/评论组件%20-%20后端.md)。

## 1. 绑定对象

评论窗口绑定当前块对象。

| 对象 | 入口 |
| --- | --- |
| 目标 | 目标行块菜单、目标评论数量入口 |
| 悬赏 | 悬赏行块菜单、悬赏评论数量入口 |
| 行动项 | 行动项行块菜单、行动项评论数量入口 |
| 子行动项 | 子行动项行块菜单、子行动项评论数量入口 |

## 2. 组件结构

```text
<CommentPanel>
├─ <CommentPanelHeader>
│  ├─ 当前块标题
│  └─ 关闭按钮
├─ <CommentView>
│  ├─ <RootCommentListView>
│  │  └─ <CommentMessageRow>[]
│  └─ <ReplyDetailView>
│     ├─ 返回按钮
│     ├─ 顶部固定外层评论
│     └─ 回复消息列表
└─ <CommentComposer>
   ├─ 当前用户
   ├─ 输入框
   ├─ `Ctrl / Cmd + Enter 发送`
   └─ 发送按钮
```

## 3. 展示规则

| 内容 | 当前实现 |
| --- | --- |
| 窗口位置 | 右下角浮窗 |
| 拖拽 | 标题栏可拖拽 |
| 宽度 | `382px`，移动端不超过视口宽度 |
| 标题 | 展示当前块标题 |
| 空评论 | 显示 `暂无评论` |
| 空回复 | 显示 `暂无回复` |
| 外层评论排序 | 按创建时间倒序 |
| 回复排序 | 按创建时间正序 |
| 回复对象标记 | 回复内层评论时显示 `回复{作者}:` |

## 4. 交互

| 操作 | 结果 |
| --- | --- |
| 点击块菜单 `评论` | 打开当前块评论窗口 |
| 点击评论数量入口 | 打开当前块评论窗口 |
| 点击关闭按钮 | 关闭评论窗口 |
| 拖拽标题栏 | 移动评论窗口 |
| 点击评论行 | 选中当前评论行 |
| 点击回复按钮 | 输入框进入回复状态 |
| 点击 `共 x 条回复` | 进入回复详情视图 |
| 点击返回按钮 | 返回外层评论列表 |
| 点击编辑按钮 | 本人或管理员可编辑，输入框带入原评论 |
| 双击评论正文 | 本人或管理员可进入编辑 |
| 点击删除按钮 | 本人或管理员可删除，确认文案为 `删除这条评论？` |
| 点击发送按钮 | 按当前输入状态发送评论、回复或保存编辑 |
| `Ctrl / Cmd + Enter` | 按当前输入状态提交 |

## 5. 输入状态

| 状态 | 输入框提示 | 提交按钮含义 |
| --- | --- | --- |
| 默认评论 | `添加评论...` | 发送评论 |
| 回复外层评论 | `回复 {作者}...` | 发送回复 |
| 回复详情默认输入 | `添加回复...` | 发送回复 |
| 回复内层评论 | `回复 {作者}...` | 发送回复 |
| 编辑评论 | `编辑评论...` | 保存评论 |

## 6. 暂不包含

- 点赞或表情反应。
- `@` 提及。
- 图片或文件评论。
