# 评论组件 - 前端

本文档记录 `src/features/challenge/comments/CommentPanel.tsx` 的展示和交互。

评论业务接口、权限和持久化规则见 [评论组件 - 后端.md](../backend/评论组件%20-%20后端.md)。

## 1. 绑定对象

评论窗口绑定当前块对象。

| 对象 | 入口 |
| --- | --- |
| 目标 | 目标行块菜单、目标评论数量入口 |
| 指标 | 指标行块菜单、指标评论数量入口 |
| 任务 | 任务行块菜单、任务评论数量入口 |
| 子任务 | 子任务行块菜单、子任务评论数量入口 |

## 2. 组件结构

```text
<CommentPanel>
├─ <CommentPanelHeader>
│  ├─ 当前块标题
│  └─ 关闭按钮
├─ <CommentView>
│  ├─ <RootCommentListView>
│  │  └─ <CommentMessageRow>[]
│  └─ <ReplyDetailView>
│     ├─ 返回按钮
│     ├─ 顶部固定外层评论
│     └─ 回复消息列表
└─ <CommentComposer>
   ├─ 当前用户
   ├─ 输入框
   ├─ `Ctrl / Cmd + Enter 发送`
   └─ 发送按钮
```

## 3. 展示规则

| 内容 | 当前实现 |
| --- | --- |
| 窗口位置 | 右下角浮窗 |
| 拖拽 | 标题栏可拖拽 |
| 宽度 | `382px`，移动端不超过视口宽度 |
| 标题 | 展示当前块标题 |
| 空评论 | 显示 `暂无评论` |
| 空回复 | 显示 `暂无回复` |
| 外层评论排序 | 按创建时间倒序 |
| 回复排序 | 按创建时间正序 |
| 回复对象标记 | 回复内层评论时显示 `回复{作者}:` |
| 回复入口 | 仅外层评论已有回复时显示 `共 x 条回复`，无回复评论不展示空钻取入口 |
| 列表评论数量入口 | 跟随目标、指标、任务或子任务标题文本后方展示，不贴到整行主列右侧 |
| 评论窗口身份 | 以绑定对象的类型和 id 为边界，不以标题作为唯一身份 |
| 切换绑定对象 | 从一个块切换到另一个块的评论窗口时，清空回复、编辑、选中评论和回复详情状态 |
| 链接展示 | 评论正文中的 `http://`、`https://` 和 `www.` 链接自动转为可点击外链，新窗口打开；正文仍按纯文本保存 |
| 标题链接 | URL 位于明确标题之后或独占标题下一行时，隐藏 URL，把标题文本显示为可点击外链 |

## 4. 交互

| 操作 | 结果 |
| --- | --- |
| 点击块菜单 `评论` | 打开当前块评论窗口 |
| 点击评论数量入口 | 打开当前块评论窗口 |
| 点击关闭按钮 | 关闭评论窗口 |
| 拖拽标题栏 | 移动评论窗口 |
| 点击评论行 | 选中当前评论行 |
| 点击回复按钮 | 输入框进入回复状态 |
| 回复或编辑中点击其他块的评论入口 | 打开新块评论窗口，输入框回到默认评论状态 |
| 点击 `共 x 条回复` | 进入回复详情视图，仅在 x 大于 0 时出现 |
| 点击返回按钮 | 返回外层评论列表 |
| 点击编辑按钮 | 本人或管理员可编辑，输入框带入原评论 |
| 双击评论正文 | 本人或管理员可进入编辑 |
| 点击删除按钮 | 本人或管理员可删除，确认文案为 `删除这条评论？` |
| 点击发送按钮 | 按当前输入状态发送评论、回复或保存编辑 |
| `Ctrl / Cmd + Enter` | 按当前输入状态提交 |

## 5. 输入状态

| 状态 | 输入框提示 | 提交按钮含义 |
| --- | --- | --- |
| 默认评论 | `添加评论...` | 发送评论 |
| 回复外层评论 | `回复 {作者}...` | 发送回复 |
| 回复详情默认输入 | `添加回复...` | 发送回复 |
| 回复内层评论 | `回复 {作者}...` | 发送回复 |
| 编辑评论 | `编辑评论...` | 保存评论 |

## 6. 暂不包含

- 点赞或表情反应。
- `@` 提及。
- 图片或文件评论。
- 链接卡片预览。
