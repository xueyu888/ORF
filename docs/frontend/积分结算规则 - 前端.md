# 积分结算规则 - 前端

非验收页只展示积分结算结果，不自行判定验收或贡献比例。验收页允许指挥官查看匿名互评明细并确认最终贡献比例。

后端口径见 [积分结算规则.md](../rules/积分结算规则.md)，匿名互评见 [贡献评价与积分分配规则.md](../rules/贡献评价与积分分配规则.md)。

## 展示字段

| 字段 | 说明 |
| --- | --- |
| 目标总分 | 冻结前已校准指标不确定性分之和 |
| 完成系数 | 目标验收后的结算系数 |
| 目标结算积分 | `目标总分 × 完成系数` |
| 贡献比例 | 指挥官验收时确认的目标级最终贡献比例，默认来自 ORF 代理读取的共享匿名互评均值 |
| 个人积分 | `目标结算积分 × 贡献比例`，以 `pointLedger` 为准 |

## 展示规则

- 不展示指标级个人积分。
- 指标只展示难度分、指标积分和验收结果；未校准时显示“待校准”。
- 悬赏大厅无指标或存在未校准指标时，目标奖励显示“待校准”，不显示 `0 分`。
- 当前不单独发放指标定义分。
- 普通成员提交匿名互评时，前端只提交逐指标整数百分比矩阵或弃权说明到 ORF 同源代理；ORF 后端补齐服务端指标和挑战者事实后转发给共享结算服务。
- 管理员验收时通过 ORF 同源代理读取共享结算服务给出的提交状态、原始评分、均值和偏离提醒，再确认最终贡献比例后提交给 ORF 后端结算。
- `pointLedger` 是公开积分结果，统计页可展示所有成员积分。
- 目标结算完成后，目标相关成员会收到 `objective.settled` 个人系统通知；通知只提示目标已结算并打开统计页，不展示匿名互评明细或个人积分明细。
- 评价缺失、弃权、申诉或偏差超过 `10%` 时在验收页提示指挥官，但不阻止指挥官确认最终比例并结算。
