# 积分结算规则 - 前端

前端只展示积分结算结果，不自行判定验收或贡献比例。

后端口径见 [积分结算规则.md](../rules/积分结算规则.md)，匿名互评见 [贡献评价与积分分配规则.md](../rules/贡献评价与积分分配规则.md)。

## 展示字段

| 字段 | 说明 |
| --- | --- |
| 目标总分 | 已验收悬赏指标不确定性分之和 |
| 完成系数 | 目标验收后的结算系数 |
| 目标结算积分 | `目标总分 × 完成系数` |
| 贡献比例 | 目标级匿名互评结果 |
| 个人积分 | `目标结算积分 × 贡献比例 + 定义分` |

## 展示规则

- 不展示指标级个人积分。
- 悬赏指标只展示难度分和验收结果。
- 贡献比例只在目标结算后展示。
- 评价缺失、申诉、偏差过大时展示“待主管核查”。
