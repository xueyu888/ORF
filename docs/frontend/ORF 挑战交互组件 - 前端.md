# ORF 挑战交互组件 - 前端

本文档描述挑战页内复用交互组件，不描述页面布局。

## 1. 行操作

行操作绑定目标、悬赏、行动项、子行动项。

| 操作 | 说明 |
| --- | --- |
| `+` | 新增当前行的下级对象 |
| 拖拽手柄 | 拖拽排序或移动所属关系 |
| 复制链接 | 复制当前行锚点链接 |
| 评论 | 打开评论组件 |
| 编辑 | 进入标题行内编辑 |
| 删除 | 删除当前对象，删除前展示影响范围 |

行操作只在 hover 当前行或菜单打开时显示。

## 2. 权限拦截

前端在执行写操作前检查 `permissionRules`。

| 操作 | 权限动作 |
| --- | --- |
| 新增 | `create` |
| 编辑标题 | `edit` |
| 勾选完成 | `edit` |
| 拖拽 | `edit` |
| 删除 | `delete` |

无权限时只提示，不执行状态修改。

## 3. 拖拽反馈

拖拽支持三种落点：

| 落点 | 含义 |
| --- | --- |
| `before` | 放到目标行前面 |
| `after` | 放到目标行后面 |
| `inside` | 移入目标对象内部 |

拖拽中显示当前拖拽行弱化样式，并高亮可放置位置。

## 4. 删除确认

删除确认必须展示受影响下级数量。

| 删除对象 | 确认内容 |
| --- | --- |
| 目标 | 悬赏、行动项、子行动项数量 |
| 悬赏 | 行动项、子行动项数量 |
| 行动项 | 子行动项数量 |
| 子行动项 | 当前子行动项标题 |

## 5. 更新时间来源

悬赏行最近更新时间取以下字段的最新值：

| 来源 | 字段 |
| --- | --- |
| 悬赏趋势 | `Result.trend[-1].date` |
| 行动项 | `Task.updatedAt` |
| 子行动项 | `TaskChecklistItem.updatedAt` |
| 反馈 | `Feedback.updatedAt` |
| 历史材料 | `Evidence.date` |

前端不展示历史材料入口，但仍允许旧数据参与更新时间计算。
