# ORF 挑战交互组件 - 前端

本文档描述挑战页内复用交互组件，不描述页面布局。

## 1. 行操作

行操作绑定目标、指标、任务、子任务。

| 操作 | 说明 |
| --- | --- |
| `+` | 新增当前行的下级对象 |
| 拖拽手柄 | 拖拽排序 |
| 复制链接 | 复制当前行锚点链接 |
| 评论 | 打开评论组件 |
| 编辑 | 进入标题行内编辑 |
| 删除 | 删除当前对象，删除前展示影响范围 |

行操作只在 hover 当前行或菜单打开时显示。空指标区是例外：当当前用户具备新增 / 提出指标能力时，“待定义指标”空态必须直接显示对应按钮，且同一空目标不要再重复显示目标行 `+` 指标入口。

菜单打开时，所属目标卡片进入前景态。层级提升发生在目标卡片层，不在单个菜单上硬提 `z-index`，避免菜单被相邻目标卡片遮挡。

## 2. 权限拦截

前端在执行下列操作前检查 `permissionRules`。

| 操作 | 权限 key |
| --- | --- |
| 新增指标 | `result.create` |
| 编辑目标 | `objective.edit` |
| 编辑指标 | `result.edit` |
| 拖拽指标 | `result.edit` |
| 删除目标 | `objective.delete` |
| 删除指标 | `result.delete` |
| 删除行动项 | `task.delete` |
| 删除子行动项 | `subtask.delete` |

无权限时只提示，不执行状态修改。

## 3. 拖拽反馈

拖拽支持三种落点：

| 落点 | 含义 |
| --- | --- |
| `before` | 放到目标行前面 |
| `after` | 放到目标行后面 |
| `inside` | 移入目标对象内部 |

拖拽中显示当前拖拽行弱化样式，并高亮可放置位置。

## 4. 删除确认

删除确认必须展示受影响下级数量。

| 删除对象 | 确认内容 |
| --- | --- |
| 目标 | 指标、任务、子任务数量 |
| 指标 | 反馈、证据和评论影响 |
| 任务 | 子任务数量 |
| 子任务 | 当前子任务标题 |

## 5. 更新时间来源

指标行最近更新时间取以下字段的最新值：

| 来源 | 字段 |
| --- | --- |
| 指标趋势 | `Result.trend[-1].date` |
| 反馈 | `Feedback.updatedAt` |
| 历史材料 | `Evidence.date` |

前端不展示历史材料入口，但仍允许旧数据参与更新时间计算。

任务行最近更新时间只来自 `Task.updatedAt` 和其子任务 `TaskChecklistItem.updatedAt`。任务不参与指标行更新时间聚合，避免重新形成任务从属指标的隐式关系。
