# ORF 登录页面

## 接口访问约定

前端数据统一通过同源 `/api` 请求后端接口，例如 `/api/tasks`。
前端不直接写死后端域名或端口，开发和生产环境由代理或网关转发到实际后端服务。

本文档只记录登录页前端组件、触发方式、触发后的动作和前端状态。

登录页用于注册、登录和登录页背景切换。已登录用户访问登录页时进入挑战页；未确认登录态时仍先展示登录页，不阻塞视觉预览。

登录页背景属于系统设置中的 `login_background`，不读取个人设置。个人背景只在登录后的 AppShell 中生效。

## 1. 页面结构

登录页固定由三层组成：

```text
背景层
└─ 顶部背景选择层
└─ 登录面板
```

| 层级 | 组件 | 展示规则 |
| --- | --- | --- |
| 1 | 背景图 | 铺满整个视口；不可拖拽、不可框选；作为装饰层，不参与表单交互。 |
| 2 | 顶部黑色渐变 | 默认隐藏；只在背景选择触发区 hover 时显示；从页面顶端向下覆盖到略超过选择点的位置。 |
| 3 | 背景选择点组 | 默认隐藏；位于页面顶部中间；可用背景有几个就显示几个点；选中点偏白并带灰色圆环，未选中点偏灰。 |
| 4 | 登录面板 | 位于页面左侧；包含 ORF 图标、标题、表单、分隔线和模式切换按钮。 |

背景选择点组和顶部黑色渐变出现、消失时必须同时具备：

- 从透明到不透明的 opacity 变化。
- 从页面顶部向下展开 / 向上收起的抽屉式位移动画。
- 鼠标离开触发区后自动隐藏；点击选择点后不保留显示状态。

## 2. 组件排列

### 登录页 `<AuthPage>`

| 顺序 | 组件 | 前端展示规则 |
| --- | --- | --- |
| 1 | 背景图 | 使用系统 `login_background` 当前选中的背景；没有选中项时使用系统默认背景。 |
| 2 | 顶部黑色渐变 | 背景选择点组可用时存在；默认透明隐藏。 |
| 3 | 背景选择触发区 | 位于页面顶部中间，形成一个横向胶囊形 hover 区域；区域高度约为视口高度的十五分之一的一半。 |
| 4 | 背景选择点组 | 横向排列；点直径较小；不显示图片名称、tooltip 或其它提示内容。 |
| 5 | 登录面板 | 固定承载认证表单；不显示额外装饰块。 |

### 登录面板 `<AuthPanel>`

| 顺序 | 组件 | 前端展示规则 |
| --- | --- | --- |
| 1 | ORF 图标 | 位于面板顶部中间；不可拖拽、不可框选。 |
| 2 | 标题 | 登录模式显示 `Sign in`；注册模式显示 `Register`。 |
| 3 | 姓名输入框 | 只在注册模式显示。 |
| 4 | 邮箱输入框 | 登录模式和注册模式都显示。 |
| 5 | 密码输入框 | 登录模式和注册模式都显示；右侧带显示 / 隐藏密码按钮。 |
| 6 | 错误提示 | 只有认证失败时显示在表单内。 |
| 7 | 主按钮 | 登录模式显示 `Sign In`；注册模式显示 `Create Account`；提交中显示提交状态文案。 |
| 8 | 分隔线 | 主按钮和模式切换按钮之间的视觉分隔。 |
| 9 | 模式切换按钮 | 登录模式显示 `Register`；注册模式显示 `Sign In`。 |

输入框规则：

- 姓名、邮箱、密码都使用胶囊输入框。
- 邮箱输入框使用邮箱输入类型。
- 密码输入框根据密码可见状态在明文和密文之间切换。
- 输入框内容允许选中和编辑；背景图、ORF 图标和按钮不允许被页面框选。

## 3. 触发方式与动作

| 触发对象 | 触发方式 | 前端动作 | 状态变化 |
| --- | --- | --- | --- |
| 登录页路由 | 访问 `/auth` | 渲染登录页；若登录态确认且已登录，跳转到挑战页。 | `authReady && isAuthenticated` 时离开登录页；否则停留登录页。 |
| 背景选择触发区 | 鼠标进入顶部中间区域 | 显示背景选择点组和顶部黑色渐变。 | 点组和渐变进入可见态。 |
| 背景选择触发区 | 鼠标离开顶部中间区域 | 隐藏背景选择点组和顶部黑色渐变。 | 点组和渐变回到隐藏态。 |
| 背景选择点 | 点击某个点 | 切换当前登录页背景预览。 | `selectedHeroId` 更新；被点击点进入选中态，其它点进入未选中态。 |
| 邮箱输入框 | 输入内容 | 更新邮箱字段。 | `email` 更新；清空当前错误提示。 |
| 密码输入框 | 输入内容 | 更新密码字段。 | `password` 更新；清空当前错误提示。 |
| 姓名输入框 | 输入内容 | 更新姓名字段。 | `name` 更新；清空当前错误提示。 |
| 显示 / 隐藏密码按钮 | 点击 | 切换密码输入框展示方式。 | `showPassword` 在 true / false 之间切换。 |
| 主按钮 | 点击或表单提交 | 根据当前模式提交登录或注册。 | `submitting` 进入 true，提交结束后回到 false。 |
| 模式切换按钮 | 点击 | 在登录模式和注册模式之间切换。 | `mode` 在 `login` / `register` 之间切换；标题、主按钮、切换按钮和姓名输入框同步变化。 |

## 4. 前端状态

| 状态 | 类型 | 初始值 | 说明 |
| --- | --- | --- | --- |
| `mode` | `login` / `register` | `login` | 控制页面处于登录模式还是注册模式。 |
| `selectedHeroId` | 系统登录背景标识 | 默认背景 | 控制当前展示的系统登录背景图；不来自个人设置。 |
| `email` | 字符串 | 空 | 邮箱输入框内容。 |
| `name` | 字符串 | 空 | 姓名输入框内容，只在注册模式使用。 |
| `password` | 字符串 | 空 | 密码输入框内容。 |
| `showPassword` | 布尔值 | `false` | 控制密码明文 / 密文显示。 |
| `submitting` | 布尔值 | `false` | 控制提交中状态，防止重复提交。 |
| `authError` | 字符串 | 空 | 认证失败时显示的表单错误。 |
| `authReady` | 布尔值 | 来自全局认证状态 | 控制是否允许提交认证请求。 |
| `isAuthenticated` | 布尔值 | 来自全局认证状态 | 控制已登录用户是否跳转到挑战页。 |

派生展示：

| 派生项 | 规则 |
| --- | --- |
| 页面标题 | `mode = login` 时显示 `Sign in`；`mode = register` 时显示 `Register`。 |
| 主按钮文案 | `mode = login` 时显示 `Sign In`；`mode = register` 时显示 `Create Account`；`submitting = true` 时显示提交中文案。 |
| 模式切换按钮文案 | `mode = login` 时显示 `Register`；`mode = register` 时显示 `Sign In`。 |
| 姓名输入框可见性 | 只在 `mode = register` 时显示。 |
| 密码输入框类型 | `showPassword = true` 时为明文；否则为密文。 |
| 错误提示可见性 | `authError` 非空时显示。 |

## 5. 提交流程

### 登录模式

```text
提交表单
校验 authReady 和 submitting
清空 authError
裁剪邮箱首尾空白并转成小写
submitting = true
调用密码登录
submitting = false
```

登录成功：

- 跳转到挑战页。

登录失败：

- `authError` 设置为失败原因。
- 显示同内容的全局提示。
- 停留在登录页。

### 注册模式

```text
提交表单
校验 authReady 和 submitting
清空 authError
裁剪姓名和邮箱首尾空白，邮箱转成小写
submitting = true
调用密码注册
submitting = false
```

注册成功：

- 跳转到挑战页。

注册失败：

- `authError` 设置为失败原因。
- 显示同内容的全局提示。
- 邮箱已注册时显示 `邮箱已存在`。
- 邮箱格式错误时显示 `邮箱格式不正确`。
- 密码不足 8 位时显示 `密码至少 8 位`。
- 停留在注册模式。

## 6. 禁用与兜底

| 场景 | 前端行为 |
| --- | --- |
| 认证状态未就绪 | 登录页仍然展示；主按钮和模式切换按钮禁用。 |
| 正在提交 | 主按钮和模式切换按钮禁用；主按钮显示提交中文案。 |
| 已登录用户访问登录页 | 认证状态确认后跳转到挑战页。 |
| 后端暂不可用 | 登录页视觉仍可展示；提交登录或注册时显示失败提示。 |
| 可用背景数量小于 2 | 不显示背景选择点组和顶部黑色渐变。 |
