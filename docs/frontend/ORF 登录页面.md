# ORF 登录页面

## 接口访问约定

前端数据统一通过同源 `/api` 请求后端接口，例如 `/api/tasks`。
前端不直接写死后端域名或端口，开发和生产环境由代理或网关转发到实际后端服务。

本文档只记录登录页前端组件、触发方式、触发后的动作和前端状态。

登录页用于注册、登录和登录页背景切换。已登录用户访问登录页时进入挑战页；未确认登录态时仍先展示登录页，不阻塞视觉预览。

登录页背景的系统默认事实源是系统设置中的 `login_background`。用户登录后可以在个人设置里维护自己的 `login_background`；前端只把当前用户选中的登录页背景压缩成只读本机预览缓存，供下次未登录时展示。未登录状态不能访问后端个人背景文件，因此没有缓存时只展示系统默认或内置默认图。登录页背景渲染复用统一固定 frame 背景槽位组件，不能保留独立的登录页取景算法。

登录页不把密码作为 ORF 业务事实保存到前端 `localStorage`。浏览器访问时只使用标准表单 `autocomplete` 和浏览器密码管理器；Win11 桌面客户端访问时，已保存账号由 Electron 主进程通过系统 `safeStorage` 加密后写入本机客户端数据目录，前端只通过受限 IPC 读取账号列表或在用户选择/提交时临时读取密码。

## 1. 页面结构

登录页固定由三层组成：

```text
背景层
└─ 顶部背景选择层
└─ 登录面板
```

| 层级 | 组件 | 展示规则 |
| --- | --- | --- |
| 1 | 背景图 | 使用统一固定 frame 背景槽位铺在整个视口；不可拖拽、不可框选；作为装饰层，不参与表单交互。 |
| 2 | 顶部黑色渐变 | 默认隐藏；只在背景选择触发区 hover 时显示；从页面顶端向下覆盖到略超过选择点的位置。 |
| 3 | 背景选择点组 | 默认隐藏；位于页面顶部中间；可用背景有几个就显示几个点；选中点偏白并带灰色圆环，未选中点偏灰。 |
| 4 | 登录面板 | 位于页面左侧；包含 ORF 图标、标题、表单、分隔线和模式切换按钮。 |

背景选择点组和顶部黑色渐变出现、消失时必须同时具备：

- 从透明到不透明的 opacity 变化。
- 从页面顶部向下展开 / 向上收起的抽屉式位移动画。
- 鼠标离开触发区后自动隐藏；点击选择点后不保留显示状态。

## 2. 组件排列

### 登录页 `<AuthPage>`

| 顺序 | 组件 | 前端展示规则 |
| --- | --- | --- |
| 1 | 背景图 | 优先使用本机缓存的当前用户个人登录页背景预览；没有缓存时使用系统 `login_background` 当前选中的背景；仍没有选中项时使用内置默认背景。系统图库在所有规范槽位间共享，因此登录页列出的 `default`、`system` 图片均允许未登录读取；`personal` 图片仍只能使用本机缓存预览，不能在未登录状态访问后端文件。 |
| 2 | 顶部黑色渐变 | 背景选择点组可用时存在；默认透明隐藏。 |
| 3 | 背景选择触发区 | 位于页面顶部中间，形成一个横向胶囊形 hover 区域；区域高度约为视口高度的十五分之一的一半。 |
| 4 | 背景选择点组 | 横向排列；点直径较小；不显示图片名称、tooltip 或其它提示内容。 |
| 5 | 登录面板 | 固定承载认证表单；不显示额外装饰块。 |

### 登录面板 `<AuthPanel>`

| 顺序 | 组件 | 前端展示规则 |
| --- | --- | --- |
| 1 | ORF 图标 | 位于面板顶部中间；不可拖拽、不可框选。 |
| 2 | 标题 | 登录模式显示 `Sign in`；注册模式显示 `Register`。 |
| 3 | 姓名输入框 | 只在注册模式显示。 |
| 4 | 已保存账号列表 | 只在登录模式、Win11 桌面客户端且本机存在已保存账号时显示；列表只展示账号标识，不展示密码。 |
| 5 | 邮箱输入框 | 登录模式和注册模式都显示。 |
| 6 | 密码输入框 | 登录模式和注册模式都显示；右侧带显示 / 隐藏密码按钮。 |
| 7 | 记住凭据开关 | 桌面客户端显示“记住到本机”；浏览器显示“让浏览器记住”。 |
| 8 | 错误提示 | 只有认证失败时显示在表单内。 |
| 9 | 主按钮 | 登录模式显示 `Sign In`；注册模式显示 `Create Account`；提交中显示提交状态文案。 |
| 10 | 分隔线 | 主按钮和模式切换按钮之间的视觉分隔。 |
| 11 | 模式切换按钮 | 登录模式显示 `Register`；注册模式显示 `Sign In`。 |

输入框规则：

- 姓名、邮箱、密码都使用胶囊输入框。
- 邮箱输入框使用邮箱输入类型。
- 密码输入框根据密码可见状态在明文和密文之间切换。
- 输入框内容允许选中和编辑；背景图、ORF 图标和按钮不允许被页面框选。

## 3. 触发方式与动作

| 触发对象 | 触发方式 | 前端动作 | 状态变化 |
| --- | --- | --- | --- |
| 登录页路由 | 访问 `/auth` | 渲染登录页；若登录态确认且已登录，跳转到挑战页。 | `authReady && isAuthenticated` 时离开登录页；否则停留登录页。 |
| 背景选择触发区 | 鼠标进入顶部中间区域 | 显示背景选择点组和顶部黑色渐变。 | 点组和渐变进入可见态。 |
| 背景选择触发区 | 鼠标离开顶部中间区域 | 隐藏背景选择点组和顶部黑色渐变。 | 点组和渐变回到隐藏态。 |
| 背景选择点 | 点击某个点 | 切换当前登录页背景预览。 | `selectedHeroId` 更新；被点击点进入选中态，其它点进入未选中态。 |
| 邮箱输入框 | 输入内容 | 更新邮箱字段。 | `email` 更新；清空当前错误提示。 |
| 密码输入框 | 输入内容 | 更新密码字段。 | `password` 更新；清空当前错误提示。 |
| 姓名输入框 | 输入内容 | 更新姓名字段。 | `name` 更新；清空当前错误提示。 |
| 显示 / 隐藏密码按钮 | 点击 | 切换密码输入框展示方式。 | `showPassword` 在 true / false 之间切换。 |
| 已保存账号 | 点击账号 | 从桌面客户端本机加密 vault 读取该账号密码并填入登录表单。 | `email`、`password` 和 `selectedSavedAccountId` 更新；不改服务端认证状态。 |
| 删除已保存账号 | 点击删除按钮 | 从桌面客户端本机加密 vault 删除该账号。 | `savedCredentialAccounts` 更新；如果删除当前选中账号，则清空邮箱和密码。 |
| 记住凭据开关 | 点击 | 切换登录成功后是否保存凭据。 | `rememberCredentials` 在 true / false 之间切换。 |
| 主按钮 | 点击或表单提交 | 根据当前模式提交登录或注册。 | `submitting` 进入 true，提交结束后回到 false。 |
| 模式切换按钮 | 点击 | 在登录模式和注册模式之间切换。 | `mode` 在 `login` / `register` 之间切换；标题、主按钮、切换按钮和姓名输入框同步变化。 |

## 4. 前端状态

| 状态 | 类型 | 初始值 | 说明 |
| --- | --- | --- | --- |
| `mode` | `login` / `register` | `login` | 控制页面处于登录模式还是注册模式。 |
| `selectedHeroId` | 登录背景标识 | 默认背景 | 控制当前展示的登录背景图；可以是本机缓存的个人预览，也可以是系统登录背景。 |
| `savedCredentialAccounts` | 本机已保存账号列表 | 空 | 只来自桌面客户端主进程加密 vault；浏览器访问时为空。 |
| `credentialProvider` | `browser` / `desktop` | `browser` | 控制记住凭据开关文案；不代表服务端认证状态。 |
| `selectedSavedAccountId` | 字符串 | 空 | 当前选中的本机已保存账号标识。 |
| `email` | 字符串 | 空 | 邮箱输入框内容。 |
| `name` | 字符串 | 空 | 姓名输入框内容，只在注册模式使用。 |
| `password` | 字符串 | 空 | 密码输入框内容。 |
| `showPassword` | 布尔值 | `false` | 控制密码明文 / 密文显示。 |
| `rememberCredentials` | 布尔值 | `true` | 控制登录或注册成功后是否触发当前环境的凭据保存能力。 |
| `submitting` | 布尔值 | `false` | 控制提交中状态，防止重复提交。 |
| `authError` | 字符串 | 空 | 认证失败时显示的表单错误。 |
| `authReady` | 布尔值 | 来自全局认证状态 | 控制是否允许提交认证请求。 |
| `isAuthenticated` | 布尔值 | 来自全局认证状态 | 控制已登录用户是否跳转到挑战页。 |

派生展示：

| 派生项 | 规则 |
| --- | --- |
| 页面标题 | `mode = login` 时显示 `Sign in`；`mode = register` 时显示 `Register`。 |
| 主按钮文案 | `mode = login` 时显示 `Sign In`；`mode = register` 时显示 `Create Account`；`submitting = true` 时显示提交中文案。 |
| 模式切换按钮文案 | `mode = login` 时显示 `Register`；`mode = register` 时显示 `Sign In`。 |
| 姓名输入框可见性 | 只在 `mode = register` 时显示。 |
| 已保存账号列表可见性 | 只在 `mode = login` 且 `savedCredentialAccounts` 非空时显示。 |
| 记住凭据文案 | `credentialProvider = desktop` 时显示“记住到本机”；否则显示“让浏览器记住”。 |
| 密码输入框类型 | `showPassword = true` 时为明文；否则为密文。 |
| 错误提示可见性 | `authError` 非空时显示。 |
| 登录背景取景 | 当前背景可以携带 `centerX`、`centerY` 和 `zoom`；系统背景从系统设置读取，个人背景从本机预览缓存读取；渲染时按统一背景槽位模型派生 cover-crop 取景，`zoom=1` 表示刚好铺满且不能露底。 |

## 5. 提交流程

### 登录模式

```text
提交表单
校验 authReady 和 submitting
清空 authError
裁剪邮箱首尾空白并转成小写
如果登录模式下当前选中本机已保存账号且密码为空，先从桌面 vault 临时读取密码
submitting = true
调用密码登录
submitting = false
```

登录成功：

- `rememberCredentials = true` 时，桌面客户端把账号密码交给主进程加密保存；浏览器访问时交给浏览器密码管理器。
- `rememberCredentials = false` 时，桌面客户端删除同邮箱的本机保存记录；浏览器访问时不写 ORF 自有凭据存储。
- 跳转到挑战页。

登录失败：

- `authError` 设置为失败原因。
- 显示同内容的全局提示。
- 停留在登录页。

### 注册模式

```text
提交表单
校验 authReady 和 submitting
清空 authError
裁剪姓名和邮箱首尾空白，邮箱转成小写
submitting = true
调用密码注册
submitting = false
```

注册成功：

- `rememberCredentials = true` 时，按当前环境保存凭据；桌面客户端使用本机加密 vault，浏览器访问时交给浏览器密码管理器。
- 跳转到挑战页。

注册失败：

- `authError` 设置为失败原因。
- 显示同内容的全局提示。
- 邮箱已注册时显示 `邮箱已存在`。
- 邮箱格式错误时显示 `邮箱格式不正确`。
- 密码不足 8 位时显示 `密码至少 8 位`。
- 停留在注册模式。

## 6. 禁用与兜底

| 场景 | 前端行为 |
| --- | --- |
| 认证状态未就绪 | 登录页仍然展示；主按钮和模式切换按钮禁用。 |
| 正在提交 | 主按钮和模式切换按钮禁用；主按钮显示提交中文案。 |
| 已登录用户访问登录页 | 认证状态确认后跳转到挑战页。 |
| 后端暂不可用 | 登录页视觉仍可展示；提交登录或注册时显示失败提示。 |
| 已登录用户设置了登录页背景 | 登录后的个人设置保存 `login_background` 后，同时刷新本机预览缓存；下次未登录打开登录页时可展示个人背景。 |
| 本机没有个人登录页背景缓存 | 未登录登录页不能读取个人后端文件，回退系统登录背景或内置默认背景。 |
| 可用背景数量小于 2 | 不显示背景选择点组和顶部黑色渐变。 |
| 桌面安全存储不可用 | 登录仍可继续；本机凭据保存失败时提示无法安全保存账号。 |
| 浏览器不支持 Credential Management API | 登录仍可继续；ORF 不写入自有密码存储，仍保留标准 `autocomplete` 让浏览器自行处理。 |
