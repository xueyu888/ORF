# ORF 挑战树线展示规则

## 1. 适用范围

本文档定义挑战页目标树的树线展示规则。

适用对象：

```text
目标
├─ 指标
└─ 任务
   └─ 子任务
```

本文档只描述前端几何展示，不描述后端数据关系和权限规则。

---

## 2. 绘制原则

* 树线只根据当前可见父子关系绘制。
* 折叠隐藏的任务和子任务不参与绘制。
* 父节点到子节点只允许一条竖线加一条圆角横线。
* 横线终点贴到子节点主图标左边缘，不能穿过图标。
* 父级竖线只延伸到最后一个可见子节点。
* 新增、删除、拖拽、折叠、展开、刷新后，需要重新测量树线。
* 树线和层级缩进只允许影响主标题列，不允许改变右侧元信息列的网格。
* 折叠入口、块操作入口和拖拽手柄属于操作层，不能参与主图标锚点计算。
* 指标详情 hover/focus 展开块是指标行的附属展示层，不是新的树节点，不参与父子关系、锚点测量、拖拽排序或树线绘制。

---

## 3. 锚点

每个节点只用主图标作为锚点：

| 对象 | 主图标 |
| --- | --- |
| 目标 | 旗帜 |
| 指标 | 方块 |
| 任务 | 勾选框 |
| 子任务 | 勾选框 |

锚点位置表示当前行内主图标左边缘相对行左侧的距离：

| 对象 | 锚点 |
| --- | ---: |
| 指标 | `56px` |
| 任务 | `56px` |
| 子任务 | `84px` |

折叠入口和块操作入口使用同一套锚点常量派生：

| 对象 | 操作入口右侧贴近位置 |
| --- | ---: |
| 指标 | `24px` |
| 任务 | `24px` |
| 子任务 | `52px` |

竖线轨道不单独硬编码。每组父子关系的竖向轨道使用父节点主图标中心 x 坐标；横线终点使用子节点主图标左边缘。这样目标到指标、目标到任务、任务到子任务都跟随真实 DOM 锚点。

---

## 4. 几何常量

```ts
HIERARCHY_TREE_METRICS = {
  anchorLeftByDepth: {
    1: 56,
    2: 84,
  },
  disclosureLeftByDepth: {
    1: 24,
    2: 52,
  },
  indentStep: 28,
  branchLength: 20,
}
```

含义：

| 常量 | 含义 |
| --- | --- |
| `indentStep` | 每层缩进步长 |
| `branchLength` | 圆角横线视觉长度 |
| `anchorLeftByDepth` | 主图标左边缘位置 |
| `disclosureLeftByDepth` | 折叠入口和块操作入口位置 |

---

## 5. 错误判定

以下情况视为展示错误：

* 树线压住图标。
* 树线连接到旧位置。
* 树线跨越非父子节点。
* 横线穿过图标或进入图标内部。
* 父级竖线穿过最后一个可见子节点继续向下延伸。
* 为修树线改变整行 `grid-template-columns`，导致目标剩余时间、日期、进度等右侧列不再对齐。
