# ORF 挑战树线展示规则

## 1. 适用范围

本文档定义挑战页目标树的树线展示规则。

适用对象：

```text
目标
└─ 悬赏
   └─ 行动项
      └─ 子行动项
```

本文档只描述前端几何展示，不描述后端数据关系和权限规则。

---

## 2. 绘制原则

* 树线只根据当前可见父子关系绘制。
* 折叠隐藏的行动项和子行动项不参与绘制。
* 父节点到子节点只允许一条竖线加一条圆角横线。
* 横线终点贴到子节点主图标左边缘，不能穿过图标。
* 父级竖线只延伸到最后一个可见子节点。
* 新增、删除、拖拽、折叠、展开、刷新后，需要重新测量树线。

---

## 3. 锚点

每个节点只用主图标作为锚点：

| 对象 | 主图标 |
| --- | --- |
| 目标 | 旗帜 |
| 悬赏 | 方块 |
| 行动项 | 勾选框 |
| 子行动项 | 勾选框 |

锚点位置：

| 对象 | 锚点 |
| --- | ---: |
| 悬赏 | `56px` |
| 行动项 | `84px` |
| 子行动项 | `112px` |

竖线轨道：

| 层级 | 轨道 |
| --- | ---: |
| 悬赏 | `36px` |
| 行动项 | `64px` |
| 子行动项 | `92px` |

---

## 4. 几何常量

```ts
HIERARCHY_TREE_METRICS = {
  indentStep: 28,
  branchLength: 20,
}
```

含义：

| 常量 | 含义 |
| --- | --- |
| `indentStep` | 每层缩进步长 |
| `branchLength` | 圆角横线视觉长度 |

---

## 5. 错误判定

以下情况视为展示错误：

* 树线压住图标。
* 树线连接到旧位置。
* 树线跨越非父子节点。
* 横线穿过图标或进入图标内部。
* 父级竖线穿过最后一个可见子节点继续向下延伸。
