# ORF 悬赏目标流程 - 前端

## 页面定位

悬赏大厅是目标挑战入口。成员在这里查看可申请目标、申请挑战、接受征召、进入我的挑战。

## 页面内容

| 区域 | 必要内容 |
| --- | --- |
| 页头 | `悬赏大厅`、我的挑战入口、提出候选目标入口 |
| 我的贡献 | 当前用户积分、积分明细入口 |
| 征召令 | 当前用户被征召的目标 |
| 工具栏 | 搜索、难度筛选、周期筛选、排序 |
| 可申请目标 | 目标卡片列表 |
| 轻详情 | 目标说明、指标清单、当前操作 |

## 目标卡片

目标卡片展示：

- 目标标题。
- 指标摘要和指标数量。
- 目标总分。
- 最高难度。
- 当前挑战者数量。
- 剩余时间。
- `申请挑战` 操作。

点击卡片主体打开轻详情；点击 `申请挑战` 打开确认弹窗。

## 征召卡片

征召卡片展示目标标题、指标数量、目标总分、最高难度、剩余时间和操作。

当前阶段被征召成员必须接受挑战。接受后成为目标挑战者，并进入确认期；确认期内仍可发起重估。

## 状态

| 状态 | 前端展示 |
| --- | --- |
| 可申请 | 显示在可申请目标列表 |
| 申请中 | 当前用户已申请，等待指挥官确认 |
| 征召中 | 显示在征召令 |

确认中、挑战中、待验收、已结算由我的挑战页面承接。

## 数据口径

| 字段 | 用途 |
| --- | --- |
| `Objective.challengers` | 当前目标挑战者；用于挑战者数量和互评范围 |
| `Objective.challengeApplications` | 当前用户申请状态 |
| `Objective.assignedChallengers` | 当前用户是否被征召 |
| `Objective.finalDueAt` | 剩余时间、排序、确认期计算 |
| `Result.uncertaintyLevel` | 最高难度和目标总分来源 |

不在 `Result` 层表达挑战关系。
