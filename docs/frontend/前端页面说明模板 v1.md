# XXX 页面 - 前端说明

## 0. 模板说明

本模板写给 AI / Codex，用于约束前端页面说明文档的写法。

目标：

- 让具体页面文档结构稳定
- 让具体页面文档只描述当前页面
- 让 AI 明确页面由哪些区域和组件组成
- 让 AI 理解每个部分展示什么
- 让 AI 理解当前页面的核心交互与状态

使用规则：

- 具体页面文档必须严格按照本模板的章节顺序编写
- 本节 `0. 模板说明` 只存在于模板文件中，不复制到具体页面文档
- 具体页面文档从 `1. 页面目录` 开始
- 不要把模板中的说明性文字原样复制到具体页面文档
- 模板中没有合适位置承载的内容，应单独说明，不强行塞入页面文档
- 前端页面文档只写 UI、UI 状态和用户可感知交互，尽可能不写业务逻辑
- 业务计算、权限判定、接口契约、数据持久化和数据库规则写到后端文档或规则文档

具体页面文档不包含：

- 后端接口设计
- 后端字段定义
- 数据库结构
- 权限系统设计
- 业务计算算法
- 全局样式系统
- 代码文件定位

本文档只描述：


## 3. 组件树与字段说明

本节说明当前页面由哪些组件组成，以及每个组件展示哪些字段。

原则：

* 只说明组件展示什么
* 不说明数据怎么来的
* 不说明后端如何计算
* 不说明代码文件放在哪里
* 组件名是结构占位，具体页面可以替换为实际名称

### 3.1 组件树

```text
<Page>
├─ <PageHeader>
│  ├─ <PageTitle>
│  └─ <PrimaryActions>
├─ <Toolbar>
│  ├─ <SearchInput>
│  ├─ <FilterGroup>
│  └─ <ViewActions>
├─ <MainContent>
│  ├─ <ContentSection>
│  └─ <ContentList / ContentTree / ContentTable>
└─ <OverlayArea>
   ├─ <Drawer>
   ├─ <Modal>
   └─ <Popover>
```

### 3.2 通用组件字段说明

| 组件              | 字段                                           | 含义       | 展示方式         | 说明         |
| --------------- | -------------------------------------------- | -------- | ------------ | ---------- |
| `<PageHeader>`  | `<PageTitle>`                                | 当前页面名称   | 文本           | 位于页面顶部     |
| `<PageHeader>`  | `<PrimaryActions>`                           | 当前页面主操作  | 按钮组          | 位于页面头部右侧   |
| `<Toolbar>`     | `<SearchInput>`                              | 搜索当前页面内容 | 输入框          | 用于关键词过滤    |
| `<Toolbar>`     | `<FilterGroup>`                              | 控制内容范围   | 下拉 / 开关 / 标签 | 按页面需要配置    |
| `<Toolbar>`     | `<ViewActions>`                              | 控制展示方式   | 按钮 / 切换器     | 可选         |
| `<MainContent>` | `<ContentSection>`                           | 内容分组     | 区块           | 用于组织主体内容   |
| `<MainContent>` | `<ContentList / ContentTree / ContentTable>` | 页面核心内容   | 列表 / 树 / 表格  | 根据当前页面类型选择 |
| `<OverlayArea>` | `<Drawer>`                                   | 侧边辅助内容   | 抽屉           | 按需出现       |
| `<OverlayArea>` | `<Modal>`                                    | 临时确认或编辑  | 弹窗           | 按需出现       |
| `<OverlayArea>` | `<Popover>`                                  | 轻量提示或菜单  | 气泡层          | 按需出现       |

交互细则只写用户看到的行为，不写业务判定算法和后端实现。

### 4.1 核心交互

| 交互      | 说明              |
| ------- | --------------- |
| 新增      | 创建新的页面对象        |

| 删除      | 删除当前页面对象        |

| 筛选      | 按条件缩小展示范围       |
| 展开 / 折叠 | 控制层级内容显示        |
| 打开详情    | 进入详情页或打开局部详情    |
| 打开浮层    | 打开抽屉、弹窗、菜单、评论区等 |

| 状态    | 说明                |

| 空态    | 当前无内容可展示          |
| 错误态   | 页面加载失败或操作失败       |
| 编辑态   | 当前对象处于编辑中         |
| 浮层打开态 | 页面存在抽屉、弹窗、菜单或其它浮层 |
