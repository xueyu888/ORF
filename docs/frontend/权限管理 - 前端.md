# 权限管理 - 前端

## 接口访问约定

前端数据统一通过同源 `/api` 请求后端接口，例如 `/api/tasks`。
前端不直接写死后端域名或端口，开发和生产环境由代理或网关转发到实际后端服务。

本文档只记录权限管理页的布局、草稿状态和组件数据字段。

后端 RBAC 模型和接口口径见 [权限管理 - 后端.md](../backend/权限管理%20-%20后端.md)。

## 页面入口

- 路由：`/permissions`。
- 侧边栏展示名：`权限管理`。
- 仅管理员可见、可访问；非管理员进入时跳回计划页。

## 草稿状态

草稿状态指用户在权限矩阵里临时勾选 / 取消的权限，还没有保存到正式权限规则。

| 状态 | 说明 |
| --- | --- |
| `state.permissionRules` | 已保存权限，业务权限判断只读这个。 |
| `draftPermissionRules` | 当前页面编辑中的临时权限。 |
| `selectedRoleHasDraftChanges` | 当前角色的草稿和已保存权限不一致时为 `true`。 |

点击 `保存角色权限` 后，当前角色的草稿覆盖 `state.permissionRules` 中该角色的权限。

## 页面布局

整个页面作为一个权限矩阵大框展示，框内包含角色切换、权限数量、保存入口和权限矩阵。

`保存角色权限` 放在 `成员 / 管理员` 角色切换行右侧，不放在页面底部；权限数量紧贴在保存按钮左侧。

## 页面区域

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 角色切换行 | `成员`、`管理员`、已开启权限数量、保存角色权限 | 左侧切换角色；右侧展示统计并保存当前角色草稿。 |
| 权限矩阵 | 阶段 × 资源 × 动作 | 勾选 / 取消权限，写入草稿状态。 |
| 影响提示 | 当前修改影响的用户数 | 只展示说明，不放保存按钮。 |

## 权限矩阵

```text
can(user, stage, action, resource)
```

| 维度 | 值 |
| --- | --- |
| `stage` | 目标设定 / 悬赏指标领取 / ORF 重估 / 目标冻结 |
| `resource` | 目标 / 悬赏指标 / 任务 / 子任务 |
| `action` | 查看 / 创建 / 编辑 / 删除 |

- 管理员默认拥有全部权限，矩阵只读。
- 成员权限可编辑，修改先进入草稿状态。
- `指挥官` 是产品称呼，不在角色切换行中单独出现；相关操作入口按管理员判断可见 / 可用。

## 组件职责

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `PermissionsPage` | 页面容器 | 读取权限数据，维护当前角色和草稿。 |
| `RoleActionBar` | 角色切换行 | 左侧放角色页签，右侧放权限数量和保存按钮。 |
| `RolePermissionMatrix` | 主体 | 展示四阶段、四资源、四动作的权限矩阵。 |
| `PermissionImpactText` | 矩阵底部 | 展示当前修改会影响多少用户。 |

权限矩阵固定使用以下维度：

| 字段 | 值 |
| --- | --- |
| `stages` | 目标设定、悬赏指标领取、ORF 重估、目标冻结 |
| `resources` | 目标、悬赏指标、任务、子任务 |
| `actions` | 查看、创建、编辑、删除 |
