# 权限管理 - 前端

## 接口访问约定

前端数据统一通过同源 `/api` 请求后端接口，例如 `/api/permissions`。

## 文档定位

本文档只记录权限管理页的布局、草稿状态和前端读取方式。

权限原则和权限清单见 [权限管理.md](../legacy/权限管理.md)。

权限 key 唯一配置来源是 `src/config/permissions.ts`，权限管理页只做这份配置的可视化。

## 页面入口

- 路由：`/permissions`。
- 侧边栏展示名：`权限管理`。
- 仅管理员可见、可访问。
- 页面入口和访问显隐由 [前端显隐配置.md](./前端显隐配置.md) 统一配置。

## 草稿状态

| 状态 | 说明 |
| --- | --- |
| `state.permissionRules` | 已保存权限。 |
| `draftPermissionRules` | 当前页面编辑中的临时权限。 |
| `selectedRoleHasDraftChanges` | 当前角色的草稿和已保存权限不一致时为 `true`。 |

点击 `保存角色权限` 后，当前角色的草稿覆盖已保存权限。

## 页面布局

页面使用一张权限列表展示配置。

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [成员 3 人]  [管理员 1 人]             0 权限  [保存图标] 保存角色权限 │
├────────────────────────────────────────────────────────────────────────┤
│ 分组        权限 key                    含义              使用位置     │
│ 目标        objective.create            新建目标          悬赏大厅...  │
│ 目标        objective.edit              编辑目标          目标页...    │
│ 指标        result.create               新建指标          悬赏大厅...  │
│ ...                                                                    │
│ 当前修改会影响 3 名用户。                                               │
└────────────────────────────────────────────────────────────────────────┘
```

## 页面区域

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 角色切换行 | `成员`、`管理员`、已开启权限数量、保存角色权限 | 左侧切换角色；右侧展示统计并保存当前角色草稿。 |
| 权限列表 | 分组、权限 key、含义、使用位置、开关 | 成员可勾选 / 取消；管理员只读全开。 |
| 影响提示 | 当前修改影响的用户数 | 只展示说明。 |

## 组件职责

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `PermissionsPage` | 页面容器 | 读取权限数据，维护当前角色和草稿。 |
| `RoleActionBar` | 角色切换行 | 切换角色、展示数量、保存草稿。 |
| `RolePermissionList` | 主体 | 按 `src/config/permissions.ts` 展示权限列表。 |
| `PermissionImpactText` | 列表底部 | 展示当前修改会影响多少用户。 |
