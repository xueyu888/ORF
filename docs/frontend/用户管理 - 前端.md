# 用户管理 - 前端

## 接口访问约定

前端数据统一通过同源 `/api` 请求后端接口，例如 `/api/tasks`。
前端不直接写死后端域名或端口，开发和生产环境由代理或网关转发到实际后端服务。

后端认证、用户和团队成员关系见 [用户管理 - 后端.md](../backend/用户管理%20-%20后端.md)。

## 页面入口

- 路由：`/members`。
- 侧边栏展示名：`成员管理`。
- 仅管理员可见、可访问；非管理员进入时跳回计划页。

## 页面区域

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 页面头部 | `成员管理`、用户总数、角色总数 | 只展示统计，不承担操作。 |
| 筛选工具栏 | 姓名 / 邮箱搜索、角色筛选、新增用户 | 搜索和筛选用户；右侧打开新增用户弹窗。 |
| 用户表 | 用户、邮箱、角色、状态、最近登录、操作 | 展示用户列表；支持编辑角色和删除用户。 |

## 交互规则
- 当前用户在列表中显示 `当前` 标记。
- 管理员不能删除自己，也不能将自己的角色降级为成员。
- 删除用户前需要二次确认。
