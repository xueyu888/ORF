# ORF 悬赏流程 - 前端说明

## 1. 页面目录

### 1.1 页面关系

```text
ORF 悬赏流程
├─ 悬赏大厅                 ← 当前文档
├─ 悬赏详情                 ← 待拆分文档
├─ 战利品提交               ← 待拆分文档
└─ 奖励结算                 ← 待拆分文档
```

### 1.2 页面清单

| 页面 | 页面类型 | 入口 | 文档 | 说明 |
| --- | --- | --- | --- | --- |
| 悬赏大厅 | 主页面 | 侧边栏 / 任务管理入口 | 本文档 | 展示悬赏列表、流程阶段和主要操作入口 |
| 悬赏详情 | 子页面 | 从悬赏卡片进入 | 待补充 | 展示单个悬赏的详细信息和操作记录 |
| 战利品提交 | 子页面 / 浮层 | 从悬赏详情或悬赏卡片进入 | 待补充 | 提交完成证据 |
| 奖励结算 | 子页面 / 浮层 | 从验收完成状态进入 | 待补充 | 展示奖励结算结果 |

### 1.3 当前文档范围

本文档只描述：

```text
ORF 悬赏流程
└─ 悬赏大厅                 ← 当前文档
```

从当前页面进入的其它页面，只在页面目录中建立关联，不在本文档展开。

### 2.2 页面区域说明

| 区域 | 含义 | 说明 |
| --- | --- | --- |
| `PageHeader` | 页面头部 | 展示页面标题和主要操作 |
| `FlowSummary` | 流程概览 | 展示悬赏流程阶段、阶段数量和总体进度 |
| `Toolbar` | 工具栏 | 承载搜索、筛选、视图切换等控制项 |
| `MainContent` | 主体内容区 | 展示悬赏大厅的核心内容 |
| `OverlayArea` | 浮层区域 | 承载挑战、重估、提交战利品、结算等临时内容 |

## 3. 组件树与字段说明

### 3.1 组件树

```text
<BountyFlowPage>
├─ <PageHeader>
│  ├─ <PageTitle>
│  └─ <PrimaryActions>
├─ <FlowSummary>
│  ├─ <StageTabs>
│  ├─ <ProgressOverview>
│  └─ <QuickStats>
├─ <Toolbar>
│  ├─ <SearchInput>
│  ├─ <FilterGroup>
│  └─ <ViewActions>
├─ <MainContent>
│  └─ <BountyBoard>
│     ├─ <BountyStageColumn>
│     └─ <BountyCard>
└─ <OverlayArea>
   ├─ <ChallengeDrawer>
   ├─ <ReestimateModal>
   ├─ <LootSubmitModal>
   └─ <SettlementDrawer>
```

### 3.2 通用组件字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<PageHeader>` | `<PageTitle>` | 当前页面名称 | 文本 | 位于页面顶部 |
| `<PageHeader>` | `<PrimaryActions>` | 当前页面主操作 | 按钮组 | 位于页面头部右侧 |
| `<Toolbar>` | `<SearchInput>` | 搜索当前页面内容 | 输入框 | 用于关键词过滤 |
| `<Toolbar>` | `<FilterGroup>` | 控制内容范围 | 下拉 / 开关 / 标签 | 按页面需要配置 |
| `<Toolbar>` | `<ViewActions>` | 控制展示方式 | 按钮 / 切换器 | 可选 |
| `<MainContent>` | `<BountyBoard>` | 页面核心内容 | 看板 / 列表 | 展示悬赏集合 |
| `<OverlayArea>` | `<ChallengeDrawer>` | 挑战操作内容 | 抽屉 | 按需出现 |
| `<OverlayArea>` | `<ReestimateModal>` | 重估操作内容 | 弹窗 | 按需出现 |
| `<OverlayArea>` | `<LootSubmitModal>` | 战利品提交内容 | 弹窗 | 按需出现 |
| `<OverlayArea>` | `<SettlementDrawer>` | 奖励结算内容 | 抽屉 | 按需出现 |

### 3.3 当前页内容字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<FlowSummary>` | `<StageTabs>` | 流程阶段 | 标签 / 分段控制 | 用于切换或定位阶段 |
| `<FlowSummary>` | `<ProgressOverview>` | 当前流程概览 | 进度条 / 数字摘要 | 展示悬赏流转状态 |
| `<FlowSummary>` | `<QuickStats>` | 快速统计 | 指标块 | 展示当前页面摘要 |
| `<BountyStageColumn>` | `<StageName>` | 阶段名称 | 文本 | 悬赏当前所在阶段 |
| `<BountyStageColumn>` | `<StageCount>` | 阶段数量 | 数字 / 徽标 | 展示该阶段悬赏数量 |
| `<BountyCard>` | `<BountyTitle>` | 悬赏名称 | 文本 | 悬赏卡片主标题 |
| `<BountyCard>` | `<BountyType>` | 悬赏类型 | 标签 | 主线悬赏 / 支线悬赏 |
| `<BountyCard>` | `<Difficulty>` | 难度 | 标签 / 星级 / 数值 | 只展示，不描述计算规则 |
| `<BountyCard>` | `<Challenger>` | 挑战者 | 头像 / 文本 | 无挑战者时展示空状态 |
| `<BountyCard>` | `<BountyStatus>` | 悬赏状态 | 标签 | 当前前端可见状态 |
| `<BountyCard>` | `<ActionEntry>` | 悬赏操作入口 | 按钮 / 菜单 | 与当前悬赏绑定 |

## 4. 交互与状态

### 4.1 核心交互

| 交互 | 说明 |
| --- | --- |
| 搜索 | 按关键词过滤悬赏 |
| 筛选 | 按悬赏类型、阶段、状态、挑战者等条件缩小展示范围 |
| 切换阶段 | 切换或定位到指定流程阶段 |
| 切换视图 | 在看板、列表等展示方式之间切换 |
| 打开详情 | 进入悬赏详情或打开局部详情 |
| 我要挑战 | 打开挑战操作入口 |
| 重估悬赏 | 打开重估操作入口 |
| 提交战利品 | 打开战利品提交入口 |
| 查看结算 | 打开奖励结算入口 |

### 4.2 页面状态

| 状态 | 说明 |
| --- | --- |
| 默认态 | 页面正常展示 |
| 加载态 | 页面数据加载中 |
| 空态 | 当前无悬赏可展示 |
| 错误态 | 页面加载失败或操作失败 |
| 筛选空态 | 当前筛选条件下无悬赏 |
| 浮层打开态 | 页面存在抽屉、弹窗、菜单或其它浮层 |

### 4.3 交互细则

| 交互 | 细则 |
| --- | --- |
| 我要挑战 | 用户点击后进入挑战确认 UI |
| 重估悬赏 | 用户点击后进入重估填写 UI |
| 提交战利品 | 用户点击后进入证据提交 UI |
| 查看结算 | 用户点击后查看结算展示 UI |
