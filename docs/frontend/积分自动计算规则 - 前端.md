# 积分自动计算规则 - 前端

## 接口访问约定

前端数据统一通过同源 `/api` 请求后端接口，例如 `/api/tasks`。
前端不直接写死后端域名或端口，开发和生产环境由代理或网关转发到实际后端服务。

本文档记录积分自动计算在 `统计` 页的排行榜布局。

后端计算口径、字段和判定条件见 [积分自动计算规则.md](../rules/积分自动计算规则.md)。

## 页面布局

整个页面作为一个大框展示，框内包含标题、时间范围选择、排行榜和右上角派蒙贴图。

```text

│ ORF 飞升战力榜                                           派蒙贴图        │
│                                                        右上角贴边        │

├────────────────────────────────────────────────────────────────────────┤
│ 成员积分排行榜                                                          │
│                                                                        │
│ 1   2 ↑   头像   ████████████████████   169.5   92%                    │

```

## 时间图标
| 选项 | 说明 |
| --- | --- |
| `按季度` | 默认选中。 |
| `按年度` | 查看当前年度积分。 |
| `全部时间` | 查看历史累计积分。 |

## 排行榜列

| 列 | 示例 | 说明 |
| --- | --- | --- |
| 排名 | `1` | 当前时间范围内的积分排名。 |
| 变化 | `2 ↑`、`1 ↓`、`0 -` | 数字在箭头前，表示相对上一周期上升或下降的名次数。 |
| 成员 | `头像` | 只展示成员头像。 |
| 积分条 | `████████` | 当前成员积分占榜首积分的比例。 |
| 积分 | `169.5` | 成员在当前时间范围内的总积分。 |
| 完成率 | `92%` | 当前时间范围内已完成指标占全部负责指标的比例。 |
