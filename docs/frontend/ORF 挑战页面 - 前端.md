# ORF 挑战页面 - 前端说明

## 1. 页面目录

ORF 功能包含全局外壳、挑战页面、提交战利品页、反馈、统计、成员管理、权限管理和设置页面。
当前文档只描述挑战页面主视图。

### 1.1 页面关系

```text
ORF
├─ AppShell                    ← 单独文档
├─ 挑战页                      ← 当前文档
├─ 提交战利品页                ← 单独文档
├─ 反馈页                      ← 单独文档
├─ 统计页                      ← 单独文档
├─ 成员管理页                  ← 单独文档
├─ 权限管理页                  ← 单独文档
└─ 设置页                      ← 单独文档
```

### 1.2 页面清单

| 页面 | 页面类型 | 入口 | 文档 | 说明 |
| --- | --- | --- | --- | --- |
| AppShell | 全局外壳 | 登录后所有页面 | [AppShell - 前端.md](./AppShell%20-%20前端.md) | 侧边栏、顶部栏、全局搜索和全局弹窗 |

## 3. 组件树与字段说明

本节说明挑战页内容区由哪些组件组成，以及每个组件展示哪些字段。

### 3.1 组件树

```text
<AppShell>
└─ <ChallengePlanPage>
   ├─ <TeamDashboard>
   ├─ <ChallengePlanToolbar>
   │  ├─ <ScopeTabs>
   │  ├─ <PeriodFilterButton>
   │  └─ <FilterButton>
   └─ <ChallengeTree>
      ├─ <ObjectiveRow>
      ├─ <BountyMetricRow>
      ├─ <TaskRow>
      ├─ <SubtaskRow>
      └─ <RowActions>
```

### 3.2 通用组件字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<AppShell>` | 全局侧边栏 | 页面主导航 | 侧边栏 | 详见 AppShell 文档 |
| `<AppShell>` | 顶部栏 | 当前路径、全局搜索、全局操作 | 顶栏 | 详见 AppShell 文档 |
| `<ChallengePlanToolbar>` | `<ScopeTabs>` | 所有挑战 / 我的挑战 | 分段按钮 | admin 可见两个入口；普通成员只进入我的挑战 |
| `<ChallengePlanToolbar>` | `<PeriodFilterButton>` | 当前周期入口 | 按钮 | 显示 `全部周期` |
| `<ChallengePlanToolbar>` | `<FilterButton>` | 筛选入口 | 按钮 | 打开筛选条件 |
| `<ChallengeTree>` | 挑战树 | 页面核心内容 | 树形列表 | 展示目标、悬赏指标、任务和子任务 |
| `<RowActions>` | 行操作入口 | 当前行可执行操作 | hover 后显示 | 只放轻量入口，不承载完整表单 |

### 3.4 布局与对齐要求

挑战页属于高密度工作台，布局以可扫描和列对齐优先。

| 区域 | 要求 |
| --- | --- |
| 团队概览 | 桌面端保持四列等宽，卡片高度一致；窄屏降为两列或单列，不允许横向挤压文本。 |
| 工具栏 | 范围切换靠左，周期和筛选靠右；窄屏改为上下排列，按钮左对齐。 |
| 挑战树行 | 目标、悬赏指标、任务、子任务共享同一套桌面元信息列，不允许每种行单独写互相不对齐的网格。 |
| 主标题列 | 主标题列占剩余空间，但宽度需要适度收敛，优先给右侧元信息列留出稳定空间；长标题单行省略，不挤压右侧元信息列。 |
| 元信息列 | 桌面端固定为 `类型/难度`、`挑战者`、`状态`、`剩余时间`、`日期`、`进度`，我的挑战视图再追加 `提交战利品` 列。 |
| 元信息对齐 | 所有右侧元信息列必须在各自列内左对齐，包括类型/难度、挑战者头像、状态徽标、剩余时间、日期、进度条和提交入口。 |
| 日期列 | 截止时间和更新时间必须放在同一列内上下排列，不拆到不同列。 |
| 任务行 | 任务和子任务不展示类型、挑战者、状态、剩余时间和进度；这些元信息列保留占位，更新时间落在与悬赏指标行一致的日期列。 |
| 进度列 | 进度条和百分比整体固定宽度，不能因为百分比位数变化导致列宽跳动。 |
| 行高 | 目标、悬赏指标、任务、子任务分别保持稳定最小行高，新增状态徽标或操作入口不能撑开单行布局。 |

### 3.5 状态与剩余时间

悬赏指标状态只保留必要状态：

| 状态 | 含义 |
| --- | --- |
| 待挑战 | 悬赏指标已发布，但还没有确认挑战者 |
| 挑战中 | 已有挑战者，正在执行 |
| 待验收 | 挑战者已提交战利品，等待验收 |
| 已结算 | 验收和奖励结算已完成 |

剩余时间按分钟粒度展示，不显示秒：

```text
剩余 2 天 4 小时
剩余 3 小时 20 分钟
剩余 18 分钟
已超时 6 分钟
```

前端最多按分钟刷新倒计时，避免秒级跳动影响阅读。

## 4. 交互与状态

本节描述挑战页的核心 UI 交互和页面状态。

### 4.1 核心交互

| 交互 | 说明 |
| --- | --- |
| 新建目标 | 从 AppShell 顶部栏主操作创建目标 |
| 新建反馈 | 从 AppShell 顶部栏主操作创建反馈 |
| 切换范围 | 在挑战工具栏切换所有挑战 / 我的挑战 |
| 周期入口 | 点击 `全部周期` 入口 |
| 筛选入口 | 点击 `筛选` 入口 |
| 新增下级 | 通过行操作入口创建悬赏指标、任务或子任务 |
| 编辑 | 通过行操作入口或双击当前行编辑对象标题 |
| TODO: 归档任务 | 通过任务行操作入口归档任务；归档不是删除，只从默认挑战树中隐藏 |
| 删除 | 通过行操作入口删除当前对象，删除前需要确认 |
| 全局搜索 | 通过 AppShell 顶部栏搜索页面和 ORF 对象 |
| 展开 / 折叠 | 控制悬赏指标下任务、任务下子任务的显示 |
| 拖拽排序 | 调整悬赏指标、任务、子任务的位置 |
| 勾选完成 | 切换任务或子任务完成状态 |
| 打开评论 | 从行操作入口或评论数入口打开当前对象评论 |
| 提交战利品 | 从我的挑战里的每条悬赏指标行旁边进入战利品提交 |

### 4.2 页面状态

| 状态 | 说明 |
| --- | --- |
| 默认态 | 页面正常展示挑战树 |
| 所有挑战视图 | admin 可见，展示团队概览和所有目标下的挑战树 |
| 我的挑战视图 | 普通成员默认视图；只展示与自己挑战目标相关的挑战树 |
| 空态 | 当前无目标或我的挑战范围无内容 |
| 编辑态 | 当前目标、悬赏指标、任务或子任务处于标题编辑中 |
| 拖拽态 | 当前对象正在被拖拽排序 |
| 折叠态 | 悬赏指标或任务的下级内容被隐藏 |
| TODO: 归档隐藏态 | 已归档任务默认不在挑战树展示；后续可通过归档筛选或单独入口查看 |

### 4.3 交互细则

| 交互 | 细则 |
| --- | --- |
| 行操作 | 目标、悬赏指标、任务、子任务行 hover 时显示行操作入口 |
| 行操作 | hover 当前行时显示当前行操作入口 |
| 行操作 | 操作入口包含 `+`、拖拽手柄、复制链接、评论、编辑、删除 |
| 行操作 | 折叠 / 展开按钮贴在当前行主图标左侧 |
| 行操作 | 无折叠入口的行保留同宽前置槽，避免主图标错位 |
| 权限拦截 | 新增、编辑、勾选、拖拽、删除前检查 `permissionRules` |
| 范围权限 | admin 可以切换 `所有挑战` / `我的挑战`；非 admin 只看到 `我的挑战` |
| 我的挑战 | 若用户挑战了某个目标下任一悬赏指标，则该目标下多个悬赏指标在我的挑战里互相可见，方便协作 |
| 我的挑战 | 与用户挑战目标不相关的其它目标和悬赏指标不展示 |
| 提交战利品 | `我的挑战` 中每条悬赏指标行旁边展示提交入口 |
| TODO: 任务归档入口 | 任务行操作后续增加 `归档` 操作；归档后任务从当前悬赏指标下隐藏，但不解除与悬赏指标的关联 |
| 新增 | 目标行 `+` 新增悬赏指标；悬赏指标行 `+` 新增任务；任务行 `+` 新增子任务；子任务行 `+` 新增同级子任务 |
| 编辑 | 行操作 `编辑` 和双击行进入同一标题编辑状态 |
| 编辑 | 勾选框、折叠按钮保持自身点击行为 |
| 拖拽 | 拖拽时页面进入拖拽态，并显示可放置位置 |
| 删除 | 删除前需要确认 |
| 删除 | 确认文案展示受影响下级数量 |
| 评论 | 评论支持列表、回复详情、回复、编辑和删除 |
