# ORF 我的挑战页面 - 前端

## 页面定位

`/tasks` 是我的挑战页面，展示当前用户已正式接受的目标、指标、任务和子任务执行树。

普通成员只看自己参与的目标；管理员可切换所有挑战 / 我的挑战。

我的挑战过滤规则：

```text
currentUser in Objective.challengers
```

目标来自悬赏大厅中的申请、征召或接受挑战流程；未正式接受的目标不在本页展示。

## 页面内容

| 区域 | 内容 |
| --- | --- |
| 团队概览 | 管理员在所有挑战视图下可见：已结算、目标总体进度、待征召、待验收 |
| 工具栏 | 所有挑战 / 我的挑战、周期、筛选 |
| 挑战树 | `Objective -> Result -> Task -> TaskChecklistItem` |

## 行字段

### 目标行

展示：

- 目标标题。
- 目标状态。
- 挑战者头像组，来源 `Objective.challengers`。
- 剩余时间，来源 `Objective.finalDueAt`。
- 截止时间。
- 目标进度，来源 `Objective.progress`。
- `提交战利品` 入口；仅 `flowStatus=frozen` 且当前用户是挑战者时展示。

### 指标行

展示：

- 指标标题。
- 难度 / 不确定性分。
- 验收状态。
- 指标进度。
- 截止要求或最近更新时间。

指标不展示挑战者列，不表达负责人。

### 任务和子任务行

展示标题、勾选框和更新时间。勾选只表示执行进度，不触发验收或积分结算。

## 状态

### 目标状态

| 状态 | 含义 |
| --- | --- |
| 重估中 | 挑战者已确认，正在重估目标下指标和任务 |
| 已冻结 | 重估完成，指标口径冻结，可提交战利品 |
| 待验收 | 已提交战利品，等待验收 |
| 已结算 | 验收和积分结算完成 |

## 交互

| 操作 | 规则 |
| --- | --- |
| 新增指标 | 指挥官从目标行新增 |
| 提出指标 | 挑战者在自己参与目标的未过期重估期从目标行提出 |
| 编辑指标 | 指挥官可编辑未冻结目标下指标；挑战者可编辑自己参与目标的未过期重估期指标 |
| 新增任务 | 从指标行新增 |
| 新增子任务 | 从任务行新增 |
| 编辑标题 | 行操作或双击进入编辑 |
| 勾选任务 / 子任务 | 只更新执行进度 |
| 拖拽排序 | 指标只在同一目标内排序；任务和子任务可在允许范围内移动 |
| 删除 | 删除前确认，并展示影响范围 |
| 评论 | 从行操作打开评论 |
| 提交战利品 | 只在目标冻结后从目标行进入提交页 |
| 发布/冻结 | 指挥官在所有挑战视图中操作 |
| 审核挑战申请 | 指挥官在目标行处理待审核申请 |

权限由 `permissionRules` 和状态机共同控制。目标内容只能由指挥官调整；指标可由指挥官编辑，挑战者只可在 `reestimating` 且未过 `confirmationDueAt` 时提出或编辑自己参与目标下的指标。冻结后指标口径锁定。

反馈状态控件仅对管理员、反馈创建人或反馈 `owner` 指定处理人显示。普通成员可以看到自己可见范围内的反馈内容，但不能关闭或改写他人反馈状态。

## 布局要求

- 我的挑战是高密度工作台，优先保证可扫描和列对齐。
- 目标、指标、任务、子任务共用同一套列结构。
- 树线、缩进、折叠入口只在主标题列内定位。
- 剩余时间按分钟展示，不显示秒。
- 长标题单行省略，不能挤压右侧列。
- 进度列宽度固定，百分比变化不能造成布局跳动。
