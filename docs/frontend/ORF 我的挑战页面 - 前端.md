# ORF 我的挑战页面 - 前端

## 页面定位

`/tasks` 是挑战工作台。普通成员看到自己已正式接受的目标，以及目标下并列的指标、任务和子任务；指挥官在所有挑战视图中创建、编辑和发布候选目标。

普通成员只看自己参与的目标；管理员可切换所有挑战 / 我的挑战。

我的挑战过滤规则：

```text
currentUser.id in Objective.challengerUserIds
```

悬赏大厅对所有已通过用户可见，但它只是发现页，不决定工作台归属。目标来自挑战页内候选目标创建、悬赏大厅申请、征召或接受挑战流程；普通成员只有在申请被通过或接受征召后，目标才进入本页。

数据加载边界：Provider 通过 `/api/me/access` 读取当前用户权限；普通成员进入本页时再请求 `/api/my-challenges?scope=mine` 等成员可访问接口，不主动请求 `/api/permissions` 或 `/api/users` 等管理员集合。管理员进入业务页时才额外加载成员列表。后端兼容的 `/api/tasks-page` 对普通成员也只返回 scoped `my-challenges` 数据，不返回全量 state。

## 页面内容

| 区域 | 内容 |
| --- | --- |
| 全局概览 | 管理员在所有挑战视图下可见：已结算、目标总体进度、待征召、待验收 |
| 工具栏 | 所有挑战 / 我的挑战、周期、状态筛选；状态筛选包含目标层级的“未分配”，按 `Objective.challengerUserIds` 为空判断 |
| 新建目标 temporary 行 | 有 `objective.create` 权限时在挑战树内插入 temporary 目标行；temporary 目标按目标统一排序进入未分配候选区，标题输入按 Enter 或输入框失焦快速生成 `candidate` 目标行；请求发起后立即退出标题编辑态，API 返回真实目标后必须连续替换为 persisted 目标，刷新完成前不能出现目标消失或跳位；没有真实指标或行动项时不渲染伪子行，新增必须通过目标行 `+` 发起 |
| 挑战树 | 先用 `projects` 注册表和可空 `Objective.projectId` 做项目一级分组，再在项目内展示 `Objective -> Result` 与 `Objective -> Task -> TaskChecklistItem` 两条分支 |

项目只作为 `/tasks` 的一级展示分类。范围、周期、成员和状态筛选先决定可见目标集合，项目分组只对筛选后的目标做派生聚合；没有项目归属或引用失效项目的目标进入“未归属目标”。项目不是权限边界，不改变目标生命周期，不引入 AppShell 项目切换、项目归档或成员配置入口。项目界面保持轻量：顶部只显示项目胶囊导航和折叠式新建入口，分组用项目色带和淡色底标出边界，分组标题只显示项目名、目标数和新增目标图标，不展示项目级大卡片、进度条或重复统计。指挥官可以在挑战页创建项目，也可以把目标放入项目、移动到其他项目或移出项目；普通成员不能操作项目归属。

## 行字段

### 目标行

展示：

- 目标标题。
- 目标状态。
- 挑战者头像组，来源 `Objective.challengers`。
- 剩余时间，来源 `Objective.finalDueAt`。
- 截止时间；点击日期本身打开 ORF 自定义日期选择器，选定不同日期后立即提交，不进入可见输入框，也不需要二次确认。指挥官可编辑 `Objective.finalDueAt`；冻结前可正常调整，`frozen` 只允许延后；无权限或状态锁定时点击日期提示原因。
- 目标进度，来源 `Objective.progress`。
- `提交战利品` 入口；仅 `flowStatus=frozen` 且当前用户是挑战者时展示。
- `处理试验收` 入口；仅 `flowStatus=frozen`、当前用户为指挥官且存在待反馈试验收时展示。
- hover 工具层包含一个主新增 `+`；点击后选择新增指标或新增行动项。

### 指标行

展示：

- 指标标题。
- 难度 / 不确定性等级，直接显示 `入门 / 进阶 / 破局 / 渡劫 / 飞升`，未设置时显示 `待校准`；挑战页不把难度转写成星级。
- 验收状态。
- 指标进度。
- 最近更新时间，来源为指标自身最后修改时间，并组合指标趋势和历史材料的最新时间；团队反馈 issue 不参与指标更新时间聚合。
- 指标详情。指标行默认保持紧凑；鼠标悬浮或键盘聚焦指标行时，在当前指标行下方展开完整指标详情，不做摘要、不截断、不进入评论区。没有详情时显示灰色占位 `未填写指标详情，双击编辑`。

指标不展示目标剩余时间、目标截止日期、挑战者列或负责人。

指标行不展示 `+`。当前模型中指标没有子级对象，任务也不归属于指标。

### 任务和子任务行

展示标题、勾选框和更新时间。任务归属于目标，不挂到指标下；同一目标的正式挑战者都可以维护该目标下所有任务和子任务，指挥官按管理员权限维护。任务行 hover 工具层包含一个 `+`，点击后直接新增该任务的子任务；`assignee` 只作为执行提示，创建人不形成前端操作锁。勾选只表示执行进度，不触发验收或积分结算。勾选任务或子任务时，前端在挑战页数据合成层使用短生命周期完成状态覆盖层立即反馈点击结果；后端刷新数据仍是持久化事实源，刷新数据包含同一完成状态后撤销覆盖层，失败时撤销覆盖层并按后端事实刷新。

## 状态

### 目标状态

| 状态 | 含义 |
| --- | --- |
| 候选中 | 指挥官刚创建，尚未发布到悬赏大厅，可先定义指标和目标行动项 |
| 重估中 | 挑战者已确认，正在重估目标下指标和任务 |
| 已冻结 | 重估完成，指标口径冻结，可提交战利品 |
| 待验收 | 已提交战利品，等待验收 |
| 已结算 | 验收和积分结算完成 |

### 新建目标会话状态

`objectiveCreationSession` 是页面内唯一的目标创建 UI 状态源；后端目标列表仍是业务事实源。

| 状态 | UI 表现 | 退出条件 |
| --- | --- | --- |
| `idle` | 不显示 temporary 目标 | 点击 `新建目标` |
| `editingDraft` | 显示完整 temporary 目标面板，标题输入框聚焦 | Enter / 失焦提交，或 Escape 取消 |
| `submittingDraft` | temporary 目标留在原位但退出标题编辑态，状态列显示“保存中” | `POST /api/objectives` 返回成功或失败 |
| `submittedOverlay` | 用 POST 返回的真实目标替换 temporary 目标，继续沿用 temporary 目标位置 | 任务数据刷新后包含同一目标，或用户手动切换筛选 |
| `anchoredCreated` | 使用已刷新的后端目标行，但继续保留一次性排序锚点 | 用户手动切换筛选，或业务排序键变化 |
| `failedEditingDraft` | 回到标题输入框并保留用户输入 | 再次提交或取消 |

### 子级创建会话状态

`childCreationSession` 是指标、行动项和子行动项创建 UI 的唯一状态源；`Objective.resultIds`、`Objective.taskIds`、`Result`、`Task`、`TaskChecklistItem` 后端快照仍是业务事实源。页面只负责编排权限和 API 调用，树组件只消费 `childCreationTemporaryRow` 的展示形态；temporary 行、提交态、POST 返回实体覆盖层和快照接管必须由 `childCreationSession` 模块内部完成。

| 状态 | UI 表现 | 退出条件 |
| --- | --- | --- |
| `idle` | 不显示子级 temporary 行，也不应用创建覆盖层 | 点击目标或任务行 `+` |
| `editingDraft` | 在对应父级下显示一条 temporary 行并聚焦标题输入 | Enter / 失焦提交，或 Escape 取消 |
| `submittingDraft` | temporary 行留在原位但退出标题编辑态，状态列显示“保存中” | 对应创建 API 返回成功或失败 |
| `submittedOverlay` | 用 POST 返回的真实指标、行动项或子行动项替换 temporary 行 | 挑战页后端快照包含同一真实 id，或用户手动切换筛选 |
| `failedEditingDraft` | 回到标题输入框并保留用户输入 | 再次提交或取消 |

`submittingDraft` 带唯一提交 token；只有同一 token 的 API 返回才能推进到 `submittedOverlay` 或 `failedEditingDraft`，避免旧请求在用户清理或重建草稿后接管新状态。`submittedOverlay` 阶段不允许启动另一条子级创建，直到后端快照接管或用户显式切换上下文清理会话。

## 交互

| 操作 | 规则 |
| --- | --- |
| 新建目标 | 从顶部栏或命令菜单进入本页创建入口；在挑战树内复用目标面板创建 temporary 目标，temporary 阶段只展示目标行，不预置“待定义指标”或“待创建行动项”伪子行；标题输入按 Enter 或输入框失焦调用创建接口，请求发起后立即退出标题编辑态并显示“保存中”，创建成功后真实目标连续替换 temporary 目标；提交中重复点击 `新建目标` 只提示“目标正在创建，请稍后”，不能发起第二次创建；标题变化、API 源顺序变化、页面数据刷新和点击其他区域都不能触发目标面板重排、消失或重新进入编辑态；创建失败时回到标题编辑态并保留输入 |
| 新建项目 | 仅指挥官可操作；在项目导航内输入项目名并创建，创建成功后 `projects` 注册表刷新，挑战页显示新的空项目分组 |
| 调整目标项目归属 | 仅指挥官可操作；目标行 hover 握把可直接拖拽目标到项目分组，拖到“未归属目标”表示移出项目；目标行 hover 块菜单也提供“移动到项目”；这些入口只写入 `Objective.projectId`，不改目标生命周期、挑战者、指标、任务或积分 |
| 新增指标 | 指挥官点击目标行唯一主新增 `+`，在类型选择层选择新增指标后插入指标 temporary 行并进入标题编辑；提交后后端返回的真实指标进入一次性创建覆盖层并替换 temporary 行，挑战页刷新数据包含同一真实 id 后撤掉覆盖层；成功后不自动生成下一条指标 temporary 行 |
| 提出指标 | 挑战者在自己参与目标的未过期重估期，点击目标行唯一主新增 `+`，在类型选择层选择提出指标后插入指标 temporary 行并进入标题编辑；提交后后端返回的真实指标进入一次性创建覆盖层并替换 temporary 行，挑战页刷新数据包含同一真实 id 后撤掉覆盖层；成功后不自动生成下一条指标 temporary 行 |
| 编辑指标 | 指挥官可编辑未冻结目标下指标；挑战者可编辑自己参与目标的未过期重估期指标；指标标题编辑和难度等级点选复用同一个指标编辑权限判断，不能在组件内分散判断角色、挑战者窗口或冻结状态 |
| 查看/编辑指标详情 | 指标行 hover/focus 时在行下方展开完整详情；已有详情时双击详情内容原地编辑，没有详情时双击灰色占位进入编辑；编辑态固定展开，保存调用 `PATCH /api/results/:resultId/details`，取消只丢弃临时草稿。无权限或冻结后不进入编辑并提示同一套指标编辑不可用原因 |
| 编辑指标难度 | 指标行难度列直接点选 `入门 / 进阶 / 破局 / 渡劫 / 飞升` 并调用 `PATCH /api/results/:resultId/uncertainty`；`Result.uncertaintyLevel` 是难度事实源，`Result.uncertaintyScore` 由后端映射写入；无权限或冻结后保留只读中文等级并提示原因 |
| 新增任务 | 指挥官或正式挑战者点击目标行唯一主新增 `+`，在类型选择层选择新增行动项后插入行动项 temporary 行并进入标题编辑；提交后后端返回的真实任务进入一次性创建覆盖层并替换 temporary 行，挑战页刷新数据包含同一真实 id 后撤掉覆盖层；成功后不自动生成下一条行动项 temporary 行 |
| 新增子任务 | 同一目标正式挑战者或指挥官点击任务行 `+` 后，在当前任务下插入子任务 temporary 行；提交后后端返回的真实子任务进入一次性创建覆盖层并替换 temporary 行，挑战页刷新数据包含同一真实 id 后撤掉覆盖层；成功后不自动生成下一条子任务 temporary 行 |
| 编辑标题 | 行操作或双击进入编辑；保存已有目标、指标、行动项或子行动项标题后，前端用短生命周期标题覆盖层立即显示新标题，后端快照包含同一标题后撤掉覆盖层；保存失败时撤掉覆盖层并回到后端事实，不能出现新标题短暂消失再回来的闪回 |
| 勾选任务 / 子任务 | 同一目标正式挑战者或指挥官可操作，只更新执行进度；点击后勾选状态立即展示，后端写入和刷新成功后由后端数据接管；失败时回到后端事实并提示 |
| 拖拽排序 | 指标只在同一目标内排序；任务只在同一目标内排序；子任务可在当前用户有维护权限的目标任务范围内移动 |
| 删除 | 同一目标正式挑战者或指挥官可删除任务和子任务；删除前确认，并展示影响范围 |
| 评论 | 从行操作打开评论 |
| 提交战利品 | 只在目标冻结后从目标行进入提交页 |
| 修改截止日期 | 点击日期本身打开 ORF 自定义日期选择器，选定不同日期后立即提交；只允许指挥官操作。冻结前可修改为合法日期，冻结后只能延后；无权限或待验收、已结算、已关闭时点击日期提示原因 |
| 发布/冻结 | 指挥官在所有挑战视图中操作 |
| 审核挑战申请 | 指挥官在目标行处理待审核申请；审批成功后立即刷新目标状态和申请记录，当前目标使用列表位置锚点保持原展示位置，直到用户离开当前目标上下文 |

目标、指标和流程操作由 `permissionRules`、状态机和对应业务能力共同控制。目标内容只能由指挥官调整；截止日期以 `Objective.finalDueAt` 为唯一事实源，指标行不展示也不保存独立截止日期。指标可由指挥官编辑，挑战者只可在 `reestimating` 且未过 `confirmationDueAt` 时提出或编辑 `Objective.challengerUserIds` 包含自己的目标下的指标。行动项和子行动项不使用独立角色权限 key；候选目标允许指挥官先维护目标行动项，挑战者正式进入 `Objective.challengerUserIds` 后，任务和子任务的新增、编辑、勾选、移动、删除都按目标共同维护，不按 `assignee` 或创建人区分。冻结后指标口径锁定。

反馈状态控件仅对管理员、反馈创建人或反馈 `owner` 指定处理人显示。普通成员可以看到自己可见范围内的反馈内容，但不能关闭或改写他人反馈状态。

## 布局要求

- 我的挑战是高密度工作台，优先保证可扫描和列对齐。
- 项目标题作为目标面板外层分段标题展示，保持紧凑，不包裹成项目卡片；项目统计只显示该分组下目标、指标和行动项数量。
- 目标排序统一为：候选中目标、未分配的待申请/待征召目标、已分配执行中的目标、待验收目标、已结算目标、已关闭目标。同一组内先按截止时间升序，再按创建日期降序；业务排序键相同则保留数据源顺序。目标标题不是列表排序键，避免用户编辑标题时改变当前目标位置。
- 操作上下文位置稳定性是挑战页列表展示不变量。后端事实源立即刷新；正在操作的目标通过短生命周期位置锚点保持当前展示位置；点击其他目标、切换范围、切换筛选、离开页面或目标不再属于当前视图时释放锚点并恢复统一排序。
- 已有标题编辑使用短生命周期 `titleEditOverlay`，只覆盖目标、指标、行动项和子行动项的标题展示；它不是业务事实源，也不参与权限、排序、结算或生命周期判断。后端快照仍是唯一业务事实源，快照包含新标题或目标离开当前上下文后覆盖层撤销。
- 指标详情以 `Result.description`、`Result.metricRequirement`、`Result.completionStandard`、`Result.sampleSet`、`Result.measurementScope` 为唯一事实源；hover/focus 展开只是展示状态，编辑表单草稿只是临时 UI 状态。详情块不是指标的子节点，不参与树线、拖拽、排序、评论计数或积分结算；保存成功后由后端快照接管，失败时保留编辑态并提示。
- 指标难度编辑只维护选择器提交中的临时展示状态，不建立第二套难度事实源；成功后由后端快照接管，失败时回到 `Result.uncertaintyLevel` 当前事实。
- 新建目标 temporary 行和创建成功后的 persisted 目标共用同一套目标面板结构；没有真实指标或行动项时不渲染“待定义指标”和“待创建行动项”伪子行，避免把不可编辑占位误认为业务行。真实目标行 hover 只保留一个主新增 `+`，点击后打开类型选择层，从当前权限和状态允许的 `新增/提出指标`、`新增行动项` 中选择一项。指标行没有 `+`；任务行 `+` 直接新增该任务的子任务。每次点击 `+` 只插入一条对应类型的 temporary 行，保存成功后替换为 persisted 行，不自动补出下一条 temporary 行。temporary 阶段只禁用依赖真实 id 的业务动作。指标、行动项和子任务行只有 `temporary / persisted` 的持久化差异：temporary 行保存标题后调用创建接口，并由 `childCreationSession` 用后端返回的真实实体进入一次性创建覆盖层；persisted 行保存标题后走更新接口。创建覆盖层只桥接 POST 成功到 `/api/my-challenges` 刷新包含同一真实 id 之间的窗口，不能成为第二套长期业务事实源，也不能在待快照阶段被新的子级创建覆盖。提交目标标题时记录 temporary 目标前后的目标邻居和当时的业务排序键；请求等待期间目标以非编辑标题形态留在原位，`POST /api/objectives` 返回后立即用真实目标作为页面级临时覆盖层连续替换 temporary 目标，任务数据刷新只负责撤掉覆盖层，一次性排序锚点继续保留到用户手动切换筛选或目标业务排序键变化。用户手动切换范围、周期、状态或目标业务状态变化后锚点失效，回到全局排序。
- 目标、指标、任务、子任务共用同一套列结构；指标和任务是目标下并列分支，不能用缩进或树线暗示任务属于指标。
- 树线、缩进、折叠入口只在主标题列内定位。
- 目标剩余时间按分钟展示，不显示秒；指标行不重复展示目标剩余时间，也不把更新时间展示成目标截止日期样式。目标、指标、行动项和子行动项的树线锚点使用统一外层尺寸，避免竖向节点因图标尺寸不同而错位。
- 长标题单行省略，不能挤压右侧列。
- 进度列宽度固定，百分比变化不能造成布局跳动。
