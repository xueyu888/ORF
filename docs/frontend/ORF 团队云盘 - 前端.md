# ORF 团队云盘 - 前端

本文档只描述团队云盘前端展示状态。云盘结构、文件元数据、版本、活动和上下文关系的事实源见 [ORF 团队云盘 - 后端.md](../backend/ORF%20团队云盘%20-%20后端.md)。

## 状态链

```text
后端云盘 bootstrap / search / details
  -> DriveBrowser 派生当前集合、选中节点、详情面板和移动端分栏
  -> 创建文件夹会话管理输入框、提交中和失败提示
  -> POST /api/drive/folders 写入 drive_nodes
  -> 后端刷新后的云盘树接管展示
```

必须保持的不变量：

1. `drive_nodes` 是文件夹是否存在、名称和层级的唯一事实源。
2. 创建文件夹输入内容只是会话草稿；空字符串不能代表“创建会话不存在”。
3. 取消创建、提交失败、提交中禁用和成功后清空都属于前端会话状态，不写入云盘事实。
4. 同一父文件夹下未删除节点名唯一由后端校验；前端只做空名拦截和错误展示。
5. 移动端与桌面端使用同一云盘读模型，只改变列表、详情和操作区的展示布局。

## 前端边界

| 模块 | 职责 | 不负责 |
| --- | --- | --- |
| `DriveBrowser.tsx` | 渲染资源集合、列表、详情、上传和创建文件夹会话 | 维护云盘树事实、重复实现后端重名规则 |
| 创建文件夹会话 | 维护 `idle/editing/submitting` 和草稿名称；空名保持输入框可见并禁用提交，Escape 或取消按钮退出 | 用草稿字符串控制组件是否存在 |
| 详情和预览面板 | 读取后端投影展示文件详情、版本、活动和预览 | 直接读取对象存储 key 或改写文件归属 |
