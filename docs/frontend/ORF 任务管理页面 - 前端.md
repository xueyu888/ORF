# ORF 任务管理页面 - 前端说明

## 1. 页面目录

ORF 功能包含任务管理、反馈、统计、成员管理和权限管理页面。
当前文档只描述任务管理页。

### 1.1 页面关系

```text
ORF
├─ 任务管理页                 ← 当前文档
├─ 反馈页                     ← 单独文档
├─ 统计页                     ← 单独文档
├─ 成员管理页                 ← 单独文档
└─ 权限管理页                 ← 单独文档
```

## 2. 当前页页面结构

任务管理页由页面头部、工具栏、目标树主体和浮层区域组成。

### 2.1 页面结构示意图

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ PageHeader                                                                             │
│ 计划 / 任务管理                                             新建反馈    新建目标        │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ Toolbar                                                                                │
│ 搜索目标、指标、任务、反馈                         阶段筛选        只看我的             │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ MainContent                                                                            │
│                                                                                        │
│ ┌────────────────────────────────────────────────────────────────────────────────────┐ │
│ │ ObjectiveTree                                                                       │ │
│ │                                                                                    │ │
│ │ 目标行        目标标题        风险      阶段      负责人      日期      进度条       │ │
│ │   ├─ 指标行   指标标题        负责人    状态      日期                              │ │
│ │   │   ├─ 任务行       任务标题          状态      日期                              │ │
│ │   │   │   └─ 子任务行 子任务标题        状态      日期                              │ │
│ │   │   └─ 任务行       任务标题          状态      日期                              │ │
│ │   └─ 指标行   指标标题        负责人    状态      日期                              │ │
│ └────────────────────────────────────────────────────────────────────────────────────┘ │
│                                                                                        │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ OverlayArea                                                                            │
│ BlockMenu / CommentDrawer / ConfirmModal / PlanModePopover             shown as needed │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 页面区域说明

| 区域 | 含义 | 说明 |
| --- | --- | --- |
| `PageHeader` | 页面头部 | 展示当前页面名称和主要操作 |
| `Toolbar` | 工具栏 | 承载搜索、筛选、个人范围等控制项 |
| `MainContent` | 主体内容区 | 展示目标、指标、任务、子任务四层树 |
| `ObjectiveTree` | 目标树 | 展示任务管理页的核心内容 |
| `OverlayArea` | 浮层区域 | 承载块菜单、评论抽屉、确认弹窗和阶段菜单 |

## 3. 组件树与字段说明

本节说明任务管理页由哪些组件组成，以及每个组件展示哪些字段。

### 3.1 组件树

```text
<TasksPage>
├─ <PageHeader>
│  ├─ <PageTitle>
│  └─ <PrimaryActions>
├─ <Toolbar>
│  ├─ <SearchInput>
│  ├─ <FilterGroup>
│  └─ <ViewActions>
├─ <MainContent>
│  └─ <ObjectiveTree>
│     ├─ <HierarchyTreeOverlay>
│     ├─ <ObjectivePanel>
│     │  └─ <PlanModeControl>
│     ├─ <ResultBlock>
│     ├─ <TaskRow>
│     └─ <SubtaskRow>
└─ <OverlayArea>
   ├─ <BlockMenu>
   ├─ <CommentDrawer>
   ├─ <ConfirmModal>
   └─ <PlanModePopover>
```

### 3.2 通用组件字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<PageHeader>` | `<PageTitle>` | 当前页面名称 | 文本 | 显示 `计划 / 任务管理` |
| `<PageHeader>` | `<PrimaryActions>` | 当前页面主操作 | 按钮组 | 包含 `新建反馈`、`新建目标` |
| `<Toolbar>` | `<SearchInput>` | 搜索当前页面内容 | 输入框 | 用于关键词过滤 |
| `<Toolbar>` | `<FilterGroup>` | 控制内容范围 | 下拉 / 开关 | 包含阶段筛选和个人范围 |
| `<Toolbar>` | `<ViewActions>` | 控制展示方式 | 按钮 / 切换器 | 按需要展示 |
| `<MainContent>` | `<ObjectiveTree>` | 页面核心内容 | 树形列表 | 展示目标四层层级 |
| `<OverlayArea>` | `<BlockMenu>` | 当前块操作 | 气泡菜单 | 按需出现 |
| `<OverlayArea>` | `<CommentDrawer>` | 块级评论 | 右侧抽屉 | 按需出现 |
| `<OverlayArea>` | `<ConfirmModal>` | 删除确认 | 弹窗 | 按需出现 |
| `<OverlayArea>` | `<PlanModePopover>` | 阶段切换 | 气泡菜单 | 按需出现 |

| 组件 | 字段 | 含义 | 展示方式 | 说明 |

## 4. 交互与状态

本节描述任务管理页的核心 UI 交互和页面状态。

### 4.1 核心交互

| 交互 | 说明 |
| --- | --- |
| 新建目标 | 从页面头部主操作创建目标 |
| 新建反馈 | 从页面头部主操作创建反馈 |
| 新增下级 | 通过块操作入口创建指标、任务或子任务 |
| 编辑 | 通过块菜单或双击当前行编辑对象 |
| 删除 | 通过块菜单删除当前对象，删除前需要确认 |
| 搜索 | 按关键词过滤目标、指标、任务和反馈 |
| 筛选 | 按阶段或个人范围缩小展示内容 |
| 展开 / 折叠 | 控制指标下任务、任务下子任务的显示 |
| 拖拽排序 | 调整指标、任务、子任务的位置 |
| 勾选完成 | 切换任务或子任务完成状态 |
| 切换阶段 | 通过目标行阶段按钮切换 ORF 阶段 |
| 打开评论 | 从块菜单打开当前对象评论抽屉 |
| 打开块菜单 | 打开当前目标、指标、任务或子任务的操作菜单 |

### 4.2 页面状态

| 状态 | 说明 |
| --- | --- |
| 默认态 | 页面正常展示目标树 |
| 加载态 | 页面数据加载中 |
| 空态 | 当前无目标、无搜索结果或筛选后无内容 |
| 错误态 | 页面加载失败或操作失败 |
| 编辑态 | 当前目标、指标、任务或子任务处于编辑中 |
| 拖拽态 | 当前对象正在被拖拽排序 |
| 折叠态 | 指标或任务的下级内容被隐藏 |
| 浮层打开态 | 页面存在块菜单、评论抽屉、确认弹窗或阶段菜单 |

### 4.3 交互细则

| 交互 | 细则 |
| --- | --- |
| 块操作 | 目标、指标、任务、子任务行 hover 时显示块操作入口 |
| 块操作 | 同一时间只显示一个块操作入口；菜单打开时其它行 hover 不再显示入口 |
| 块操作 | 操作入口包含 `+`、拖拽手柄、折叠 / 展开按钮 |
| 块操作 | 折叠 / 展开按钮贴在当前行主图标左侧 |
| 块操作 | 无折叠入口的行保留同宽前置槽，避免主图标错位 |
| 块菜单 | 菜单固定包含：复制链接、编辑、评论、删除 |
| 新增 | 目标行 `+` 新增指标；指标行 `+` 新增任务；任务行 `+` 新增子任务；子任务行 `+` 新增同级子任务 |
| 编辑 | 块菜单 `编辑` 和双击行进入同一编辑状态 |
| 编辑 | 勾选框、状态下拉、阶段按钮、折叠按钮保持自身点击行为 |
| 拖拽 | 拖拽时页面进入拖拽态，并显示可放置位置 |
| 删除 | 删除前打开确认弹窗 |
| 删除 | 确认弹窗展示受影响下级数量 |
| 评论 | 评论绑定到当前块；已解决线程保留用于回看结论 |
