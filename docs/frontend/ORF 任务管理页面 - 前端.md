# ORF 任务管理页面 - 前端说明

## 1. 页面目录

ORF 功能包含全局外壳、任务管理、反馈、统计、成员管理、权限管理和设置页面。
当前文档只描述任务管理页在内容区内的 UI。

### 1.1 页面关系

```text
ORF
├─ AppShell                    ← 单独文档
├─ 任务管理页                  ← 当前文档
├─ 反馈页                      ← 单独文档
├─ 统计页                      ← 单独文档
├─ 成员管理页                  ← 单独文档
├─ 权限管理页                  ← 单独文档
└─ 设置页                      ← 单独文档
```

### 1.2 页面清单

| 页面 | 页面类型 | 入口 | 文档 | 说明 |
| --- | --- | --- | --- | --- |
| AppShell | 全局外壳 | 登录后所有页面 | [AppShell - 前端.md](./AppShell%20-%20前端.md) | 侧边栏、顶部栏、全局搜索和全局浮层 |
| 任务管理页 | 主页面 | 侧边栏 `计划` / `/tasks` | 当前文档 | 当前文档描述的页面 |
| 反馈页 | 子页面 | 侧边栏 `反馈`、顶部栏 `新建反馈` | 待补充 | 单独描述 |
| 统计页 | 子页面 | 侧边栏 `统计` | 待补充 | 单独描述 |
| 成员管理页 | 管理页面 | 侧边栏 `成员管理` | [用户管理 - 前端.md](./用户管理%20-%20前端.md) | 单独描述 |
| 权限管理页 | 管理页面 | 侧边栏 `权限管理` | [权限管理 - 前端.md](./权限管理%20-%20前端.md) | 单独描述 |
| 设置页 | 设置页面 | 侧边栏 `设置` | 待补充 | 单独描述 |

### 1.3 当前文档范围

本文档只描述：

```text
ORF
└─ AppShell
   └─ 任务管理页              ← 当前文档
```

AppShell 的侧边栏、顶部栏、全局搜索、全局弹窗和 Toast 只在本文档建立关联，不展开说明。

## 2. 当前页页面结构

任务管理页内容区由团队指标卡、任务页工具栏、目标树和浮层内容组成。

### 2.1 页面结构示意图

```text
┌────────────────────────────────────────────────────────────────────────────────────┐
│ AppShell                                                                           │
│ Sidebar / Topbar / GlobalSearch / GlobalActions                  see AppShell doc  │
├────────────────────────────────────────────────────────────────────────────────────┤
│ TasksPage                                                                          │
│                                                                                    │
│ ┌────────────────────────────────────────────────────────────────────────────────┐ │
│ │ TeamDashboard                                             shown in team scope   │ │
│ │ 指标完成        目标总体进度        待定指标        活跃任务数                 │ │
│ └────────────────────────────────────────────────────────────────────────────────┘ │
│                                                                                    │
│ TaskToolbar                                                                        │
│ 团队 / 个人                                      全部周期        筛选              │
│                                                                                    │
│ ┌────────────────────────────────────────────────────────────────────────────────┐ │
│ │ ObjectiveTree                                                                   │ │
│ │ 目标行        标题        风险      阶段      负责人      日期      进度条       │ │
│ │   ├─ 指标行   标题        负责人    状态      更新时间                          │ │
│ │   │   ├─ 任务行       勾选框        标题      更新时间                          │ │
│ │   │   │   └─ 子任务行 勾选框        标题      更新时间                          │ │
│ │   │   └─ 任务行       勾选框        标题      更新时间                          │ │
│ │   └─ 指标行   标题        负责人    状态      更新时间                          │ │
│ └────────────────────────────────────────────────────────────────────────────────┘ │
│                                                                                    │
│ FloatingLayer                                                                      │
│ BlockMenu / CommentPanel / NativeConfirmDialog / PlanModePopover   shown as needed │
└────────────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 页面区域说明

| 区域 | 含义 | 说明 |
| --- | --- | --- |
| `AppShell` | 全局外壳 | 提供侧边栏、顶部栏、全局搜索、全局新建入口 |
| `TasksPage` | 当前页内容区 | 承载任务管理页自身内容 |
| `TeamDashboard` | 团队指标卡 | 团队视图下展示；具体卡片内容以当前实现为准 |
| `TaskToolbar` | 任务页工具栏 | 承载团队 / 个人切换、周期入口和筛选入口 |
| `ObjectiveTree` | 目标树 | 展示目标、指标、任务、子任务四层层级 |
| `FloatingLayer` | 浮层区域 | 承载块菜单、评论浮窗、浏览器确认框和阶段菜单 |

## 3. 组件树与字段说明

本节说明任务管理页内容区由哪些组件组成，以及每个组件展示哪些字段。

### 3.1 组件树

```text
<AppShell>
└─ <TasksPage>
   ├─ <TeamDashboard>
   ├─ <TaskToolbar>
   │  ├─ <ScopeTabs>
   │  ├─ <PeriodFilterButton>
   │  └─ <FilterButton>
   ├─ <ObjectiveTree>
   │  ├─ <HierarchyTreeOverlay>
   │  ├─ <ObjectivePanel>
   │  │  └─ <PlanModeControl>
   │  ├─ <ResultBlock>
   │  ├─ <TaskRow>
   │  └─ <SubtaskRow>
   └─ <FloatingLayer>
      ├─ <BlockMenu>
      ├─ <CommentPanel>
      ├─ <NativeConfirmDialog>
      └─ <PlanModePopover>
```

### 3.2 通用组件字段说明

| 组件 | 字段 | 含义 | 展示方式 | 说明 |
| --- | --- | --- | --- | --- |
| `<AppShell>` | 全局侧边栏 | 页面主导航 | 侧边栏 | 详见 AppShell 文档 |
| `<AppShell>` | 顶部栏 | 当前路径、全局搜索、全局操作 | 顶栏 | 详见 AppShell 文档 |
| `<TaskToolbar>` | `<ScopeTabs>` | 团队 / 个人范围 | 分段按钮 | 控制目标树展示范围 |
| `<TaskToolbar>` | `<PeriodFilterButton>` | 当前周期入口 | 按钮 | 显示 `全部周期` |
| `<TaskToolbar>` | `<FilterButton>` | 筛选入口 | 按钮 | 打开筛选入口 |
| `<ObjectiveTree>` | 目标树 | 页面核心内容 | 树形列表 | 展示目标四层层级 |
| `<FloatingLayer>` | `<BlockMenu>` | 当前块操作 | 气泡菜单 | 按需出现 |
| `<FloatingLayer>` | `<CommentPanel>` | 块级评论 | 右下角可拖拽浮窗 | 按需出现 |
| `<FloatingLayer>` | `<NativeConfirmDialog>` | 删除确认 | 浏览器确认框 | 按需出现 |
| `<FloatingLayer>` | `<PlanModePopover>` | 阶段切换 | 气泡菜单 | 按需出现 |

## 4. 交互与状态

本节描述任务管理页的核心 UI 交互和页面状态。

### 4.1 核心交互

| 交互 | 说明 |
| --- | --- |
| 新建目标 | 从 AppShell 顶部栏主操作创建目标 |
| 新建反馈 | 从 AppShell 顶部栏主操作创建反馈 |
| 切换范围 | 在任务页工具栏切换团队 / 个人 |
| 周期入口 | 点击 `全部周期` 入口 |
| 筛选入口 | 点击 `筛选` 入口 |
| 新增下级 | 通过块操作入口创建指标、任务或子任务 |
| 编辑 | 通过块菜单或双击当前行编辑对象标题 |
| TODO: 归档任务 | 通过任务块菜单归档任务；归档不是删除，只从默认任务树中隐藏 |
| 删除 | 通过块菜单删除当前对象，删除前打开浏览器确认框 |
| 全局搜索 | 通过 AppShell 顶部栏搜索页面和 ORF 对象 |
| 展开 / 折叠 | 控制指标下任务、任务下子任务的显示 |
| 拖拽排序 | 调整指标、任务、子任务的位置 |
| 勾选完成 | 切换任务或子任务完成状态 |
| 切换阶段 | 通过目标行阶段按钮切换 ORF 阶段 |
| 打开评论 | 从块菜单或评论数入口打开当前对象评论浮窗 |
| 打开块菜单 | 打开当前目标、指标、任务或子任务的操作菜单 |

### 4.2 页面状态

| 状态 | 说明 |
| --- | --- |
| 默认态 | 页面正常展示目标树 |
| 团队视图 | 展示团队指标卡和团队范围目标树 |
| 个人视图 | 隐藏团队指标卡，只展示个人范围目标树 |
| 空态 | 当前无目标或个人范围无内容 |
| 编辑态 | 当前目标、指标、任务或子任务处于标题编辑中 |
| 拖拽态 | 当前对象正在被拖拽排序 |
| 折叠态 | 指标或任务的下级内容被隐藏 |
| TODO: 归档隐藏态 | 已归档任务默认不在任务树展示；后续可通过归档筛选或单独入口查看 |
| 浮层打开态 | 页面存在块菜单、评论浮窗、浏览器确认框或阶段菜单 |

### 4.3 交互细则

| 交互 | 细则 |
| --- | --- |
| 块操作 | 目标、指标、任务、子任务行 hover 时显示块操作入口 |
| 块操作 | 同一时间只显示一个块操作入口；菜单打开时其它行 hover 不再显示入口 |
| 块操作 | 操作入口包含 `+`、拖拽手柄、折叠 / 展开按钮 |
| 块操作 | 折叠 / 展开按钮贴在当前行主图标左侧 |
| 块操作 | 无折叠入口的行保留同宽前置槽，避免主图标错位 |
| 块菜单 | 菜单固定包含：复制链接、编辑、评论、删除 |
| TODO: 任务归档入口 | 任务块菜单后续增加 `归档` 操作；归档后任务从当前指标下隐藏，但不解除与指标的关联 |
| 新增 | 目标行 `+` 新增指标；指标行 `+` 新增任务；任务行 `+` 新增子任务；子任务行 `+` 新增同级子任务 |
| 编辑 | 块菜单 `编辑` 和双击行进入同一标题编辑状态 |
| 编辑 | 勾选框、阶段按钮、折叠按钮保持自身点击行为 |
| 拖拽 | 拖拽时页面进入拖拽态，并显示可放置位置 |
| 删除 | 删除前打开浏览器确认框 |
| 删除 | 确认框文案展示受影响下级数量 |
| 评论 | 评论面板为右下角可拖拽浮窗 |
| 评论 | 评论支持列表、回复详情、回复、编辑和删除 |
