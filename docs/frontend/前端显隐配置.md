# 前端显隐配置

## 是什么

前端显隐配置用于控制固定入口和固定区域是否展示，例如导航入口、页面访问入口、挑战页全量视图入口。

唯一数据配置：

```text
src/config/frontendVisibility.config.json
```

唯一代码入口：

```text
src/config/frontendVisibility.ts
```

## 为什么

显隐配置只处理前端展示，不处理业务权限，也不是安全边界。

业务动作是否允许执行，由权限表和后端接口校验。

## 怎么做

组件只能通过以下方法判断显隐：

```text
canShowFrontend()
canShowFrontendPath()
```

新增显隐点时，先在 `frontendVisibility.config.json` 增加 key；如果涉及路由路径，再在 `frontendVisibility.ts` 补充 `frontendVisibilityByPath`。

命令菜单只管理已登录应用内的业务入口；登录 / 注册页属于公共认证路由，不放入 `quickPages`。

不要在组件里单独写 `adminOnlyPaths`、`isAdmin && ...`、`RequireAdmin` 这类显隐规则。

`tests/frontendVisibility.test.ts` 用于防止显隐逻辑绕过统一入口。
