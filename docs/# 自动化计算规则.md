# 自动化计算规则：数学版

## 目标

在目标冻结快照 `F` 上，计算 `goal → ret → task → subtask` 各层级对象的完成状态。

---

## 最小基

对象定义：

- `g = goal`
- `r = ret`
- `t = task`
- `s = subtask`

状态域：

- `B = {0, 1}`
- `1 = done`
- `0 = undone`

状态函数：

- `A(x) ∈ B`：对象 `x` 的自身状态。
- `C(x) ∈ B`：对象 `x` 的系统计算状态。

---

## 结构约束

对任意目标 `g`：

> `R(g) = {r₁, r₂, ..., rₙ}, n ≥ 1`

对任意指标 `rᵢ`：

> `T(rᵢ) = {tᵢ₁, tᵢ₂, ..., tᵢₘ}, m ≥ 1`

对任意任务 `tᵢⱼ`：

> `S(tᵢⱼ) = {sᵢⱼ₁, sᵢⱼ₂, ..., sᵢⱼₖ}, k ≥ 0`

即：

- `goal` 下必须有 `ret`
- `ret` 下必须有 `task`
- `task` 下可以没有 `subtask`

---

## 组合原则

### 1. subtask

子任务是叶子节点：

> `C(s) = A(s)`

---

### 2. task

任务分两种情况：

- 当 `task` 没有 `subtask` 时：`C(t) = A(t), if |S(t)| = 0`
- 当 `task` 有 `subtask` 时：`C(t) = ∧ C(s), s ∈ S(t), if |S(t)| > 0`

合并写法：

> `C(t) = A(t), if |S(t)| = 0`
>
> `C(t) = ∧_{s ∈ S(t)} C(s), if |S(t)| > 0`

---

### 3. ret

> `C(r) = ∧_{t ∈ T(r)} C(t)`

即：

> `ret done ⇔ ret 下所有 task done`

---

### 4. goal

> `C(g) = ∧_{r ∈ R(g)} C(r)`

即：

> `goal done ⇔ goal 下所有 ret done`

---

## 组合空间

完整组合空间为：

> `GoalSpace = { g | R(g) = {r₁, ..., rₙ}, n ≥ 1; T(rᵢ) = {tᵢ₁, ..., tᵢₘ}, m ≥ 1; S(tᵢⱼ) = {sᵢⱼ₁, ..., sᵢⱼₖ}, k ≥ 0 }`

也就是：

- `goal`
- `goal → ret ¹..n`
- `goal → ret → task ¹..m`
- `goal → ret → task → subtask ⁰..k`

因此存在两类合法路径：

- `goal → ret → task`
- `goal → ret → task → subtask`

---

## 最终计算式

> `C(g) = ∧_{r ∈ R(g)} ∧_{t ∈ T(r)} F(t)`

其中：

> `F(t) = A(t), if |S(t)| = 0`
>
> `F(t) = ∧_{s ∈ S(t)} A(s), if |S(t)| > 0`

---

## 核心规则

- `task` 无 `subtask` 时，看 `task` 自身状态。
- `task` 有 `subtask` 时，看全部 `subtask` 状态。
- `ret` 看全部 `task`。
- `goal` 看全部 `ret`。

关键边界条件：

- `|R(g)| ≥ 1`
- `|T(r)| ≥ 1`
- `|S(t)| ≥ 0`

这些边界条件用于避免空集合被误算为完成。
