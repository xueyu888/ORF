# 自动化计算规则：数学版

## 目标

在目标冻结快照 `F` 上，计算：

```text
goal → ret → task → subtask
```

各层级对象的完成状态。

---

## 最小基

设：

```text
g = goal
r = ret
t = task
s = subtask
```

状态域：

```text
B = {0, 1}
```

其中：

```text
1 = done
0 = undone
```

定义：

```text
A(x) ∈ B
```

表示对象 `x` 的自身状态。

```text
C(x) ∈ B
```

表示对象 `x` 的系统计算状态。

---

## 结构约束

对任意目标 `g`：

```text
R(g) = {r₁, r₂, ..., rₙ}, n ≥ 1
```

对任意指标 `rᵢ`：

```text
T(rᵢ) = {tᵢ₁, tᵢ₂, ..., tᵢₘ}, m ≥ 1
```

对任意任务 `tᵢⱼ`：

```text
S(tᵢⱼ) = {sᵢⱼ₁, sᵢⱼ₂, ..., sᵢⱼₖ}, k ≥ 0
```

即：

```text
goal 下必须有 ret
ret 下必须有 task
task 下可以没有 subtask
```

---

## 组合原则

### 1. subtask

子任务是叶子节点：

```text
C(s) = A(s)
```

---

### 2. task

任务分两种情况。

当 `task` 没有 `subtask` 时：

```text
C(t) = A(t), if |S(t)| = 0
```

当 `task` 有 `subtask` 时：

```text
C(t) = ∧ C(s), s ∈ S(t), if |S(t)| > 0
```

合并写法：

```text
C(t) =
{
  A(t),                    |S(t)| = 0
  ∧_{s ∈ S(t)} C(s),        |S(t)| > 0
}
```

---

### 3. ret

```text
C(r) = ∧_{t ∈ T(r)} C(t)
```

即：

```text
ret done ⇔ ret 下所有 task done
```

---

### 4. goal

```text
C(g) = ∧_{r ∈ R(g)} C(r)
```

即：

```text
goal done ⇔ goal 下所有 ret done
```

---

# 组合空间

完整组合空间为：

```text
GoalSpace =
{
  g |
  R(g) = {r₁, ..., rₙ}, n ≥ 1,
  T(rᵢ) = {tᵢ₁, ..., tᵢₘ}, m ≥ 1,
  S(tᵢⱼ) = {sᵢⱼ₁, ..., sᵢⱼₖ}, k ≥ 0
}
```

也就是：

```text
goal
 └── ret ¹..n
      └── task ¹..m
           └── subtask ⁰..k
```

因此存在两类合法路径：

```text
goal → ret → task
```

和：

```text
goal → ret → task → subtask
```

---

# 最终计算式

```text
C(g) = ∧_{r ∈ R(g)} ∧_{t ∈ T(r)} F(t)
```

其中：

```text
F(t) =
{
  A(t),                    |S(t)| = 0
  ∧_{s ∈ S(t)} A(s),        |S(t)| > 0
}
```

---

这个版本的核心是：

```text
task 无 subtask 时，看 task 自身状态；
task 有 subtask 时，看全部 subtask 状态；
ret 看全部 task；
goal 看全部 ret。
```

关键边界条件是：

```text
|R(g)| ≥ 1
|T(r)| ≥ 1
|S(t)| ≥ 0
```

这样可以避免空集合被误算为完成。
