# ORF 任务管理页面

## 接口访问约定

前端数据统一通过同源 `/api` 请求后端接口，例如 `/api/tasks`。
前端不直接写死后端域名或端口，开发和生产环境由代理或网关转发到实际后端服务。

任务管理页文档已拆成前端和后端两部分。

## 文档入口

| 文档 | 内容 |
| --- | --- |
| [ORF 任务管理页面 - 前端.md](./ORF%20任务管理页面%20-%20前端.md) | 前端字段排列、组件定位、派生状态、进度计算、视觉规则和 TODO。 |
| [ORF 任务管理页面 - 后端.md](./ORF%20任务管理页面%20-%20后端.md) | 后端返回集合、对象关系、原始字段、枚举和接口边界。 |

## 拆分原则

- 后端文档只记录原始数据契约：字段、类型、枚举和对象关系。
- 前端文档只记录页面展示契约：组件、字段排列、派生状态、进度计算和视觉表现。
- 若某个状态由后端直接返回，写入后端文档；若某个状态由前端计算得到，写入前端文档。
