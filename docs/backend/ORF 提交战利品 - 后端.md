# ORF 提交战利品 - 后端

## 1. 当前契约

当前前端提交战利品不调用独立后端接口。

提交内容暂存为悬赏指标评论：

| 字段 | 值 |
| --- | --- |
| `targetType` | `result` |
| `targetId` | 当前悬赏指标 `Result.id` |
| `body` | `战利品提交：{完成说明}` |

同时前端会把该悬赏指标下未完成任务更新为 `In Review`，用于展示待验收。

## 2. 后续接口

正式后端应增加独立接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/results/:resultId/loot` | 提交当前悬赏指标战利品 |

请求体：

```json
{
  "body": "完成说明"
}
```

后端保存后应返回更新后的悬赏指标、任务和评论数据。
