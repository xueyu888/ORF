# 目标完成自动化计算规则测试

## 来源文档

[自动化计算规则.md](./自动化计算规则.md)

## 测试入口

```text
npm test
```

## 测试代码

```text
tests/automaticCompletionRules.test.ts
tests/databaseAutomaticCompletionLegality.test.ts
```

`tests/automaticCompletionRules.test.ts` 只作为规则验收代码存在，只依赖后端自动化计算模块，不依赖前端页面、后端接口、仓库业务状态或浏览器状态。

`tests/databaseAutomaticCompletionLegality.test.ts` 读取数据库内容，只验收数据库层级数据在阶段门控下是否会被计算模块正确处理，不绑定任何具体页面、业务模块、业务目标标题或浏览器状态。

## 覆盖范围

### 阶段门控覆盖

测试必须覆盖自动化计算模块的调用边界：

```text
stage = goalFrozen 时，允许调用计算模块
stage != goalFrozen 时，不调用计算模块
```

测试必须覆盖自动化计算模块的触发条件：

```text
目标阶段由非 goalFrozen 转为 goalFrozen 时，重新计算 C(task)、C(ret)、C(goal)
目标已经处于 goalFrozen，且 goal / ret / task / subtask 发生变化时，重新计算 C(task)、C(ret)、C(goal)
目标不处于 goalFrozen 时，即使 goal / ret / task / subtask 发生变化，也不调用计算模块
```

重新计算必须基于目标最新层级快照进行整棵目标树级别计算，不得只断言单个局部节点。

### 规则组合覆盖

测试必须覆盖文档定义的合法组合空间：

```text
goal → ret → task
goal → ret → task → subtask
```

结构约束：

```text
n ≥ 1
mᵢ ≥ 1
kᵢⱼ ≥ 0
d(x) ∈ {0, 1}
```

自动化测试包含三类输入：

```text
固定验收用例
小规模组合穷举
固定种子随机组合
```

小规模组合穷举范围：

```text
1 ≤ n ≤ 2
1 ≤ mᵢ ≤ 2
0 ≤ kᵢⱼ ≤ 2
d(x) 全状态组合
```

固定种子随机组合范围：

```text
1 ≤ n ≤ 8
1 ≤ mᵢ ≤ 8
0 ≤ kᵢⱼ ≤ 8
d(x) 随机取 0 或 1
```

随机测试使用固定种子，保证失败可复现。

### 数据库合法性覆盖

数据库测试必须读取以下表：

```text
objectives
results
tasks
task_checklist_items
```

数据库测试必须校验：

```text
目标下的悬赏指标集合来自 results.objective_id
悬赏指标下的任务集合来自 tasks.linked_result_id
任务下的子任务集合来自 task_checklist_items.task_id
无 subtask 的 task 使用 task.status = Done 映射 d(task) = 1
有 subtask 的 task 使用所有 subtask.done 映射 C(task)
```

数据库测试必须验证：当目标不处于 `goalFrozen` 时，即使数据库中存在不满足 `n ≥ 1` 或 `mᵢ ≥ 1` 的数据，也不会调用自动化计算模块。

数据库测试必须验证：当目标处于 `goalFrozen` 且数据库数据不满足 `n ≥ 1` 或 `mᵢ ≥ 1` 时，该目标不能被计算为完成。

数据库测试不得为某个具体业务模块、页面或目标写固定断言。

## 固定验收用例

组合结构：

```text
n = 2
m₁ = 2
m₂ = 1
k₁₁ = 0
k₁₂ = 2
k₂₁ = 2
```

叶子输入：

```text
d(t₁₁) = 1
d(s₁₂₁) = 1
d(s₁₂₂) = 1
d(s₂₁₁) = 1
d(s₂₁₂) = 0
```

断言：

```text
C(t₁₁) = 1
C(t₁₂) = 1
C(t₂₁) = 0
C(r₁) = 1
C(r₂) = 0
C(g) = 0
```

## 通用断言

每个自动生成的合法组合都必须满足：

```text
kᵢⱼ = 0 时，C(tᵢⱼ) = d(tᵢⱼ)
kᵢⱼ > 0 时，C(tᵢⱼ) = ∧ₗ d(sᵢⱼₗ)
C(rᵢ) = ∧ⱼ C(tᵢⱼ)
C(g) = ∧ᵢ C(rᵢ)
C(g) = ∧ᵢ ∧ⱼ F(tᵢⱼ)
```
