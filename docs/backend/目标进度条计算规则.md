# 目标进度条规则

## 口径

`Objective.progress` 是后端业务字段，取值为 `0..100` 的整数。

前端只读取并展示该字段，不根据任务、子任务或指标自行计算目标进度。

## 更新来源

`Objective.progress` 只能由以下动作更新：

- 指挥官在目标验收或复盘中更新。
- 后端基于明确验收结果写入。
- 后续单独设计的进度更新接口写入。

没有明确更新动作时，接口返回持久化值。

## 禁止推导

以下变化不能自动改变目标进度、验收状态或结算结果：

- 任务勾选完成。
- 子任务勾选完成。
- 指标下所有任务完成。
- 目标下所有指标的任务完成。

目标是否完成，必须通过目标战利品提交和指挥官验收确认。
