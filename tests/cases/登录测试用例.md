## 1. 测试目标

验证：已存在的 ORF 普通成员，在 Ory/Kratos 中存在可用密码凭据时，可以使用正确邮箱和密码，从当前浏览器未登录状态进入 ORF 已登录状态。

边界：

- 本用例只验证成功登录，不验证注册、错误密码、账号不存在或权限配置。
- 本用例的 Action 只包含用户登录动作，不包含创建用户、写数据库、写 cookie 或清理 session。

## 2. 状态模型

- B：
  - 前端、ORF 后端、Ory/Kratos 和数据库均可用。
  - Ory/Kratos 中存在专用测试身份：
    - email：测试邮箱
    - password：测试密码
    - 密码登录方式可用
  - ORF 数据库中存在与测试邮箱对应的用户。
  - 该用户在测试团队中存在成员关系，角色为 `member`。
  - 当前测试浏览器上下文未登录：
    - 不存在 `orf_ory_session` cookie
    - localStorage/sessionStorage 不包含登录态
    - `/api/auth/session` 返回 `authenticated: false`

- Setup：
  - 使用测试 helper 或 Ory Admin API upsert 测试身份，并设置固定测试密码。
  - 使用数据库 helper upsert ORF 测试用户和 `team_members` 记录，角色设置为 `member`。
  - 记录测试用户登录前需要恢复的字段，例如 `last_login_at`。
  - 若测试身份为本用例独占身份，清理该身份已有 Ory session。
  - 创建全新的浏览器上下文，或清空当前上下文的 cookies/localStorage/sessionStorage。
  - 打开 `/auth`。
  - 等待登录页认证状态就绪，即主登录按钮可点击。

- S0：
  - 当前页面停留在 `/auth`。
  - 登录模式可见，标题为 `Sign in`。
  - `Email` 输入框可见且为空。
  - `Password` 输入框可见且为空。
  - `Sign In` 按钮可见且可点击。
  - `/api/auth/session` 返回 `authenticated: false`。
  - 浏览器上下文不存在 `orf_ory_session` cookie。
  - Ory/Kratos 测试身份存在，且已由 Setup 设置好密码凭据。
  - ORF 测试用户存在，并且团队角色为 `member`。

- Action：
  - 用 Playwright 按业务语义定位 `Email` 输入框，输入测试邮箱。
  - 用 Playwright 按业务语义定位 `Password` 输入框，输入测试密码。
  - 用 Playwright 点击 `Sign In` 按钮提交登录表单。

- S1：
  - `/api/auth/login` 返回成功。
  - ORF 后端向当前浏览器设置 `orf_ory_session` HttpOnly cookie。
  - `/api/auth/session` 返回：
    - `authenticated: true`
    - `user.email` 等于测试邮箱
    - `user.role` 等于 `member`
  - 页面离开登录页，并进入当前实现的登录后入口 `/tasks`。
  - 受保护的应用 Shell 可见：
    - 主导航可见
    - 当前用户区域可见
    - `退出登录` 按钮可见
  - 登录表单不再作为当前页面的主要状态出现。
  - ORF 测试用户和团队成员关系仍然存在。

- Clean：
  - 在当前浏览器上下文中调用 `/api/auth/logout`，撤销本次登录产生的 Ory session。
  - 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - 如本用例修改了 `last_login_at` 等非基准字段，将其恢复为 Setup 前记录的值。
  - 保留测试 Ory 身份、ORF 测试用户和 `member` 成员关系。
  - 系统回到“测试身份和 ORF 成员存在，但当前浏览器未登录”的 B 状态。

## 3. 断言

- S0 断言：
  - `page` URL 为 `/auth`。
  - `page.getByRole("heading", { name: "Sign in" })` 可见。
  - `page.getByLabel("Email")` 可见且值为空。
  - `page.getByLabel("Password")` 可见且值为空。
  - `page.getByRole("button", { name: "Sign In" })` 可见且可点击。
  - 通过同源请求确认 `/api/auth/session` 返回 `authenticated: false`。
  - 通过浏览器上下文 cookies 确认不存在 `orf_ory_session`。
  - 通过 Ory/数据库 helper 确认测试身份、ORF 用户和 `member` 成员关系存在。

- S1 断言：
  - 等待 `POST /api/auth/login` 响应成功。
  - `page` URL 为 `/tasks`。
  - 通过浏览器上下文 cookies 确认存在 `orf_ory_session`。
  - 通过同源请求确认 `/api/auth/session` 返回 `authenticated: true`，且用户邮箱和角色符合测试数据。
  - `page.getByLabel("主导航")` 可见。
  - `page.getByLabel("当前用户")` 可见。
  - `page.getByRole("button", { name: "退出登录" })` 可见。
  - `page.getByRole("button", { name: "Sign In" })` 不再作为当前页面主要操作出现。

- Clean 后断言：
  - `/api/auth/session` 返回 `authenticated: false`。
  - 浏览器上下文不存在 `orf_ory_session`。
  - 访问受保护路由会回到 `/auth`。
  - Ory/Kratos 测试身份仍然存在。
  - ORF 测试用户仍然存在。
  - 该用户的团队角色仍然是 `member`。
  - 如恢复了 `last_login_at`，确认其等于 Setup 前记录的值。
