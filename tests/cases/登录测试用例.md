## 1. 测试目标

验证：已存在的正常用户，使用正确账号密码，可以从未登录状态进入已登录状态。

## 2. 状态模型

- B：
  - 系统正常运行
  - 测试用户存在
  - 测试用户状态为 active
  - 测试用户密码可验证
  - 当前测试浏览器未登录

- Setup：
  - upsert 测试用户
  - 设置用户状态为 active
  - 设置用户默认角色为 user
  - 清理该用户已有 session
  - 清空浏览器 cookies/localStorage/sessionStorage
  - 打开登录页

- S0：
  - 登录页可见
  - 邮箱输入框可见
  - 密码输入框可见
  - 登录按钮可见
  - 当前浏览器无登录态
  - 数据库中测试用户存在且可登录

- Action：
  - [pw]: 输入测试用户邮箱, 用playwright
  - 输入测试用户密码, 用Prisma
  - 点击登录按钮

- S1：
  - 页面进入已登录状态
  - 用户可以看到已登录后的页面元素
  - 浏览器存在登录态
  - 后端存在有效 session，或等价的登录状态记录

- Clean：
  - 清空浏览器登录态
  - 删除本次测试用户产生的 session
  - 保留测试用户
  - 恢复到“用户存在，但当前浏览器未登录”的 B 状态

## 3. 断言

- S0 断言：
  - 登录表单可见
  - 测试用户存在
  - 用户状态正常
  - 密码可验证
  - 当前浏览器未登录

- S1 断言：
  - 已登录页面元素可见
  - 登录表单不再作为主要状态出现
  - 浏览器存在登录态
  - 后端存在有效登录状态

- Clean 后断言：
  - 浏览器登录态已清除
  - 测试用户 session 已删除
  - 测试用户仍然存在
  - 系统回到 B
