# 测试用例模板

## 1. 测试目标

验证：xxx

## 2. 状态模型

- B：测试开始前，系统处于什么基准状态？

- Setup：如何构造测试前状态？  
  Setup 中的具体动作需要加执行手段标签。

```text
- [prisma] xxx
- [playwright] xxx
- [api] xxx
- [mock] xxx
```

- S0：Action 前必须满足什么条件？

- Action：本次测试唯一要验证的业务动作是什么？  
  Action 中的具体动作需要加执行手段标签。

```text
- [playwright] xxx
```

- S1：Action 后系统应该变成什么状态？

- Clean：如何清理并恢复到 B？  
  Clean 中的具体动作需要加执行手段标签。

```text
- [playwright] xxx
- [prisma] xxx
- [api] xxx
```

标签目前只允许使用：

```text
[playwright]
[prisma]
[api]
[mock]
```

注意：标签只标注 Setup、Action、Clean 中的具体动作，不标注 B、S0、S1 这些状态本身。

## 3. 断言

- S0 断言：确认 Setup 成功
- S1 断言：确认业务动作正确
- Clean 后断言：确认测试没有污染环境
