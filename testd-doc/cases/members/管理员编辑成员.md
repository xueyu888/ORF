# 管理员编辑成员

## 1. 测试目标

- [api] 编辑成员接口响应 应成功。
- [prisma] 可编辑成员 的姓名 应变为 新姓名。
- [prisma] 可编辑成员 的邮箱 应变为 新邮箱。
- [prisma] 可编辑成员 的角色 应变为 admin。
- [playwright] 成员管理列表 应显示 已编辑成员。

边界：

- 覆盖对象：管理员编辑成员姓名、邮箱、角色。
- 不覆盖对象：新增成员、停用成员、删除成员、注册审批、普通成员不可编辑成员。
- B 基础数据：预置管理员账号 "zrx831@gmail.com"。
- Setup 产物：本用例创建的可编辑普通成员。
- Clean 产物：本用例创建的测试成员。

## 2. 状态模型

- B：基准状态。
  - [api] 前端服务 应可用。
  - [api] 后端服务 应可用。
  - [api] 健康检查或等价探测 应通过。
  - [prisma] ORF 数据库 应可连接。
  - [api] Ory/Kratos Admin API 应可访问。
  - [api] Ory/Kratos Public API 应可访问。
  - [api] 应存在 邮箱为 "zrx831@gmail.com" 的管理员 Ory/Kratos 测试身份。
  - [prisma] 应存在 邮箱为 "zrx831@gmail.com"、角色为 admin、状态为 active 的管理员用户。
  - [prisma] 应不存在 邮箱为 "e2e-member-edit-source@orf.local" 的测试成员。
  - [prisma] 应不存在 邮箱为 "e2e-member-edit-updated@orf.local" 的测试成员。
  - [api] 当前会话 应为 未登录。
  - [playwright] 当前浏览器 应不存在 登录 cookie。
  - [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [playwright] 清空 当前浏览器状态。
  - [prisma] 创建 姓名为 "E2E Member Edit Source"、邮箱为 "e2e-member-edit-source@orf.local"、角色为 member、状态为 active 的测试成员。
  - [playwright] 打开 "/auth" 登录页。
  - [playwright] 填写 Email 输入框 为 管理员邮箱。
  - [playwright] 填写 Password 输入框 为 管理员密码。
  - [playwright] 点击 "Sign In" 登录操作。
  - [api] 当前会话 应为 管理员已登录。
  - [playwright] 打开 "/members" 成员管理页。

- S0：Action 前状态。
  - [api] 当前会话 应为 邮箱为 "zrx831@gmail.com" 的管理员已登录。
  - [playwright] 当前页面 应为 成员管理页。
  - [playwright] 成员管理列表 应显示 原测试成员。
  - [playwright] 原测试成员 的 "编辑" 操作 应可见。
  - [prisma] 原测试成员 的姓名 应为 "E2E Member Edit Source"。
  - [prisma] 原测试成员 的邮箱 应为 "e2e-member-edit-source@orf.local"。
  - [prisma] 原测试成员 的角色 应为 member。

- Action：被测业务动作。
  - [api] 监听 编辑成员接口响应。
  - [playwright] 点击 原测试成员 的 "编辑" 操作。
  - [playwright] 填写 姓名 输入框 为 "E2E Member Edit Updated"。
  - [playwright] 填写 邮箱 输入框 为 "e2e-member-edit-updated@orf.local"。
  - [playwright] 选择 角色 为 admin。
  - [playwright] 点击 "保存" 操作。

- S1：Action 后状态。
  - [api] 编辑成员接口响应 应成功。
  - [prisma] 已编辑成员 的姓名 应为 "E2E Member Edit Updated"。
  - [prisma] 已编辑成员 的邮箱 应为 "e2e-member-edit-updated@orf.local"。
  - [prisma] 已编辑成员 的角色 应为 admin。
  - [playwright] 成员管理列表 应显示 已编辑成员。
  - [playwright] 成员管理列表 应不显示 原测试成员。
  - [api] 当前会话 应保持 管理员已登录。

- Clean：恢复 B。
  - [prisma] 删除 本用例创建的测试成员。
  - [api] 注销 当前登录会话。
  - [playwright] 清空 当前浏览器状态。
  - [api] 应存在 邮箱为 "zrx831@gmail.com" 的管理员 Ory/Kratos 测试身份。
  - [prisma] 应存在 邮箱为 "zrx831@gmail.com"、角色为 admin、状态为 active 的管理员用户。
  - [prisma] 应不存在 邮箱为 "e2e-member-edit-source@orf.local" 的测试成员。
  - [prisma] 应不存在 邮箱为 "e2e-member-edit-updated@orf.local" 的测试成员。
