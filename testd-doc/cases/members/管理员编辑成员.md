# 管理员编辑成员

## 1. 测试目标

验证：由当前用例独占准备的管理员可以编辑当前用例独占成员的姓名、邮箱和角色；保存后，成员管理列表和数据库中的成员资料同步更新。

边界：

- 覆盖对象：管理员编辑成员姓名、邮箱、角色。
- 不覆盖对象：新增成员、停用成员、删除成员、注册审批、普通成员不可编辑成员。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体管理员账号或可编辑成员。
- Setup 产物：本次运行独占管理员邮箱对应的管理员认证身份、用户和 admin 成员关系；本次运行独占原邮箱对应的可编辑普通成员。
- Action 产物：同一个可编辑成员被改为姓名 "ORF Member Edit Updated E2E"、本次运行独占更新后邮箱、角色 admin。
- Clean 产物：删除本用例创建或覆盖的管理员身份、管理员用户、成员关系和可编辑成员，并同时覆盖本次运行独占原邮箱与更新后邮箱。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除本用例残留的可编辑成员。
  - [Setup-2] [api] 准备本次运行独占管理员认证身份，密码为固定测试密码。
  - [Setup-3] [prisma] 准备本次运行独占管理员用户和默认团队成员关系，角色为 `admin`、状态为 `active`。
  - [Setup-4] [api] 撤销管理员认证身份的残留登录会话。
  - [Setup-5] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-6] [prisma] 创建姓名为 "ORF Member Edit Source E2E"、邮箱为本次运行独占原邮箱、角色为 `member`、状态为 `active` 的可编辑成员。
  - [Setup-7] [playwright] 打开 ORF 登录页。
  - [Setup-8] [playwright] 在邮箱输入框输入本次运行独占管理员邮箱。
  - [Setup-9] [playwright] 在密码输入框输入管理员固定测试密码。
  - [Setup-10] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-11] [playwright] 打开成员管理页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 本次运行独占管理员邮箱、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 成员管理页面。
  - [S0-3] [playwright] 成员管理列表 应显示 原测试成员。
  - [S0-4] [playwright] 原测试成员 的 "编辑" 操作 应可见。
  - [S0-5] [prisma] 原测试成员 的姓名 应为 "ORF Member Edit Source E2E"。
  - [S0-6] [prisma] 原测试成员 的邮箱 应为 本次运行独占原邮箱。
  - [S0-7] [prisma] 原测试成员 的角色 应为 member。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击 原测试成员 的 "编辑" 操作。
  - [Action-2] [playwright] 填写 姓名 输入框 为 "ORF Member Edit Updated E2E"。
  - [Action-3] [playwright] 填写 邮箱 输入框 为 本次运行独占更新后邮箱。
  - [Action-4] [playwright] 选择 角色 为 admin。
  - [Action-5] [playwright] 点击 "保存" 操作。

- S1：Action 后状态。
  - [S1-1] [api] 编辑成员结果 应成功。
  - [S1-2] [prisma] 已编辑成员 的姓名 应为 "ORF Member Edit Updated E2E"。
  - [S1-3] [prisma] 已编辑成员 的邮箱 应为 本次运行独占更新后邮箱。
  - [S1-4] [prisma] 已编辑成员 的角色 应为 admin。
  - [S1-5] [playwright] 成员管理列表 应显示 已编辑成员。
  - [S1-6] [playwright] 成员管理列表 应不显示 原测试成员。
  - [S1-7] [api] 当前会话 应仍为 本次运行独占管理员邮箱、角色为 `admin`、状态为 `active` 的已登录会话。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除本用例可编辑成员。
  - [Clean-2] [prisma] 本用例可编辑成员 应不存在。
  - [Clean-3] [api] 注销当前登录会话。
  - [Clean-4] [playwright] 离开当前 ORF 前端页面。
  - [Clean-5] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-6] [api] 撤销管理员认证身份的残留登录会话。
  - [Clean-7] [api] 删除本次运行独占管理员认证身份。
  - [Clean-8] [prisma] 删除管理员用户的默认团队成员关系。
  - [Clean-9] [prisma] 删除本次运行独占管理员用户。
