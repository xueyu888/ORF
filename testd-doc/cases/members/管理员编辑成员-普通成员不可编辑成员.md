# 管理员编辑成员-普通成员不可编辑成员

## 1. 测试目标

验证：普通成员不能进入成员管理页面，也不能编辑其他成员资料；成员管理入口被前端隐藏，成员资料保持不变。

边界：

- 覆盖对象：普通成员不可编辑成员。
- 不覆盖对象：管理员编辑成员、停用成员、删除成员、普通成员修改个人设置。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体普通成员账号或被管理成员。
- Setup 产物：邮箱为 `orf-member-edit-forbidden-e2e@orf.local` 的普通成员认证身份、用户和 member 成员关系；邮箱为 `orf-member-edit-forbidden-target-e2e@orf.local` 的被管理成员。
- Action 产物：普通成员打开悬赏大厅后的前端可见入口和成员数据保持结果。
- Clean 产物：删除本用例创建或覆盖的普通成员认证身份、普通成员用户、成员关系和被管理成员。
- 原状态恢复：普通成员账号和被管理成员均为当前用例独占资源，Clean 直接删除，不恢复任何共享成员状态。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除本用例残留的被管理成员。
  - [Setup-2] [api] 准备普通成员认证身份，邮箱为 `orf-member-edit-forbidden-e2e@orf.local`，密码为固定测试密码。
  - [Setup-3] [prisma] 准备普通成员用户和默认团队成员关系，邮箱为 `orf-member-edit-forbidden-e2e@orf.local`、角色为 `member`、状态为 `active`。
  - [Setup-4] [prisma] 准备被管理成员，邮箱为 `orf-member-edit-forbidden-target-e2e@orf.local`、角色为 `member`、状态为 `active`。
  - [Setup-5] [api] 撤销普通成员认证身份的残留登录会话。
  - [Setup-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-7] [playwright] 打开 ORF 登录页。
  - [Setup-8] [playwright] 在邮箱输入框输入普通成员固定测试邮箱。
  - [Setup-9] [playwright] 在密码输入框输入普通成员固定测试密码。
  - [Setup-10] [playwright] 点击 "Sign In" 登录操作。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-member-edit-forbidden-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] "系统管理" 导航入口 应不可见。
  - [S0-3] [prisma] 被管理成员 的姓名 应为 "ORF Member Edit Forbidden Target E2E"。
  - [S0-4] [prisma] 被管理成员 的邮箱 应为 "orf-member-edit-forbidden-target-e2e@orf.local"。
  - [S0-5] [prisma] 被管理成员 的角色 应为 member。
  - [S0-6] [prisma] 被管理成员 的状态 应为 `active`。

- Action：被测业务动作。
  - [Action-1] [playwright] 普通成员打开悬赏大厅页面。

- S1：Action 后状态。
  - [S1-1] [playwright] 当前页面 应为 悬赏大厅。
  - [S1-2] [playwright] "系统管理" 导航入口 应不可见。
  - [S1-3] [playwright] 成员管理表格 应不可见。
  - [S1-4] [playwright] 成员编辑入口 应不可见。
  - [S1-5] [prisma] 被管理成员 的姓名 应仍为 "ORF Member Edit Forbidden Target E2E"。
  - [S1-6] [prisma] 被管理成员 的邮箱 应仍为 "orf-member-edit-forbidden-target-e2e@orf.local"。
  - [S1-7] [prisma] 被管理成员 的角色 应仍为 member。
  - [S1-8] [prisma] 被管理成员 的状态 应仍为 `active`。
  - [S1-9] [api] 当前会话 应仍为 邮箱为 `orf-member-edit-forbidden-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除本用例被管理成员。
  - [Clean-2] [api] 注销当前登录会话。
  - [Clean-3] [playwright] 离开当前 ORF 前端页面。
  - [Clean-4] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-5] [api] 撤销普通成员认证身份的残留登录会话。
  - [Clean-6] [api] 删除邮箱为 `orf-member-edit-forbidden-e2e@orf.local` 的普通成员认证身份。
  - [Clean-7] [prisma] 删除普通成员用户的默认团队成员关系。
  - [Clean-8] [prisma] 删除邮箱为 `orf-member-edit-forbidden-e2e@orf.local` 的普通成员用户。
  - [Clean-9] [prisma] 本用例被管理成员 应不存在。
  - [Clean-10] [api] 邮箱为 `orf-member-edit-forbidden-e2e@orf.local` 的普通成员认证身份 应不存在。
  - [Clean-11] [prisma] 邮箱为 `orf-member-edit-forbidden-e2e@orf.local` 的普通成员用户 应不存在。
