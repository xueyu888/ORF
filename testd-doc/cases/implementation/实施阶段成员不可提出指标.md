# 实施阶段成员不可提出指标

## 1. 测试目标

验证：由当前用例独占准备的目标进入实施阶段后，当前用例独占普通成员即使以账号身份参与该目标，也不能再从冻结目标的新增子级菜单提出成员建议指标；页面和数据库都不会产生新指标。

边界：

- 覆盖对象：实施阶段成员不可提出指标。
- 不覆盖对象：评估阶段成员可提出指标、管理员新增指标、指标编辑、指标删除、战利品提交、验收。
- 原 legacy B 依赖：预置普通成员账号 `orf-member-e2e@orf.local`，以及默认团队中任意可改造为实施阶段成员不可提出指标起点的共享目标。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体成员账号、目标或指标。
- Setup 产物：邮箱为 "orf-member-frozen-propose-result-e2e@orf.local" 的普通成员身份、用户和 member 成员关系；标题为 "E2E-FROZEN-MEMBER-PROPOSE: 目标前置"、`flowStatus` 为 `frozen`、阶段为 `goalFrozen` 且挑战者账号身份包含该成员的本用例冻结目标；运行时记录的 `runtime.frozenProposalTarget`。
- Action 产物：普通成员打开本用例冻结目标的新增子级菜单。
- Clean 产物：删除同标题测试指标、目标及其派生数据，删除本用例独占普通成员身份、用户、成员关系与 session。
- 原状态恢复：目标和指标均为当前用例独占资源，Clean 直接删除，不恢复任何共享目标状态。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的同标题测试指标。
  - [Setup-2] [prisma] 删除可能残留的本用例目标及其派生数据。
  - [Setup-3] [api] 准备邮箱为 `orf-member-frozen-propose-result-e2e@orf.local`、使用固定测试密码的普通成员登录身份。

  - [Setup-5] [prisma] 创建标题为 `E2E-FROZEN-MEMBER-PROPOSE: 目标前置`、流转状态为 `frozen`、阶段为 `goalFrozen` 的本用例冻结目标。

  - [Setup-7] [prisma] 设置本用例冻结目标的挑战者账号身份包含普通成员，并保持实施阶段状态。
  - [Setup-8] [api] 撤销普通成员登录身份可能残留的登录会话。
  - [Setup-9] [playwright] 移除当前浏览器中的残留登录态。
