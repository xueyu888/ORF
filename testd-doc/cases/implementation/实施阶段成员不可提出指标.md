# 实施阶段成员不可提出指标

## 1. 测试目标

验证：目标进入实施阶段后，普通成员即使是该目标挑战者，也不能再提出成员建议指标；越权提交不会产生新指标。

边界：

- 覆盖对象：实施阶段成员不可提出指标。
- 不覆盖对象：评估阶段成员可提出指标、管理员新增指标、指标编辑、指标删除、战利品提交、验收。
- B 基础数据：预置普通成员账号 "orf-member-e2e@orf.local"，角色为 member，状态为 active。
- Setup 产物：flowStatus 为 frozen、stage 为 goalFrozen、挑战者包含普通成员的目标。
- Clean 产物：同标题测试指标和目标原始状态。

## 2. 状态模型

- B：基准状态。
  - [api] 前端和后端服务 应为 可用。
  - [api] 前端登录页入口 应可访问。
  - [api] 当前会话查询接口 应可访问。
  - [prisma] ORF 数据库 应为 可连接。
  - [api] Ory/Kratos Admin/Public API 应为 可访问。
  - [api] Ory/Kratos 中 应存在 邮箱为 `orf-member-e2e@orf.local` 的普通成员测试身份。
  - [prisma] 应存在 邮箱为 `orf-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户。
  - [prisma] 应存在 一个可构造为实施阶段成员不可提出指标起点的目标。
  - [prisma] 应不存在 标题为 `E2E-FROZEN-PROPOSE: 实施阶段成员不可提出指标` 的测试指标。
  - [api] 当前会话 应为 未登录。
  - [playwright] 浏览器 应不存在 登录 cookie。
  - [playwright] 浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [playwright] 清空 浏览器状态。
  - [prisma] 选择 一个可构造为实施阶段成员不可提出指标起点的目标。
  - [prisma] 记录 目标 的原始状态。
  - [prisma] 设置 目标 flowStatus 为 `frozen`。
  - [prisma] 设置 目标 stage 为 `goalFrozen`。
  - [prisma] 设置 目标 挑战者列表包含普通成员。
  - [playwright] 打开 登录页。
  - [playwright] 在 Email 输入框 输入 普通成员邮箱。
  - [playwright] 在 Password 输入框 输入 普通成员密码。
  - [playwright] 点击 `Sign In` 登录操作。
  - [api] 当前会话 应为 普通成员已登录。
  - [playwright] 打开 挑战工作台。

- S0：Action 前状态。
  - [api] 当前会话 应为 邮箱 `orf-member-e2e@orf.local` 的普通成员已登录。
  - [playwright] 当前页面 应为 挑战工作台。
  - [playwright] 目标 面板 应可见。
  - [playwright] 目标 的 `提出指标` 操作 应不存在。
  - [prisma] 目标 flowStatus 应为 `frozen`。
  - [prisma] 目标 stage 应为 `goalFrozen`。
  - [prisma] 目标 的挑战者列表 应包含 普通成员。
  - [prisma] 目标 应不存在 标题为测试指标标题的指标。

- Action：被测业务动作。
  - [api] 普通成员直接提交 新增成员建议指标请求。
  - [api] 记录 新增成员建议指标接口响应。

- S1：Action 后状态。
  - [api] 新增成员建议指标接口响应 应被拒绝。
  - [api] 新增成员建议指标接口响应状态码 应为 `403`。
  - [prisma] 目标 应仍不存在 标题为测试指标标题的指标。
  - [playwright] 目标面板 应仍不显示 测试指标标题。
  - [api] 当前会话 应仍为 普通成员已登录。

- Clean：恢复 B。
  - [prisma] 删除 同标题测试指标。
  - [prisma] 恢复 目标 在 Setup 前记录的原始状态。
  - [api] 退出 当前登录态。
  - [playwright] 清空 浏览器状态。
  - [api] Ory/Kratos 中 应仍存在 普通成员测试身份。
  - [prisma] 应仍存在 邮箱为 `orf-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户。
