# 管理员冻结目标进入实施阶段-普通成员不可冻结目标

## 1. 测试目标

验证：当前普通成员是本用例四个阶段目标的挑战者时，可以在挑战工作台看到这些目标，但前端不提供 "冻结" 操作；页面、接口数据和数据库都保持目标原有流转状态。

边界：

- 覆盖对象：普通成员不可冻结任意阶段目标。
- 不覆盖对象：管理员冻结评估阶段目标、管理员冻结评估阶段之外目标、目标缺少指标时不可冻结、已冻结目标重新重估、冻结后指标不可新增、冻结后提交战利品、验收、结算。
- 依赖对象：[管理员冻结目标进入实施阶段](管理员冻结目标进入实施阶段.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体普通成员账号、目标或指标。
- Setup 产物：邮箱为 `orf-member-freeze-forbidden-e2e@orf.local` 的普通成员身份、用户和 member 成员关系；四个本用例独占目标：标题为 `E2E-FREEZE-MEMBER-FORBIDDEN: 目标设定阶段`、流转状态为 `candidate`、阶段为 `goalSetting` 的目标，标题为 `E2E-FREEZE-MEMBER-FORBIDDEN: 结果申领阶段`、流转状态为 `open`、阶段为 `resultClaiming` 的目标，标题为 `E2E-FREEZE-MEMBER-FORBIDDEN: 评估阶段`、流转状态为 `reestimating`、阶段为 `orfReestimate` 的目标，标题为 `E2E-FREEZE-MEMBER-FORBIDDEN: 实施阶段`、流转状态为 `frozen`、阶段为 `goalFrozen` 的目标；四个目标的挑战者均包含该普通成员；标题为 `E2E-FREEZE-MEMBER-FORBIDDEN: 评估阶段冻结前置指标` 的评估阶段冻结前置指标；普通成员已登录会话。
- Action 产物：普通成员进入挑战工作台后的页面状态。
- Clean 产物：删除本用例评估阶段冻结前置指标、四个阶段目标及其派生数据，删除本用例独占普通成员身份、用户、成员关系与 session。
- 原状态恢复：目标和指标均为当前用例独占资源，Clean 直接删除，不恢复任何共享目标状态。
