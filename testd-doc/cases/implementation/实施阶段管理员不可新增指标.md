# 实施阶段管理员不可新增指标

## 1. 测试目标

验证：目标进入实施阶段后，管理员也不能再新增管理员定义指标；提交请求应被阶段锁拒绝，接口、数据库和页面都不产生新增指标。

边界：

- 本用例只验证实施阶段管理员不可新增指标，不验证评估阶段管理员可新增指标、成员提出指标、指标编辑、指标删除、战利品提交或验收。
- 本用例使用预置管理员账号 `zrx831@gmail.com`，角色为 `admin`，状态为 `active`。
- Setup 记录并改造一个运行时目标，使目标位于 Action 起点：目标为 `frozen`，stage 为 `goalFrozen`。
- 本用例尝试创建固定标题的测试指标，Clean 会删除同标题指标并恢复目标在 Setup 前的原始状态。

## 2. 状态模型

- B：测试开始前和 Clean 后都必须满足的基准状态。
  - [api] 前端和后端服务 应为 可用。
  - [api] 健康检查或等价探测 应为 通过。
  - [prisma] ORF 数据库 应为 可连接。
  - [api] Ory/Kratos Admin/Public API 应为 可访问。
  - [api] Ory/Kratos 中 应存在 邮箱为 `zrx831@gmail.com` 的管理员测试身份。
  - [prisma] 应存在 邮箱为 `zrx831@gmail.com`、角色为 `admin`、状态为 `active` 的管理员用户。
  - [prisma] 应存在 一个可构造为实施阶段管理员不可新增指标起点的目标。
  - [prisma] 应不存在 标题为 `E2E-FROZEN-ADMIN-CREATE: 实施阶段管理员不可新增指标` 的测试指标。
  - [api] 当前会话 应为 未登录。
  - [playwright] 浏览器 应不存在 登录 cookie。
  - [playwright] 浏览器 storage 应不包含 登录态。

- Setup：如何从 B 构造 S0？
  - [playwright] 清空 浏览器状态。
  - [prisma] 选择 一个可构造为实施阶段管理员不可新增指标起点的目标。
  - [prisma] 记录 目标 的原始状态。
  - [prisma] 设置 目标 flowStatus 为 `frozen`。
  - [prisma] 设置 目标 stage 为 `goalFrozen`。
  - [playwright] 打开 `/auth` 登录页。
  - [playwright] 在 Email 输入框 输入 管理员邮箱。
  - [playwright] 在 Password 输入框 输入 管理员密码。
  - [playwright] 点击 `Sign In` 登录操作。
  - [api] 当前会话 应为 管理员已登录。
  - [playwright] 打开 `/tasks` 挑战工作台。
  - [playwright] 点击 `所有挑战` 视图切换操作。

- S0：Action 前必须满足什么条件？
  - [api] 当前会话 应为 邮箱 `zrx831@gmail.com` 的管理员已登录。
  - [playwright] 当前页面 应为 挑战工作台。
  - [playwright] 目标 面板 应可见。
  - [playwright] 目标 的 `新增指标` 操作 应不存在。
  - [prisma] 目标 flowStatus 应为 `frozen`。
  - [prisma] 目标 stage 应为 `goalFrozen`。
  - [prisma] 目标 应不存在 标题为测试指标标题的指标。

- Action：本次测试唯一要验证的业务动作是什么？
  - [api] 管理员直接提交 新增管理员定义指标请求。
  - [api] 记录 新增管理员定义指标接口响应。

- S1：Action 后系统应该变成什么状态？
  - [api] 新增管理员定义指标接口响应 应被拒绝。
  - [api] 新增管理员定义指标接口响应状态码 应为 `409`。
  - [prisma] 目标 仍应不存在 标题为测试指标标题的指标。
  - [playwright] 目标 面板 仍应不显示 测试指标标题。
  - [api] 当前会话 应仍为 管理员已登录。

- Clean：如何清理并恢复到 B？
  - [prisma] 删除 同标题测试指标。
  - [prisma] 恢复 目标 在 Setup 前记录的原始状态。
  - [api] 退出 当前登录态。
  - [playwright] 清空 浏览器状态。
  - [api] Ory/Kratos 中 应仍存在 管理员测试身份。
  - [prisma] 应仍存在 邮箱为 `zrx831@gmail.com`、角色为 `admin`、状态为 `active` 的管理员用户。
