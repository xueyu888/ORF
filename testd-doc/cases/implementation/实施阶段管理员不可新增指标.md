# 实施阶段管理员不可新增指标

## 1. 测试目标

验证：由当前用例独占准备的目标进入实施阶段后，当前用例独占管理员不能再新增管理员定义指标；越权提交不会产生新指标。

边界：

- 覆盖对象：实施阶段管理员不可新增指标。
- 不覆盖对象：评估阶段管理员可新增指标、成员提出指标、指标编辑、指标删除、战利品提交、验收。
- 原 legacy B 依赖：预置管理员账号 `zrx831@gmail.com`，以及默认团队中任意可改造为实施阶段管理员不可新增指标起点的共享目标。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体管理员账号、目标或指标。
- Setup 产物：邮箱为 "orf-admin-frozen-create-result-e2e@orf.local" 的管理员身份、用户和 admin 成员关系；标题为 "E2E-FROZEN-ADMIN-CREATE: 目标前置"、`flowStatus` 为 `frozen`、阶段为 `goalFrozen` 的本用例冻结目标；运行时记录的 `runtime.frozenAdminResultTarget`。
- Action 产物：管理员对本用例冻结目标直接提交管理员定义指标请求，接口返回阶段锁拒绝响应。
- Clean 产物：删除同标题测试指标、目标及其派生数据，删除本用例独占管理员身份、用户、成员关系与 session。
- 原状态恢复：目标和指标均为当前用例独占资源，Clean 直接删除，不恢复任何共享目标状态。
