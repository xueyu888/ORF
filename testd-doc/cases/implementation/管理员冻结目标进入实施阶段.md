# 管理员冻结目标进入实施阶段

## 1. 测试目标

验证：管理员可以将一个重估中的目标冻结，使目标进入实施阶段；冻结后，目标状态在接口、数据库和页面中都显示为已冻结。

边界：

- 本用例只验证管理员冻结目标，不验证普通成员不可冻结、冻结后指标不可新增、冻结后成员提交战利品、验收或结算。
- 本用例使用预置管理员账号 `zrx831@gmail.com`，角色为 `admin`，状态为 `active`。
- Setup 记录并改造一个运行时目标，使目标位于 Action 起点：目标为 `reestimating`，且至少存在一个指标。
- 本用例创建固定标题的冻结前置指标，Clean 删除该指标，并恢复目标在 Setup 前的原始状态。

## 2. 状态模型

- B：测试开始前和 Clean 后都必须满足的基准状态。
  - [api] 前端和后端服务 应为 可用。
  - [api] 健康检查或等价探测 应为 通过。
  - [prisma] ORF 数据库 应为 可连接。
  - [api] Ory/Kratos Admin/Public API 应为 可访问。
  - [api] Ory/Kratos 中 应存在 邮箱为 `zrx831@gmail.com` 的管理员测试身份。
  - [prisma] 应存在 邮箱为 `zrx831@gmail.com`、角色为 `admin`、状态为 `active` 的管理员用户。
  - [prisma] 应存在 一个可构造成管理员冻结起点的目标。
  - [prisma] 应不存在 标题为 `E2E-FREEZE-RESULT: 冻结前置指标` 的测试指标。
  - [api] 当前会话 应为 未登录。
  - [playwright] 浏览器 应不存在 登录 cookie。
  - [playwright] 浏览器 storage 应不包含 登录态。

- Setup：如何从 B 构造 S0？
  - [playwright] 清空 浏览器状态。
  - [prisma] 选择 一个可构造成管理员冻结起点的目标。
  - [prisma] 记录 目标 的原始状态。
  - [prisma] 设置 目标 flowStatus 为 `reestimating`。
  - [prisma] 为 目标 创建 标题为 `E2E-FREEZE-RESULT: 冻结前置指标` 的指标。
  - [playwright] 打开 `/auth` 登录页。
  - [playwright] 在 Email 输入框 输入 管理员邮箱。
  - [playwright] 在 Password 输入框 输入 管理员密码。
  - [playwright] 点击 `Sign In` 登录操作。
  - [api] 当前会话 应为 管理员已登录。
  - [playwright] 打开 `/tasks` 挑战工作台。
  - [playwright] 点击 `所有挑战` 视图切换操作。

- S0：Action 前必须满足什么条件？
  - [api] 当前会话 应为 邮箱 `zrx831@gmail.com` 的管理员已登录。
  - [playwright] 当前页面 应为 挑战工作台。
  - [playwright] 目标 面板 应可见。
  - [playwright] 目标 的 `冻结` 操作 应可点击。
  - [prisma] 目标 flowStatus 应为 `reestimating`。
  - [prisma] 目标 应存在 冻结前置指标。

- Action：本次测试唯一要验证的业务动作是什么？
  - [playwright] 在点击 `冻结` 前注册 冻结目标接口响应捕获。
  - [playwright] 点击 目标 的 `冻结` 操作。
  - [api] 记录 冻结目标接口返回的目标。

- S1：Action 后系统应该变成什么状态？
  - [api] 冻结目标接口响应 应成功。
  - [api] 冻结目标接口返回的目标 flowStatus 应为 `frozen`。
  - [api] 冻结目标接口返回的目标 stage 应为 `goalFrozen`。
  - [prisma] 目标 flowStatus 应为 `frozen`。
  - [prisma] 目标 stage 应为 `goalFrozen`。
  - [prisma] 目标 confirmedAt 应存在。
  - [playwright] 目标 面板 应显示 `已冻结`。
  - [api] 当前会话 应仍为 管理员已登录。

- Clean：如何清理并恢复到 B？
  - [prisma] 删除 本用例创建的冻结前置指标。
  - [prisma] 恢复 目标 在 Setup 前记录的原始状态。
  - [api] 退出 当前登录态。
  - [playwright] 清空 浏览器状态。
  - [api] Ory/Kratos 中 应仍存在 管理员测试身份。
  - [prisma] 应仍存在 邮箱为 `zrx831@gmail.com`、角色为 `admin`、状态为 `active` 的管理员用户。
