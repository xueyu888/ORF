# 管理员冻结目标进入实施阶段

## 1. 测试目标

验证：由当前用例独占准备的管理员可以将当前用例独占的重估目标冻结，使目标进入实施阶段；冻结后，接口、数据库和页面都显示目标已冻结。

边界：

- 覆盖对象：管理员冻结目标。
- 不覆盖对象：普通成员不可冻结、冻结后指标不可新增、冻结后成员提交战利品、验收、结算。
- 原 legacy B 依赖：预置管理员账号 `zrx831@gmail.com`，以及默认团队中任意可改造为管理员冻结起点的共享目标。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体管理员账号、目标或指标。
- Setup 产物：邮箱为 "orf-admin-freeze-objective-e2e@orf.local" 的管理员身份、用户和 admin 成员关系；标题为 "E2E-ADMIN-FREEZE-OBJECTIVE: 目标前置"、`flowStatus` 为 `reestimating`、阶段为 `orfReestimate` 的本用例目标；标题为 "E2E-FREEZE-RESULT: 冻结前置指标" 的冻结前置指标；运行时记录的 `runtime.freezeTarget` 和 `runtime.freezeResult`。
- Action 产物：本用例目标被 PATCH `/api/objectives/:objectiveId/freeze` 冻结。
- Clean 产物：删除本用例冻结前置指标、目标及其派生数据，删除本用例独占管理员身份、用户、成员关系与 session。
- 原状态恢复：目标和指标均为当前用例独占资源，Clean 直接删除，不恢复任何共享目标状态。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询接口 应可访问。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos Admin/Public API 应可访问。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory session cookie。
  - [B-10] [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例冻结前置指标。
  - [Setup-2] [prisma] 删除可能残留的本用例目标及其派生数据。
  - [Setup-3] [api] 准备邮箱为 "orf-admin-freeze-objective-e2e@orf.local" 的管理员登录身份，并设置固定测试密码。

  - [Setup-5] [prisma] 创建标题为 "E2E-ADMIN-FREEZE-OBJECTIVE: 目标前置"、流转状态为 reestimating、阶段为 orfReestimate 的本用例冻结目标。
  - [Setup-6] [prisma] 记录本用例冻结目标为 runtime.freezeTarget。
  - [Setup-7] [prisma] 清空本用例冻结目标的已确认时间并保持重估状态。
  - [Setup-8] [prisma] 为本用例冻结目标创建标题为 "E2E-FREEZE-RESULT: 冻结前置指标" 的冻结前置指标。
  - [Setup-9] [api] 撤销管理员登录身份可能残留的 Ory session。
  - [Setup-10] [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [Setup-11] [playwright] 打开 登录页。
  - [Setup-12] [playwright] 在邮箱输入框输入管理员测试邮箱。
  - [Setup-13] [playwright] 在密码输入框输入管理员测试密码。
  - [Setup-14] [playwright] 点击 "Sign In" 登录操作。

  - [Setup-16] [playwright] 打开 挑战工作台。
  - [Setup-17] [playwright] 切换到 "所有挑战" 视图。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 "orf-admin-freeze-objective-e2e@orf.local"、角色为 admin、状态为 active 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 挑战工作台。
  - [S0-3] [playwright] 本用例冻结目标面板 应可见。
