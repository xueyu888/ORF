# 反馈新建与详情进入

## 1. 测试目标

验证：已登录且状态为 `active` 的用户在反馈页面点击新建反馈操作后，可以进入新建反馈页面；点击反馈列表中的指定反馈 issue 后，可以进入该反馈 issue 对应的详情页面。

边界：

- 覆盖对象：反馈页面的新建反馈入口和反馈列表项进入详情页入口。
- 不覆盖对象：填写或提交新建反馈表单、反馈详情编辑、反馈状态变更、反馈评论、搜索和筛选。
- B 基准：仅要求前端、后端、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何具体用户或反馈 issue。
- Setup 产物：邮箱为 `orf-feedback-entry-e2e@orf.local` 的管理员认证身份、用户和默认团队成员关系；现象为 `ORF反馈入口E2E-详情目标` 的独占 Open 反馈 issue 及其技术问题分类记录。
- Action 产物：点击新建反馈操作后的新建反馈页面运行时快照，以及点击指定反馈 issue 后的反馈详情页面运行时快照。
- Clean 产物：删除本用例独占反馈 issue、认证身份、用户和成员关系，并清空当前浏览器登录态。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除现象为 `ORF反馈入口E2E-详情目标` 的残留反馈 issue 及其分类记录。
  - [Setup-2] [api] 准备邮箱为 `orf-feedback-entry-e2e@orf.local`、使用固定测试密码的反馈入口测试认证身份。
  - [Setup-3] [prisma] 准备邮箱为 `orf-feedback-entry-e2e@orf.local`、姓名为 `ORF Feedback Entry E2E`、角色为 `admin`、状态为 `active` 的反馈入口测试用户和默认团队成员关系。
  - [Setup-4] [prisma] 准备现象为 `ORF反馈入口E2E-详情目标`、状态为 `Open`、分类为 `技术问题` 且处理人为反馈入口测试用户的独占反馈 issue。
  - [Setup-5] [api] 撤销邮箱为 `orf-feedback-entry-e2e@orf.local` 的反馈入口测试认证身份的残留登录会话。
  - [Setup-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-7] [playwright] 打开 ORF 登录页。
  - [Setup-8] [playwright] 在邮箱输入框输入 `orf-feedback-entry-e2e@orf.local`。
  - [Setup-9] [playwright] 在密码输入框输入反馈入口测试固定密码。
  - [Setup-10] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-11] [api] 当前会话 应为 邮箱为 `orf-feedback-entry-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [Setup-12] [playwright] 打开 反馈页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-feedback-entry-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 反馈页面。
  - [S0-3] [playwright] 反馈页面的新建反馈操作 应可见。
  - [S0-4] [playwright] 反馈页面的新建反馈操作 应可点击。
  - [S0-5] [playwright] 反馈页面的列表 应显示现象为 `ORF反馈入口E2E-详情目标` 的独占反馈 issue。
  - [S0-6] [playwright] 现象为 `ORF反馈入口E2E-详情目标` 的独占反馈 issue 在反馈页面的列表中 应可点击。
  - [S0-7] [prisma] 现象为 `ORF反馈入口E2E-详情目标`、状态为 `Open`、分类为 `技术问题` 的独占反馈 issue 及其分类记录 应存在。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击 反馈页面的新建反馈操作。
  - [Action-2] [playwright] 记录点击新建反馈操作后的页面状态。
  - [Action-3] [playwright] 打开 反馈页面。
  - [Action-4] [playwright] 点击反馈页面列表中现象为 `ORF反馈入口E2E-详情目标` 的独占反馈 issue。
  - [Action-5] [playwright] 记录点击独占反馈 issue 后的页面状态。

- S1：Action 后状态。
  - [S1-1] [playwright] 点击新建反馈操作后，当前页面 应为 新建反馈页面。
  - [S1-2] [playwright] 点击新建反馈操作后，新建反馈表单 应可见。
  - [S1-3] [playwright] 点击新建反馈操作后，新建反馈表单的标题输入框 应可见。
  - [S1-4] [playwright] 点击新建反馈操作后，新建反馈表单的反馈正文输入区域 应可见。
  - [S1-5] [playwright] 点击独占反馈 issue 后，当前页面 应为现象为 `ORF反馈入口E2E-详情目标` 的反馈详情页面。
  - [S1-6] [playwright] 点击独占反馈 issue 后，反馈详情页面 应显示 `ORF反馈入口E2E-详情目标`。
  - [S1-7] [playwright] 点击独占反馈 issue 后，反馈详情页面 应显示状态为 `Open`。
  - [S1-8] [playwright] 点击独占反馈 issue 后，反馈详情页面 应显示分类为 `技术问题`。
  - [S1-9] [api] 当前会话 应仍为 邮箱为 `orf-feedback-entry-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。

- Clean：恢复 B。
  - [Clean-1] [api] 注销当前登录会话。
  - [Clean-2] [playwright] 离开当前 ORF 前端页面。
  - [Clean-3] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-4] [prisma] 删除现象为 `ORF反馈入口E2E-详情目标` 的本用例反馈 issue 及其分类记录。
  - [Clean-5] [api] 撤销邮箱为 `orf-feedback-entry-e2e@orf.local` 的反馈入口测试认证身份的残留登录会话。
  - [Clean-6] [api] 删除邮箱为 `orf-feedback-entry-e2e@orf.local` 的反馈入口测试认证身份。
  - [Clean-7] [prisma] 删除邮箱为 `orf-feedback-entry-e2e@orf.local` 的反馈入口测试用户的默认团队成员关系。
  - [Clean-8] [prisma] 删除邮箱为 `orf-feedback-entry-e2e@orf.local` 的反馈入口测试用户。
  - [Clean-9] [prisma] 现象为 `ORF反馈入口E2E-详情目标` 的本用例反馈 issue 及其分类记录 应不存在。
  - [Clean-10] [api] 邮箱为 `orf-feedback-entry-e2e@orf.local` 的反馈入口测试认证身份 应不存在。
  - [Clean-11] [prisma] 邮箱为 `orf-feedback-entry-e2e@orf.local` 的反馈入口测试用户 应不存在。
