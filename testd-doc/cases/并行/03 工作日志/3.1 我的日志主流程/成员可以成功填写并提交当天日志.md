# 成员可以成功填写并提交当天日志

## 1. 测试目标

验证：角色为 `member` 的成员作为目标当前挑战者时，可在工作日志页面的当天日志视图选择参与目标、填写目标进度估计、记录时间和日志正文，并成功提交当天日志；提交后当天记录、接口数据和数据库数据均包含本次提交的日志。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的工作日志正文标记 `E2E-WORK-LOG-TODAY-BODY` 对应的工作日志。
  - [Setup-2] [prisma] 删除 本用例残留的目标 `E2E-TARGET-WORK-LOG-TODAY` 及其派生数据。
  - [Setup-3] [api] 准备邮箱为 `orf-member-submit-today-work-log-e2e@orf.local`、使用固定测试密码的成员登录身份。
  - [Setup-4] [prisma] 准备 角色为 `member`、状态为 `active`、名称为 `ORF Member Submit Today Work Log E2E` 的本用例成员用户。
  - [Setup-5] [prisma] 准备 标题为 `E2E-TARGET-WORK-LOG-TODAY`、当前挑战者包含本用例成员、可填写工作日志的目标。
  - [Setup-6] [playwright] 使用 本用例成员账号 登录 ORF。
  - [Setup-7] [playwright] 打开 工作日志页面的当天日志视图。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-member-submit-today-work-log-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `member`。
  - [S0-4] [api] 当前会话用户名称 应为 `ORF Member Submit Today Work Log E2E`。
  - [S0-5] [api] 工作日志可选目标 应包含目标 `E2E-TARGET-WORK-LOG-TODAY`。
  - [S0-6] [api] 当天工作日志数据 应不包含正文标记 `E2E-WORK-LOG-TODAY-BODY`。
  - [S0-7] [prisma] 应不存在 本用例成员在测试执行当天提交的正文标记为 `E2E-WORK-LOG-TODAY-BODY` 的工作日志。
  - [S0-8] [playwright] 页面 应进入 工作日志。
  - [S0-9] [playwright] "日志" 视图 应处于选中状态。
  - [S0-10] [playwright] "我的日志" 面板 应可见。
  - [S0-11] [playwright] "日志归类" 控件 应可见。
  - [S0-12] [playwright] "提交日志" 操作 应不可点击。
  - [S0-13] [api] 工作日志可选目标中的目标 `E2E-TARGET-WORK-LOG-TODAY` 对当前成员 应为 当前挑战者。

- Action：被测业务动作。
  - [Action-1] [playwright] 在 "日志归类" 控件中选择目标 `E2E-TARGET-WORK-LOG-TODAY`。
  - [Action-2] [playwright] 在 "目标进度估计百分比" 输入框输入 `40`。
  - [Action-3] [playwright] 在 "记录时间分钟数" 输入框输入 `90`。
  - [Action-4] [playwright] 在工作日志正文编辑器输入 `E2E-WORK-LOG-TODAY-BODY：完成当天目标推进并同步风险。`。
  - [Action-5] [playwright] 点击 "提交日志" 操作。

- S1：Action 后状态。
  - [S1-1] [playwright] 页面 应提示 `工作日志已提交`。
  - [S1-2] [playwright] "当天记录" 区域 应显示日志正文 `E2E-WORK-LOG-TODAY-BODY：完成当天目标推进并同步风险。`。
  - [S1-3] [playwright] "当天记录" 区域 应显示目标 `E2E-TARGET-WORK-LOG-TODAY`。
  - [S1-4] [playwright] "当天记录" 区域 应显示记录时间 `1h 30m`。
  - [S1-5] [playwright] "当天记录" 区域 应显示目标进度 `进 40%`。
  - [S1-6] [api] 当天工作日志数据 应包含正文为 `E2E-WORK-LOG-TODAY-BODY：完成当天目标推进并同步风险。` 的工作日志。
  - [S1-7] [api] 当天工作日志数据中的本用例工作日志目标标题快照 应为 `E2E-TARGET-WORK-LOG-TODAY`。
  - [S1-8] [api] 当天工作日志数据中的本用例工作日志记录时间分钟数 应为 `90`。
  - [S1-9] [api] 当天工作日志数据中的本用例工作日志剩余进度估计百分比 应为 `60`。
  - [S1-10] [prisma] 应存在 本用例成员在测试执行当天提交的正文标记为 `E2E-WORK-LOG-TODAY-BODY` 的工作日志。
  - [S1-11] [prisma] 本用例工作日志的目标标题快照 应为 `E2E-TARGET-WORK-LOG-TODAY`。
  - [S1-12] [prisma] 本用例工作日志的记录时间分钟数 应为 `90`。
  - [S1-13] [prisma] 本用例工作日志的剩余进度估计百分比 应为 `60`。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的工作日志正文标记 `E2E-WORK-LOG-TODAY-BODY` 对应的工作日志。
  - [Clean-2] [prisma] 删除 本用例创建的目标 `E2E-TARGET-WORK-LOG-TODAY` 及其派生数据。
  - [Clean-3] [api] 注销当前成员登录会话。
  - [Clean-4] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-5] [api] 删除 本用例成员登录身份。
  - [Clean-6] [prisma] 删除 本用例成员用户。
  - [Clean-7] [prisma] 应不存在 正文标记为 `E2E-WORK-LOG-TODAY-BODY` 的工作日志。
  - [Clean-8] [prisma] 应不存在 标题为 `E2E-TARGET-WORK-LOG-TODAY` 的目标。
  - [Clean-9] [api] 邮箱为 `orf-member-submit-today-work-log-e2e@orf.local` 的成员登录身份 应不存在。
  - [Clean-10] [prisma] 邮箱为 `orf-member-submit-today-work-log-e2e@orf.local` 的成员用户 应不存在。
  - [Clean-11] [api] 当前会话 应为 未登录。
