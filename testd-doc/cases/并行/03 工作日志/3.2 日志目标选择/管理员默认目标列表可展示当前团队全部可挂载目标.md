# 管理员默认目标列表可展示当前团队全部可挂载目标

## 1. 测试目标

验证：角色为 `admin` 的管理员进入工作日志页面后，"日志归类" 控件的目标默认列表展示当前团队内全部可挂载目标；目标默认列表不按当前挑战者过滤，也包含已验收、已结算和已关闭目标；接口数据与页面展示一致。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的目标标题前缀 `E2E-TWL-ADMIN-ALL` 对应的目标及其派生数据。
  - [Setup-2] [api] 准备邮箱为 `orf-admin-default-work-log-objective-list-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-3] [prisma] 准备 角色为 `admin`、状态为 `active`、名称为 `ORF Admin Default Work Log Objective List E2E` 的本用例管理员用户。
  - [Setup-4] [prisma] 准备 角色为 `member`、状态为 `active`、名称为 `ORF Other Admin Default Work Log Objective List E2E`、与本用例管理员属于同一团队的本用例其他成员用户。
  - [Setup-5] [prisma] 准备 标题为 `E2E-TWL-ADMIN-ALL-OTHER-OPEN`、属于本用例管理员团队、当前挑战者包含本用例其他成员且不包含本用例管理员、流转状态为 `open` 的未完成目标。
  - [Setup-6] [prisma] 准备 标题为 `E2E-TWL-ADMIN-ALL-OWN-FROZEN`、属于本用例管理员团队、当前挑战者包含本用例管理员、流转状态为 `frozen` 的已冻结目标。
  - [Setup-7] [prisma] 准备 标题为 `E2E-TWL-ADMIN-ALL-ACCEPTED`、属于本用例管理员团队、当前挑战者包含本用例其他成员且不包含本用例管理员、流转状态为 `accepted` 的已验收目标。
  - [Setup-8] [prisma] 准备 标题为 `E2E-TWL-ADMIN-ALL-SETTLED`、属于本用例管理员团队、当前挑战者包含本用例管理员、流转状态为 `settled` 的已结算目标。
  - [Setup-9] [prisma] 准备 标题为 `E2E-TWL-ADMIN-ALL-CLOSED`、属于本用例管理员团队、当前挑战者包含本用例其他成员且不包含本用例管理员、流转状态为 `closed` 的已关闭目标。
  - [Setup-10] [playwright] 使用 本用例管理员账号 登录 ORF。
  - [Setup-11] [playwright] 打开 工作日志页面的当天日志视图。
