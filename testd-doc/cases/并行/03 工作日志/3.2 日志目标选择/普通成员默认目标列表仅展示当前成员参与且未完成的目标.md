# 普通成员默认目标列表仅展示当前成员参与且未完成的目标

## 1. 测试目标

验证：角色为 `member` 的普通成员进入工作日志页面后，"日志归类" 控件的目标默认列表仅展示当前成员已参与且未完成的目标；当前成员未参与的未完成目标、当前成员已参与但已完成的目标均不出现在目标默认列表中。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的目标标题前缀 `E2E-TARGET-WORK-LOG-DEFAULT-LIST` 对应的目标及其派生数据。
  - [Setup-2] [api] 准备邮箱为 `orf-member-work-log-default-objective-list-e2e@orf.local`、使用固定测试密码的成员登录身份。
  - [Setup-3] [prisma] 准备 角色为 `member`、状态为 `active`、名称为 `ORF Member Work Log Default Objective List E2E` 的本用例成员用户。
  - [Setup-4] [prisma] 准备 角色为 `member`、状态为 `active`、名称为 `ORF Other Work Log Default Objective List E2E`、与本用例成员属于同一团队的本用例其他成员用户。
  - [Setup-5] [prisma] 准备 标题为 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-PARTICIPATED-OPEN`、属于本用例成员团队、当前挑战者包含本用例成员、流转状态为 `open` 的未完成目标。
  - [Setup-6] [prisma] 准备 标题为 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-OTHER-OPEN`、属于本用例成员团队、当前挑战者包含本用例其他成员且不包含本用例成员、流转状态为 `open` 的未完成目标。
  - [Setup-7] [prisma] 准备 标题为 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-PARTICIPATED-ACCEPTED`、属于本用例成员团队、当前挑战者包含本用例成员、流转状态为 `accepted` 的已完成目标。
  - [Setup-8] [playwright] 使用 本用例成员账号 登录 ORF。
  - [Setup-9] [playwright] 打开 工作日志页面的当天日志视图。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-member-work-log-default-objective-list-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `member`。
  - [S0-4] [api] 当前会话用户名称 应为 `ORF Member Work Log Default Objective List E2E`。
  - [S0-5] [prisma] 应存在 标题为 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-PARTICIPATED-OPEN`、属于本用例成员团队、当前挑战者包含本用例成员、流转状态为 `open` 的目标。
  - [S0-6] [prisma] 应存在 标题为 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-OTHER-OPEN`、属于本用例成员团队、当前挑战者不包含本用例成员、流转状态为 `open` 的目标。
  - [S0-7] [prisma] 应存在 标题为 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-PARTICIPATED-ACCEPTED`、属于本用例成员团队、当前挑战者包含本用例成员、流转状态为 `accepted` 的目标。
  - [S0-8] [api] 工作日志默认目标列表 应包含目标 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-PARTICIPATED-OPEN`。
  - [S0-9] [api] 工作日志默认目标列表 应不包含目标 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-OTHER-OPEN`。
  - [S0-10] [api] 工作日志默认目标列表 应不包含目标 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-PARTICIPATED-ACCEPTED`。
  - [S0-11] [api] 工作日志默认目标列表中的目标 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-PARTICIPATED-OPEN` 对当前成员 应为 当前挑战者。
  - [S0-12] [api] 工作日志默认目标列表中的目标 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-PARTICIPATED-OPEN` 流转状态 应为 `open`。
  - [S0-13] [playwright] 页面 应进入 工作日志。
  - [S0-14] [playwright] "日志" 视图 应处于选中状态。
  - [S0-15] [playwright] "我的日志" 面板 应可见。
  - [S0-16] [playwright] "日志归类" 控件 应可见。

- Action：被测业务动作。
  - [Action-1] [playwright] 打开 "日志归类" 控件的目标默认列表。

- S1：Action 后状态。
  - [S1-1] [playwright] "日志归类" 控件的目标默认列表 应显示目标 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-PARTICIPATED-OPEN`。
  - [S1-2] [playwright] "日志归类" 控件的目标默认列表 应不显示目标 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-OTHER-OPEN`。
  - [S1-3] [playwright] "日志归类" 控件的目标默认列表 应不显示目标 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-PARTICIPATED-ACCEPTED`。
  - [S1-4] [api] 工作日志默认目标列表 应包含且仅包含标题前缀为 `E2E-TARGET-WORK-LOG-DEFAULT-LIST` 的目标 `E2E-TARGET-WORK-LOG-DEFAULT-LIST-PARTICIPATED-OPEN`。
  - [S1-5] [playwright] 页面 应不显示 错误提示。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的目标标题前缀 `E2E-TARGET-WORK-LOG-DEFAULT-LIST` 对应的目标及其派生数据。
  - [Clean-2] [api] 注销当前成员登录会话。
  - [Clean-3] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-4] [api] 删除 本用例成员登录身份。
  - [Clean-5] [prisma] 删除 本用例成员用户。
  - [Clean-6] [prisma] 删除 本用例其他成员用户。
  - [Clean-7] [prisma] 应不存在 标题前缀为 `E2E-TARGET-WORK-LOG-DEFAULT-LIST` 的目标。
  - [Clean-8] [api] 邮箱为 `orf-member-work-log-default-objective-list-e2e@orf.local` 的成员登录身份 应不存在。
  - [Clean-9] [prisma] 邮箱为 `orf-member-work-log-default-objective-list-e2e@orf.local` 的成员用户 应不存在。
  - [Clean-10] [prisma] 名称为 `ORF Other Work Log Default Objective List E2E` 的本用例其他成员用户 应不存在。
  - [Clean-11] [api] 当前会话 应为 未登录。
