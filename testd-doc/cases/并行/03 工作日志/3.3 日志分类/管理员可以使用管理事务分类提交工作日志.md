# 管理员可以使用管理事务分类提交工作日志

## 1. 测试目标

验证：角色为 `admin`、状态为 `active` 的管理员进入工作日志页面后，可以在 "日志归类" 控件中搜索并选择同团队已经存在的管理事务分类 `管理事务`，不选择目标、不填写目标进度估计，只填写记录时间和日志正文即可提交当天工作日志；提交后的页面记录、接口数据和数据库数据均显示本次日志归类为 `管理事务`，且目标快照与剩余进度估计为空。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的工作日志正文标记 `E2E-WORK-LOG-ADMIN-MANAGEMENT-CATEGORY-BODY` 对应的工作日志。
  - [Setup-2] [api] 准备邮箱为 `orf-admin-use-management-category-work-log-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-3] [prisma] 准备 角色为 `admin`、状态为 `active`、名称为 `ORF Admin Use Management Category Work Log E2E` 的本用例管理员用户。
  - [Setup-4] [prisma] 准备 名称为 `管理事务`、属于本用例管理员团队、由本用例管理员创建的工作日志管理分类。
  - [Setup-5] [playwright] 使用 本用例管理员账号 登录 ORF。
  - [Setup-6] [playwright] 打开 工作日志页面的当天日志视图。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-admin-use-management-category-work-log-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `admin`。
  - [S0-4] [api] 当前会话用户状态 应为 `active`。
  - [S0-5] [api] 当前会话用户名称 应为 `ORF Admin Use Management Category Work Log E2E`。
  - [S0-6] [prisma] 应存在 名称为 `管理事务`、属于本用例管理员团队的工作日志管理分类。
  - [S0-7] [api] 工作日志可选分类 应包含管理分类 `管理事务`。
  - [S0-8] [api] 工作日志可选分类中的分类 `管理事务` 的来源 应为 `managed`。
  - [S0-9] [api] 当天工作日志数据 应不包含正文标记 `E2E-WORK-LOG-ADMIN-MANAGEMENT-CATEGORY-BODY`。
  - [S0-10] [prisma] 应不存在 本用例管理员在测试执行当天提交的正文标记为 `E2E-WORK-LOG-ADMIN-MANAGEMENT-CATEGORY-BODY` 的工作日志。
  - [S0-11] [playwright] 页面 应进入 工作日志。
  - [S0-12] [playwright] "日志" 视图 应处于选中状态。
  - [S0-13] [playwright] "我的日志" 面板 应可见。
  - [S0-14] [playwright] "日志归类" 控件 应可见。
  - [S0-15] [playwright] "提交日志" 操作 应不可点击。

- Action：被测业务动作。
  - [Action-1] [playwright] 在 "日志归类" 控件中选择分类 `管理事务`。
  - [Action-2] [playwright] "日志归类" 控件 应显示分类 `管理事务`。
  - [Action-3] [playwright] "目标进度估计百分比" 输入框 应不可用。
  - [Action-4] [playwright] 在 "记录时间分钟数" 输入框输入 `120`。
  - [Action-5] [playwright] 在工作日志正文编辑器输入 `E2E-WORK-LOG-ADMIN-MANAGEMENT-CATEGORY-BODY：管理员处理管理事务，不关联目标和目标进度估计。`。
  - [Action-6] [playwright] 点击 "提交日志" 操作。

- S1：Action 后状态。
  - [S1-1] [playwright] 页面 应提示 `工作日志已提交`。
  - [S1-2] [playwright] "当天记录" 区域 应显示日志正文 `E2E-WORK-LOG-ADMIN-MANAGEMENT-CATEGORY-BODY：管理员处理管理事务，不关联目标和目标进度估计。`。
  - [S1-3] [playwright] "当天记录" 区域 应显示分类 `管理事务`。
  - [S1-4] [playwright] "当天记录" 区域 应显示记录时间 `2h`。
  - [S1-5] [playwright] "当天记录" 区域 应不显示目标进度。
  - [S1-6] [api] 当天工作日志数据 应包含正文为 `E2E-WORK-LOG-ADMIN-MANAGEMENT-CATEGORY-BODY：管理员处理管理事务，不关联目标和目标进度估计。` 的工作日志。
  - [S1-7] [api] 当天工作日志数据中的本用例工作日志分类 ID 快照 应为 本用例工作日志管理分类 ID。
  - [S1-8] [api] 当天工作日志数据中的本用例工作日志分类名称快照 应为 `管理事务`。
  - [S1-9] [api] 当天工作日志数据中的本用例工作日志目标 ID 快照 应为空。
  - [S1-10] [api] 当天工作日志数据中的本用例工作日志目标标题快照 应为空。
  - [S1-11] [api] 当天工作日志数据中的本用例工作日志记录时间分钟数 应为 `120`。
  - [S1-12] [api] 当天工作日志数据中的本用例工作日志剩余进度估计百分比 应为空。
  - [S1-13] [prisma] 应存在 本用例管理员在测试执行当天提交的正文标记为 `E2E-WORK-LOG-ADMIN-MANAGEMENT-CATEGORY-BODY` 的工作日志。
  - [S1-14] [prisma] 本用例工作日志的分类 ID 快照 应为 本用例工作日志管理分类 ID。
  - [S1-15] [prisma] 本用例工作日志的分类名称快照 应为 `管理事务`。
  - [S1-16] [prisma] 本用例工作日志的目标 ID 快照 应为空。
  - [S1-17] [prisma] 本用例工作日志的目标标题快照 应为空。
  - [S1-18] [prisma] 本用例工作日志的记录时间分钟数 应为 `120`。
  - [S1-19] [prisma] 本用例工作日志的剩余进度估计百分比 应为空。
  - [S1-20] [prisma] 名称为 `管理事务` 的工作日志管理分类 应仍属于本用例管理员团队。
