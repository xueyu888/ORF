# 管理员可以删除有聊天成员关系的普通用户

## 1. 测试目标

验证：管理员可以从成员管理页删除具有公共聊天成员关系的普通成员；删除动作同时清理 ORF 用户、团队和聊天成员关系以及 Ory 登录身份，聊天成员移除同步事件不再引用已删除用户。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] Ory 管理服务 应可用。
  - [B-5] [api] 当前会话 应为 未登录。
  - [B-6] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例管理员的残留用户数据。
  - [Setup-2] [prisma] 删除 本用例普通成员的残留用户数据。
  - [Setup-3] [api] 删除 本用例管理员的残留登录身份。
  - [Setup-4] [api] 删除 本用例普通成员的残留登录身份。
  - [Setup-5] [api] 准备 使用固定测试密码的本用例管理员登录身份。
  - [Setup-6] [prisma] 准备 角色为 `admin`、状态为 `active` 的本用例管理员用户。
  - [Setup-7] [api] 准备 使用固定测试密码的本用例普通成员登录身份。
  - [Setup-8] [prisma] 准备 角色为 `member`、状态为 `active` 的本用例普通成员用户。
  - [Setup-9] [playwright] 使用 本用例管理员账号 登录 ORF。
  - [Setup-10] [api] 通过聊天服务准备活跃成员的公共聊天成员关系。
  - [Setup-11] [playwright] 打开 成员管理页。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户角色 应为 `admin`。
  - [S0-3] [prisma] 应存在 本用例普通成员用户。
  - [S0-4] [api] 应存在 本用例普通成员的 Ory 登录身份。
  - [S0-5] [prisma] 应存在 本用例普通成员的活跃公共聊天成员关系。
  - [S0-6] [playwright] 当前页面 应为 成员管理页。
  - [S0-7] [playwright] 成员管理页 应显示 本用例普通成员。
  - [S0-8] [playwright] 本用例普通成员的 "删除用户" 操作 应可见。
  - [S0-9] [playwright] 本用例普通成员的 "删除用户" 操作 应可点击。

- Action：被测业务动作。
  - [Action-1] [playwright] 在成员管理页确认删除 本用例普通成员。
  - [Action-2] [api] 删除用户结果 应成功。

- S1：Action 后状态。
  - [S1-1] [playwright] 成员管理页 应不显示 本用例普通成员。
  - [S1-2] [prisma] 应不存在 本用例普通成员用户。
  - [S1-3] [api] 应不存在 本用例普通成员的 Ory 登录身份。
  - [S1-4] [prisma] 应不存在 本用例普通成员的公共聊天成员关系。
  - [S1-5] [prisma] 应存在 不再引用已删除普通成员的聊天成员移除同步事件。

- Clean：恢复 B。
  - [Clean-1] [api] 注销当前登录会话。
  - [Clean-2] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-3] [api] 删除 本用例普通成员的残留登录身份。
  - [Clean-4] [prisma] 删除 本用例普通成员的残留用户数据和聊天同步事件。
  - [Clean-5] [api] 删除 本用例管理员登录身份。
  - [Clean-6] [prisma] 删除 本用例管理员用户。
