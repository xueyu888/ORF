# 管理员在重估中支持删除行动项

## 1. 测试目标

验证：当前管理员作为本用例目标的正式挑战者，且目标处于挑战工作台“待重估”筛选对应的 `reestimating` 流转状态时，可以删除目标下已有行动项；删除前页面会展示删除确认和受影响范围，删除后页面、接口和数据库都不再保留该行动项及其子行动项。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的重估中测试行动项及其子行动项。
  - [Setup-2] [prisma] 删除 本用例残留的重估中行动项目标及其派生数据。
  - [Setup-3] [api] 准备邮箱为 `orf-admin-delete-task-reestimate-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-4] [prisma] 准备邮箱为 `orf-admin-delete-task-reestimate-e2e@orf.local`、角色为 `admin`、状态为 `active` 的管理员用户和默认团队成员关系。
  - [Setup-5] [prisma] 创建标题为 `E2E-TASK-DELETE-REESTIMATE-ADMIN: 目标前置`、流转状态为 `reestimating`、阶段为 `orfReestimate` 的本用例重估中行动项目标。
  - [Setup-6] [prisma] 记录 本用例重估中行动项目标。
  - [Setup-7] [prisma] 设置本用例重估中行动项目标的挑战者账号身份包含管理员。
  - [Setup-8] [prisma] 创建标题为 `E2E-TASK-DELETE-REESTIMATE-ADMIN: 管理员删除行动项`、执行人为管理员的本用例重估中测试行动项。
  - [Setup-9] [prisma] 创建标签为 `重估中管理员删除行动项子任务`、归属于本用例重估中测试行动项的本用例重估中测试子行动项。
  - [Setup-10] [prisma] 记录 本用例重估中测试行动项和测试子行动项。
  - [Setup-11] [api] 撤销管理员登录身份可能残留的登录会话。
  - [Setup-12] [playwright] 注销当前登录会话。
  - [Setup-13] [playwright] 离开当前 ORF 前端页面。
  - [Setup-14] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-15] [playwright] 打开 ORF 登录页。
  - [Setup-16] [playwright] 在邮箱输入框输入管理员固定测试邮箱。
  - [Setup-17] [playwright] 在密码输入框输入管理员固定测试密码。
  - [Setup-18] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-19] [playwright] 打开 挑战工作台。
  - [Setup-20] [playwright] 切换到 "我的挑战" 视图。
  - [Setup-21] [playwright] 将状态筛选切换到 "待重估"。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
