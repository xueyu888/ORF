# 被征召挑战者成功接受挑战

## 1. 测试目标

验证：管理员已征召挑战者后，被征召挑战者登录悬赏大厅，在 "全部" 视图中看到目标 `E2E-TARGET-ACCEPT-RECRUITED` 的待响应征召状态，点击并确认 "接受挑战" 后，目标进入挑战中，被征召挑战者成为当前挑战者。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的目标 `E2E-TARGET-ACCEPT-RECRUITED` 及其派生数据。
  - [Setup-2] [prisma] 删除 本用例残留的项目 `E2E-PROJECT-ACCEPT-RECRUITED`。
  - [Setup-3] [api] 准备邮箱为 `orf-admin-accept-recruited-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-4] [api] 准备邮箱为 `orf-member-accept-recruited-e2e@orf.local`、使用固定测试密码的被征召挑战者登录身份。
  - [Setup-5] [prisma] 准备 角色为 `admin`、状态为 `active` 的本用例管理员用户。
  - [Setup-6] [prisma] 准备 角色为 `member`、状态为 `active` 的本用例被征召挑战者用户。
  - [Setup-7] [prisma] 准备 本用例项目 `E2E-PROJECT-ACCEPT-RECRUITED`。
  - [Setup-8] [prisma] 准备 属于项目 `E2E-PROJECT-ACCEPT-RECRUITED`、标题为 `E2E-TARGET-ACCEPT-RECRUITED`、已发布且已征召本用例被征召挑战者的目标。
  - [Setup-9] [playwright] 使用 本用例被征召挑战者账号 打开 悬赏大厅的 "全部" 视图。

- S0：Action 前状态。
  - [S0-1] [api] 目标 `E2E-TARGET-ACCEPT-RECRUITED` 对当前被征召挑战者 应允许接受挑战。
  - [S0-2] [playwright] 目标 `E2E-TARGET-ACCEPT-RECRUITED` 在悬赏大厅 "全部" 视图中 应可见。
  - [S0-3] [playwright] 目标 `E2E-TARGET-ACCEPT-RECRUITED` 的参与状态 应显示为 "待响应征召"。
  - [S0-4] [playwright] 目标 `E2E-TARGET-ACCEPT-RECRUITED` 的 "接受挑战" 操作 应可点击。
  - [S0-5] [prisma] 目标 `E2E-TARGET-ACCEPT-RECRUITED` 的待响应征召挑战者 应包含 本用例被征召挑战者。
  - [S0-6] [prisma] 目标 `E2E-TARGET-ACCEPT-RECRUITED` 的当前挑战者 应不包含 本用例被征召挑战者。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击目标 `E2E-TARGET-ACCEPT-RECRUITED` 的 "接受挑战" 操作。
  - [Action-2] [playwright] "接受后会进入你的挑战页" 确认弹窗 应可见。
  - [Action-3] [playwright] 点击确认弹窗中的 "接受挑战" 操作。
  - [Action-4] [api] 接受挑战结果 应成功。

- S1：Action 后状态。
  - [S1-1] [prisma] 目标 `E2E-TARGET-ACCEPT-RECRUITED` 的当前挑战者 应包含 本用例被征召挑战者。
  - [S1-2] [prisma] 目标 `E2E-TARGET-ACCEPT-RECRUITED` 的待响应征召挑战者 应不包含 本用例被征召挑战者。
  - [S1-3] [prisma] 目标 `E2E-TARGET-ACCEPT-RECRUITED` 的流程状态 应为 `reestimating`。
  - [S1-4] [api] 悬赏大厅数据中目标 `E2E-TARGET-ACCEPT-RECRUITED` 对当前被征召挑战者 应为已接受挑战。
  - [S1-5] [playwright] 页面 应跳转到 我的挑战。
  - [S1-6] [playwright] 我的挑战中应显示目标 `E2E-TARGET-ACCEPT-RECRUITED`。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的目标 `E2E-TARGET-ACCEPT-RECRUITED` 及其派生数据。
  - [Clean-2] [prisma] 删除 本用例创建的项目 `E2E-PROJECT-ACCEPT-RECRUITED`。
  - [Clean-3] [api] 注销当前被征召挑战者登录会话。
  - [Clean-4] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-5] [api] 删除 本用例管理员登录身份。
  - [Clean-6] [api] 删除 本用例被征召挑战者登录身份。
  - [Clean-7] [prisma] 删除 本用例管理员用户。
  - [Clean-8] [prisma] 删除 本用例被征召挑战者用户。
