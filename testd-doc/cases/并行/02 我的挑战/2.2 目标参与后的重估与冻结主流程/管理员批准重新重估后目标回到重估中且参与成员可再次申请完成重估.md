# 管理员批准重新重估后目标回到重估中且参与成员可再次申请完成重估

## 1. 测试目标

验证：角色为 `admin` 的管理员在我的挑战页面进入 "所有挑战" 视图时，可以批准已冻结目标上的 `frozenReestimate` 类型待处理阶段对齐申请。批准后，目标从 `goalFrozen/frozen` 回到 `orfReestimate/reestimating`，冻结时间被清空，新的重估截止时间生效；作为当前挑战者的普通成员再次进入我的挑战后，可以点击 "申请完成重估" 发起新的 `reestimateCompletion` 阶段对齐申请。

  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。
