# 重估完成期限按剩余验收周期50%计算并展示

## 1. 测试目标

验证：角色为 `member` 的普通成员接受目标征召后，系统应根据普通成员接受时间到目标最终验收截止日当日 `23:59` 的剩余验收周期，按 `50%` 比例并以 `12` 小时粒度取整计算目标的重估完成期限；目标进入我的挑战页面的重估中状态后，页面应展示该重估完成期限对应的重估剩余时间，并在时间摘要中保留精确重估截止时间。

  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。

  - [Setup-5] [playwright] 使用 本用例普通成员账号 登录 ORF。
