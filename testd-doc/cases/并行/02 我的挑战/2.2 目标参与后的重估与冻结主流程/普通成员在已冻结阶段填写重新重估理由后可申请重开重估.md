# 普通成员在已冻结阶段填写重新重估理由后可申请重开重估

## 1. 测试目标

验证：角色为 `member` 的普通成员在我的挑战页面查看自己参与且处于 `goalFrozen/frozen` 的目标时，可以填写 "重新重估理由" 并点击 "申请重新重估" 操作。提交成功后，目标仍保持已冻结状态，系统生成 `frozenReestimate` 类型、状态为 `requested` 的阶段对齐申请，并保存普通成员填写的重估理由。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的目标标题前缀 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 对应的目标及其派生数据。
  - [Setup-2] [api] 准备邮箱为 `orf-member-frozen-reestimate-request-e2e@orf.local`、使用固定测试密码的普通成员登录身份。
  - [Setup-3] [prisma] 准备 角色为 `member`、状态为 `active`、名称为 `ORF Member Frozen Reestimate Request E2E` 的本用例普通成员用户。
  - [Setup-4] [prisma] 准备 标题为 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST`、阶段为 `goalFrozen`、流转状态为 `frozen`、最终验收截止日为运行时当前日期后 `8` 天、冻结时间存在、当前挑战者包含本用例普通成员的目标。
  - [Setup-5] [prisma] 准备 归属于目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST`、口径为 `E2E-METRIC-MEMBER-FROZEN-REESTIMATE-REQUEST`、等级积分等级为 `进阶`、等级积分为 `30` 的指标。
  - [Setup-6] [prisma] 确保 归属于目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST`、类型为 `frozenReestimate`、状态为 `requested` 或 `scheduled` 的阶段对齐申请不存在。
  - [Setup-7] [playwright] 使用 本用例普通成员账号 登录 ORF。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-member-frozen-reestimate-request-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `member`。
  - [S0-4] [api] 当前会话用户名称 应为 `ORF Member Frozen Reestimate Request E2E`。
  - [S0-5] [prisma] 应存在 标题为 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST`、阶段为 `goalFrozen`、流转状态为 `frozen` 的目标。
  - [S0-6] [prisma] 目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 的当前挑战者 应包含本用例普通成员。
  - [S0-7] [prisma] 目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 的冻结时间 应存在。
  - [S0-8] [prisma] 应存在 归属于目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST`、口径为 `E2E-METRIC-MEMBER-FROZEN-REESTIMATE-REQUEST`、等级积分等级为 `进阶`、等级积分为 `30` 的指标。
  - [S0-9] [prisma] 目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 的 `frozenReestimate` 类型待处理阶段对齐申请数量 应为 `0`。

- Action：被测业务动作。
  - [Action-1] [playwright] 普通成员打开 我的挑战。
  - [Action-2] [playwright] 在目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 的 "重新重估理由" 输入框输入 `E2E-REASON-MEMBER-FROZEN-REESTIMATE-REQUEST`。
  - [Action-3] [playwright] 点击目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 的 "申请重新重估" 操作。

- S1：Action 后状态。
  - [S1-1] [playwright] 页面 应进入 我的挑战。
  - [S1-2] [playwright] "我的挑战" 视图 应处于选中状态。
  - [S1-3] [playwright] 页面 应提示 已申请重新重估，请等待指挥官审批。
  - [S1-4] [playwright] 我的挑战列表 应显示目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST`。
  - [S1-5] [playwright] 目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 的状态 应显示为 已冻结。
  - [S1-6] [playwright] 目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 的 "申请重新重估" 操作 应不可见。
  - [S1-7] [playwright] 目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 下 应显示指标口径 `E2E-METRIC-MEMBER-FROZEN-REESTIMATE-REQUEST`。
  - [S1-8] [playwright] 指标 `E2E-METRIC-MEMBER-FROZEN-REESTIMATE-REQUEST` 的等级积分等级 应显示为 `进阶`。
  - [S1-9] [api] 我的挑战数据 应包含目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST`。
  - [S1-10] [api] 我的挑战数据中目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 的阶段 应为 `goalFrozen`，流转状态 应为 `frozen`。
  - [S1-11] [api] 我的挑战数据中目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 应包含 `frozenReestimate` 类型、状态为 `requested`、申请人为本用例普通成员、申请理由为 `E2E-REASON-MEMBER-FROZEN-REESTIMATE-REQUEST` 的阶段对齐申请。
  - [S1-12] [prisma] 标题为 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 的目标阶段 应为 `goalFrozen`，流转状态 应为 `frozen`。
  - [S1-13] [prisma] 应存在 归属于目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST`、类型为 `frozenReestimate`、状态为 `requested`、申请人为本用例普通成员、申请理由为 `E2E-REASON-MEMBER-FROZEN-REESTIMATE-REQUEST` 的阶段对齐申请。
  - [S1-14] [prisma] 目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 的 `frozenReestimate` 类型待处理阶段对齐申请数量 应为 `1`。
  - [S1-15] [prisma] 目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST` 的当前挑战者 应仍包含本用例普通成员。
  - [S1-16] [prisma] 应存在 归属于目标 `E2E-TARGET-MEMBER-FROZEN-REESTIMATE-REQUEST`、口径为 `E2E-METRIC-MEMBER-FROZEN-REESTIMATE-REQUEST`、等级积分等级为 `进阶`、等级积分为 `30` 的指标。
