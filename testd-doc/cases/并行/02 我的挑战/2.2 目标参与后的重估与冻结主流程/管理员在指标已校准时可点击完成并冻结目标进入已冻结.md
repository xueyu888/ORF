# 管理员在指标已校准时可点击完成并冻结目标进入已冻结

## 1. 测试目标

验证：角色为 `admin` 的管理员在我的挑战页面进入 "所有挑战" 视图时，可以对处于 `orfReestimate/reestimating`、已存在已校准指标、且存在 `reestimateCompletion` 待处理阶段对齐申请的目标，点击 "完成并冻结" 操作。操作完成后，目标阶段进入 `goalFrozen`，流转状态进入 `frozen`，页面显示目标为已冻结，对齐申请进入已完成状态。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的目标标题前缀 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 对应的目标及其派生数据。
  - [Setup-2] [api] 准备邮箱为 `orf-admin-freeze-reestimate-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-3] [api] 准备邮箱为 `orf-member-freeze-reestimate-e2e@orf.local`、使用固定测试密码的普通成员登录身份。
  - [Setup-4] [prisma] 准备 角色为 `admin`、状态为 `active`、名称为 `ORF Admin Freeze Reestimate E2E` 的本用例管理员用户。
  - [Setup-5] [prisma] 准备 角色为 `member`、状态为 `active`、名称为 `ORF Member Freeze Reestimate E2E` 的本用例普通成员用户。
  - [Setup-6] [prisma] 准备 标题为 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE`、阶段为 `orfReestimate`、流转状态为 `reestimating`、当前挑战者包含本用例普通成员的目标。
  - [Setup-7] [prisma] 准备 归属于目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE`、口径为 `E2E-METRIC-ADMIN-FREEZE-REESTIMATE`、等级积分等级为 `进阶`、等级积分为 `30` 的指标。
  - [Setup-8] [prisma] 准备 归属于目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE`、类型为 `reestimateCompletion`、状态为 `requested`、申请人为本用例普通成员的阶段对齐申请。
  - [Setup-9] [playwright] 使用 本用例管理员账号 登录 ORF。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-admin-freeze-reestimate-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `admin`。
  - [S0-4] [api] 当前会话用户名称 应为 `ORF Admin Freeze Reestimate E2E`。
  - [S0-5] [prisma] 应存在 标题为 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE`、阶段为 `orfReestimate`、流转状态为 `reestimating` 的目标。
  - [S0-6] [prisma] 目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 的当前挑战者 应包含本用例普通成员。
  - [S0-7] [prisma] 应存在 归属于目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE`、口径为 `E2E-METRIC-ADMIN-FREEZE-REESTIMATE`、等级积分等级为 `进阶`、等级积分为 `30` 的指标。
  - [S0-8] [prisma] 应存在 归属于目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE`、类型为 `reestimateCompletion`、状态为 `requested`、申请人为本用例普通成员的阶段对齐申请。
  - [S0-9] [prisma] 目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 的 `reestimateCompletion` 类型待处理阶段对齐申请数量 应为 `1`。

- Action：被测业务动作。
  - [Action-1] [playwright] 管理员打开 我的挑战。
  - [Action-2] [playwright] 管理员切换到 "所有挑战" 视图。
  - [Action-3] [playwright] 点击目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 的 "完成并冻结" 操作。

- S1：Action 后状态。
  - [S1-1] [playwright] 页面 应进入 我的挑战。
  - [S1-2] [playwright] "所有挑战" 视图 应处于选中状态。
  - [S1-3] [playwright] 页面 应提示 对齐已完成。
  - [S1-4] [playwright] 我的挑战列表 应显示目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE`。
  - [S1-5] [playwright] 目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 的状态 应显示为 已冻结。
  - [S1-6] [playwright] 目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 的 "完成并冻结" 操作 应不可见。
  - [S1-7] [playwright] 目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 下 应显示指标口径 `E2E-METRIC-ADMIN-FREEZE-REESTIMATE`。
  - [S1-8] [playwright] 指标 `E2E-METRIC-ADMIN-FREEZE-REESTIMATE` 的等级积分等级 应显示为 `进阶`。
  - [S1-9] [api] 所有挑战数据 应包含目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE`。
  - [S1-10] [api] 所有挑战数据中目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 的阶段 应为 `goalFrozen`，流转状态 应为 `frozen`。
  - [S1-11] [api] 所有挑战数据中目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 应包含口径为 `E2E-METRIC-ADMIN-FREEZE-REESTIMATE`、等级积分等级为 `进阶`、等级积分为 `30` 的指标。
  - [S1-12] [api] 所有挑战数据中目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 应包含 `reestimateCompletion` 类型的已完成阶段对齐申请。
  - [S1-13] [prisma] 标题为 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 的目标阶段 应为 `goalFrozen`，流转状态 应为 `frozen`。
  - [S1-14] [prisma] 标题为 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 的目标冻结时间 应存在。
  - [S1-15] [prisma] 应存在 归属于目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE`、类型为 `reestimateCompletion`、状态为 `completed`、申请人为本用例普通成员、审核人为本用例管理员的阶段对齐申请。
  - [S1-16] [prisma] 目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 的 `reestimateCompletion` 类型待处理阶段对齐申请数量 应为 `0`。
  - [S1-17] [prisma] 目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE` 的当前挑战者 应仍包含本用例普通成员。
  - [S1-18] [prisma] 应存在 归属于目标 `E2E-TARGET-ADMIN-FREEZE-REESTIMATE`、口径为 `E2E-METRIC-ADMIN-FREEZE-REESTIMATE`、等级积分等级为 `进阶`、等级积分为 `30` 的指标。
