# 验证管理员在待验收已验收已结算阶段可修改目标不可删除目标

## 1. 测试目标

验证：角色为 `admin` 的管理员在我的挑战页面进入 "所有挑战" 视图后，可以修改处于待验收、已验收、已结算阶段的目标标题；管理员对上述阶段目标执行删除并确认后，删除请求被目标生命周期锁定拒绝，目标在页面、接口数据和数据库中仍然存在。修改和删除失败后，目标阶段和流转状态保持不变。
