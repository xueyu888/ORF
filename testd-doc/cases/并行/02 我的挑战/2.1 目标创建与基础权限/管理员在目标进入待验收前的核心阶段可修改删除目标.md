# 验证管理员在目标进入待验收前的核心阶段可修改删除目标

## 1. 测试目标

验证：角色为 `admin` 的管理员在我的挑战页面进入 "所有挑战" 视图后，可以修改处于 `goalSetting/candidate`、`resultClaiming/open`、`orfReestimate/reestimating` 三个待验收前且可编辑核心阶段的目标标题；管理员也可以删除处于上述三个阶段的目标。修改后目标标题变更且阶段和流转状态保持不变；删除后目标在页面、接口数据和数据库中均不存在。
