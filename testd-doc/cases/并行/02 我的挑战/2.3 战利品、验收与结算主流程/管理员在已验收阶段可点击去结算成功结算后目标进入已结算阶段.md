# 管理员在已验收阶段可点击去结算成功结算后目标进入已结算阶段

## 1. 测试目标

验证：角色为 `admin` 的管理员在我的挑战页面查看处于 `goalFrozen/accepted` 已验收阶段、已存在战利品正式提交记录和验收记录且尚未最终结算的目标时，可以点击 "去结算" 进入确认结算页面，查看默认单人贡献比例并确认结算。提交成功后，目标进入 `goalFrozen/settled` 已结算阶段，系统生成 `finalCompletion` 类型结算事件和成员积分流水，并保存目标基础积分、目标累计结算积分和完成倍数。
