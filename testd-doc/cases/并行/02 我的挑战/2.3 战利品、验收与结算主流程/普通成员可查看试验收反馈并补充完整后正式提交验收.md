# 普通成员可查看试验收反馈并补充完整后正式提交验收

## 1. 测试目标

验证：角色为 `member` 的普通成员在我的挑战页面查看自己参与且处于 `goalFrozen/frozen`、已存在状态为 `approved` 的试验收反馈且尚未正式提交战利品的目标时，可以进入战利品提交页面，查看管理员试验收反馈和 "可正式提交" 状态，补充正式验收材料并点击 "正式提交" 操作。提交成功后，目标进入待验收状态，系统保存正式战利品提交记录、提交人、提交时间、完成说明、指标完成主张、指标证据和自测报告，原试验收反馈保持已通过状态。
