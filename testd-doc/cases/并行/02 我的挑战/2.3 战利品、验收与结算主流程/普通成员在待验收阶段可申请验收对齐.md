# 普通成员在待验收阶段可申请验收对齐

## 1. 测试目标

验证：角色为 `member` 的普通成员在我的挑战页面查看自己参与且处于 `goalFrozen/submitted`、已存在战利品正式提交记录、当前不存在 `acceptance` 类型待处理阶段对齐申请的目标时，可以点击 "申请验收对齐" 操作。提交成功后，目标仍保持待验收状态，系统生成 `acceptance` 类型、状态为 `requested` 的阶段对齐申请，申请人为本用例普通成员，原战利品正式提交记录保持不变。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。

  - [Setup-2] [api] 准备邮箱为 `orf-member-acceptance-alignment-request-e2e@orf.local`、使用固定测试密码的普通成员登录身份。
  - [Setup-3] [prisma] 准备 角色为 `member`、状态为 `active`、名称为 `ORF Member Acceptance Alignment Request E2E` 的本用例普通成员用户。
  - [Setup-4] [api] 准备邮箱为 `orf-admin-acceptance-alignment-request-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-5] [prisma] 准备 角色为 `admin`、状态为 `active`、名称为 `ORF Admin Acceptance Alignment Request E2E` 的本用例管理员用户。
  - [Setup-6] [prisma] 准备 标题为 `E2E-TARGET-ACCEPTANCE-ALIGNMENT-REQUEST`、阶段为 `goalFrozen`、流转状态为 `submitted`、最终验收截止日为运行时当前日期后 `8` 天、冻结时间存在、战利品提交时间存在、当前挑战者包含本用例普通成员的目标。
  - [Setup-7] [prisma] 准备 归属于目标 `E2E-TARGET-ACCEPTANCE-ALIGNMENT-REQUEST`、口径为 `E2E-METRIC-ACCEPTANCE-ALIGNMENT-REQUEST`、等级积分等级为 `进阶`、等级积分为 `30` 的指标。
  - [Setup-8] [prisma] 准备 归属于目标 `E2E-TARGET-ACCEPTANCE-ALIGNMENT-REQUEST`、提交人为本用例普通成员、完成说明为 `E2E-ACCEPTANCE-ALIGNMENT-LOOT-BODY：普通成员已正式提交验收材料。`、自测报告为 `E2E-ACCEPTANCE-ALIGNMENT-SELF-TEST：正式验收前已完成自测。`、指标 `E2E-METRIC-ACCEPTANCE-ALIGNMENT-REQUEST` 的完成主张为 `completed`、证据为 `E2E-ACCEPTANCE-ALIGNMENT-EVIDENCE：https://example.test/acceptance-alignment-request` 的战利品正式提交记录。
  - [Setup-9] [prisma] 确保 归属于目标 `E2E-TARGET-ACCEPTANCE-ALIGNMENT-REQUEST`、类型为 `acceptance`、状态为 `requested` 或 `scheduled` 的阶段对齐申请不存在。
  - [Setup-10] [playwright] 使用 本用例普通成员账号 登录 ORF。
