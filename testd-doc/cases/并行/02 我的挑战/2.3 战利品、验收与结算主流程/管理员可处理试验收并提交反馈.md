# 管理员可处理试验收并提交反馈

## 1. 测试目标

验证：角色为 `admin` 的管理员在我的挑战页面查看处于 `goalFrozen/frozen` 且存在 `requested` 试验收记录的目标时，可以进入处理试验收页面，查看普通成员提交的试验收材料，选择试验收结论为 "可正式提交"，填写反馈说明并提交反馈。提交成功后，试验收记录状态更新为 `approved`，保存管理员反馈、处理人和处理时间，目标仍保持已冻结状态，且不会生成战利品正式提交记录。
