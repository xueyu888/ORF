# 普通成员在已冻结阶段可填写完整战利品并提交试验收

## 1. 测试目标

验证：角色为 `member` 的普通成员在我的挑战页面查看自己参与且处于 `goalFrozen/frozen` 的目标时，可以进入战利品提交页面，填写完成说明、每个指标的完成主张和证据、自测报告，并点击 "提交试验收" 操作。提交成功后，目标仍保持已冻结状态，系统生成状态为 `requested` 的试验收记录，并保存普通成员填写的完整战利品内容。
