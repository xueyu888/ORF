# 普通成员在已验收阶段可提交匿名互评

## 1. 测试目标

验证：角色为 `member` 的普通成员作为目标当前挑战者之一，在我的挑战页面查看处于 `goalFrozen/accepted` 已验收阶段且尚未最终结算的多人目标时，可以进入提交匿名互评页面，按指标为每位挑战者填写合计为 `100%` 的贡献百分比并提交。提交成功后，系统通过 ORF 代理将匿名互评保存到共享结算服务，当前成员可以读取自己的最新互评记录，目标仍保持已验收且未产生最终结算事件。
