# 管理员确认验收通过后目标进入已验收阶段

## 1. 测试目标

验证：角色为 `admin` 的管理员在我的挑战页面查看处于 `goalFrozen/submitted`、已存在战利品正式提交记录且存在 `acceptance` 类型待处理阶段对齐申请的目标时，可以从阶段对齐入口进入验收战利品页面，查看普通成员提交的正式验收材料，将指标验收结论确认为 "完成"，填写验收说明并确认验收通过。提交成功后，目标进入 `goalFrozen/accepted` 已验收阶段，系统保存验收记录、指标验收结果，并将对应的验收对齐申请更新为已完成。
