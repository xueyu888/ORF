# 非指挥官不允许进入编辑修改目标

## 1. 测试目标

验证：普通成员登录后，在我的挑战页面看到自己参与的目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN`，双击目标标题不会进入目标标题编辑态；普通成员直接提交目标详情修改请求会被拒绝，目标标题保持不变。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN` 及其派生数据。
  - [Setup-2] [prisma] 删除 本用例残留的目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN-EDITED` 及其派生数据。
  - [Setup-3] [api] 准备邮箱为 `orf-member-edit-objective-forbidden-e2e@orf.local`、使用固定测试密码的普通成员登录身份。
  - [Setup-4] [prisma] 准备 角色为 `member`、状态为 `active` 的本用例普通成员用户。
  - [Setup-5] [prisma] 准备 标题为 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN`、流转状态为 `frozen`、挑战者包含本用例普通成员的执行中目标。
  - [Setup-6] [api] 撤销本用例普通成员登录身份可能残留的登录会话。
  - [Setup-7] [playwright] 注销当前登录会话。
  - [Setup-8] [playwright] 离开当前 ORF 前端页面。
  - [Setup-9] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-10] [playwright] 打开 ORF 登录页。
  - [Setup-11] [playwright] 在邮箱输入框输入本用例普通成员固定测试邮箱。
  - [Setup-12] [playwright] 在密码输入框输入本用例普通成员固定测试密码。
  - [Setup-13] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-14] [playwright] 打开 我的挑战。
  - [Setup-15] [playwright] 切换到 "我的挑战" 视图。
  - [Setup-16] [playwright] 将状态筛选切换到 "执行中"。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-member-edit-objective-forbidden-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `member`。
  - [S0-4] [api] 当前会话用户状态 应为 `active`。
  - [S0-5] [prisma] 目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN` 的流转状态 应为 `frozen`。
  - [S0-6] [prisma] 目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN` 的挑战者账号身份 应包含 本用例普通成员。
  - [S0-7] [playwright] 当前页面 应为 我的挑战。
  - [S0-8] [playwright] "我的挑战" 视图 应处于选中状态。
  - [S0-9] [playwright] "执行中" 状态筛选 应处于选中状态。
  - [S0-10] [playwright] 我的挑战中应显示目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN`。
  - [S0-11] [playwright] 目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN` 的标题编辑输入框 应不可见。

- Action：被测业务动作。
  - [Action-1] [playwright] 普通成员双击目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN` 的标题。
  - [Action-2] [api] 普通成员调用目标详情修改接口提交新标题 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN-EDITED`。

- S1：Action 后状态。
  - [S1-1] [playwright] 页面 应显示 "只有指挥官可以编辑目标" 提示。
  - [S1-2] [playwright] 目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN` 的标题编辑输入框 应不可见。
  - [S1-3] [playwright] 我的挑战中应仍显示目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN`。
  - [S1-4] [api] 目标详情修改结果 应为 权限不足。
  - [S1-5] [prisma] 目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN` 的标题 应保持 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN`。
  - [S1-6] [prisma] 应不存在 标题为 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN-EDITED` 的目标。
  - [S1-7] [api] 当前会话用户角色 应仍为 `member`。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN` 及其派生数据。
  - [Clean-2] [prisma] 删除 本用例残留的目标 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN-EDITED` 及其派生数据。
  - [Clean-3] [api] 注销当前登录会话。
  - [Clean-4] [playwright] 离开当前 ORF 前端页面。
  - [Clean-5] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-6] [api] 撤销本用例普通成员登录身份的残留登录会话。
  - [Clean-7] [api] 删除 本用例普通成员登录身份。
  - [Clean-8] [prisma] 删除 本用例普通成员用户默认团队成员关系。
  - [Clean-9] [prisma] 删除 本用例普通成员用户。
  - [Clean-10] [prisma] 应不存在 标题为 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN` 的目标。
  - [Clean-11] [prisma] 应不存在 标题为 `E2E-TARGET-MEMBER-EDIT-FORBIDDEN-EDITED` 的目标。
  - [Clean-12] [api] 本用例普通成员登录身份 应不存在。
  - [Clean-13] [prisma] 本用例普通成员用户 应不存在。
