# 普通用户不允许新建目标

## 1. 测试目标

验证：角色为 `member` 的普通用户不具备 `objective.create` 权限时，登录 ORF 并进入我的挑战页面后，页面不提供“新建目标”入口，也不展示新建目标草稿输入；测试结束后，不存在由本用例标题 `E2E-TARGET-MEMBER-CREATE-FORBIDDEN` 对应的新建目标。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的目标 `E2E-TARGET-MEMBER-CREATE-FORBIDDEN` 及其派生数据。
  - [Setup-2] [api] 记录 成员角色的当前权限配置。
  - [Setup-3] [api] 设置 成员角色权限不包含 `objective.create`。
  - [Setup-4] [api] 准备邮箱为 `orf-member-create-target-forbidden-e2e@orf.local`、使用固定测试密码的普通用户登录身份。
  - [Setup-5] [prisma] 准备 角色为 `member`、状态为 `active` 的本用例普通用户。
  - [Setup-6] [playwright] 使用 本用例普通用户账号 登录 ORF。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-member-create-target-forbidden-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `member`。
  - [S0-4] [api] 当前普通用户的新建目标权限 应为 未授权。
  - [S0-5] [prisma] 应不存在 标题为 `E2E-TARGET-MEMBER-CREATE-FORBIDDEN` 的目标。

- Action：被测业务动作。
  - [Action-1] [playwright] 普通用户打开 我的挑战。

- S1：Action 后状态。
  - [S1-1] [playwright] 页面 应进入 我的挑战。
  - [S1-2] [playwright] "我的挑战" 视图 应处于选中状态。
  - [S1-3] [playwright] 页面顶部的 "新建目标" 操作 应不可见。
  - [S1-4] [playwright] 我的挑战项目区的新增目标操作 应不可见。
  - [S1-5] [playwright] 新建目标标题输入框 应不可见。
  - [S1-6] [api] 当前普通用户的新建目标权限 应仍为 未授权。
  - [S1-7] [prisma] 应仍不存在 标题为 `E2E-TARGET-MEMBER-CREATE-FORBIDDEN` 的目标。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的目标 `E2E-TARGET-MEMBER-CREATE-FORBIDDEN` 及其派生数据。
  - [Clean-2] [api] 注销当前普通用户登录会话。
  - [Clean-3] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-4] [api] 删除 本用例普通用户登录身份。
  - [Clean-5] [prisma] 删除 本用例普通用户。
  - [Clean-6] [api] 恢复 成员角色为 Setup 前记录的权限配置。
  - [Clean-7] [prisma] 应不存在 标题为 `E2E-TARGET-MEMBER-CREATE-FORBIDDEN` 的目标。
  - [Clean-8] [api] 邮箱为 `orf-member-create-target-forbidden-e2e@orf.local` 的普通用户登录身份 应不存在。
  - [Clean-9] [prisma] 邮箱为 `orf-member-create-target-forbidden-e2e@orf.local` 的普通用户 应不存在。
  - [Clean-10] [api] 当前会话 应为 未登录。
