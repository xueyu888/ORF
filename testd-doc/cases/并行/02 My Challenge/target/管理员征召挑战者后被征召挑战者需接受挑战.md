# 管理员征召挑战者后被征召挑战者需接受挑战

## 1. 测试目标

验证：管理员登录后，在我的挑战页面发布项目 `E2E-PROJECT-RECRUIT-NEED-ACCEPT` 下的目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT`，并征召挑战者；征召发送后，目标显示待响应征召，被征召挑战者在悬赏大厅-全部中看到待响应征召状态，并看到可点击的 "接受挑战" 操作。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 及其派生数据。
  - [Setup-2] [prisma] 删除 本用例残留的项目 `E2E-PROJECT-RECRUIT-NEED-ACCEPT`。
  - [Setup-3] [api] 准备邮箱为 `orf-admin-recruit-need-accept-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-4] [api] 准备邮箱为 `orf-member-recruit-need-accept-e2e@orf.local`、使用固定测试密码的被征召挑战者登录身份。
  - [Setup-5] [prisma] 准备 角色为 `admin`、状态为 `active` 的本用例管理员用户。
  - [Setup-6] [prisma] 准备 角色为 `member`、状态为 `active` 的本用例被征召挑战者用户。
  - [Setup-7] [prisma] 准备 本用例项目 `E2E-PROJECT-RECRUIT-NEED-ACCEPT`。
  - [Setup-8] [prisma] 准备 属于项目 `E2E-PROJECT-RECRUIT-NEED-ACCEPT`、标题为 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 的未发布目标。
  - [Setup-9] [playwright] 使用 本用例管理员账号 登录 ORF。
  - [Setup-10] [playwright] 打开 我的挑战。
  - [Setup-11] [playwright] 切换到 "所有挑战" 视图。
  - [Setup-12] [playwright] 选择项目筛选 `E2E-PROJECT-RECRUIT-NEED-ACCEPT`。

- S0：Action 前状态。
  - [S0-1] [playwright] 项目 `E2E-PROJECT-RECRUIT-NEED-ACCEPT` 中应显示目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT`。
  - [S0-2] [playwright] 点击目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 的 "发布" 操作。
  - [S0-3] [api] 发布目标结果 应成功。
  - [S0-4] [prisma] 目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 的发布时间 应不为空。
  - [S0-5] [playwright] 目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 处于征召阶段。
  - [S0-6] [playwright] 目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 的 "征召" 操作 应可点击。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 的 "征召" 操作。
  - [Action-2] [playwright] "征召挑战者" 弹窗 应可见。
  - [Action-3] [playwright] 勾选 本用例被征召挑战者。
  - [Action-4] [playwright] 点击 "发送征召" 操作。
  - [Action-5] [api] 征召挑战者结果 应成功。

- S1：Action 后状态。
  - [S1-1] [playwright] 目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 的 "待响应征召" 区域 应可见。
  - [S1-2] [playwright] 目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 中 本用例被征召挑战者 的状态 应显示为 "已征召，等待接受"。
  - [S1-3] [prisma] 目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 的待响应征召挑战者 应包含 本用例被征召挑战者。
  - [S1-4] [prisma] 目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 的当前挑战者 应不包含 本用例被征召挑战者。
  - [S1-5] [playwright] 使用 本用例被征召挑战者账号 打开 悬赏大厅的 "全部" 视图。
  - [S1-6] [api] 目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 对当前被征召挑战者 应允许接受挑战。
  - [S1-7] [playwright] 目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 的参与状态 应显示为 "待响应征召"。
  - [S1-8] [playwright] 目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 的 "接受挑战" 操作 应可点击。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的目标 `E2E-TARGET-RECRUIT-NEED-ACCEPT` 及其派生数据。
  - [Clean-2] [prisma] 删除 本用例创建的项目 `E2E-PROJECT-RECRUIT-NEED-ACCEPT`。
  - [Clean-3] [api] 注销当前被征召挑战者登录会话。
  - [Clean-4] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-5] [api] 删除 本用例管理员登录身份。
  - [Clean-6] [api] 删除 本用例被征召挑战者登录身份。
  - [Clean-7] [prisma] 删除 本用例管理员用户。
  - [Clean-8] [prisma] 删除 本用例被征召挑战者用户。
