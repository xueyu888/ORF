# 管理员可以新建目标并发布

## 1. 测试目标

验证：管理员登录后，通过“新建目标”入口创建目标 `E2E-TARGET-PUBLISH-ADMIN`，在我的挑战页的“所有挑战 / 未归属目标”中看到该目标，并发布到悬赏大厅；发布后该目标可征召挑战者，且在悬赏大厅可见。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的目标 `E2E-TARGET-PUBLISH-ADMIN` 及其派生数据。
  - [Setup-2] [api] 准备邮箱为 `orf-admin-create-target-publish-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-3] [prisma] 准备 角色为 `admin`、状态为 `active` 的本用例管理员用户。
  - [Setup-4] [playwright] 使用 本用例管理员账号 登录 ORF。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户角色 应为 `admin`。
  - [S0-3] [playwright] "新建目标" 操作 应可见。
  - [S0-4] [playwright] "新建目标" 操作 应可点击。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击 "新建目标" 操作。
  - [Action-2] [playwright] 当前页面 应为 我的挑战。
  - [Action-3] [playwright] "所有挑战" 视图 应处于选中状态。
  - [Action-4] [playwright] "未归属目标" 项目筛选 应处于选中状态。
  - [Action-5] [playwright] 在新建目标标题输入框输入 `E2E-TARGET-PUBLISH-ADMIN`。
  - [Action-6] [playwright] 提交 新建目标标题。
  - [Action-7] [playwright] 我的挑战的 "所有挑战 / 未归属目标" 中应显示目标 `E2E-TARGET-PUBLISH-ADMIN`。
  - [Action-8] [playwright] 点击目标 `E2E-TARGET-PUBLISH-ADMIN` 的 "发布" 操作。

- S1：Action 后状态。
  - [S1-1] [playwright] 目标 `E2E-TARGET-PUBLISH-ADMIN` 的 "征召" 操作 应可见。
  - [S1-2] [playwright] 目标 `E2E-TARGET-PUBLISH-ADMIN` 的 "征召" 操作 应可点击。
  - [S1-3] [api] 悬赏大厅数据 应包含目标 `E2E-TARGET-PUBLISH-ADMIN`。
  - [S1-4] [playwright] 打开 悬赏大厅。
  - [S1-5] [playwright] 悬赏大厅 应显示目标 `E2E-TARGET-PUBLISH-ADMIN`。
  - [S1-6] [prisma] 目标 `E2E-TARGET-PUBLISH-ADMIN` 的发布时间 应不为空。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的目标 `E2E-TARGET-PUBLISH-ADMIN` 及其派生数据。
  - [Clean-2] [api] 注销当前登录会话。
  - [Clean-3] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-4] [api] 删除 本用例管理员登录身份。
  - [Clean-5] [prisma] 删除 本用例管理员用户。
