# 管理员征召成员执行目标-普通成员不可征召成员

## 1. 测试目标

验证：征召成员执行目标是管理员业务能力；普通成员进入挑战工作台后，前端不提供 "征召" 入口，目标不会产生待响应征召成员。

实现说明：

- 当前实现：征召入口只向具备征召权限的管理员开放。
- 当前用例类型：反向权限用例。
- 当前代码状态：已生成独立 testd 用例。

边界：

- 覆盖对象：普通成员不可征召成员执行目标。
- 不覆盖对象：管理员征召成员、被征召成员接受挑战、成员拒绝征召、征召多个成员、重复征召、挑战申请审批、普通成员提交申请、冻结、验收、结算。
- 依赖对象：[管理员征召成员执行目标](管理员征召成员执行目标.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体普通成员账号、目标或征召关系。
- Setup 产物：邮箱为 `orf-member-recruit-forbidden-e2e@orf.local` 的普通成员身份、用户和 member 成员关系；邮箱为 `orf-member-recruit-target-e2e@orf.local` 的被征召候选普通成员身份、用户和 member 成员关系；标题为 `E2E-RECRUIT-FORBIDDEN: 普通成员不可征召成员` 的本用例可征召目标；普通成员已登录会话。
- Action 产物：普通成员进入挑战工作台后可见的目标操作入口和工作台数据。
- Clean 产物：删除本用例目标及其派生数据，删除本用例独占两个普通成员身份、用户、成员关系与 session。
- 原状态恢复：目标为当前用例独占资源，Clean 直接删除目标及派生数据，不恢复任何共享目标状态。
