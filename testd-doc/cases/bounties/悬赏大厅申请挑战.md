## 1. 测试目标

验证：已审核普通成员可以在悬赏大厅选择一个当前可申请目标并提交挑战申请；提交后该目标进入已申请状态，并产生一条待审批挑战申请。

边界：

- 覆盖对象：普通成员提交挑战申请。
- 不覆盖对象：管理员审批申请、接受征召、拒绝申请、重复申请、已关闭目标、已是挑战者的目标。
- B 基础数据：预置普通成员账号 "orf-member-e2e@orf.local"，角色为 member，状态为 active。
- Setup 产物：运行时选择的当前可申请目标。
- Clean 产物：本用例创建的 pending 挑战申请和目标申请前流转状态。

## 2. 状态模型

- B：基准状态。
  - [api] 前端服务 应可用。
  - [api] 后端服务 应可用。
  - [api] 前端登录页入口 应可访问。
  - [api] 当前会话查询接口 应可访问。
  - [prisma] ORF 数据库 应可连接。
  - [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [api] Ory/Kratos Admin/Public API 应可访问。
  - [api] 应存在 邮箱为 `orf-member-e2e@orf.local` 的普通成员测试身份。
  - [api] 普通成员测试身份 的密码凭据 应可用。
  - [prisma] 应存在 名称为 `ORF Member E2E`、角色为 `member`、状态为 `active` 的普通成员测试用户。
  - [prisma] 默认团队中 应存在 一个非终态且允许申请挑战的目标。
  - [prisma] 目标 的 `flowStatus` 应属于 `open`、`applying` 或 `recruiting`。
  - [prisma] 目标 的当前挑战者集合 应不包含 `ORF Member E2E`。
  - [prisma] 目标 应不存在 申请人为 `ORF Member E2E` 且状态为 `pending` 的挑战申请。
  - [api] 当前会话 应为 未登录。
  - [playwright] 当前浏览器 应不存在 Ory session cookie。
  - [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [playwright] 创建全新的浏览器上下文，或清空当前上下文的 cookies/localStorage/sessionStorage。
  - [playwright] 打开 登录页，使用普通成员测试邮箱和密码登录。
  - [playwright] 打开 悬赏大厅。
  - [api] 读取悬赏大厅数据接口。
  - [api] 从悬赏大厅可申请目标集合中选择一个当前普通成员尚未申请的目标，记录为 `runtime.bountyTarget`。

- S0：Action 前状态。
  - [api] 当前会话 应为 邮箱为 `orf-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [playwright] 当前页面 应为 悬赏大厅。
  - [playwright] 主导航 应可见。
  - [playwright] 当前用户显示 应为 `ORF Member E2E`。
  - [api] 悬赏大厅数据接口 应返回 `runtime.bountyTarget` 对应的悬赏目标。
  - [api] `runtime.bountyTarget` 对当前普通成员 应为 尚未申请。
  - [playwright] 悬赏大厅列表中 `runtime.bountyTarget.objective.title` 对应的行 应可见。
  - [playwright] 该目标行中的 `申请挑战` 操作 应可见。
  - [playwright] 该目标行中的 `申请挑战` 操作 应可点击。
  - [prisma] 目标 应不存在 申请人为 `ORF Member E2E` 且状态为 `pending` 的挑战申请。

- Action：被测业务动作。
  - [playwright] 点击所选目标行的 `申请挑战` 按钮。
  - [playwright] 确认弹窗 应显示 "提交后等待指挥官确认"。
  - [playwright] 在点击确认弹窗的 `申请挑战` 前注册提交挑战申请接口响应捕获。
  - [playwright] 点击 确认弹窗中的 `申请挑战` 操作。

- S1：Action 后状态。
  - [api] 提交挑战申请接口响应 应成功。
  - [api] 提交挑战申请响应的目标 ID 应为 `runtime.bountyTarget.objective.id`。
  - [prisma] 该目标的 `challengeApplications` 中新增一条申请人为 `ORF Member E2E`、状态为 `pending` 的记录，且 `createdAt` 不为空。
  - [prisma] 若该目标申请前不是 `recruiting`，提交申请后 `flowStatus` 为 `applying`；若申请前是 `recruiting`，则仍保持 `recruiting`。
  - [api] 再次读取悬赏大厅数据接口时，该目标对当前用户 应为 已申请。
  - [playwright] 该目标行的操作按钮显示为 `已申请` 且不可点击，或该目标不再作为可申请项出现。
  - [playwright] 页面 应不显示 错误提示。

- Clean：恢复 B。
  - [prisma] 从 `runtime.bountyTarget.objective.challengeApplications` 中删除申请人为 `ORF Member E2E` 且由本用例创建的 `pending` 记录。
  - [prisma] 如果删除后该目标没有其他待处理申请，且申请前 `flowStatus` 不是 `recruiting`，将目标 `flowStatus` 恢复为申请前状态。
  - [api] 调用退出登录接口撤销本次登录产生的 Ory session。
  - [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [api] 普通成员测试身份 应仍存在。
  - [prisma] 预置普通成员账号和 `member` 成员关系 应仍存在。
  - [prisma] `runtime.bountyTarget` 对应目标 应仍存在。
  - [prisma] `runtime.bountyTarget` 对应目标 应不包含 本用例挑战申请残留。
