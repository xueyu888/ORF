# 管理员征召成员执行目标

## 1. 测试目标

验证：由当前用例独占准备的管理员可以在挑战工作台征召普通成员执行本用例目标；被征召普通成员可以在悬赏大厅看到征召目标并接受挑战；接受后该普通成员进入目标挑战者列表，目标进入重估阶段。

实现说明：

- 当前实现：征召成员需要管理员会话；接受挑战需要被征召普通成员会话。
- 当前缺口：成员拒绝征召能力尚未实现。
- 当前代码状态：已生成独立 testd 用例。

边界：

- 覆盖对象：管理员征召普通成员执行目标。
- 覆盖对象：被征召普通成员接受挑战。
- 不覆盖对象：成员拒绝征召、征召多个成员、重复征召、挑战申请审批、普通成员提交申请、目标发布、新增指标、行动项、冻结、验收、结算。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体管理员账号、普通成员账号、目标或征召关系。
- Setup 产物：邮箱为 `orf-admin-recruit-member-e2e@orf.local` 的管理员身份、用户和 admin 成员关系；邮箱为 `orf-member-recruit-member-e2e@orf.local` 的普通成员身份、用户和 member 成员关系；标题为 `E2E-RECRUIT-MEMBER: 管理员征召成员执行目标` 的本用例可征召目标。
- Action 产物：本用例目标先把 "ORF Member Recruit Member E2E" 记录为待响应征召成员，随后把该成员记录为已接受挑战者。
- Clean 产物：删除本用例目标及其派生数据，删除本用例独占管理员和普通成员身份、用户、成员关系与 session。
- 原状态恢复：目标为当前用例独占资源，Clean 直接删除目标及派生数据，不恢复任何共享目标状态。
