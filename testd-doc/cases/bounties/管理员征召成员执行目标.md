# 管理员征召成员执行目标

## 1. 功能确认

- [api] 管理员征召成员接口 应存在。
- [playwright] 挑战工作台中 目标 的 "征召" 操作 应存在。
- [api] 被征召成员接受征召接口 应存在。
- [playwright] 悬赏大厅中 被征召目标 的 "接受挑战" 操作 应存在。
- [api] 被征召成员拒绝征召接口 应不存在。
- [playwright] 悬赏大厅中 被征召目标 的 "拒绝征召" 操作 应不存在。

边界：

- 当前 ORF 已实现：管理员征召成员。
- 当前 ORF 已实现：被征召成员接受征召。
- 当前 ORF 未实现：被征召成员拒绝征召。
- 本用例不生成独立测试代码，直到 ORF 明确支持成员拒绝征召。
