# 成员申请挑战审批

## 1. 测试目标

- [api] 审批通过接口响应 应成功。
- [api] 审批拒绝接口响应 应成功。
- [prisma] 被通过的普通成员 应进入 目标 的挑战者列表。
- [prisma] 被拒绝的普通成员 应不进入 目标 的挑战者列表。

边界：

- 覆盖对象：管理员审批 pending 挑战申请。
- 不覆盖对象：普通成员提交申请入口、普通成员不可审批、目标关闭后的审批限制。
- B 基础数据：预置管理员账号 "zrx831@gmail.com"。
- B 基础数据：预置普通成员 "ORF Member E2E" 和 "m2"。
- Setup 产物：两个 pending 挑战申请。
- Clean 产物：目标 的原始状态。

## 2. 状态模型

- B：基准状态。
  - [api] 前端服务 应可用。
  - [api] 后端服务 应可用。
  - [api] 健康检查或等价探测 应通过。
  - [prisma] ORF 数据库 应可连接。
  - [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [api] Ory/Kratos Admin API 应可访问。
  - [api] Ory/Kratos Public API 应可访问。
  - [api] 应存在 邮箱为 "zrx831@gmail.com" 的管理员 Ory/Kratos 测试身份。
  - [prisma] 应存在 邮箱为 "zrx831@gmail.com"、角色为 admin、状态为 active 的管理员用户。
  - [prisma] 应存在 名称为 "ORF Member E2E"、角色为 member、状态为 active 的普通成员用户。
  - [prisma] 应存在 名称为 "m2"、角色为 member、状态为 active 的普通成员用户。
  - [prisma] 应存在 一个允许创建 pending 挑战申请的目标。
  - [api] 当前会话 应为 未登录。
  - [playwright] 当前浏览器 应不存在 登录 cookie。
  - [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [playwright] 清空 当前浏览器状态。
  - [playwright] 打开 "/auth" 登录页。
  - [playwright] 填写 Email 输入框 为 管理员邮箱。
  - [playwright] 填写 Password 输入框 为 管理员密码。
  - [playwright] 点击 "Sign In" 登录操作。
  - [api] 当前会话 应为 管理员已登录。
  - [prisma] 选择 一个允许审批挑战申请的目标 作为 目标。
  - [prisma] 记录 目标 的原始状态 作为 原目标状态。
  - [prisma] 创建 "ORF Member E2E" 对 目标 的 pending 挑战申请。
  - [prisma] 创建 "m2" 对 目标 的 pending 挑战申请。
  - [playwright] 打开 "/tasks" 挑战工作台。
  - [playwright] 点击 "所有挑战" 视图切换操作。

- S0：Action 前状态。
  - [api] 当前会话 应为 邮箱为 "zrx831@gmail.com" 的管理员已登录。
  - [playwright] 当前页面 应为 挑战工作台。
  - [playwright] 目标面板 应可见。
  - [playwright] 目标中 "ORF Member E2E" 的 "通过" 操作 应可见。
  - [playwright] 目标中 "m2" 的 "拒绝" 操作 应可见。
  - [prisma] 应存在 "ORF Member E2E" 对 目标 的 pending 挑战申请。
  - [prisma] 应存在 "m2" 对 目标 的 pending 挑战申请。
  - [prisma] 目标 的挑战者列表 应不包含 "ORF Member E2E"。
  - [prisma] 目标 的挑战者列表 应不包含 "m2"。

- Action：被测业务动作。
  - [api] 监听 审批通过接口响应。
  - [playwright] 点击 目标中 "ORF Member E2E" 挑战申请的 "通过" 操作。
  - [api] 监听 审批拒绝接口响应。
  - [playwright] 点击 目标中 "m2" 挑战申请的 "拒绝" 操作。

- S1：Action 后状态。
  - [api] 审批通过接口响应 应成功。
  - [api] 审批拒绝接口响应 应成功。
  - [prisma] "ORF Member E2E" 对 目标 的挑战申请状态 应变为 approved。
  - [prisma] 目标 的挑战者列表 应包含 "ORF Member E2E"。
  - [prisma] "m2" 对 目标 的挑战申请状态 应变为 declined。
  - [prisma] 目标 的挑战者列表 应不包含 "m2"。
  - [prisma] 目标 的 flowStatus 应变为 reestimating。
  - [api] 当前会话 应保持 管理员已登录。

- Clean：恢复 B。
  - [prisma] 恢复 目标 的状态 为 原目标状态。
  - [api] 注销 当前登录会话。
  - [playwright] 清空 当前浏览器状态。
  - [api] 应存在 邮箱为 "zrx831@gmail.com" 的管理员 Ory/Kratos 测试身份。
  - [prisma] 应存在 邮箱为 "zrx831@gmail.com"、角色为 admin、状态为 active 的管理员用户。
  - [prisma] 应存在 名称为 "ORF Member E2E"、角色为 member、状态为 active 的普通成员用户。
  - [prisma] 应存在 名称为 "m2"、角色为 member、状态为 active 的普通成员用户。
