# 成员申请挑战审批

## 1. 测试目标

验证：由当前用例独占准备的管理员可以审批两个普通成员提交的挑战申请；通过的成员进入目标挑战者列表，拒绝的成员不进入目标挑战者列表。

实现说明：

- 当前实现：审批接口要求管理员会话；通过申请会把申请人加入目标挑战者列表，拒绝申请不会加入目标挑战者列表。
- 当前用例类型：正向业务用例。
- 当前代码状态：已生成独立 testd 用例，已锁定。

边界：

- 覆盖对象：管理员审批 pending 挑战申请。
- 不覆盖对象：普通成员提交申请入口、普通成员不可审批、目标关闭后的审批限制。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体管理员账号、普通成员账号、目标或申请。
- Setup 产物：邮箱为 "orf-admin-review-application-e2e@orf.local" 的管理员身份、用户和 admin 成员关系；邮箱为 "orf-member-review-approve-e2e@orf.local"、"orf-member-review-reject-e2e@orf.local" 的两个普通成员身份、用户和 member 成员关系；标题为 "E2E-REVIEW-APPLICATION: 成员申请审批" 的本用例审批目标；两个 pending 挑战申请。
- Action 产物：审批通过申请变为 `approved`，审批拒绝申请变为 `declined`，通过申请人成为目标挑战者，目标进入 `reestimating`。
- Clean 产物：删除本用例审批目标及其派生申请，删除本用例独占管理员和两个普通成员身份、用户、成员关系与 session。
- 原状态恢复：目标为当前用例独占资源，Clean 直接删除目标及派生数据，不恢复任何共享目标状态。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例审批目标及其派生数据。

  - [Setup-4] [api] 准备邮箱为 `orf-member-review-approve-e2e@orf.local`、使用固定测试密码的审批通过申请人登录身份。
  - [Setup-5] [prisma] 准备邮箱为 `orf-member-review-approve-e2e@orf.local`、角色为 `member`、状态为 `active` 的审批通过申请人用户和默认团队成员关系。
  - [Setup-6] [api] 准备邮箱为 `orf-member-review-reject-e2e@orf.local`、使用固定测试密码的审批拒绝申请人登录身份。
  - [Setup-7] [prisma] 准备邮箱为 `orf-member-review-reject-e2e@orf.local`、角色为 `member`、状态为 `active` 的审批拒绝申请人用户和默认团队成员关系。

  - [Setup-9] [prisma] 记录本用例审批目标的原始状态为 runtime.reviewTarget。
  - [Setup-10] [prisma] 创建 "ORF Member Review Approve E2E" 对本用例审批目标的 pending 挑战申请。
  - [Setup-11] [prisma] 创建 "ORF Member Review Reject E2E" 对本用例审批目标的 pending 挑战申请。
  - [Setup-12] [api] 撤销管理员登录身份可能残留的登录会话。
  - [Setup-13] [api] 撤销审批通过申请人登录身份可能残留的登录会话。
  - [Setup-14] [api] 撤销审批拒绝申请人登录身份可能残留的登录会话。
  - [Setup-15] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-16] [playwright] 打开 ORF 登录页。
  - [Setup-17] [playwright] 在邮箱输入框输入管理员固定测试邮箱。
  - [Setup-18] [playwright] 在密码输入框输入管理员固定测试密码。

  - [Setup-21] [playwright] 打开 挑战工作台。
  - [Setup-22] [playwright] 切换到 "所有挑战" 视图。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-admin-review-application-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。

  - [S1-5] [prisma] "ORF Member Review Reject E2E" 对本用例审批目标的挑战申请状态 应变为 `declined`。
  - [S1-6] [prisma] 本用例审批目标的挑战者列表 应不包含 "ORF Member Review Reject E2E"。
