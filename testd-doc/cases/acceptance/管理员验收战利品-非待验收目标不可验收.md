# 管理员验收战利品-非待验收目标不可验收

## 1. 测试目标

验证：管理员只能验收待验收目标；发布阶段、评估阶段、实施未提交战利品和已结算四类非待验收目标在挑战工作台中不提供验收战利品入口，数据库验收状态和积分流水不变化。

边界：

- 覆盖对象：管理员不可验收非待验收目标。
- 不覆盖对象：管理员验收待验收目标、普通成员不可验收、成员提交战利品、成员提交匿名互评、积分排行榜展示。
- 依赖对象：[管理员验收战利品](管理员验收战利品.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体管理员账号、目标、战利品、指标或积分流水。
- Setup 产物：邮箱为 `orf-admin-review-loot-state-forbidden-e2e@orf.local` 的管理员认证身份、用户和默认团队成员关系；四个本用例非待验收目标：发布阶段目标、评估阶段目标、实施未提交战利品目标、已结算目标；四个目标的挑战者均为 `ORF Review Loot State Challenger E2E`；已结算目标存在标题为 `E2E-REVIEW-LOOT-STATE-FORBIDDEN: 已结算前置指标` 且积分为 `30` 的前置指标，以及内容为 `E2E-REVIEW-LOOT-STATE-FORBIDDEN-BODY: 已结算前置战利品` 的前置战利品；管理员已登录后的页面状态。
- Action 产物：管理员进入挑战工作台并切换到所有挑战视图后的页面状态。
- Clean 产物：删除本用例四个非待验收目标、已结算前置指标、已结算前置战利品、测试积分流水、管理员认证身份、用户、成员关系与 session。
- 原状态恢复：目标、指标、战利品和账号均为当前用例独占资源，Clean 直接删除，不恢复任何共享目标状态。
