# 成员提交匿名互评

## 1. 测试目标

验证：挑战成员可以在已提交战利品的目标中提交匿名互评；提交后，系统保存该成员对目标的贡献比例评价。

边界：

- 覆盖对象：挑战成员提交匿名互评。
- 不覆盖对象：非参与成员不可互评、管理员验收、贡献分歧处理、分数结算。
- B 基础数据：预置普通成员账号 "orf-member-e2e@orf.local"。
- Setup 产物：submitted 目标。
- Setup 产物：目标 的已提交测试战利品。
- Clean 产物：本用例创建的测试匿名互评和测试战利品。
- Clean 产物：目标 的原始状态。

## 2. 状态模型

- B：基准状态。
  - [api] 前端服务 应可用。
  - [api] 后端服务 应可用。
  - [api] 前端登录页入口 应可访问。
  - [api] 当前会话查询接口 应可访问。
  - [prisma] ORF 数据库 应可连接。
  - [api] Ory/Kratos Admin API 应可访问。
  - [api] Ory/Kratos Public API 应可访问。
  - [api] 应存在 邮箱为 "orf-member-e2e@orf.local" 的普通成员 Ory/Kratos 测试身份。
  - [prisma] 应存在 邮箱为 "orf-member-e2e@orf.local"、角色为 member、状态为 active 的普通成员用户。
  - [prisma] 应存在 一个可构造成员提交匿名互评起点的目标。
  - [prisma] 应不存在 内容为 "E2E-PEER-LOOT-BODY: 匿名互评前置战利品" 的测试战利品。
  - [prisma] 应不存在 reviewer 为 "ORF Member E2E" 的测试匿名互评。
  - [api] 当前会话 应为 未登录。
  - [playwright] 当前浏览器 应不存在 登录 cookie。
  - [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [playwright] 清空 当前浏览器状态。
  - [prisma] 选择 一个可构造成员提交匿名互评起点的目标 作为 目标。
  - [prisma] 记录 目标 的原始状态 作为 原目标状态。
  - [prisma] 更新 目标 的 flowStatus 为 submitted。
  - [prisma] 更新 目标 的挑战者列表 为 普通成员。
  - [prisma] 创建 目标 的已提交测试战利品。
  - [playwright] 打开 "/auth" 登录页。
  - [playwright] 填写 Email 输入框 为 普通成员邮箱。
  - [playwright] 填写 Password 输入框 为 普通成员密码。
  - [playwright] 点击 "Sign In" 登录操作。
  - [api] 当前会话 应为 普通成员已登录。
  - [playwright] 打开 目标战利品页面。

- S0：Action 前状态。
  - [api] 当前会话 应为 邮箱为 "orf-member-e2e@orf.local" 的普通成员已登录。
  - [playwright] 当前页面 应为 目标战利品页面。
  - [playwright] 匿名互评表单 应可见。
  - [prisma] 目标 的 flowStatus 应为 submitted。
  - [prisma] 目标 的挑战者列表 应包含 普通成员。
  - [prisma] 目标 应存在 测试战利品。
  - [prisma] 应不存在 普通成员 对 目标 的测试匿名互评。

- Action：被测业务动作。
  - [playwright] 填写 普通成员贡献比例输入框 为 "1"。
  - [api] 监听 提交匿名互评接口响应。
  - [playwright] 点击 "提交匿名互评" 操作。
  - [api] 记录 提交匿名互评接口返回的互评 作为 提交匿名互评结果。

- S1：Action 后状态。
  - [api] 提交匿名互评接口响应 应成功。
  - [api] 提交匿名互评结果 的 reviewer 应为 普通成员。
  - [api] 提交匿名互评结果 的 allocations 应包含 普通成员贡献比例 "1"。
  - [prisma] 应存在 普通成员 对 目标 的测试匿名互评。
  - [api] 当前会话 应保持 普通成员已登录。

- Clean：恢复 B。
  - [prisma] 删除 本用例创建的测试匿名互评。
  - [prisma] 删除 本用例创建的测试战利品。
  - [prisma] 恢复 目标 的状态 为 原目标状态。
  - [api] 注销 当前登录会话。
  - [playwright] 清空 当前浏览器状态。
  - [api] 应存在 邮箱为 "orf-member-e2e@orf.local" 的普通成员 Ory/Kratos 测试身份。
  - [prisma] 应存在 邮箱为 "orf-member-e2e@orf.local"、角色为 member、状态为 active 的普通成员用户。
