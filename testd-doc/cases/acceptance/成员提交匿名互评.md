# 成员提交匿名互评

## 1. 测试目标

验证：本用例独占目标的两个挑战成员进入匿名互评范围；提交成员可以为自己和协作成员填写 0 到 100 之间的贡献百分比并提交匿名互评；提交后，前端只向本地结算服务发送加密匿名互评信封，ORF 服务端不保存原始匿名互评数据。

边界：

- 覆盖对象：挑战成员提交匿名互评。
- 不覆盖对象：非参与成员不可互评、管理员验收、贡献分歧处理、分数结算。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：邮箱为 `orf-member-submit-peer-review-e2e@orf.local` 的提交成员身份和用户、邮箱为 `orf-peer-submit-peer-review-e2e@orf.local` 的协作成员身份和用户、默认团队成员关系、标题为 `E2E-MEMBER-SUBMIT-PEER-REVIEW: 目标前置` 的独占 submitted 目标、包含提交成员和协作成员的目标挑战者关系，以及内容为 `E2E-PEER-LOOT-BODY: 匿名互评前置战利品` 的前置战利品。
- Action 产物：本地结算服务收到的加密匿名互评提交。
- Clean 产物：删除本用例可能残留的服务端原始互评、测试战利品、独占目标、提交成员和协作成员的身份、用户和成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例普通成员服务端原始匿名互评记录。
  - [Setup-2] [prisma] 删除可能残留的内容为 `E2E-PEER-LOOT-BODY: 匿名互评前置战利品` 的测试战利品。
  - [Setup-3] [prisma] 删除可能残留的标题为 `E2E-MEMBER-SUBMIT-PEER-REVIEW: 目标前置` 的本用例目标及其派生数据。
  - [Setup-4] [api] 准备邮箱为 `orf-member-submit-peer-review-e2e@orf.local`、使用固定测试密码的普通成员登录身份。
  - [Setup-5] [prisma] 准备邮箱为 `orf-member-submit-peer-review-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户和默认团队成员关系。
  - [Setup-6] [api] 准备邮箱为 `orf-peer-submit-peer-review-e2e@orf.local`、使用固定测试密码的协作成员登录身份。
  - [Setup-7] [prisma] 准备邮箱为 `orf-peer-submit-peer-review-e2e@orf.local`、角色为 `member`、状态为 `active` 的协作成员用户和默认团队成员关系。
  - [Setup-8] [prisma] 创建 本用例目标，标题为 `E2E-MEMBER-SUBMIT-PEER-REVIEW: 目标前置`、流转状态为 `submitted`。
  - [Setup-9] [prisma] 记录 本用例目标。
  - [Setup-10] [prisma] 设置 本用例目标的挑战者包含提交成员。
  - [Setup-11] [prisma] 设置 本用例目标的挑战者包含协作成员。
  - [Setup-12] [prisma] 设置 本用例目标为已提交战利品状态。
  - [Setup-13] [prisma] 创建 本用例目标的前置测试战利品，内容为 `E2E-PEER-LOOT-BODY: 匿名互评前置战利品`。
  - [Setup-14] [api] 撤销普通成员登录身份可能残留的登录会话。
  - [Setup-15] [api] 撤销协作成员登录身份可能残留的登录会话。
  - [Setup-16] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-17] [playwright] 打开 ORF 登录页。
  - [Setup-18] [playwright] 在邮箱输入框输入普通成员固定测试邮箱。
  - [Setup-19] [playwright] 在密码输入框输入普通成员固定测试密码。
  - [Setup-20] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-21] [api] 当前会话 应为 普通成员的已登录会话。
  - [Setup-22] [playwright] 打开 本用例目标战利品页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-member-submit-peer-review-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 本用例目标战利品页面。
  - [S0-3] [playwright] 匿名互评表单 应可见。
  - [S0-4] [prisma] 本用例目标 应为 流转状态 `submitted` 且战利品提交时间已存在。
  - [S0-5] [prisma] 本用例目标的挑战者 应包含 提交成员。
  - [S0-6] [prisma] 本用例目标的挑战者 应包含 协作成员。
  - [S0-7] [prisma] 本用例目标 应存在 内容为 `E2E-PEER-LOOT-BODY: 匿名互评前置战利品` 的测试战利品。
  - [S0-8] [prisma] 本用例目标 应不存在 提交成员提交的服务端原始匿名互评。

- Action：被测业务动作。
  - [Action-1] [playwright] 在提交成员贡献百分比输入框 输入 `50`。
  - [Action-2] [playwright] 在协作成员贡献百分比输入框 输入 `50`。
  - [Action-3] [playwright] 点击 "提交匿名互评" 提交匿名互评操作。
  - [Action-4] [api] 记录 本地结算服务收到的加密匿名互评提交。

- S1：Action 后状态。
  - [S1-1] [api] 提交后的匿名互评请求 应发送到 本地结算服务。
  - [S1-2] [api] 本地结算服务 应接受 加密匿名互评提交。
  - [S1-3] [api] 提交后的匿名互评请求 应包含 加密正文。
  - [S1-4] [api] 提交后的匿名互评请求 应包含 加密数据密钥。
  - [S1-5] [prisma] ORF 数据库 应不存在 提交成员提交的原始匿名互评。
  - [S1-6] [api] 提交后的匿名互评加密信封 应不包含 提交成员明文。
  - [S1-7] [api] 提交后的匿名互评加密信封 应不包含 协作成员明文。
  - [S1-8] [api] 当前会话 应仍为 普通成员的已登录会话。

- Clean：恢复 B。

  - [Clean-3] [prisma] 删除 本用例独占目标及其派生数据。

  - [Clean-5] [playwright] 离开当前 ORF 前端页面。
  - [Clean-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-7] [api] 撤销普通成员登录身份的残留登录会话。
  - [Clean-8] [api] 撤销协作成员登录身份的残留登录会话。
  - [Clean-9] [api] 删除邮箱为 `orf-member-submit-peer-review-e2e@orf.local` 的普通成员登录身份。
  - [Clean-10] [api] 删除邮箱为 `orf-peer-submit-peer-review-e2e@orf.local` 的协作成员登录身份。

  - [Clean-15] [prisma] 应不存在 本用例提交成员提交的服务端原始匿名互评。
  - [Clean-16] [prisma] 应不存在 内容为 `E2E-PEER-LOOT-BODY: 匿名互评前置战利品` 的测试战利品。
