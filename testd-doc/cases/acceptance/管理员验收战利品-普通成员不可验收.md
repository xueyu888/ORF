# 管理员验收战利品-普通成员不可验收

## 1. 测试目标

验证：目标处于待验收状态且存在普通成员提交的战利品时，普通成员在挑战工作台中看不到验收战利品入口；页面、接口和数据库均不产生验收结算结果。

边界：

- 覆盖对象：普通成员不可验收战利品。
- 不覆盖对象：管理员验收战利品、非待验收目标不可验收、成员提交战利品、成员提交匿名互评、积分排行榜展示。
- 依赖对象：[管理员验收战利品](管理员验收战利品.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体普通成员账号、目标、战利品、指标或积分流水。
- Setup 产物：邮箱为 `orf-member-review-loot-forbidden-e2e@orf.local` 的普通成员认证身份、用户和默认团队成员关系，标题为 `E2E-REVIEW-LOOT-MEMBER-FORBIDDEN: 待验收目标` 的本用例待验收目标，标题为 `E2E-REVIEW-LOOT-MEMBER-FORBIDDEN: 前置指标` 且指标积分为 `42` 的前置指标，内容为 `E2E-REVIEW-LOOT-MEMBER-FORBIDDEN-BODY: 普通成员提交的战利品说明` 的前置战利品，以及普通成员已登录后的页面状态。
- Action 产物：普通成员进入挑战工作台后的页面状态。
- Clean 产物：删除本用例待验收目标、前置指标、前置战利品、测试积分流水、普通成员认证身份、用户、成员关系与 session。
- 原状态恢复：目标、指标、战利品和账号均为当前用例独占资源，Clean 直接删除，不恢复任何共享目标状态。
