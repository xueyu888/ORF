# 管理员验收战利品

## 1. 测试目标

验证：本用例独占的管理员可以验收成员提交的战利品并完成结算；验收后目标进入已结算状态，并生成成员积分流水。

边界：

- 覆盖对象：管理员验收战利品并结算。
- 不覆盖对象：普通成员不可验收、战利品提交、匿名互评分歧处理、排行榜排序。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：独占管理员身份/用户/成员关系、独占普通成员身份/用户/成员关系、标题为 `E2E-ADMIN-REVIEW-LOOT: 目标前置` 的 submitted 目标、测试指标和测试战利品。
- Action 产物：reason 为 `E2E-REVIEW-LOOT: 管理员验收战利品` 的测试积分流水，以及目标结算状态。
- Clean 产物：删除本用例创建的测试积分流水、测试战利品、测试指标、独占目标、管理员和普通成员身份、用户与成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的 reason 为 `E2E-REVIEW-LOOT: 管理员验收战利品` 的测试积分流水。
  - [Setup-2] [prisma] 删除可能残留的内容为 `E2E-REVIEW-LOOT-BODY: 管理员验收战利品完成说明` 的测试战利品。
  - [Setup-3] [prisma] 删除可能残留的标题为 `E2E-REVIEW-RESULT: 管理员验收战利品指标` 的测试指标。
  - [Setup-4] [prisma] 删除可能残留的标题为 `E2E-ADMIN-REVIEW-LOOT: 目标前置` 的本用例目标及其派生数据。
  - [Setup-5] [api] 准备邮箱为 `orf-admin-review-loot-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-6] [prisma] 准备邮箱为 `orf-admin-review-loot-e2e@orf.local`、角色为 `admin`、状态为 `active` 的管理员用户和默认团队成员关系。
  - [Setup-7] [api] 准备邮箱为 `orf-member-admin-review-loot-e2e@orf.local`、使用固定测试密码的普通成员登录身份。
  - [Setup-8] [prisma] 准备邮箱为 `orf-member-admin-review-loot-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户和默认团队成员关系。
  - [Setup-9] [prisma] 创建标题为 `E2E-ADMIN-REVIEW-LOOT: 目标前置` 的本用例独占目标。
  - [Setup-10] [prisma] 记录 本用例独占目标。
  - [Setup-11] [prisma] 设置本用例目标为 `submitted`，记录 lootSubmittedAt，并设置挑战者列表仅包含普通成员。
  - [Setup-12] [prisma] 创建本用例目标的测试指标，指标积分为 `42`。
  - [Setup-13] [prisma] 创建本用例目标的测试战利品，并声明测试指标已完成。
  - [Setup-14] [api] 撤销管理员登录身份可能残留的登录会话。
  - [Setup-15] [api] 撤销普通成员登录身份可能残留的登录会话。
  - [Setup-16] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-17] [playwright] 打开 ORF 登录页。
  - [Setup-18] [playwright] 在邮箱输入框输入管理员固定测试邮箱。
  - [Setup-19] [playwright] 在密码输入框输入管理员固定测试密码。
  - [Setup-20] [playwright] 点击 `Sign In` 登录操作。
  - [Setup-21] [api] 当前会话 应为 管理员的已登录会话。
  - [Setup-22] [playwright] 打开 本用例目标战利品页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱 `orf-admin-review-loot-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 本用例目标战利品页面。
  - [S0-3] [playwright] 验收战利品表单 应可见。
  - [S0-4] [prisma] 本用例目标流转状态 应为 `submitted` 且战利品提交时间已存在。
  - [S0-5] [prisma] 本用例目标 应存在 测试指标。
  - [S0-6] [prisma] 本用例目标 应存在 测试战利品。

  - [Action-2] [api] 监听 验收战利品请求响应。
  - [Action-3] [playwright] 点击 `验收并结算` 操作。

- S1：Action 后状态。
  - [S1-1] [api] 验收战利品结果 应成功。
  - [S1-2] [prisma] 本用例目标流转状态 应为 `settled`，验收结果应为 `completed`，目标结算分数应为 `42`。

  - [S1-4] [playwright] 当前页面 应为 统计页面。
  - [S1-5] [api] 当前会话 应仍为 管理员的已登录会话。
