# 管理员验收战利品

## 1. 测试目标

验证：管理员可以在待验收目标中验收普通成员提交的战利品；验收完成后，目标进入已结算状态，测试指标验收结果为完成，并为挑战成员生成积分流水。

边界：

- 覆盖对象：管理员验收战利品并结算。
- 不覆盖对象：普通成员不可验收、成员提交战利品、匿名互评分歧处理、排行榜排序。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：邮箱为 `orf-admin-review-loot-e2e@orf.local` 的管理员认证身份、用户和默认团队成员关系，邮箱为 `orf-member-admin-review-loot-e2e@orf.local` 的普通成员认证身份、用户和默认团队成员关系，标题为 `E2E-ADMIN-REVIEW-LOOT: 目标前置` 且挑战者账号身份绑定到该普通成员的本用例待验收目标，标题为 `E2E-REVIEW-RESULT: 管理员验收战利品指标` 且指标积分为 `30` 的测试指标，内容为 `E2E-REVIEW-LOOT-BODY: 管理员验收战利品完成说明` 的测试战利品，以及管理员已登录并打开任务模块下的本用例目标战利品页面后的页面状态。
- Action 产物：管理员提交本用例目标战利品验收表单后的验收提交结果。
- Clean 产物：删除本用例创建的测试积分流水、测试战利品、测试指标、独占目标、管理员和普通成员认证身份、用户与成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除本用例残留的测试积分流水，积分流水 reason 为 `E2E-REVIEW-LOOT: 管理员验收战利品`。
  - [Setup-2] [prisma] 删除内容为 `E2E-REVIEW-LOOT-BODY: 管理员验收战利品完成说明` 的本用例残留测试战利品。
  - [Setup-3] [prisma] 删除标题为 `E2E-REVIEW-RESULT: 管理员验收战利品指标` 的本用例残留测试指标。
  - [Setup-4] [prisma] 删除标题为 `E2E-ADMIN-REVIEW-LOOT: 目标前置` 的本用例残留目标及其派生数据。
  - [Setup-5] [api] 准备管理员认证身份，邮箱为 `orf-admin-review-loot-e2e@orf.local`，密码为固定测试密码。
  - [Setup-6] [prisma] 准备管理员用户和默认团队成员关系，邮箱为 `orf-admin-review-loot-e2e@orf.local`、角色为 `admin`、状态为 `active`。
  - [Setup-7] [api] 准备普通成员认证身份，邮箱为 `orf-member-admin-review-loot-e2e@orf.local`，密码为固定测试密码。
  - [Setup-8] [prisma] 准备普通成员用户和默认团队成员关系，邮箱为 `orf-member-admin-review-loot-e2e@orf.local`、角色为 `member`、状态为 `active`。
  - [Setup-9] [prisma] 创建本用例待验收目标，标题为 `E2E-ADMIN-REVIEW-LOOT: 目标前置`。
  - [Setup-10] [prisma] 设置本用例待验收目标为 `submitted`，阶段为 `goalFrozen`，战利品提交时间已存在，挑战者账号身份仅包含普通成员。
  - [Setup-11] [prisma] 创建本用例待验收目标的测试指标，标题为 `E2E-REVIEW-RESULT: 管理员验收战利品指标`，指标积分为 `30`。
  - [Setup-12] [prisma] 创建普通成员提交到本用例待验收目标的测试战利品，测试指标声明为 `completed`。
  - [Setup-13] [api] 撤销管理员认证身份的残留登录会话。
  - [Setup-14] [api] 撤销普通成员认证身份的残留登录会话。
  - [Setup-15] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-16] [playwright] 打开 ORF 登录页。
  - [Setup-17] [playwright] 在邮箱输入框输入管理员固定测试邮箱。
  - [Setup-18] [playwright] 在密码输入框输入管理员固定测试密码。
  - [Setup-19] [playwright] 点击 `Sign In` 登录操作。
  - [Setup-20] [api] 当前会话 应为 管理员的已登录会话。
  - [Setup-21] [playwright] 管理员打开任务模块下的本用例目标战利品页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱 `orf-admin-review-loot-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 任务模块下的本用例目标战利品页面。
  - [S0-3] [playwright] 验收战利品表单 应可见。
  - [S0-4] [prisma] 本用例待验收目标 应为 `submitted`，阶段为 `goalFrozen`，战利品提交时间已存在，挑战者账号身份仅包含普通成员。
  - [S0-5] [prisma] 本用例待验收目标 应存在 指标积分为 `30` 的测试指标。

- Action：被测业务动作。
  - [Action-1] [playwright] 管理员在 `验收说明` 输入框输入测试验收说明。
  - [Action-2] [playwright] 管理员点击 `验收并结算` 操作。

- S1：Action 后状态。

  - [S1-2] [prisma] 本用例待验收目标的流转状态 应为 `settled`，验收结果 应为 `completed`，目标基础分数 应为 `30`，目标结算分数 应为 `30`。

  - [S1-4] [prisma] 数据库中 应存在 普通成员对本用例待验收目标的测试积分流水，积分为 `30`，reason 为 `E2E-REVIEW-LOOT: 管理员验收战利品`。
  - [S1-5] [playwright] 当前页面 应为 统计页面。
  - [S1-6] [api] 当前会话 应仍为 管理员的已登录会话。
