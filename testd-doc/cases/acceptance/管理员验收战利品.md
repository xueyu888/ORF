# 管理员验收战利品

## 1. 测试目标

验证：管理员可以验收普通成员提交的战利品；验收后，目标进入已结算状态，并生成成员积分流水。

边界：

- 本用例只验证管理员验收战利品并结算。
- 本用例不验证普通成员不可验收、战利品提交、匿名互评分歧处理或排行榜排序。
- 本用例使用预置管理员账号 "zrx831@gmail.com"。
- Setup 准备 submitted 目标、测试指标和测试战利品，因为它们是 Action 起点。
- Clean 删除 本用例创建的测试积分流水、测试战利品和测试指标。
- Clean 恢复 目标 在 Setup 前记录的原始状态。

## 2. 状态模型

- B：基准状态。
  - [api] 前端服务 应可用。
  - [api] 后端服务 应可用。
  - [api] 健康检查或等价探测 应通过。
  - [prisma] ORF 数据库 应可连接。
  - [api] Ory/Kratos Admin API 应可访问。
  - [api] Ory/Kratos Public API 应可访问。
  - [api] 应存在 邮箱为 "zrx831@gmail.com" 的管理员 Ory/Kratos 测试身份。
  - [prisma] 应存在 邮箱为 "zrx831@gmail.com"、角色为 admin、状态为 active 的管理员用户。
  - [prisma] 应存在 名称为 "ORF Member E2E"、角色为 member、状态为 active 的普通成员用户。
  - [prisma] 应存在 一个可构造管理员验收战利品起点的目标。
  - [prisma] 应不存在 标题为 "E2E-REVIEW-RESULT: 管理员验收战利品指标" 的测试指标。
  - [prisma] 应不存在 内容为 "E2E-REVIEW-LOOT-BODY: 管理员验收战利品完成说明" 的测试战利品。
  - [prisma] 应不存在 reason 为 "E2E-REVIEW-LOOT: 管理员验收战利品" 的测试积分流水。
  - [api] 当前会话 应为 未登录。
  - [playwright] 当前浏览器 应不存在 登录 cookie。
  - [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [playwright] 清空 当前浏览器状态。
  - [prisma] 选择 一个可构造管理员验收战利品起点的目标 作为 目标。
  - [prisma] 记录 目标 的原始状态 作为 原目标状态。
  - [prisma] 更新 目标 的 flowStatus 为 submitted。
  - [prisma] 更新 目标 的挑战者列表 为 普通成员。
  - [prisma] 创建 目标 的测试指标。
  - [prisma] 创建 目标 的测试战利品。
  - [playwright] 打开 "/auth" 登录页。
  - [playwright] 填写 Email 输入框 为 管理员邮箱。
  - [playwright] 填写 Password 输入框 为 管理员密码。
  - [playwright] 点击 "Sign In" 登录操作。
  - [api] 当前会话 应为 管理员已登录。
  - [playwright] 打开 目标战利品页面。

- S0：Action 前状态。
  - [api] 当前会话 应为 邮箱为 "zrx831@gmail.com" 的管理员已登录。
  - [playwright] 当前页面 应为 目标战利品页面。
  - [playwright] 验收战利品表单 应可见。
  - [prisma] 目标 的 flowStatus 应为 submitted。
  - [prisma] 目标 应存在 测试指标。
  - [prisma] 目标 应存在 测试战利品。
  - [prisma] 应不存在 普通成员 对 目标 的测试积分流水。

- Action：被测业务动作。
  - [api] 监听 验收战利品接口响应。
  - [playwright] 点击 "验收并结算" 操作。

- S1：Action 后状态。
  - [api] 验收战利品接口响应 应成功。
  - [prisma] 目标 的 flowStatus 应变为 settled。
  - [prisma] 目标 的 acceptedResult 应变为 completed。
  - [prisma] 目标 的 objectiveSettlementPoints 应为 42。
  - [prisma] 应存在 普通成员 对 目标 的测试积分流水。
  - [playwright] 当前页面 应为 统计页面。
  - [api] 当前会话 应保持 管理员已登录。

- Clean：恢复 B。
  - [prisma] 删除 本用例创建的测试积分流水。
  - [prisma] 删除 本用例创建的测试战利品。
  - [prisma] 删除 本用例创建的测试指标。
  - [prisma] 恢复 目标 的状态 为 原目标状态。
  - [api] 注销 当前登录会话。
  - [playwright] 清空 当前浏览器状态。
  - [api] 应存在 邮箱为 "zrx831@gmail.com" 的管理员 Ory/Kratos 测试身份。
  - [prisma] 应存在 邮箱为 "zrx831@gmail.com"、角色为 admin、状态为 active 的管理员用户。
  - [prisma] 应存在 名称为 "ORF Member E2E"、角色为 member、状态为 active 的普通成员用户。
