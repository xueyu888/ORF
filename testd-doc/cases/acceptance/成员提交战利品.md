# 成员提交战利品

## 1. 测试目标

验证：普通成员作为目标挑战者时，可以在目标实施阶段提交战利品；提交后，完成说明、指标证据和自测报告链接在接口与数据库中保存，目标进入待验收状态。

边界：

- 本用例只验证挑战成员提交战利品，不验证非挑战成员不可提交、匿名互评、管理员验收、分数结算或战利品编辑。
- 本用例使用预置普通成员账号 `orf-member-e2e@orf.local`，角色为 `member`，状态为 `active`。
- Setup 记录并改造一个运行时目标，使目标位于 Action 起点：目标为 `frozen`，stage 为 `goalFrozen`，挑战者包含该普通成员，且存在一个可验收指标。
- 本用例创建固定标题的测试指标，提交固定内容的测试战利品，Clean 删除该战利品和指标，并恢复目标在 Setup 前的原始状态。

## 2. 状态模型

- B：测试开始前和 Clean 后都必须满足的基准状态。
  - [api] 前端和后端服务 应为 可用。
  - [api] 健康检查或等价探测 应为 通过。
  - [prisma] ORF 数据库 应为 可连接。
  - [api] Ory/Kratos Admin/Public API 应为 可访问。
  - [api] Ory/Kratos 中 应存在 邮箱为 `orf-member-e2e@orf.local` 的普通成员测试身份。
  - [prisma] 应存在 邮箱为 `orf-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户。
  - [prisma] 应存在 一个可构造成员提交战利品起点的目标。
  - [prisma] 应不存在 标题为 `E2E-LOOT-RESULT: 成员提交战利品指标` 的测试指标。
  - [prisma] 应不存在 内容为 `E2E-LOOT-BODY: 成员提交战利品完成说明` 的测试战利品。
  - [api] 当前会话 应为 未登录。
  - [playwright] 浏览器 应不存在 登录 cookie。
  - [playwright] 浏览器 storage 应不包含 登录态。

- Setup：如何从 B 构造 S0？
  - [playwright] 清空 浏览器状态。
  - [prisma] 选择 一个可构造成员提交战利品起点的目标。
  - [prisma] 记录 目标 的原始状态。
  - [prisma] 设置 目标 flowStatus 为 `frozen`。
  - [prisma] 设置 目标 stage 为 `goalFrozen`。
  - [prisma] 设置 目标 挑战者列表包含普通成员。
  - [prisma] 为 目标 创建 一个测试指标。
  - [playwright] 打开 `/auth` 登录页。
  - [playwright] 在 Email 输入框 输入 普通成员邮箱。
  - [playwright] 在 Password 输入框 输入 普通成员密码。
  - [playwright] 点击 `Sign In` 登录操作。
  - [api] 当前会话 应为 普通成员已登录。
  - [playwright] 打开 目标战利品提交页。

- S0：Action 前必须满足什么条件？
  - [api] 当前会话 应为 邮箱 `orf-member-e2e@orf.local` 的普通成员已登录。
  - [playwright] 当前页面 应为 目标战利品提交页。
  - [playwright] 战利品提交表单 应可见。
  - [prisma] 目标 flowStatus 应为 `frozen`。
  - [prisma] 目标 stage 应为 `goalFrozen`。
  - [prisma] 目标 的挑战者列表 应包含 普通成员。
  - [prisma] 目标 应存在 测试指标。
  - [prisma] 目标 应不存在 测试战利品。

- Action：本次测试唯一要验证的业务动作是什么？
  - [playwright] 在 `完成说明` 输入框 输入 测试完成说明。
  - [playwright] 在测试指标证据输入框 输入 测试证据文本。
  - [playwright] 在 `自测报告` 输入框 输入 包含链接的测试报告内容。
  - [playwright] 在点击 `提交` 前注册 提交战利品接口响应捕获。
  - [playwright] 点击 `提交` 操作。
  - [api] 记录 提交战利品接口返回的战利品。

- S1：Action 后系统应该变成什么状态？
  - [api] 提交战利品接口响应 应成功。
  - [api] 提交战利品接口返回的战利品 应属于 目标。
  - [api] 提交战利品接口返回的战利品 submittedBy 应为 普通成员。
  - [api] 提交战利品接口返回的完成说明 应为 测试完成说明。
  - [api] 提交战利品接口返回的自测报告 应包含 测试报告链接。
  - [api] 提交战利品接口返回的指标证据 应包含 测试证据文本。
  - [prisma] 数据库中 应存在 该测试战利品。
  - [prisma] 目标 flowStatus 应为 `submitted`。
  - [api] 当前会话 应仍为 普通成员已登录。

- Clean：如何清理并恢复到 B？
  - [prisma] 删除 本用例创建的测试战利品。
  - [prisma] 删除 本用例创建的测试指标。
  - [prisma] 恢复 目标 在 Setup 前记录的原始状态。
  - [api] 退出 当前登录态。
  - [playwright] 清空 浏览器状态。
  - [api] Ory/Kratos 中 应仍存在 普通成员测试身份。
  - [prisma] 应仍存在 邮箱为 `orf-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户。
