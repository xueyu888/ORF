# 成员提交战利品

## 1. 测试目标

验证：本用例独占的目标挑战成员可以在实施阶段提交战利品；提交后，完成说明、指标证据和自测报告链接被保存，目标进入待验收状态。

边界：

- 覆盖对象：挑战成员提交战利品。
- 不覆盖对象：非挑战成员不可提交、匿名互评、管理员验收、分数结算、战利品编辑。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：邮箱为 `orf-member-submit-loot-e2e@orf.local` 的普通成员身份、用户、默认团队成员关系、标题为 `E2E-MEMBER-SUBMIT-LOOT: 目标前置` 的独占目标、目标挑战者关系和标题为 `E2E-LOOT-RESULT: 成员提交战利品指标` 的前置指标。
- Action 产物：内容为 `E2E-LOOT-BODY: 成员提交战利品完成说明` 的测试战利品，以及目标进入 `submitted` 状态。
- Clean 产物：删除本用例创建的测试战利品、测试指标、独占目标、普通成员身份、用户和成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的内容为 `E2E-LOOT-BODY: 成员提交战利品完成说明` 的测试战利品。
  - [Setup-2] [prisma] 删除可能残留的标题为 `E2E-LOOT-RESULT: 成员提交战利品指标` 的测试指标。
  - [Setup-3] [prisma] 删除可能残留的标题为 `E2E-MEMBER-SUBMIT-LOOT: 目标前置` 的本用例目标及其派生数据。
  - [Setup-4] [api] 准备邮箱为 `orf-member-submit-loot-e2e@orf.local`、使用固定测试密码的普通成员登录身份。
  - [Setup-5] [prisma] 准备邮箱为 `orf-member-submit-loot-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户和默认团队成员关系。
  - [Setup-6] [prisma] 创建标题为 `E2E-MEMBER-SUBMIT-LOOT: 目标前置`、流转状态为 `frozen`、阶段为 `goalFrozen` 的本用例独占目标。
  - [Setup-7] [prisma] 记录 本用例独占目标。
  - [Setup-8] [prisma] 设置本用例目标的挑战者包含普通成员，并保持实施阶段待提交战利品状态。
  - [Setup-9] [prisma] 为本用例目标创建标题为 `E2E-LOOT-RESULT: 成员提交战利品指标` 的前置指标。
  - [Setup-10] [api] 撤销普通成员登录身份可能残留的登录会话。
  - [Setup-11] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-12] [playwright] 打开 ORF 登录页。
  - [Setup-13] [playwright] 在邮箱输入框输入普通成员固定测试邮箱。
  - [Setup-14] [playwright] 在密码输入框输入普通成员固定测试密码。
  - [Setup-15] [playwright] 点击 `Sign In` 登录操作。
  - [Setup-16] [api] 当前会话 应为 普通成员的已登录会话。
  - [Setup-17] [playwright] 打开 本用例目标战利品提交页。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱 `orf-member-submit-loot-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 本用例目标战利品提交页。
  - [S0-3] [playwright] 战利品提交表单 应可见。
  - [S0-4] [prisma] 本用例目标 应为 `frozen` / `goalFrozen` 且挑战者包含普通成员。
  - [S0-5] [prisma] 本用例目标 应存在 前置测试指标。
  - [S0-6] [prisma] 本用例目标 应不存在 测试战利品。

- Action：被测业务动作。
  - [Action-1] [playwright] 在 `完成说明` 输入框 输入 测试完成说明。
  - [Action-2] [playwright] 在测试指标证据输入框 输入 测试证据文本。
  - [Action-3] [playwright] 在 `自测报告` 输入框 输入 包含链接的测试报告内容。
  - [Action-4] [api] 监听 提交战利品请求响应。
  - [Action-5] [playwright] 点击 `提交` 操作。
  - [Action-6] [api] 记录 提交战利品结果中的战利品。

- S1：Action 后状态。
  - [S1-1] [api] 提交战利品结果 应成功。
  - [S1-2] [api] 提交战利品结果中的战利品 应属于本用例目标、由普通成员提交，并包含测试完成说明、测试证据文本和测试报告链接。
  - [S1-3] [prisma] 数据库中 应存在 该测试战利品。
  - [S1-4] [prisma] 本用例目标流转状态 应为 `submitted` 且战利品提交时间已存在。
  - [S1-5] [api] 当前会话 应仍为 普通成员的已登录会话。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的测试战利品。
  - [Clean-2] [prisma] 删除 本用例创建的测试指标。
  - [Clean-3] [prisma] 删除 本用例独占目标及其派生数据。
  - [Clean-4] [api] 注销当前登录会话。
  - [Clean-5] [playwright] 离开当前 ORF 前端页面。
  - [Clean-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-7] [api] 撤销普通成员登录身份的残留登录会话。
  - [Clean-8] [api] 删除普通成员登录身份。
  - [Clean-9] [prisma] 删除 普通成员默认团队成员关系。
  - [Clean-10] [prisma] 删除 普通成员用户。
  - [Clean-11] [prisma] 内容为 `E2E-LOOT-BODY: 成员提交战利品完成说明` 的测试战利品 应不存在。
  - [Clean-12] [prisma] 标题为 `E2E-LOOT-RESULT: 成员提交战利品指标` 的测试指标 应不存在。
  - [Clean-13] [prisma] 标题为 `E2E-MEMBER-SUBMIT-LOOT: 目标前置` 的本用例目标 应不存在。
  - [Clean-14] [prisma] 邮箱为 `orf-member-submit-loot-e2e@orf.local` 的普通成员用户 应不存在。
