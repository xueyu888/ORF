# 查看最终分数

## 1. 测试目标

验证：普通成员存在已结算目标积分时，可以在统计页面看到自己的最终积分。

边界：

- 本用例只验证普通成员查看最终积分。
- 本用例不验证管理员验收战利品、积分计算公式、排行榜排序或未结算目标不可查看积分。
- 本用例使用预置普通成员账号 "orf-member-e2e@orf.local"。
- Setup 准备 settled 目标和积分流水，因为它们是 Action 起点。
- Clean 删除 本用例创建的积分流水。
- Clean 恢复 目标 在 Setup 前记录的原始状态。

## 2. 状态模型

- B：基准状态。
  - [api] 前端服务 应可用。
  - [api] 后端服务 应可用。
  - [api] 健康检查或等价探测 应通过。
  - [prisma] ORF 数据库 应可连接。
  - [api] Ory/Kratos Admin API 应可访问。
  - [api] Ory/Kratos Public API 应可访问。
  - [api] 应存在 邮箱为 "orf-member-e2e@orf.local" 的普通成员 Ory/Kratos 测试身份。
  - [prisma] 应存在 邮箱为 "orf-member-e2e@orf.local"、角色为 member、状态为 active 的普通成员用户。
  - [prisma] 应存在 一个可构造最终分数查看起点的目标。
  - [prisma] 应不存在 reason 为 "E2E-FINAL-SCORE: 查看最终分数" 的测试积分流水。
  - [api] 当前会话 应为 未登录。
  - [playwright] 当前浏览器 应不存在 登录 cookie。
  - [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [playwright] 清空 当前浏览器状态。
  - [prisma] 选择 一个可构造最终分数查看起点的目标 作为 目标。
  - [prisma] 记录 目标 的原始状态 作为 原目标状态。
  - [prisma] 更新 目标 的 flowStatus 为 settled。
  - [prisma] 更新 目标 的挑战者列表 为 普通成员。
  - [prisma] 创建 普通成员 对 目标 的测试积分流水。
  - [playwright] 打开 "/auth" 登录页。
  - [playwright] 填写 Email 输入框 为 普通成员邮箱。
  - [playwright] 填写 Password 输入框 为 普通成员密码。
  - [playwright] 点击 "Sign In" 登录操作。
  - [api] 当前会话 应为 普通成员已登录。

- S0：Action 前状态。
  - [api] 当前会话 应为 邮箱为 "orf-member-e2e@orf.local" 的普通成员已登录。
  - [prisma] 目标 的 flowStatus 应为 settled。
  - [prisma] 目标 的挑战者列表 应包含 普通成员。
  - [prisma] 应存在 普通成员 对 目标 的测试积分流水。
  - [playwright] 当前页面 应为 已登录用户可访问页面。

- Action：被测业务动作。
  - [playwright] 打开 "/reports" 统计页面。
  - [playwright] 点击 "全部时间" 时间范围操作。

- S1：Action 后状态。
  - [playwright] 当前页面 应为 统计页面。
  - [playwright] 成员积分排行榜 应可见。
  - [playwright] 成员积分排行榜 应显示 普通成员。
  - [playwright] 成员积分排行榜 应显示 普通成员最终积分 "42.0"。
  - [prisma] 普通成员 对 目标 的测试积分 应为 42。
  - [api] 当前会话 应保持 普通成员已登录。

- Clean：恢复 B。
  - [prisma] 删除 本用例创建的测试积分流水。
  - [prisma] 恢复 目标 的状态 为 原目标状态。
  - [api] 注销 当前登录会话。
  - [playwright] 清空 当前浏览器状态。
  - [api] 应存在 邮箱为 "orf-member-e2e@orf.local" 的普通成员 Ory/Kratos 测试身份。
  - [prisma] 应存在 邮箱为 "orf-member-e2e@orf.local"、角色为 member、状态为 active 的普通成员用户。
