# 查看最终分数

## 1. 测试目标

验证：本用例独占的普通成员可以在统计页面查看已结算目标产生的最终积分。

边界：

- 覆盖对象：普通成员查看最终积分。
- 不覆盖对象：管理员验收战利品、积分计算公式、排行榜排序、未结算目标不可查看积分。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：邮箱为 `orf-member-view-final-score-e2e@orf.local` 的普通成员身份、用户、默认团队成员关系、标题为 `E2E-VIEW-FINAL-SCORE: 目标前置` 的独占 settled 目标，以及 reason 为 `E2E-FINAL-SCORE: 查看最终分数` 的测试积分流水。
- Action 产物：无新增业务资源，只打开统计页面并切换全部时间范围。
- Clean 产物：删除本用例创建的测试积分流水、独占目标、普通成员身份、用户和成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询接口 应可访问。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos Admin/Public API 应可访问。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory session cookie。
  - [B-10] [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的 reason 为 `E2E-FINAL-SCORE: 查看最终分数` 的测试积分流水。
  - [Setup-2] [prisma] 删除可能残留的标题为 `E2E-VIEW-FINAL-SCORE: 目标前置` 的本用例目标及其派生数据。
  - [Setup-3] [api] 准备邮箱为 `orf-member-view-final-score-e2e@orf.local` 的普通成员登录身份，并设置固定测试密码。
  - [Setup-4] [prisma] 准备邮箱为 `orf-member-view-final-score-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户和默认团队成员关系。
  - [Setup-5] [prisma] 创建标题为 `E2E-VIEW-FINAL-SCORE: 目标前置` 的本用例独占目标。
  - [Setup-6] [prisma] 记录本用例独占目标为 runtime.finalScoreTarget。
  - [Setup-7] [prisma] 设置本用例目标为 `settled`，挑战者包含普通成员，目标结算积分为 `42`。
  - [Setup-8] [prisma] 创建普通成员对本用例目标的测试积分流水，积分为 `42`。
  - [Setup-9] [api] 撤销普通成员登录身份可能残留的 Ory session。
  - [Setup-10] [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [Setup-11] [playwright] 打开 登录页。
  - [Setup-12] [playwright] 在邮箱输入框输入普通成员测试邮箱。
  - [Setup-13] [playwright] 在密码输入框输入普通成员测试密码。
  - [Setup-14] [playwright] 点击 `Sign In` 登录操作。
  - [Setup-15] [api] 当前会话 应为 普通成员已登录。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱 `orf-member-view-final-score-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [S0-2] [prisma] 本用例目标 应为 `settled` 且挑战者包含普通成员。
  - [S0-3] [prisma] 数据库中 应存在 普通成员对本用例目标的测试积分流水，积分为 `42`。

- Action：被测业务动作。
  - [Action-1] [playwright] 打开 统计页面。
  - [Action-2] [playwright] 点击 `全部时间` 时间范围操作。

- S1：Action 后状态。
  - [S1-1] [playwright] 当前页面 应为 统计页面。
  - [S1-2] [playwright] 成员积分排行榜 应显示普通成员和最终积分 `42.0`。
  - [S1-3] [prisma] 数据库中 普通成员对本用例目标的测试积分流水 应保持为 `42`。
  - [S1-4] [api] 当前会话 应仍为 普通成员已登录。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的测试积分流水。
  - [Clean-2] [prisma] 删除 本用例独占目标及其派生数据。
  - [Clean-3] [api] 退出 当前登录态。
  - [Clean-4] [playwright] 停止 当前页面运行态。
  - [Clean-5] [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [Clean-6] [api] 撤销普通成员登录身份的 Ory session。
  - [Clean-7] [api] 删除 普通成员 Ory 身份。
  - [Clean-8] [prisma] 删除 普通成员默认团队成员关系。
  - [Clean-9] [prisma] 删除 普通成员用户。
  - [Clean-10] [prisma] reason 为 `E2E-FINAL-SCORE: 查看最终分数` 的测试积分流水 应不存在。
  - [Clean-11] [prisma] 标题为 `E2E-VIEW-FINAL-SCORE: 目标前置` 的本用例目标 应不存在。
  - [Clean-12] [prisma] 邮箱为 `orf-member-view-final-score-e2e@orf.local` 的普通成员用户 应不存在。
