# 查看最终分数

## 1. 测试目标

验证：普通成员可以在统计页面查看所有成员的最终积分汇总，包含与当前成员无共同目标的成员积分。

边界：

- 覆盖对象：普通成员查看所有成员最终积分汇总，包含与当前成员无共同目标的成员积分。
- 不覆盖对象：管理员验收战利品、积分计算公式、排行榜排序、未结算目标不可查看积分。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：邮箱为 `orf-member-view-final-score-primary-e2e@orf.local` 的登录普通成员身份、用户、默认团队成员关系，邮箱为 `orf-member-view-final-score-other-e2e@orf.local` 的其他普通成员身份、用户、默认团队成员关系，标题为 `E2E-VIEW-FINAL-SCORE: 登录成员目标前置` 的登录成员独占 settled 目标，标题为 `E2E-VIEW-FINAL-SCORE: 其他成员目标前置` 的其他成员独占 settled 目标，以及 reason 为 `E2E-FINAL-SCORE: 查看最终分数` 的两条测试积分流水。
- Action 产物：无新增业务资源，只打开统计页面并切换全部时间范围。
- Clean 产物：删除本用例创建的测试积分流水、两个独占目标、两个普通成员身份、用户和成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除本用例残留的测试积分流水，积分流水 reason 为 `E2E-FINAL-SCORE: 查看最终分数`。
  - [Setup-2] [prisma] 删除标题为 `E2E-VIEW-FINAL-SCORE: 登录成员目标前置` 的本用例残留登录成员目标及其派生数据。

  - [Setup-6] [api] 准备其他普通成员认证身份，邮箱为 `orf-member-view-final-score-other-e2e@orf.local`，密码为固定测试密码。

  - [Setup-8] [prisma] 创建本用例登录成员独占目标，标题为 `E2E-VIEW-FINAL-SCORE: 登录成员目标前置`。
  - [Setup-9] [prisma] 设置本用例登录成员独占目标为 `settled`，挑战者仅包含登录普通成员，目标结算积分为 `42`。

  - [Setup-11] [prisma] 创建本用例其他成员独占目标，标题为 `E2E-VIEW-FINAL-SCORE: 其他成员目标前置`。

  - [Setup-14] [api] 撤销登录普通成员认证身份的残留登录会话。
  - [Setup-15] [api] 撤销其他普通成员认证身份的残留登录会话。
  - [Setup-16] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-17] [playwright] 打开 ORF 登录页。

  - [Setup-19] [playwright] 在密码输入框输入登录普通成员固定测试密码。
  - [Setup-20] [playwright] 点击 `Sign In` 登录操作。
  - [Setup-21] [api] 当前会话 应为 登录普通成员的已登录会话。
