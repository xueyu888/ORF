# 成员提交匿名互评-非已验收状态不可互评

## 1. 测试目标

验证：当前普通成员是本用例目标挑战者时，发布阶段、评估阶段、实施未提交战利品、待验收和已结算五类非已验收状态目标会显示在挑战工作台中，但前端不提供提交匿名互评入口；页面、接口和数据库均不会产生本用例匿名互评记录。

边界：

- 覆盖对象：非已验收状态不可提交匿名互评。
- 不覆盖对象：已验收状态提交匿名互评、管理员不可互评、非参与成员不可互评、管理员验收、贡献分歧处理、分数结算。
- 依赖对象：[成员提交匿名互评](成员提交匿名互评.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体普通成员账号、目标、战利品或匿名互评记录。
- Setup 产物：邮箱为 `orf-member-peer-review-state-forbidden-e2e@orf.local` 的普通成员身份、用户和 member 成员关系；五个本用例非已验收状态互评目标：发布阶段目标、评估阶段目标、实施未提交战利品目标、待验收目标、已结算目标；五个目标的挑战者均包含当前普通成员和 `ORF Peer Review State Collaborator E2E`；待验收目标和已结算目标分别存在独占前置战利品；普通成员已登录会话。
- Action 产物：普通成员进入挑战工作台后的页面状态。
- Clean 产物：删除本用例五个非已验收状态互评目标、待验收和已结算前置战利品、匿名互评残留、普通成员身份、用户、成员关系与 session。
- 原状态恢复：目标、战利品和账号均为当前用例独占资源，Clean 直接删除，不恢复任何共享目标状态。
