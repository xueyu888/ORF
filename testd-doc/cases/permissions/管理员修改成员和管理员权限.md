# 管理员修改成员和管理员权限

## 1. 功能确认

- [api] member 角色权限 应可修改。
- [playwright] 权限管理页面中 member 角色权限开关 应可操作。
- [api] admin 角色权限 应不可修改。
- [playwright] 权限管理页面中 admin 角色权限开关 应锁定。

边界：

- 当前 ORF 已实现：管理员修改 member 角色权限。
- 当前 ORF 未实现：管理员修改 admin 角色权限。
- 已有用例：[管理员变更权限](../auth/管理员变更权限.md) 已覆盖 member 角色权限修改。
- 本用例不生成独立测试代码，直到 ORF 明确支持 admin 角色权限修改。
