## 1. 测试目标

验证：未注册用户在注册页提交注册申请后进入待审核状态；管理员审核通过后，该用户可以再次使用注册邮箱和密码登录，并进入 ORF 已登录状态。

边界：

- 覆盖对象：注册成功、待审核、管理员通过、通过后再次登录。
- 不覆盖对象：注册表单校验、重复邮箱、拒绝申请、停用账号、错误密码。
- Setup 产物：独占测试管理员、未被占用的注册邮箱、注册表单页面。
- Clean 产物：邮箱为 "orf-register-e2e@orf.local" 的注册测试身份和用户、邮箱为 "orf-register-admin-e2e@orf.local" 的测试管理员身份和用户。
- 注册用户通过后的团队角色 应为 member。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询接口 应可访问。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos Admin/Public API 应可访问。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory session cookie。
  - [B-10] [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 撤销注册测试登录身份可能残留的 Ory session。
  - [Setup-2] [api] 删除邮箱为 `orf-register-e2e@orf.local` 的注册测试登录身份。
  - [Setup-3] [prisma] 删除注册测试用户的默认团队成员关系。
  - [Setup-4] [prisma] 删除邮箱为 `orf-register-e2e@orf.local` 的注册测试用户。
  - [Setup-5] [api] 准备邮箱为 `orf-register-admin-e2e@orf.local` 的测试管理员登录身份，并设置固定测试密码。
  - [Setup-6] [prisma] 准备邮箱为 `orf-register-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的测试管理员用户。
  - [Setup-7] [api] 撤销测试管理员登录身份可能残留的 Ory session。
  - [Setup-8] [playwright] 清理浏览器状态。
  - [Setup-9] [playwright] 打开 登录页。
  - [Setup-10] [playwright] 点击登录页的 `Register` 切换到注册模式。

- S0：Action 前状态。
  - [S0-1] [playwright] 当前页面 应为 注册页。
  - [S0-2] [playwright] 注册页标题 "Register" 应可见。
  - [S0-3] [playwright] 姓名输入框 应可见。
  - [S0-4] [playwright] 姓名输入框的值 应为空。
  - [S0-5] [playwright] 邮箱输入框 应可见。
  - [S0-6] [playwright] 邮箱输入框的值 应为空。
  - [S0-7] [playwright] 密码输入框 应可见。
  - [S0-8] [playwright] 密码输入框的值 应为空。
  - [S0-9] [playwright] "Create Account" 注册操作 应可见。
  - [S0-10] [playwright] "Create Account" 注册操作 应可点击。
  - [S0-11] [api] 当前会话 应为 未登录。
  - [S0-12] [api] 认证系统中 应存在 邮箱为 `orf-register-admin-e2e@orf.local` 的测试管理员登录身份。
  - [S0-13] [api] 测试管理员登录身份 的密码凭据 应可用。
  - [S0-14] [prisma] ORF 业务系统中 应存在 邮箱为 `orf-register-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的测试管理员用户。
  - [S0-15] [api] 认证系统中 应不存在 注册测试登录身份。
  - [S0-16] [prisma] ORF 业务系统中 应不存在 注册测试用户。

- Action：被测业务流程。
  - [Action-1] [playwright] 在姓名输入框输入 `ORF Register E2E`。
  - [Action-2] [playwright] 在邮箱输入框输入 `orf-register-e2e@orf.local`。
  - [Action-3] [playwright] 在密码输入框输入固定测试密码。
  - [Action-4] [playwright] 在点击 "Create Account" 注册操作前注册注册申请接口响应捕获。
  - [Action-5] [playwright] 点击 "Create Account" 注册操作。
  - [Action-6] [playwright] "等待注册审核" 状态 应可见。
  - [Action-7] [api] 记录 注册响应用户。
  - [Action-8] [prisma] 记录 注册测试用户的待审核状态。
  - [Action-9] [playwright] 点击 `退出登录` 清理注册用户当前会话。
  - [Action-10] [playwright] 清理注册用户浏览器状态。
  - [Action-11] [playwright] 打开 登录页。
  - [Action-12] [playwright] 在邮箱输入框输入测试管理员邮箱。
  - [Action-13] [playwright] 在密码输入框输入测试管理员密码。
  - [Action-14] [playwright] 点击 `Sign In` 登录操作。
  - [Action-15] [api] 当前会话 应为 测试管理员已登录。
  - [Action-16] [playwright] 打开 成员管理页面。
  - [Action-17] [playwright] 成员管理列表 应显示 `ORF Register E2E` 或 `orf-register-e2e@orf.local`。
  - [Action-18] [playwright] 在点击 `通过` 操作前注册审批通过接口响应捕获。
  - [Action-19] [playwright] 点击该用户行的 `通过` 操作。
  - [Action-20] [api] 审批通过接口响应 应成功。
  - [Action-21] [prisma] ORF 业务系统中 注册测试用户状态 应变为 `active`，且成员关系角色 应仍为 `member`。
  - [Action-22] [playwright] 管理员退出登录。
  - [Action-23] [playwright] 清理管理员浏览器状态。
  - [Action-24] [playwright] 打开 登录页。
  - [Action-25] [playwright] 在邮箱输入框输入注册测试用户邮箱。
  - [Action-26] [playwright] 在密码输入框输入注册测试用户密码。
  - [Action-27] [playwright] 点击 `Sign In` 登录操作。

- S1：Action 后状态。
  - [S1-1] [api] 注册申请接口响应 应成功。
  - [S1-2] [api] 注册响应的用户邮箱 应匹配 测试邮箱。
  - [S1-3] [api] 注册响应的用户状态 应为 `pending`。
  - [S1-4] [api] 注册响应的用户角色 应为 `member`。
  - [S1-5] [playwright] "等待注册审核" 提示 应曾可见。
  - [S1-6] [prisma] ORF 业务系统中 应存在 注册测试用户。
  - [S1-7] [prisma] 注册测试用户 的状态 应曾为 `pending`。
  - [S1-8] [prisma] 注册测试用户 的成员关系角色 应为 `member`。
  - [S1-9] [api] 注册测试用户再次登录后的当前会话 应为 邮箱为 `orf-register-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [S1-10] [playwright] 再次登录后的当前页面 应为 ORF 已登录页面。
  - [S1-11] [playwright] 主导航 应可见。
  - [S1-12] [playwright] 当前用户入口 应可见。
  - [S1-13] [playwright] 成员管理入口 应不对该普通成员可见。

- Clean：恢复 B。
  - [Clean-1] [api] 撤销当前会话的 Ory session。
  - [Clean-2] [playwright] 当前页面离开 ORF 前端应用。
  - [Clean-3] [playwright] 清理浏览器状态。
  - [Clean-4] [api] 撤销注册测试登录身份的残留 Ory session。
  - [Clean-5] [api] 删除邮箱为 `orf-register-e2e@orf.local` 的注册测试登录身份。
  - [Clean-6] [prisma] 删除注册测试用户的默认团队成员关系。
  - [Clean-7] [prisma] 删除邮箱为 `orf-register-e2e@orf.local` 的注册测试用户。
  - [Clean-8] [api] 撤销测试管理员登录身份的残留 Ory session。
  - [Clean-9] [api] 删除邮箱为 `orf-register-admin-e2e@orf.local` 的测试管理员登录身份。
  - [Clean-10] [prisma] 删除测试管理员的默认团队成员关系。
  - [Clean-11] [prisma] 删除邮箱为 `orf-register-admin-e2e@orf.local` 的测试管理员用户。
