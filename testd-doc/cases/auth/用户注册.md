## 1. 测试目标

验证：未注册用户可以在登录页提交注册申请；管理员 `zrx831@gmail.com` 审核通过后，该用户可以再次使用注册邮箱和密码登录，并进入 ORF 已登录状态。

边界：

- 本用例只验证注册成功、待审核、管理员通过和通过后再次登录，不验证注册表单校验、重复邮箱、拒绝申请、停用账号或错误密码。
- 本用例的管理员账号使用现有预置管理员账号 `zrx831@gmail.com`，密码为 `123123123`。
- 本用例使用独占注册测试身份，例如 `orf-register-e2e@orf.local`，密码为 `OrfRegisterE2E!2026`；Clean 必须删除该身份和 ORF 用户，恢复到注册前基准状态。
- 注册用户通过后应是普通成员 `member`，不是管理员。

## 2. 状态模型

- B：测试开始前和 Clean 后都必须满足的基准状态，用于确认基础环境可用、预置管理员账号存在、注册测试用户不存在，且当前浏览器未登录。
  - [api] 前端和后端服务已正常启动，健康检查或等价探测通过。
  - [prisma] ORF 数据库连接正常，schema 已迁移到当前测试版本。
  - [api] Ory/Kratos 服务可访问，Admin/Public API 对测试环境可用。
  - [api] Ory/Kratos 中已存在管理员测试身份 `zrx831@gmail.com`，并具备可用密码凭据。
  - [prisma] ORF 中已存在管理员用户和 `team_members` 记录，角色为 `admin`，状态为 `active`。
  - [api] Ory/Kratos 中不存在本用例独占注册测试身份 `orf-register-e2e@orf.local`。
  - [prisma] ORF 中不存在邮箱为 `orf-register-e2e@orf.local` 的用户和成员关系。
  - [api] `/api/auth/session` 返回 `authenticated: false`。
  - [playwright] 当前浏览器上下文不存在 `orf_ory_session` cookie。
  - [playwright] localStorage/sessionStorage 不包含登录态。

- Setup：如何从 B 构造 S0？
  - [playwright] 创建全新的浏览器上下文，或清空当前上下文的 cookies/localStorage/sessionStorage。
  - [playwright] 打开 `/auth`。
  - [playwright] 点击登录页的 `Register` 切换到注册模式。

- S0：Action 前必须满足什么条件？用于确认 Setup 成功。
  - [playwright] `page` URL 为 `/auth`。
  - [playwright] `page.getByRole("heading", { name: "Register" })` 可见。
  - [playwright] `page.getByPlaceholder("Name")` 可见且值为空。
  - [playwright] `page.getByPlaceholder("Email")` 可见且值为空。
  - [playwright] `page.getByPlaceholder("Password")` 可见且值为空。
  - [playwright] `page.getByRole("button", { name: "Create Account" })` 可见且可点击。
  - [api] `/api/auth/session` 返回 `authenticated: false`。
  - [api] Ory/Kratos 中不存在注册测试身份。
  - [prisma] ORF 中不存在注册测试用户。

- Action：本次测试要验证的业务流程是什么？
  - [playwright] 在注册表单输入姓名 `ORF Register E2E`、邮箱 `orf-register-e2e@orf.local` 和固定测试密码。
  - [playwright] 在点击 `Create Account` 前注册 `POST /api/auth/registration` 响应捕获。
  - [playwright] 点击 `Create Account` 提交注册申请。
  - [playwright] 注册后应进入“等待注册审核”状态，点击 `退出登录` 清理注册用户当前会话。
  - [playwright] 使用管理员账号 `zrx831@gmail.com` 登录。
  - [playwright] 打开 `/members`，在成员管理中找到 `ORF Register E2E` 或 `orf-register-e2e@orf.local`。
  - [playwright] 在点击 `通过` 前注册 `PATCH /api/registration-requests/{userId}/approve` 响应捕获。
  - [playwright] 点击该用户行的 `通过`。
  - [api] 立即等待 `PATCH /api/registration-requests/{userId}/approve` 响应成功。
  - [prisma] 确认 ORF 中注册测试用户状态变为 `active`，成员关系角色仍为 `member`。
  - [playwright] 管理员退出登录。
  - [playwright] 使用注册测试用户邮箱和密码再次登录。

- S1：Action 后系统应该变成什么状态？用于确认业务流程正确。
  - [api] `POST /api/auth/registration` 响应成功，返回 `authenticated: true`，用户邮箱匹配测试邮箱，状态为 `pending`，角色为 `member`。
  - [playwright] 注册提交后曾显示“等待注册审核”。
  - [prisma] ORF 中存在注册测试用户，状态曾为 `pending`，成员关系角色为 `member`。
  - [api] 注册测试用户再次登录后的 `/api/auth/session` 返回 `authenticated: true`，用户邮箱为 `orf-register-e2e@orf.local`，角色为 `member`，状态为 `active`。
  - [playwright] 再次登录后进入 ORF 已登录页面，例如 `/tasks` 或 `/bounties`。
  - [playwright] 主导航和当前用户入口可见。
  - [playwright] 成员管理入口不应对该普通成员可见。

- Clean：如何清理并恢复到 B？
  - [api] 在当前浏览器上下文中调用 `/api/auth/logout`，先撤销本次登录产生的 Ory session；如果当前页面已关闭，不能阻断后续数据清理。
  - [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage；如果当前上下文已不可用，不能阻断后续数据清理。
  - [api] 撤销注册测试身份可能残留的 Ory session。
  - [prisma] 删除注册测试用户在默认团队中的 `team_members` 记录。
  - [prisma] 删除邮箱为 `orf-register-e2e@orf.local` 的 ORF 用户记录，或恢复为测试开始前不存在状态。
  - [api] 删除 Ory/Kratos 中邮箱为 `orf-register-e2e@orf.local` 的测试身份。
  - [api] 确认管理员 Ory 身份仍然存在。
  - [prisma] 确认管理员 ORF 用户和 `admin` 成员关系仍然存在。
