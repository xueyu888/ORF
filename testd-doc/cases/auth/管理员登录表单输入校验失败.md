## 1. 测试目标

验证：登录页面中，管理员在登录表单输入邮箱格式错误、邮箱为空、密码为空或密码不满足规则时，系统应阻止登录并提示对应规则错误，当前浏览器保持未登录状态。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-2] [playwright] 打开 ORF 登录页。

- S0：Action 前状态。
  - [S0-1] [playwright] 当前页面 应为 登录页。
  - [S0-2] [playwright] 邮箱输入框 应可见。
  - [S0-3] [playwright] 邮箱输入框的值 应为空。
  - [S0-4] [playwright] 密码输入框 应可见。
  - [S0-5] [playwright] 密码输入框的值 应为空。
  - [S0-6] [playwright] 登录页的 "Sign In" 登录操作 应可见。
  - [S0-7] [playwright] 登录页的 "Sign In" 登录操作 应可点击。
  - [S0-8] [api] 当前会话 应为 未登录。
  - [S0-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [S0-10] [playwright] 当前浏览器 应不保留本地登录态。

- Action：被测业务动作。
  - [Action-1] [playwright] 清空邮箱输入框。
  - [Action-2] [playwright] 清空密码输入框。
  - [Action-3] [playwright] 在密码输入框输入满足规则的管理员测试密码。
  - [Action-4] [playwright] 点击 "Sign In" 登录操作。
  - [Action-5] [playwright] 登录页错误提示 "请输入邮箱" 应可见。

  - [Action-6] [playwright] 清空邮箱输入框。
  - [Action-7] [playwright] 清空密码输入框。
  - [Action-8] [playwright] 在邮箱输入框输入 `orf-admin-login-invalid-account`。
  - [Action-9] [playwright] 在密码输入框输入满足规则的管理员测试密码。
  - [Action-10] [playwright] 点击 "Sign In" 登录操作。
  - [Action-11] [playwright] 登录页错误提示 "邮箱格式不正确" 应可见。

  - [Action-12] [playwright] 清空邮箱输入框。
  - [Action-13] [playwright] 清空密码输入框。
  - [Action-14] [playwright] 在邮箱输入框输入 `orf-admin-login-form-validation-e2e@orf.local`。
  - [Action-15] [playwright] 点击 "Sign In" 登录操作。
  - [Action-16] [playwright] 登录页错误提示 "请输入密码" 应可见。

  - [Action-17] [playwright] 清空邮箱输入框。
  - [Action-18] [playwright] 清空密码输入框。
  - [Action-19] [playwright] 在邮箱输入框输入 `orf-admin-login-form-validation-e2e@orf.local`。
  - [Action-20] [playwright] 在密码输入框输入不满足规则的短密码。
  - [Action-21] [playwright] 点击 "Sign In" 登录操作。
  - [Action-22] [playwright] 登录页错误提示 "密码至少 8 位" 应可见。

- S1：Action 后状态。
  - [S1-1] [playwright] 当前页面 应仍为 登录页。
  - [S1-2] [api] 当前会话 应仍为 未登录。
  - [S1-3] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [S1-4] [playwright] 当前浏览器 应不保留本地登录态。
  - [S1-5] [playwright] 登录页的 "Sign In" 登录操作 应仍可见。
  - [S1-6] [playwright] 登录后主导航 应不可见。
  - [S1-7] [playwright] 登录后的 "退出登录" 操作 应不可见。
  - [S1-8] [playwright] 登录页错误提示 "密码至少 8 位" 应仍可见。

- Clean：恢复 B。
  - [Clean-1] [api] 注销当前登录会话。
  - [Clean-2] [playwright] 离开当前 ORF 前端页面。
  - [Clean-3] [playwright] 移除当前浏览器中的残留登录态。
