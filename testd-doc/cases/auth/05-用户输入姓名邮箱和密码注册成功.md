## 1. 测试目标

验证：注册页面中，用户输入姓名、未注册邮箱和满足规则的密码后，系统应注册成功并进入待审核状态。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 撤销邮箱为 `orf-register-e2e@orf.local` 的注册测试认证身份的残留登录会话。
  - [Setup-2] [api] 删除邮箱为 `orf-register-e2e@orf.local` 的注册测试认证身份。
  - [Setup-3] [prisma] 删除邮箱为 `orf-register-e2e@orf.local` 的注册测试用户的默认团队成员关系。
  - [Setup-4] [prisma] 删除邮箱为 `orf-register-e2e@orf.local` 的注册测试用户。
  - [Setup-5] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-6] [playwright] 打开 ORF 登录页。
  - [Setup-7] [playwright] 点击登录页的 "Register" 操作。

- S0：Action 前状态。
  - [S0-1] [playwright] 当前页面 应为 注册页。
  - [S0-2] [playwright] 姓名输入框 应可见。
  - [S0-3] [playwright] 姓名输入框的值 应为空。
  - [S0-4] [playwright] 邮箱输入框 应可见。
  - [S0-5] [playwright] 邮箱输入框的值 应为空。
  - [S0-6] [playwright] 密码输入框 应可见。
  - [S0-7] [playwright] 密码输入框的值 应为空。
  - [S0-8] [playwright] "Create Account" 注册操作 应可见。
  - [S0-9] [playwright] "Create Account" 注册操作 应可点击。
  - [S0-10] [api] 当前会话 应为 未登录。
  - [S0-11] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [S0-12] [api] 认证系统中 应不存在 邮箱为 `orf-register-e2e@orf.local` 的注册测试认证身份。
  - [S0-13] [prisma] ORF 业务系统中 应不存在 邮箱为 `orf-register-e2e@orf.local` 的注册测试用户。

- Action：被测业务动作。
  - [Action-1] [playwright] 在姓名输入框输入 `ORF Register E2E`。
  - [Action-2] [playwright] 在邮箱输入框输入未注册邮箱 `orf-register-e2e@orf.local`。
  - [Action-3] [playwright] 在密码输入框输入满足规则的固定测试密码。
  - [Action-4] [playwright] 点击 "Create Account" 注册操作。

- S1：Action 后状态。
  - [S1-1] [api] 注册申请结果 应成功。
  - [S1-2] [api] 注册申请结果中的用户邮箱 应为 `orf-register-e2e@orf.local`。
  - [S1-3] [api] 注册申请结果中的用户状态 应为 `pending`。
  - [S1-4] [api] 注册申请结果中的用户角色 应为 `member`。
  - [S1-5] [playwright] 注册提交后 "等待注册审核" 提示 应可见。
  - [S1-6] [api] 认证系统中 应存在 邮箱为 `orf-register-e2e@orf.local` 的注册测试认证身份。
  - [S1-7] [api] 邮箱为 `orf-register-e2e@orf.local` 的注册测试认证身份的密码凭据 应可用。
  - [S1-8] [prisma] ORF 业务系统中 应存在 邮箱为 `orf-register-e2e@orf.local` 的注册测试用户。
  - [S1-9] [prisma] 注册测试用户的状态 应为 `pending`。
  - [S1-10] [prisma] 注册测试用户的团队角色 应为 `member`。
  - [S1-11] [api] 当前会话 应为 邮箱为 `orf-register-e2e@orf.local`、角色为 `member`、状态为 `pending` 的已登录会话。
  - [S1-12] [playwright] 当前浏览器 应存在 Ory 登录会话 cookie。

- Clean：恢复 B。
  - [Clean-1] [api] 注销当前登录会话。
  - [Clean-2] [playwright] 离开当前 ORF 前端页面。
  - [Clean-3] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-4] [api] 撤销邮箱为 `orf-register-e2e@orf.local` 的注册测试认证身份的残留登录会话。
  - [Clean-5] [api] 删除邮箱为 `orf-register-e2e@orf.local` 的注册测试认证身份。
  - [Clean-6] [prisma] 删除邮箱为 `orf-register-e2e@orf.local` 的注册测试用户的默认团队成员关系。
  - [Clean-7] [prisma] 删除邮箱为 `orf-register-e2e@orf.local` 的注册测试用户。
  - [Clean-8] [api] 邮箱为 `orf-register-e2e@orf.local` 的注册测试认证身份 应不存在。
  - [Clean-9] [prisma] 邮箱为 `orf-register-e2e@orf.local` 的注册测试用户 应不存在。
