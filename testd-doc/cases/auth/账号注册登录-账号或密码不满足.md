# 账号注册登录-账号或密码不满足

## 1. 测试目标

验证：未注册用户在注册页提交账号或密码不满足要求的注册申请时应被正确阻拦；系统不创建对应的新认证身份，不创建对应的新 ORF 用户，当前浏览器保持未登录状态，并停留在注册页显示明确失败提示。

实现说明：

- 当前实现：注册页先进行前端输入校验；合法格式但已占用邮箱会由注册接口和 Ory/Kratos 拒绝。
- 当前账号契约：注册账号必须是非空邮箱，且不能被已有认证身份占用。
- 当前密码契约：注册密码必须非空，且长度不少于 8 位。
- 当前用例类型：反向输入校验用例。
- 当前代码状态：已生成独立 testd 用例。

边界：

- 覆盖对象：空邮箱、非邮箱文本、缺少邮箱域名、缺少顶级域、含空格邮箱、已占用邮箱、空密码、纯空白密码、长度不足 8 位密码。
- 不覆盖对象：合法注册、管理员审核通过、审核通过后登录、登录页错误密码、账号停用、密码复杂度或泄露密码策略。
- 依赖对象：[用户注册](用户注册.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体注册用户。
- Setup 产物：已占用邮箱 `orf-register-existing-e2e@orf.local` 对应的测试身份和用户，三个用于非法密码注册尝试且应保持未占用的目标邮箱，干净浏览器状态和已打开的注册页。
- Action 产物：各类非法账号或非法密码的注册提交结果。
- Clean 产物：删除本用例准备的已占用邮箱测试身份和用户，删除本用例可能残留的非法注册测试身份和用户，并清理登录态和页面运行态。
