## 1. 测试目标

验证：已登录管理员可以修改普通成员角色的权限配置，保存后该权限配置会持久化，并能通过权限接口再次读取到。

边界：

- 本用例只验证管理员修改 `member` 角色权限，不验证管理员自身权限变更；当前 ORF 中管理员权限固定，不允许修改。
- 本用例只切换一个明确权限 key，例如 `comment.manage`，不覆盖所有权限组合。
- 本用例必须在 Clean 中恢复修改前的 `member` 权限配置，避免影响后续测试。

## 2. 状态模型

- B：测试开始前和 Clean 后都必须满足的基准状态，用于确认基础环境可用、预置管理员可用，且当前浏览器未登录。
  - [api] 前端和后端服务已正常启动，健康检查或等价探测通过。
  - [prisma] ORF 数据库连接正常，schema 已迁移到当前测试版本。
  - [api] Ory/Kratos 服务可访问，Admin/Public API 对测试环境可用。
  - [api] Ory/Kratos 中已存在管理员测试身份 `zrx831@gmail.com`，并具备可用密码凭据。
  - [prisma] ORF 中已存在管理员用户和 `team_members` 记录，角色为 `admin`，状态为 `active`。
  - [api] `/api/auth/session` 返回 `authenticated: false`。
  - [playwright] 当前浏览器上下文不存在 `orf_ory_session` cookie。
  - [playwright] localStorage/sessionStorage 不包含登录态。

- Setup：如何从 B 构造 S0？
  - [api] 记录管理员登录前的 `last_online_at`，用于 Clean 恢复。
  - [api] 撤销管理员测试身份可能残留的 Ory session。
  - [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [playwright] 打开 `/auth`，使用管理员账号登录。
  - [api] 读取 `GET /api/permissions`，记录当前 `member` 角色权限为 `runtime.originalMemberPermissionRules`。
  - [playwright] 打开 `/permissions`。

- S0：Action 前必须满足什么条件？用于确认 Setup 成功。
  - [api] `/api/auth/session` 返回 `authenticated: true`，用户邮箱为 `zrx831@gmail.com`，角色为 `admin`，状态为 `active`。
  - [playwright] `page` URL 为 `/permissions`。
  - [playwright] 权限管理页面显示 `成员` 角色页签。
  - [playwright] 权限管理页面显示 `comment.manage` 对应的权限开关。
  - [api] 已记录修改前的 `member` 权限配置。

- Action：本次测试唯一要验证的业务动作是什么？
  - [api] 基于 `runtime.originalMemberPermissionRules` 生成新的 `member` 权限配置：如果原来包含 `comment.manage`，则移除；如果原来不包含，则加入。
  - [api] 以当前管理员会话调用 `PUT /api/permissions/member` 保存新的 `member` 权限配置。

- S1：Action 后系统应该变成什么状态？用于确认业务动作正确。
  - [api] `PUT /api/permissions/member` 响应成功。
  - [api] 再次读取 `GET /api/permissions` 时，`member` 角色权限配置等于 Action 中保存的新配置。
  - [playwright] 管理员仍停留在 ORF 已登录状态。
  - [prisma] ORF 管理员用户和 `admin` 成员关系仍然存在。

- Clean：如何清理并恢复到 B？
  - [api] 以当前管理员会话调用 `PUT /api/permissions/member`，恢复 `runtime.originalMemberPermissionRules`。
  - [api] 在当前浏览器上下文中调用 `/api/auth/logout`，撤销本次登录产生的 Ory session。
  - [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [prisma] 恢复管理员登录前记录的 `last_online_at`。
  - [api] 撤销管理员测试身份可能残留的 Ory session。
  - [api] 确认管理员 Ory 身份仍然存在。
  - [prisma] 确认管理员 ORF 用户和 `admin` 成员关系仍然存在。
