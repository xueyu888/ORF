## 1. 测试目标

验证：由当前用例独占准备的已登录管理员可以修改 member 角色权限配置；保存后该配置可以再次读取，并在 Clean 中恢复为修改前状态。

边界：

- 覆盖对象：管理员修改 member 角色权限。
- 不覆盖对象：admin 角色权限变更、所有权限组合验证。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体管理员账号。
- Setup 产物：邮箱为 "orf-admin-permission-e2e@orf.local" 的管理员 Ory 身份、ORF 用户和默认团队 admin 成员关系。
- 共享状态恢复：member 角色权限配置属于共享配置，本用例只记录原状态、保存新状态，并在 Clean 中恢复原状态。
- Action 边界：只生成并保存一个明确权限 key，例如 "comment.manage"。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询接口 应可访问。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos Admin/Public API 应可访问。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory session cookie。
  - [B-10] [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 准备邮箱为 "orf-admin-permission-e2e@orf.local" 的管理员登录身份，并设置固定测试密码。
  - [Setup-2] [prisma] 准备邮箱为 "orf-admin-permission-e2e@orf.local"、角色为 admin、状态为 active 的管理员用户和默认团队成员关系。
  - [Setup-3] [api] 撤销管理员登录身份可能残留的 Ory session。
  - [Setup-4] [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [Setup-5] [playwright] 打开 登录页。
  - [Setup-6] [playwright] 在邮箱输入框输入管理员测试邮箱。
  - [Setup-7] [playwright] 在密码输入框输入管理员测试密码。
  - [Setup-8] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-9] [api] 当前会话 应为 管理员已登录。
  - [Setup-10] [api] 读取权限配置接口，记录当前 member 角色权限为 "runtime.originalMemberPermissionRules"。
  - [Setup-11] [playwright] 打开 权限管理页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 "orf-admin-permission-e2e@orf.local"、角色为 admin、状态为 active 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 权限管理页面。
  - [S0-3] [playwright] 权限管理页面 应显示 "成员" 角色页签。
  - [S0-4] [playwright] 权限管理页面 应显示 "comment.manage" 对应的权限开关。
  - [S0-5] [api] 已记录修改前的 member 权限配置。

- Action：被测业务动作。
  - [Action-1] [api] 基于 "runtime.originalMemberPermissionRules" 生成新的 member 权限配置。
  - [Action-2] [api] 以当前管理员会话调用 member 权限保存接口，保存新的 member 权限配置。

- S1：Action 后状态。
  - [S1-1] [api] member 权限保存接口响应 应成功。
  - [S1-2] [api] 再次读取权限配置接口时，member 角色权限配置应等于 Action 中保存的新配置。
  - [S1-3] [api] 当前会话 应保持 管理员已登录。
  - [S1-4] [prisma] ORF 管理员用户和 admin 成员关系 应仍存在。

- Clean：恢复 B。
  - [Clean-1] [api] 以当前管理员会话调用 member 权限保存接口，恢复 "runtime.originalMemberPermissionRules"。
  - [Clean-2] [api] 调用退出登录接口撤销本次登录产生的 Ory session。
  - [Clean-3] [playwright] 当前页面离开 ORF 前端应用。
  - [Clean-4] [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [Clean-5] [api] 撤销管理员登录身份的残留 Ory session。
  - [Clean-6] [api] 删除邮箱为 "orf-admin-permission-e2e@orf.local" 的管理员登录身份。
  - [Clean-7] [prisma] 删除管理员用户的默认团队成员关系。
  - [Clean-8] [prisma] 删除邮箱为 "orf-admin-permission-e2e@orf.local" 的管理员用户。
