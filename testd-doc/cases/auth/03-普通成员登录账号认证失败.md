## 1. 测试目标

验证：登录页面中，输入未注册邮箱或邮箱密码不匹配时，系统应拒绝登录并提示账号或密码错误，当前浏览器保持未登录状态。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 撤销邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员登录身份的残留登录会话。
  - [Setup-2] [api] 删除邮箱为 `orf-member-login-missing-e2e@orf.local` 的不存在账号测试登录身份。
  - [Setup-3] [prisma] 删除邮箱为 `orf-member-login-missing-e2e@orf.local` 的不存在账号测试用户默认团队成员关系和用户。
  - [Setup-4] [api] 准备邮箱为 `orf-member-login-invalid-e2e@orf.local`、使用固定测试密码的普通成员登录身份。
  - [Setup-5] [prisma] 准备邮箱为 `orf-member-login-invalid-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户和默认团队成员关系。
  - [Setup-6] [api] 撤销邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员登录身份的残留登录会话。
  - [Setup-7] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-8] [playwright] 打开 ORF 登录页。

- S0：Action 前状态。
  - [S0-1] [playwright] 当前页面 应为 登录页。
  - [S0-2] [playwright] 邮箱输入框 应可见。
  - [S0-3] [playwright] 邮箱输入框的值 应为空。
  - [S0-4] [playwright] 密码输入框 应可见。
  - [S0-5] [playwright] 密码输入框的值 应为空。
  - [S0-6] [playwright] 登录页的 "Sign In" 登录操作 应可见。
  - [S0-7] [playwright] 登录页的 "Sign In" 登录操作 应可点击。
  - [S0-8] [api] 当前会话 应为 未登录。
  - [S0-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [S0-10] [playwright] 当前浏览器 应不保留本地登录态。
  - [S0-11] [api] 认证系统中 应存在 邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员登录身份。
  - [S0-12] [api] 邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员登录身份的密码凭据 应可用。
  - [S0-13] [prisma] ORF 业务系统中 应存在 邮箱为 `orf-member-login-invalid-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户。
  - [S0-14] [api] 认证系统中 应不存在 邮箱为 `orf-member-login-missing-e2e@orf.local` 的登录身份。
  - [S0-15] [prisma] ORF 业务系统中 应不存在 邮箱为 `orf-member-login-missing-e2e@orf.local` 的用户。

- Action：被测业务动作。
  - [Action-1] [playwright] 清空邮箱输入框。
  - [Action-2] [playwright] 清空密码输入框。
  - [Action-3] [playwright] 在邮箱输入框输入未注册普通成员测试邮箱 `orf-member-login-missing-e2e@orf.local`。
  - [Action-4] [playwright] 在密码输入框输入普通成员固定测试密码。
  - [Action-5] [playwright] 点击 "Sign In" 登录操作。
  - [Action-6] [api] 登录结果 应被拒绝。
  - [Action-7] [playwright] 验证登录页错误提示 "账号或密码不正确" 应可见。

  - [Action-8] [playwright] 清空邮箱输入框。
  - [Action-9] [playwright] 清空密码输入框。
  - [Action-10] [playwright] 在邮箱输入框输入已注册普通成员测试邮箱。
  - [Action-11] [playwright] 在密码输入框输入普通成员错误测试密码。
  - [Action-12] [playwright] 点击 "Sign In" 登录操作。
  - [Action-13] [api] 登录结果 应被拒绝。
  - [Action-14] [playwright] 验证登录页错误提示 "账号或密码不正确" 应可见。

- S1：Action 后状态。
  - [S1-1] [playwright] 当前页面 应仍为 登录页。
  - [S1-2] [api] 当前会话 应仍为 未登录。
  - [S1-3] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [S1-4] [playwright] 当前浏览器 应不保留本地登录态。
  - [S1-5] [playwright] 登录页的 "Sign In" 登录操作 应仍可见。
  - [S1-6] [playwright] 登录后主导航 应不可见。
  - [S1-7] [playwright] 登录后的 "退出登录" 操作 应不可见。
  - [S1-8] [api] 认证系统中 应仍存在 邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员登录身份。
  - [S1-9] [api] 邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员登录身份的密码凭据 应仍可用。
  - [S1-10] [prisma] ORF 业务系统中 应仍存在 邮箱为 `orf-member-login-invalid-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户。
  - [S1-11] [api] 认证系统中 应不存在 邮箱为 `orf-member-login-missing-e2e@orf.local` 的登录身份。
  - [S1-12] [prisma] ORF 业务系统中 应不存在 邮箱为 `orf-member-login-missing-e2e@orf.local` 的用户。

- Clean：恢复 B。
  - [Clean-1] [api] 注销当前登录会话。
  - [Clean-2] [playwright] 离开当前 ORF 前端页面。
  - [Clean-3] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-4] [api] 撤销邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员登录身份的残留登录会话。
  - [Clean-5] [api] 删除邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员登录身份。
  - [Clean-6] [prisma] 删除邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员用户的默认团队成员关系。
  - [Clean-7] [prisma] 删除邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员用户。
  - [Clean-8] [api] 删除邮箱为 `orf-member-login-missing-e2e@orf.local` 的不存在账号测试登录身份。
  - [Clean-9] [prisma] 删除邮箱为 `orf-member-login-missing-e2e@orf.local` 的不存在账号测试用户默认团队成员关系和用户。
  - [Clean-10] [api] 邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员登录身份 应不存在。
  - [Clean-11] [prisma] 邮箱为 `orf-member-login-invalid-e2e@orf.local` 的普通成员用户 应不存在。
