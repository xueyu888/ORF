# 评论回复-非参与成员不可回复

## 1. 测试目标

验证：非参与普通成员不能回复目标和任务评论；计划页不展示当前评论对象，直接调用回复接口也会被拒绝，并且数据库不会产生本用例回复。

实现说明：

- 当前实现：管理员可以回复任意可评论目标；本反向用例只验证非参与普通成员不可回复。
- 当前用例类型：反向权限用例。
- 当前代码状态：生成独立 testd 用例，按目标和任务两个评论对象参数化执行。

边界：

- 覆盖对象：非参与普通成员不可回复目标和任务评论。
- 不覆盖对象：管理员回复、参与成员回复、回复编辑、回复删除、多级回复、附件、提及。
- 依赖对象：[评论回复](评论回复.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何业务 fixture。
- Setup 产物：非参与普通成员、目标参与成员、生命周期允许评论操作的目标、该目标下任务、当前评论对象、可回复外层评论、非参与普通成员已登录会话。
- Action 产物：非参与普通成员直接提交回复请求的结果。
- Clean 产物：恢复 member 角色评论管理权限快照，删除本用例评论、回复、任务、目标、两个普通成员身份、用户、成员关系和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例测试评论和回复。
  - [Setup-2] [prisma] 删除可能残留的本用例目标和任务。
  - [Setup-3] [api] 准备非参与普通成员登录身份。
  - [Setup-4] [prisma] 准备状态为 `active` 的非参与普通成员用户和默认团队成员关系，角色为 `member`。
  - [Setup-5] [prisma] 记录默认团队 member 角色评论管理权限配置快照。
  - [Setup-6] [prisma] 确保默认团队 member 角色不具备 `comment.manage` 权限。
  - [Setup-7] [api] 准备目标参与成员登录身份。
  - [Setup-8] [prisma] 准备状态为 `active` 的目标参与成员用户和默认团队成员关系，角色为 `member`。
  - [Setup-9] [prisma] 创建生命周期允许评论操作的目标。
  - [Setup-10] [prisma] 设置目标参与成员参与该目标。
  - [Setup-11] [prisma] 创建该目标下的任务。
  - [Setup-12] [prisma] 记录当前评论对象，评论对象为目标或任务。
  - [Setup-13] [prisma] 创建当前评论对象上的可回复外层评论。
  - [Setup-14] [api] 撤销非参与普通成员登录身份可能残留的登录会话。
  - [Setup-15] [api] 撤销目标参与成员登录身份可能残留的登录会话。
  - [Setup-16] [playwright] 移除当前浏览器中的残留登录态。

  - [Setup-19] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-20] [api] 当前会话 应为 非参与普通成员的已登录会话。
  - [Setup-21] [playwright] 打开 计划页面。
  - [Setup-22] [api] 非参与普通成员计划页数据 应不包含 当前评论对象。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 非参与普通成员的已登录会话。
  - [S0-2] [api] 当前会话用户角色 应为 `member`。
  - [S0-3] [prisma] 当前评论对象 应属于 非参与普通成员未参与且生命周期允许评论操作的目标。

  - [S0-5] [prisma] 数据库中 应存在 可回复外层评论。
  - [S0-6] [prisma] 数据库中 应不存在 本用例回复正文。

- Action：被测业务动作。
  - [Action-1] [api] 当前非参与普通成员直接尝试回复可回复外层评论。

- S1：Action 后状态。
  - [S1-1] [api] 新增回复结果状态码 应为 403 或等价权限错误。
  - [S1-2] [api] 非参与普通成员计划页数据 应不包含 当前评论对象。

  - [S1-4] [prisma] 数据库中 应不存在 本用例回复正文。
