# 评论上传图片

## 1. 测试目标

验证：已登录用户可以在评论中上传图片。

边界：

- 覆盖对象：目标外层评论图片、任务外层评论图片，图片通过评论附件入口上传。
- 不覆盖对象：非图片文件、图片预览大图、粘贴上传、附件删除、回复中的图片、提及。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何业务 fixture。
- Setup 产物：普通成员用户、该成员参与的可评论目标、目标下的任务、当前评论对象，以及本用例测试图片文件。
- Action 产物：普通成员新增一条包含测试图片的外层评论。
- Clean 产物：删除本用例创建的评论、图片附件、任务、目标、普通成员身份、用户、成员关系和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例测试评论和图片附件。
  - [Setup-2] [prisma] 删除可能残留的本用例目标和任务。
  - [Setup-3] [api] 准备普通成员登录身份。
  - [Setup-4] [prisma] 准备状态为 `active` 的普通成员用户和默认团队成员关系。
  - [Setup-5] [prisma] 创建生命周期允许新增评论的目标。
  - [Setup-6] [prisma] 设置普通成员账号身份参与该目标。
  - [Setup-7] [prisma] 创建该目标下的任务。
  - [Setup-8] [prisma] 记录当前评论对象，评论对象为目标或任务。
  - [Setup-9] [mock] 准备本用例测试图片文件。
  - [Setup-10] [api] 撤销普通成员登录身份可能残留的登录会话。
  - [Setup-11] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-12] [playwright] 打开 ORF 登录页。
  - [Setup-13] [playwright] 输入普通成员邮箱和密码。
  - [Setup-14] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-15] [api] 当前会话 应为 普通成员的已登录会话。
  - [Setup-16] [playwright] 打开 计划页面。
  - [Setup-17] [api] 普通成员计划页数据 应包含 当前评论对象。
  - [Setup-18] [playwright] 打开当前评论对象的评论窗口。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 普通成员的已登录会话。
  - [S0-2] [playwright] 评论输入框 应可用于输入评论。
  - [S0-3] [playwright] "添加图片或附件" 操作 应可点击。
  - [S0-4] [prisma] 数据库中 应不存在 本用例测试评论正文。
  - [S0-5] [prisma] 数据库中 应不存在 本用例测试图片附件。

- Action：被测业务动作。
  - [Action-1] [playwright] 通过 "添加图片或附件" 操作选择本用例测试图片文件。
  - [Action-2] [playwright] 在评论输入框中补充本用例测试评论正文。
  - [Action-3] [playwright] 点击 "发送评论" 操作。

- S1：Action 后状态。
  - [S1-1] [api] 上传评论图片结果 应成功。
  - [S1-2] [api] 新增评论结果 应成功并关联当前评论对象。
  - [S1-3] [playwright] 评论窗口 应显示 本用例测试评论正文。
  - [S1-4] [playwright] 评论窗口的本用例测试评论 应显示 本用例测试图片。
  - [S1-5] [api] 普通成员计划页数据 应包含 当前评论对象的图片评论。
  - [S1-6] [prisma] 数据库中 应持久化 本用例测试评论和图片附件关联。

- Clean：恢复 B。
  - [Clean-1] [playwright] 若评论窗口仍打开，关闭评论窗口。
  - [Clean-2] [prisma] 删除 本用例创建的测试评论、图片附件及空线程。
  - [Clean-3] [api] 删除 本用例上传的测试图片存储对象。
  - [Clean-4] [prisma] 删除 本用例创建的任务。
  - [Clean-5] [prisma] 删除 本用例创建的目标及其派生数据。
  - [Clean-6] [api] 注销当前登录会话。
  - [Clean-7] [playwright] 离开当前 ORF 前端页面。
  - [Clean-8] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-9] [api] 撤销普通成员登录身份的残留登录会话。
  - [Clean-10] [api] 删除普通成员登录身份。
  - [Clean-11] [prisma] 删除普通成员默认团队成员关系和用户记录。
  - [Clean-12] [prisma] 本用例测试评论和图片附件 应不存在。
  - [Clean-13] [prisma] 本用例创建的目标和任务 应不存在。
