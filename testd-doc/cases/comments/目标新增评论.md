## 1. 测试目标

验证：已登录管理员可以在计划页面打开目标评论窗口并新增外层评论；新增后，评论会在页面显示，并持久化到后端评论数据中。

边界：

- 覆盖对象：计划页面目标的外层评论新增。
- 不覆盖对象：指标评论、任务评论、子任务评论、回复、编辑、删除、解决状态、跨用户协作、越权管理。
- B 基础数据：可评论计划数据、测试管理员、测试管理员可见目标。
- Setup 产物：打开了目标评论窗口的计划页面。
- Clean 产物：本用例创建的测试评论消息和空测试评论线程。

## 2. 状态模型

- B：基准状态。
  - [api] 前端服务 应可用。
  - [api] 后端服务 应可用。
  - [api] 前端登录页入口 应可访问。
  - [api] 当前会话查询接口 应可访问。
  - [prisma] ORF 数据库 应可连接。
  - [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [api] Ory/Kratos Admin/Public API 应可访问。
  - [api] 应存在 本用例使用的测试身份。
  - [api] 测试身份 的密码凭据 应可用。
  - [prisma] 应存在 本用例使用的测试用户和 `team_members` 记录。
  - [prisma] 测试用户 的状态 应为 可登录状态。
  - [prisma] 测试用户 的角色 应为 `admin`。
  - [prisma] 测试用户所属团队 应存在。
  - [prisma] 测试用户所属团队 应存在 至少一个当前测试管理员可见的目标。
  - [api] 测试管理员视角的计划页数据接口 应返回 至少一个标题非空的目标对象。
  - [prisma] 应不存在 `comment_messages.body` 以 `E2E-PLAN-COMMENT:` 开头的独占评论数据。
  - [api] 当前会话 应为 未登录。
  - [playwright] 当前浏览器 应不存在 Ory session cookie。
  - [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [playwright] 创建全新的浏览器上下文，或清空当前上下文的 cookies/localStorage/sessionStorage。
  - [playwright] 打开 登录页。
  - [playwright] 使用 B 中已存在的测试管理员账号 登录。
  - [playwright] 打开 计划页面。
  - [api] 读取 测试管理员视角的计划页数据接口。
  - [api] 从计划页数据接口返回的目标集合中选择一个标题非空的可见目标并记录为 `runtime.commentTarget`。
  - [api] `runtime.commentTarget.type` 应为 `objective`。
  - [api] `runtime.commentTarget` 应不依赖固定标题或固定 ID。
  - [playwright] 在计划页挑战树中定位 `runtime.commentTarget.title` 对应的目标行，通过目标行块菜单点击 `评论`，打开该目标的评论窗口。

- S0：Action 前状态。
  - [api] 当前会话 应为 角色为 `admin` 的已登录会话。
  - [api] 计划页数据接口 应返回 `runtime.commentTarget` 对应的目标对象。
  - [playwright] 当前页面 应为 计划页面。
  - [playwright] 计划页面中 `runtime.commentTarget.title` 对应的目标行 应可见。
  - [playwright] 评论窗口 应可见。
  - [playwright] 评论窗口标题 应为 `runtime.commentTarget.title`。
  - [playwright] 评论输入框可见，placeholder 为 `添加评论...`。
  - [playwright] "发送评论" 操作 应存在。
  - [playwright] 评论输入框为空时 "发送评论" 操作 应不可点击。
  - [prisma] `comment_threads` 和 `comment_messages` 中 应不存在 本用例的测试评论正文。

- Action：被测业务动作。
  - [playwright] 在评论输入框中输入 `E2E-PLAN-COMMENT: 需要补充边界样例覆盖情况`。
  - [playwright] 点击 "发送评论" 操作提交评论，或在评论输入框中使用快捷键提交评论。

- S1：Action 后状态。
  - [api] 新增评论接口响应 应成功。
  - [api] 新增评论响应的 `ok` 应为 `true`。
  - [api] 新增评论响应的 `commentThread.targetType`、`commentThread.targetId`、`commentThread.targetTitle` 应与 `runtime.commentTarget` 一致。
  - [playwright] 评论窗口 应显示 当前测试管理员名称。
  - [playwright] 评论窗口 应显示 正文 `E2E-PLAN-COMMENT: 需要补充边界样例覆盖情况`。
  - [playwright] 评论输入框 应清空。
  - [playwright] 评论输入框 placeholder 应为 `添加评论...`。
  - [playwright] 关闭评论窗口后，计划页面该目标显示评论数量入口；再次打开后仍能看到该评论。
  - [api] 计划页数据接口 应返回 `runtime.commentTarget` 对应的评论线程。
  - [api] 评论线程 应包含 一条 `parentMessageId` 为空的测试消息。
  - [api] 测试消息作者和正文 应符合 测试数据。
  - [prisma] `comment_threads` 中 应存在 一条 `status = "open"`、`target_type = "objective"`、`target_id` 与 `runtime.commentTarget.id` 一致的线程。
  - [prisma] `comment_messages` 中 应存在 一条关联该线程的测试消息。
  - [prisma] 测试消息的 `author_user_id` 应为 当前测试用户。
  - [prisma] 测试消息的 `body` 应为 `E2E-PLAN-COMMENT: 需要补充边界样例覆盖情况`。
  - [prisma] 测试消息的 `parent_message_id`、`reply_to_message_id`、`reply_to_author` 应为空。

- Clean：恢复 B。
  - [prisma] 删除 `comment_messages.body` 以 `E2E-PLAN-COMMENT:` 开头的测试消息。
  - [prisma] 若删除消息后对应测试评论线程已无消息，删除 `runtime.commentTarget` 对应的空评论线程。
  - [playwright] 若评论窗口仍打开，点击 `关闭评论窗口`。
  - [api] 调用退出登录接口撤销本次登录产生的 Ory session。
  - [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [prisma] B 中用于开测的可见目标数据、测试管理员和成员关系 应仍存在。
  - [api] 测试 Ory 身份 应仍存在。
