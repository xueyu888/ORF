# 目标新增评论

## 1. 测试目标

验证：本用例独占管理员可以在计划页面打开独占目标的评论窗口并新增外层评论；新增后，评论会在页面显示，并持久化到后端评论数据中。

边界：

- 覆盖对象：计划页面目标的外层评论新增。
- 不覆盖对象：指标评论、任务评论、子任务评论、回复、编辑、删除、解决状态、跨用户协作、越权管理。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：独占管理员身份/用户/成员关系、标题为 `E2E-OBJECTIVE-COMMENT: 目标前置` 的独占目标，以及打开了该目标评论窗口的计划页面。
- Action 产物：正文以 `E2E-PLAN-COMMENT:` 开头的测试评论消息及其评论线程。
- Clean 产物：删除本用例创建的测试评论消息、空测试评论线程、独占目标、管理员身份、用户和成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的正文以 `E2E-PLAN-COMMENT:` 开头的测试评论消息及空线程。
  - [Setup-2] [prisma] 删除可能残留的标题为 `E2E-OBJECTIVE-COMMENT: 目标前置` 的本用例目标及其派生数据。
  - [Setup-3] [api] 准备邮箱为 `orf-admin-objective-comment-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-4] [prisma] 准备邮箱为 `orf-admin-objective-comment-e2e@orf.local`、状态为 `active` 的管理员用户记录。
  - [Setup-5] [prisma] 准备管理员用户的默认团队成员关系，角色为 `admin`。
  - [Setup-6] [prisma] 创建标题为 `E2E-OBJECTIVE-COMMENT: 目标前置` 的本用例独占目标。
  - [Setup-7] [prisma] 记录本用例独占目标为评论目标。
  - [Setup-8] [api] 撤销管理员登录身份可能残留的登录会话。
  - [Setup-9] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-10] [playwright] 打开 ORF 登录页。
  - [Setup-11] [playwright] 在邮箱输入框输入管理员固定测试邮箱。
  - [Setup-12] [playwright] 在密码输入框输入管理员固定测试密码。
  - [Setup-13] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-14] [api] 当前会话 应为 已登录。
  - [Setup-15] [api] 当前会话用户邮箱 应为 `orf-admin-objective-comment-e2e@orf.local`。
  - [Setup-16] [api] 当前会话用户角色 应为 `admin`。
  - [Setup-17] [api] 当前会话用户状态 应为 `active`。
  - [Setup-18] [playwright] 打开 计划页面。
  - [Setup-19] [api] 计划页数据 应包含 评论目标。
  - [Setup-20] [playwright] 在计划页挑战树中打开评论目标的评论窗口。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-admin-objective-comment-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `admin`。
  - [S0-4] [api] 当前会话用户状态 应为 `active`。
  - [S0-5] [api] 计划页数据 应包含 评论目标。
  - [S0-6] [playwright] 当前页面 应为 计划页面。
  - [S0-7] [playwright] 计划页面中 评论目标行 应可见。
  - [S0-8] [playwright] 评论窗口标题 应为 评论目标标题。
  - [S0-9] [playwright] 评论输入框 应可用于输入评论。
  - [S0-10] [playwright] 评论输入框为空时 "发送评论" 操作 应不可点击。
  - [S0-11] [prisma] 数据库中 应不存在 本用例的测试评论正文。

- Action：被测业务动作。
  - [Action-1] [api] 监听新增评论请求响应。
  - [Action-2] [playwright] 在评论输入框中输入测试评论正文。
  - [Action-3] [playwright] 点击 "发送评论" 操作。

- S1：Action 后状态。
  - [S1-1] [api] 新增评论结果 应成功并关联评论目标。
  - [S1-2] [playwright] 评论窗口 应显示 当前测试管理员名称。
  - [S1-3] [playwright] 评论窗口 应显示 测试评论正文。
  - [S1-4] [playwright] 评论输入框 应清空。
  - [S1-5] [playwright] 关闭评论窗口。
  - [S1-6] [playwright] 目标行 应显示评论数量入口。
  - [S1-7] [playwright] 通过评论数量入口重新打开评论窗口。
  - [S1-8] [playwright] 重新打开后仍能看到测试评论正文。
  - [S1-9] [api] 计划页数据 应包含 评论目标的评论线程和测试消息。
  - [S1-10] [prisma] 数据库中 应持久化该目标外层评论。

- Clean：恢复 B。
  - [Clean-1] [playwright] 若评论窗口仍打开，点击 `关闭评论窗口`。
  - [Clean-2] [prisma] 删除 本用例创建的测试评论消息及空线程。
  - [Clean-3] [prisma] 删除 本用例独占目标及其派生数据。
  - [Clean-4] [api] 注销当前登录会话。
  - [Clean-5] [playwright] 离开当前 ORF 前端页面。
  - [Clean-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-7] [api] 撤销管理员登录身份的残留登录会话。
  - [Clean-8] [api] 删除邮箱为 `orf-admin-objective-comment-e2e@orf.local` 的管理员登录身份。
  - [Clean-9] [prisma] 删除邮箱为 `orf-admin-objective-comment-e2e@orf.local` 的管理员用户默认团队成员关系。
  - [Clean-10] [prisma] 删除邮箱为 `orf-admin-objective-comment-e2e@orf.local` 的管理员用户。
  - [Clean-11] [prisma] 正文以 `E2E-PLAN-COMMENT:` 开头的测试评论消息 应不存在。
  - [Clean-12] [prisma] 标题为 `E2E-OBJECTIVE-COMMENT: 目标前置` 的本用例目标 应不存在。
  - [Clean-13] [prisma] 邮箱为 `orf-admin-objective-comment-e2e@orf.local` 的管理员用户 应不存在。
