# 评论上传图片-非图片文件不可上传

## 1. 测试目标

验证：已登录且参与目标的普通成员不能在目标和任务评论中上传非图片文件；直接调用上传接口会被拒绝，界面选择非图片文件会提示错误，并且数据库不会产生图片附件。

实现说明：

- 当前用例类型：反向校验用例。
- 当前代码状态：生成独立 testd 用例，按目标和任务两个评论对象参数化执行。

边界：

- 覆盖对象：评论图片上传的非图片文件校验。
- 不覆盖对象：图片预览大图、粘贴上传、附件删除、回复中的图片、提及、非参与成员不可上传附件。
- 依赖对象：[评论上传图片](评论上传图片.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何业务 fixture。
- Setup 产物：普通成员用户、该成员参与的可评论目标、目标下的任务、当前评论对象、本用例非图片文件、打开后的评论窗口。
- Action 产物：普通成员上传非图片文件的接口结果和界面错误提示。
- Clean 产物：恢复 member 角色评论管理权限快照，删除本用例评论、附件残留、任务、目标、普通成员身份、用户、成员关系和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例测试评论和图片附件。
  - [Setup-2] [prisma] 删除可能残留的本用例目标和任务。
  - [Setup-3] [api] 准备普通成员登录身份。
  - [Setup-4] [prisma] 准备状态为 `active` 的普通成员用户和默认团队成员关系。
  - [Setup-5] [prisma] 记录默认团队 member 角色评论管理权限配置快照。
  - [Setup-6] [prisma] 确保默认团队 member 角色不具备 `comment.manage` 权限。
  - [Setup-7] [prisma] 创建生命周期允许新增评论的目标。
  - [Setup-8] [prisma] 设置普通成员参与该目标。
  - [Setup-9] [prisma] 创建该目标下的任务。
  - [Setup-10] [prisma] 记录当前评论对象，评论对象为目标或任务。
  - [Setup-11] [mock] 准备本用例非图片文件。
  - [Setup-12] [api] 撤销普通成员登录身份可能残留的登录会话。
  - [Setup-13] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-14] [playwright] 打开 ORF 登录页。
  - [Setup-15] [playwright] 输入普通成员邮箱和密码。
  - [Setup-16] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-17] [api] 当前会话 应为 普通成员的已登录会话。
  - [Setup-18] [playwright] 打开 计划页面。
  - [Setup-19] [api] 普通成员计划页数据 应包含 当前评论对象。
  - [Setup-20] [playwright] 打开当前评论对象的评论窗口。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 普通成员的已登录会话。
  - [S0-2] [playwright] 评论输入框 应可用于输入评论。
  - [S0-3] [playwright] "添加图片" 操作 应可点击。
  - [S0-4] [prisma] 数据库中 应不存在 本用例非图片附件。

- Action：被测业务动作。
  - [Action-1] [api] 当前普通成员直接尝试上传本用例非图片文件作为评论图片。
  - [Action-2] [playwright] 通过 "添加图片" 操作选择本用例非图片文件。

- S1：Action 后状态。
  - [S1-1] [api] 上传非图片文件结果状态码 应为 415 或等价文件类型错误。
  - [S1-2] [playwright] 评论窗口 应显示 非图片文件错误提示。
  - [S1-3] [prisma] 数据库中 应不存在 本用例非图片附件。
  - [S1-4] [api] 当前会话 应为 普通成员的已登录会话。

- Clean：恢复 B。
  - [Clean-1] [playwright] 若评论窗口仍打开，关闭评论窗口。
  - [Clean-2] [prisma] 若已记录 member 角色评论管理权限配置快照，恢复该快照。
  - [Clean-3] [prisma] 删除 本用例创建的测试评论、图片附件及空线程。
  - [Clean-4] [prisma] 删除 本用例创建的任务。
  - [Clean-5] [prisma] 删除 本用例创建的目标及其派生数据。
  - [Clean-6] [api] 注销当前登录会话。
  - [Clean-7] [playwright] 离开当前 ORF 前端页面。
  - [Clean-8] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-9] [api] 撤销普通成员登录身份的残留登录会话。
  - [Clean-10] [api] 删除普通成员登录身份。
  - [Clean-11] [prisma] 删除普通成员默认团队成员关系和用户记录。
  - [Clean-12] [prisma] 本用例测试评论和图片附件 应不存在。
  - [Clean-13] [prisma] 本用例创建的目标和任务 应不存在。
  - [Clean-14] [api] 普通成员登录身份 应不存在。
  - [Clean-15] [prisma] 普通成员用户记录 应不存在。
