# 成员新增评论-非参与成员不可新增评论

## 1. 测试目标

验证：非参与普通成员不能给目标和任务新增评论；计划页不展示当前评论对象，直接调用新增评论接口也会被拒绝，并且数据库不会产生本用例测试评论。

实现说明：

- 当前用例类型：反向权限用例。
- 当前代码状态：生成独立 testd 用例，按目标和任务两个评论对象参数化执行。

边界：

- 覆盖对象：非参与普通成员不可评论目标和该目标下任务。
- 不覆盖对象：成员参与目标后新增评论、管理员新增评论、回复、编辑、删除、附件、提及。
- 依赖对象：[成员新增评论](成员新增评论.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何业务 fixture。
- Setup 产物：非参与普通成员、目标参与成员、生命周期允许新增评论的目标、该目标下任务、当前评论对象、非参与普通成员已登录会话。
- Action 产物：非参与普通成员直接提交新增评论请求的结果。
- Clean 产物：删除本用例评论、任务、目标、两个普通成员身份、用户、成员关系和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例测试评论。
  - [Setup-2] [prisma] 删除可能残留的本用例目标和任务。
  - [Setup-3] [api] 准备非参与普通成员登录身份。
  - [Setup-4] [prisma] 准备状态为 `active` 的非参与普通成员用户和默认团队成员关系，角色为 `member`。
  - [Setup-5] [api] 准备目标参与成员登录身份。
  - [Setup-6] [prisma] 准备状态为 `active` 的目标参与成员用户和默认团队成员关系，角色为 `member`。
  - [Setup-7] [prisma] 创建生命周期允许新增评论的目标。
  - [Setup-8] [prisma] 设置目标参与成员参与该目标。
  - [Setup-9] [prisma] 创建该目标下的任务。
  - [Setup-10] [prisma] 记录当前评论对象，评论对象为目标或任务。
  - [Setup-11] [api] 撤销非参与普通成员登录身份可能残留的登录会话。
  - [Setup-12] [api] 撤销目标参与成员登录身份可能残留的登录会话。
  - [Setup-13] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-14] [playwright] 打开 ORF 登录页。
  - [Setup-15] [playwright] 输入非参与普通成员邮箱和密码。
  - [Setup-16] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-17] [api] 当前会话 应为 非参与普通成员的已登录会话。
  - [Setup-18] [playwright] 打开 计划页面。
  - [Setup-19] [api] 非参与普通成员计划页数据 应不包含 当前评论对象。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 非参与普通成员的已登录会话。
  - [S0-2] [api] 当前会话用户角色 应为 `member`。
  - [S0-3] [prisma] 当前评论对象 应属于 非参与普通成员未参与且生命周期允许新增评论的目标。
  - [S0-4] [playwright] 当前页面 应为 计划页面。
  - [S0-5] [playwright] 当前评论对象行 应不可见。
  - [S0-6] [api] 非参与普通成员计划页数据 应不包含 当前评论对象。
  - [S0-7] [prisma] 数据库中 应不存在 本用例测试评论正文。

- Action：被测业务动作。
  - [Action-1] [api] 当前非参与普通成员直接尝试在当前评论对象新增本用例测试评论。

- S1：Action 后状态。
  - [S1-1] [api] 新增评论结果状态码 应为 403 或等价权限错误。
  - [S1-2] [api] 非参与普通成员计划页数据 应不包含 当前评论对象。
  - [S1-3] [prisma] 数据库中 应不存在 本用例测试评论正文。
  - [S1-4] [api] 当前会话 应为 非参与普通成员的已登录会话。
  - [S1-5] [api] 当前会话用户角色 应为 `member`。

- Clean：恢复 B。
  - [Clean-1] [playwright] 若评论窗口仍打开，关闭评论窗口。
  - [Clean-2] [prisma] 删除 本用例创建的测试评论及空线程。
  - [Clean-3] [prisma] 删除 本用例创建的任务。
  - [Clean-4] [prisma] 删除 本用例创建的目标及其派生数据。
  - [Clean-5] [api] 注销当前登录会话。
  - [Clean-6] [playwright] 离开当前 ORF 前端页面。
  - [Clean-7] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-8] [api] 撤销非参与普通成员登录身份的残留登录会话。
  - [Clean-9] [api] 撤销目标参与成员登录身份的残留登录会话。
  - [Clean-10] [api] 删除非参与普通成员登录身份。
  - [Clean-11] [api] 删除目标参与成员登录身份。
  - [Clean-12] [prisma] 删除非参与普通成员默认团队成员关系和用户记录。
  - [Clean-13] [prisma] 删除目标参与成员默认团队成员关系和用户记录。
  - [Clean-14] [prisma] 本用例测试评论 应不存在。
  - [Clean-15] [prisma] 本用例创建的目标和任务 应不存在。
  - [Clean-16] [api] 非参与普通成员登录身份 应不存在。
  - [Clean-17] [api] 目标参与成员登录身份 应不存在。
  - [Clean-18] [prisma] 非参与普通成员用户记录 应不存在。
  - [Clean-19] [prisma] 目标参与成员用户记录 应不存在。
