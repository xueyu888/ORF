# 评论回复

## 1. 测试目标

验证：已登录用户可以回复评论。

边界：

- 覆盖对象：目标外层评论的回复、任务外层评论的回复。
- 不覆盖对象：回复编辑、回复删除、多级回复、附件、提及、非参与成员不可回复。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何业务 fixture。
- Setup 产物：普通成员用户、该成员参与的可评论目标、目标下的任务、当前评论对象，以及一条可回复的外层评论。
- Action 产物：普通成员对外层评论新增一条回复。
- Clean 产物：删除本用例创建的评论、回复、任务、目标、普通成员身份、用户、成员关系和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例测试评论和回复。
  - [Setup-2] [prisma] 删除可能残留的本用例目标和任务。
  - [Setup-3] [api] 准备普通成员登录身份。
  - [Setup-4] [prisma] 准备状态为 `active` 的普通成员用户和默认团队成员关系。
  - [Setup-5] [prisma] 创建生命周期允许评论操作的目标。
  - [Setup-6] [prisma] 设置普通成员参与该目标。
  - [Setup-7] [prisma] 创建该目标下的任务。
  - [Setup-8] [prisma] 记录当前评论对象，评论对象为目标或任务。
  - [Setup-9] [prisma] 创建当前评论对象上的可回复外层评论。
  - [Setup-10] [api] 撤销普通成员登录身份可能残留的登录会话。
  - [Setup-11] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-12] [playwright] 打开 ORF 登录页。
  - [Setup-13] [playwright] 输入普通成员邮箱和密码。
  - [Setup-14] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-15] [api] 当前会话 应为 普通成员的已登录会话。
  - [Setup-16] [playwright] 打开 计划页面。
  - [Setup-17] [api] 普通成员计划页数据 应包含 当前评论对象和可回复外层评论。
  - [Setup-18] [playwright] 打开当前评论对象的评论窗口。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 普通成员的已登录会话。
  - [S0-2] [playwright] 评论窗口 应显示 可回复外层评论正文。
  - [S0-3] [playwright] 可回复外层评论的 "回复评论" 操作 应可点击。
  - [S0-4] [prisma] 数据库中 应存在 可回复外层评论。
  - [S0-5] [prisma] 数据库中 应不存在 本用例回复正文。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击 可回复外层评论的 "回复评论" 操作。
  - [Action-2] [playwright] 在回复评论输入框中输入本用例回复正文。
  - [Action-3] [playwright] 点击 "发送回复" 操作。

- S1：Action 后状态。
  - [S1-1] [api] 新增回复结果 应成功并关联当前评论对象。
  - [S1-2] [playwright] 可回复外层评论 应显示回复数量入口。
  - [S1-3] [playwright] 打开可回复外层评论的回复列表。
  - [S1-4] [playwright] 回复列表 应显示 本用例回复正文。
  - [S1-5] [api] 普通成员计划页数据 应包含 本用例回复。
  - [S1-6] [prisma] 数据库中 应持久化 本用例回复，并关联可回复外层评论。

- Clean：恢复 B。
  - [Clean-1] [playwright] 若评论窗口仍打开，关闭评论窗口。
  - [Clean-2] [prisma] 删除 本用例创建的测试评论、回复及空线程。
  - [Clean-3] [prisma] 删除 本用例创建的任务。
  - [Clean-4] [prisma] 删除 本用例创建的目标及其派生数据。
  - [Clean-5] [api] 注销当前登录会话。
  - [Clean-6] [playwright] 离开当前 ORF 前端页面。
  - [Clean-7] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-8] [api] 撤销普通成员登录身份的残留登录会话。
  - [Clean-9] [api] 删除普通成员登录身份。
  - [Clean-10] [prisma] 删除普通成员默认团队成员关系和用户记录。
  - [Clean-11] [prisma] 本用例测试评论和回复 应不存在。
  - [Clean-12] [prisma] 本用例创建的目标和任务 应不存在。
