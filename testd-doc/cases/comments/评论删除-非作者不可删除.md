# 评论删除-非作者不可删除

## 1. 测试目标

验证：参与目标但不是评论作者的普通成员不能删除他人评论；界面不显示删除操作，直接调用删除评论接口也会被拒绝，并且原评论仍然存在。

实现说明：

- 当前用例类型：反向权限用例。
- 当前代码状态：生成独立 testd 用例，按目标和任务两个评论对象参数化执行。

边界：

- 覆盖对象：非作者普通成员不可删除目标和任务外层评论。
- 不覆盖对象：评论作者删除、管理员删除他人评论、回复删除、附件清理策略、提及通知。
- 依赖对象：[评论删除](评论删除.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何业务 fixture。
- Setup 产物：非作者普通成员、评论作者普通成员、双方参与的可评论目标、该目标下任务、当前评论对象、作者已发布的一条外层评论、非作者普通成员已登录会话。
- Action 产物：非作者普通成员直接提交删除评论请求的结果。
- Clean 产物：恢复 member 角色评论管理权限快照，删除本用例评论、任务、目标、两个普通成员身份、用户、成员关系和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例测试评论。
  - [Setup-2] [prisma] 删除可能残留的本用例目标和任务。
  - [Setup-3] [api] 准备非作者普通成员登录身份。
  - [Setup-4] [prisma] 准备状态为 `active` 的非作者普通成员用户和默认团队成员关系，角色为 `member`。
  - [Setup-5] [prisma] 记录默认团队 member 角色评论管理权限配置快照。
  - [Setup-6] [prisma] 确保默认团队 member 角色不具备 `comment.manage` 权限。
  - [Setup-7] [api] 准备评论作者普通成员登录身份。
  - [Setup-8] [prisma] 准备状态为 `active` 的评论作者普通成员用户和默认团队成员关系，角色为 `member`。
  - [Setup-9] [prisma] 创建生命周期允许评论操作的目标。
  - [Setup-10] [prisma] 设置非作者普通成员参与该目标。
  - [Setup-11] [prisma] 设置评论作者普通成员参与该目标。
  - [Setup-12] [prisma] 创建该目标下的任务。
  - [Setup-13] [prisma] 记录当前评论对象，评论对象为目标或任务。
  - [Setup-14] [prisma] 创建评论作者普通成员在当前评论对象上的外层评论。
  - [Setup-15] [api] 撤销非作者普通成员登录身份可能残留的登录会话。
  - [Setup-16] [api] 撤销评论作者普通成员登录身份可能残留的登录会话。
  - [Setup-17] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-18] [playwright] 打开 ORF 登录页。
  - [Setup-19] [playwright] 输入非作者普通成员邮箱和密码。
  - [Setup-20] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-21] [api] 当前会话 应为 非作者普通成员的已登录会话。
  - [Setup-22] [playwright] 打开 计划页面。
  - [Setup-23] [api] 非作者普通成员计划页数据 应包含 当前评论对象和本用例测试评论。
  - [Setup-24] [playwright] 打开当前评论对象的评论窗口。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 非作者普通成员的已登录会话。
  - [S0-2] [playwright] 评论窗口 应显示 本用例测试评论正文。
  - [S0-3] [playwright] 本用例测试评论的 "删除评论" 操作 应不可见。
  - [S0-4] [playwright] 本用例测试评论的 "编辑评论" 操作 应不可见。
  - [S0-5] [prisma] 数据库中 应存在 本用例测试评论正文。

- Action：被测业务动作。
  - [Action-1] [api] 当前非作者普通成员直接尝试删除本用例测试评论。

- S1：Action 后状态。
  - [S1-1] [api] 删除评论结果状态码 应为 403 或等价权限错误。
  - [S1-2] [playwright] 评论窗口 应仍显示 本用例测试评论正文。
  - [S1-3] [prisma] 数据库中 应仍存在 本用例测试评论正文。
  - [S1-4] [api] 当前会话 应为 非作者普通成员的已登录会话。

- Clean：恢复 B。
  - [Clean-1] [playwright] 若评论窗口仍打开，关闭评论窗口。
  - [Clean-2] [prisma] 若已记录 member 角色评论管理权限配置快照，恢复该快照。
  - [Clean-3] [prisma] 删除 本用例创建的测试评论及空线程。
  - [Clean-4] [prisma] 删除 本用例创建的任务。
  - [Clean-5] [prisma] 删除 本用例创建的目标及其派生数据。
  - [Clean-6] [api] 注销当前登录会话。
  - [Clean-7] [playwright] 离开当前 ORF 前端页面。
  - [Clean-8] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-9] [api] 撤销非作者普通成员登录身份的残留登录会话。
  - [Clean-10] [api] 撤销评论作者普通成员登录身份的残留登录会话。
  - [Clean-11] [api] 删除非作者普通成员登录身份。
  - [Clean-12] [api] 删除评论作者普通成员登录身份。
  - [Clean-13] [prisma] 删除非作者普通成员默认团队成员关系和用户记录。
  - [Clean-14] [prisma] 删除评论作者普通成员默认团队成员关系和用户记录。
  - [Clean-15] [prisma] 本用例测试评论 应不存在。
  - [Clean-16] [prisma] 本用例创建的目标和任务 应不存在。
  - [Clean-17] [api] 非作者普通成员登录身份 应不存在。
  - [Clean-18] [api] 评论作者普通成员登录身份 应不存在。
  - [Clean-19] [prisma] 非作者普通成员用户记录 应不存在。
  - [Clean-20] [prisma] 评论作者普通成员用户记录 应不存在。
