# 管理员新增并发布目标-普通成员不可新增目标

## 1. 测试目标

验证：普通成员不能新增目标；普通成员界面不显示 "新建目标" 操作，直接调用创建目标接口也会被拒绝，并且系统不会产生普通成员创建的测试目标。

实现说明：

- 当前实现：创建目标需要 `objective.create` 权限，普通成员默认不具备该权限。
- 当前用例类型：反向权限用例。
- 当前代码状态：已生成独立 testd 用例。

边界：

- 覆盖对象：普通成员不可新增目标。
- 不覆盖对象：管理员新增目标并发布、目标发布后可见性、目标指标和行动项创建、挑战申请、征召、冻结、验收、结算。
- 依赖对象：[管理员新增并发布目标](管理员新增并发布目标.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体用户或目标。
- Setup 产物：邮箱为 `orf-member-objective-create-forbidden-e2e@orf.local` 的普通成员身份、用户、默认团队成员关系和已登录会话。
- Action 产物：普通成员直接提交创建目标请求的结果。
- Clean 产物：删除可能残留的测试目标，删除本用例独占普通成员身份、用户、成员关系和 session。
