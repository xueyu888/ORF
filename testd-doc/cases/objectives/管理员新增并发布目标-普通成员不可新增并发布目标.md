# 管理员新增并发布目标-普通成员不可新增并发布目标

## 1. 测试目标

验证：新增并发布目标是管理员业务能力；未被授予 `objective.create` 权限的普通成员进入挑战工作台后，前端不提供新增目标入口和发布目标入口，系统不会产生普通成员创建的目标，也不会把该目标发布到悬赏大厅。

边界：

- 覆盖对象：普通成员在前端不可新增目标，也不可发布目标。
- 不覆盖对象：管理员新增并发布、已授权普通成员新增目标、普通成员发布既有候选目标、目标指标和行动项创建、挑战申请、征召、冻结、验收、结算。
- 依赖对象：[管理员新增并发布目标](管理员新增并发布目标.md) 的正向业务定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体用户或目标。
- Setup 产物：本次运行独占普通成员邮箱对应的普通成员身份、用户、默认团队成员关系和已登录会话；普通成员角色在默认团队中不具备 `objective.create` 权限。
- Action 产物：普通成员进入挑战工作台后可见的目标操作入口和工作台数据。
- Clean 产物：删除可能残留的测试目标，恢复普通成员角色的 Setup 前权限配置，删除本用例独占普通成员身份、用户、成员关系和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例测试目标及其派生数据。
  - [Setup-2] [api] 准备本次运行独占普通成员登录身份，使用固定测试密码。
  - [Setup-3] [prisma] 准备本次运行独占普通成员用户记录，状态为 `active`。
  - [Setup-4] [prisma] 准备本次运行独占普通成员用户默认团队成员关系，角色为 `member`。
  - [Setup-5] [prisma] 记录普通成员角色的原始权限配置，并移除 `objective.create` 权限。
  - [Setup-6] [api] 撤销普通成员登录身份可能残留的登录会话。
  - [Setup-7] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-8] [playwright] 打开 ORF 登录页。
  - [Setup-9] [playwright] 在邮箱输入框输入本次运行独占普通成员邮箱。
  - [Setup-10] [playwright] 在密码输入框输入普通成员固定测试密码。
  - [Setup-11] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-12] [api] 当前会话 应为 已登录。
  - [Setup-13] [api] 当前会话用户邮箱 应为 本次运行独占普通成员邮箱。
  - [Setup-14] [api] 当前会话用户角色 应为 `member`。
  - [Setup-15] [api] 当前会话用户状态 应为 `active`。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 本次运行独占普通成员邮箱。
  - [S0-3] [api] 当前会话用户角色 应为 `member`。
  - [S0-4] [api] 当前会话用户状态 应为 `active`。
  - [S0-5] [prisma] 普通成员角色 应不具备 `objective.create` 权限。
  - [S0-6] [prisma] 应不存在 本次运行独占测试目标标题对应的测试目标。

- Action：被测业务动作。
  - [Action-1] [playwright] 普通成员打开 挑战工作台。
  - [Action-2] [api] 读取 普通成员挑战工作台数据。

- S1：Action 后状态。
  - [S1-1] [playwright] 当前页面 应为 挑战工作台。
  - [S1-2] [playwright] "我的挑战" 视图 应可用。
  - [S1-3] [playwright] "新建目标" 操作 应不可见。
  - [S1-4] [playwright] "发布" 操作 应不可见。
  - [S1-5] [api] 普通成员挑战工作台数据 应不包含 本次运行独占测试目标标题对应的测试目标。
  - [S1-6] [api] 普通成员视角的悬赏大厅数据 应不包含 本次运行独占测试目标标题对应的测试目标。
  - [S1-7] [prisma] 应不存在 本次运行独占测试目标标题对应的测试目标。
  - [S1-8] [api] 当前会话 应为 已登录。
  - [S1-9] [api] 当前会话用户邮箱 应为 本次运行独占普通成员邮箱。
  - [S1-10] [api] 当前会话用户角色 应为 `member`。
  - [S1-11] [api] 当前会话用户状态 应为 `active`。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的目标及其派生数据。
  - [Clean-2] [prisma] 恢复普通成员角色的 Setup 前权限配置。
  - [Clean-3] [api] 注销当前登录会话。
  - [Clean-4] [playwright] 离开当前 ORF 前端页面。
  - [Clean-5] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-6] [api] 撤销普通成员登录身份的残留登录会话。
  - [Clean-7] [api] 删除本次运行独占普通成员登录身份。
  - [Clean-8] [prisma] 删除本次运行独占普通成员用户默认团队成员关系。
  - [Clean-9] [prisma] 删除本次运行独占普通成员用户。
  - [Clean-10] [prisma] 应不存在 本次运行独占测试目标标题对应的测试目标。
  - [Clean-11] [api] 本次运行独占普通成员登录身份 应不存在。
  - [Clean-12] [prisma] 本次运行独占普通成员用户 应不存在。
