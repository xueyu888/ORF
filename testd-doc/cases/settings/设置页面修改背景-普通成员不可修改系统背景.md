# 设置页面修改背景-普通成员不可修改系统背景

## 1. 测试目标

验证：普通成员不能修改系统登录页背景和系统默认 顶部栏皮肤；系统设置页面不可访问，直接调用系统背景写接口也会被拒绝，并且系统背景配置保持不变。

实现说明：

- 当前实现：`/system/settings` 仅管理员可访问。
- 当前实现：系统背景上传、设置默认背景和保存切换规则的写接口要求管理员权限。
- 当前用例类型：反向权限用例。
- 当前代码状态：生成独立 testd 用例。

边界：

- 覆盖对象：普通成员不可访问系统设置，不可写入系统级 `login_background` 和 `topbar_background` 配置。
- 不覆盖对象：普通成员个人背景、管理员系统背景配置、图片上传文件校验、背景图片渲染效果。
- 依赖对象：[设置页面修改背景-管理员可以修改背景](设置页面修改背景-管理员可以修改背景.md) 的系统管理背景配置定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何业务 fixture。
- Setup 产物：普通成员身份、用户记录、默认团队成员关系、系统背景配置快照、普通成员已登录会话。
- Action 产物：普通成员访问系统设置页面的结果，普通成员直接提交系统登录页和 顶部栏皮肤配置写请求的结果。
- Clean 产物：系统背景列表与配置恢复为 Setup 记录快照，删除独占普通成员身份、用户和成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 记录当前系统 `login_background` 和 `topbar_background` 背景列表与配置快照。
  - [Setup-2] [api] 准备邮箱为 `orf-member-background-system-forbidden-e2e@orf.local`、使用固定测试密码的普通成员登录身份。
  - [Setup-3] [prisma] 准备邮箱为 `orf-member-background-system-forbidden-e2e@orf.local`、状态为 `active` 的普通成员用户记录。
  - [Setup-4] [prisma] 准备普通成员用户的默认团队成员关系，角色为 `member`。
  - [Setup-5] [api] 撤销普通成员登录身份可能残留的登录会话。
  - [Setup-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-7] [playwright] 打开 ORF 登录页。
  - [Setup-8] [playwright] 在邮箱输入框输入普通成员固定测试邮箱。
  - [Setup-9] [playwright] 在密码输入框输入普通成员固定测试密码。
  - [Setup-10] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-11] [api] 当前会话 应为 已登录。
  - [Setup-12] [api] 当前会话用户邮箱 应为 `orf-member-background-system-forbidden-e2e@orf.local`。
  - [Setup-13] [api] 当前会话用户角色 应为 `member`。
  - [Setup-14] [api] 当前会话用户状态 应为 `active`。
  - [Setup-15] [playwright] 打开 悬赏大厅。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-member-background-system-forbidden-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `member`。
  - [S0-4] [api] 当前会话用户状态 应为 `active`。
  - [S0-5] [playwright] 当前页面 应为 悬赏大厅。
  - [S0-6] [playwright] 系统设置入口 应不可见。
  - [S0-7] [api] 当前系统 `login_background` 配置 应等于 系统背景配置快照中的 `login_background` 配置。
  - [S0-8] [api] 当前系统 `topbar_background` 配置 应等于 系统背景配置快照中的 `topbar_background` 配置。

- Action：被测业务动作。
  - [Action-1] [playwright] 普通成员直接打开 系统设置页面。
  - [Action-2] [api] 当前普通成员直接提交系统 `login_background` 背景配置修改。
  - [Action-3] [api] 当前普通成员直接提交系统 `topbar_background` 顶部栏皮肤配置修改。

- S1：Action 后状态。
  - [S1-1] [playwright] 当前页面 应回到 悬赏大厅。
  - [S1-2] [api] 修改系统 `login_background` 背景配置结果状态码 应为 403 或等价权限错误。
  - [S1-3] [api] 修改系统 `topbar_background` 背景配置结果状态码 应为 403 或等价权限错误。
  - [S1-4] [api] 当前系统 `login_background` 配置 应等于 系统背景配置快照中的 `login_background` 配置。
  - [S1-5] [api] 当前系统 `topbar_background` 配置 应等于 系统背景配置快照中的 `topbar_background` 配置。
  - [S1-6] [api] 当前会话 应为 已登录。
  - [S1-7] [api] 当前会话用户邮箱 应为 `orf-member-background-system-forbidden-e2e@orf.local`。
  - [S1-8] [api] 当前会话用户角色 应为 `member`。
  - [S1-9] [api] 当前会话用户状态 应为 `active`。

- Clean：恢复 B。
  - [Clean-1] [api] 若已记录系统背景配置快照，恢复系统 `login_background` 和 `topbar_background` 背景列表与配置。
  - [Clean-2] [api] 注销当前登录会话。
  - [Clean-3] [playwright] 离开当前 ORF 前端页面。
  - [Clean-4] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-5] [api] 撤销普通成员登录身份的残留登录会话。
  - [Clean-6] [api] 删除邮箱为 `orf-member-background-system-forbidden-e2e@orf.local` 的普通成员登录身份。
  - [Clean-7] [prisma] 删除邮箱为 `orf-member-background-system-forbidden-e2e@orf.local` 的普通成员默认团队成员关系。
  - [Clean-8] [prisma] 删除邮箱为 `orf-member-background-system-forbidden-e2e@orf.local` 的普通成员用户。
  - [Clean-9] [api] 系统 `login_background` 和 `topbar_background` 背景列表与配置 应等于 系统背景配置快照。
  - [Clean-10] [api] 邮箱为 `orf-member-background-system-forbidden-e2e@orf.local` 的普通成员登录身份 应不存在。
  - [Clean-11] [prisma] 邮箱为 `orf-member-background-system-forbidden-e2e@orf.local` 的普通成员用户 应不存在。
