# 设置页面修改背景-管理员可以修改背景

## 1. 测试目标

验证：管理员可以进入设置页面并修改侧边栏背景配置；保存后接口返回成功，重新读取的侧边栏背景配置变为管理员提交的新配置。

实现说明：

- 当前实现：设置入口和背景写接口要求管理员权限。
- 当前用例类型：正向权限用例。
- 当前代码状态：已生成独立 testd 用例。

边界：

- 覆盖对象：管理员可进入设置页面并修改侧边栏背景配置。
- 不覆盖对象：普通成员权限拒绝、图片上传文件校验、登录页背景切换规则、背景图片渲染效果。
- 依赖对象：[设置页面修改背景](设置页面修改背景.md) 的权限防护定义。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：独占管理员身份、管理员用户、默认团队成员关系、背景配置快照，以及打开后的设置页面。
- Action 产物：管理员提交的新侧边栏背景配置。
- Clean 产物：背景配置恢复为 Setup 记录快照，删除独占管理员身份、用户和成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 记录当前登录页背景和侧边栏背景配置快照。
  - [Setup-2] [api] 准备邮箱为 `orf-admin-background-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-3] [prisma] 准备邮箱为 `orf-admin-background-e2e@orf.local`、状态为 `active` 的管理员用户记录。
  - [Setup-4] [prisma] 准备管理员用户的默认团队成员关系，角色为 `admin`。
  - [Setup-5] [api] 撤销管理员登录身份可能残留的登录会话。
  - [Setup-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-7] [playwright] 打开 ORF 登录页。
  - [Setup-8] [playwright] 在邮箱输入框输入管理员固定测试邮箱。
  - [Setup-9] [playwright] 在密码输入框输入管理员固定测试密码。
  - [Setup-10] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-11] [api] 当前会话 应为 已登录。
  - [Setup-12] [api] 当前会话用户邮箱 应为 `orf-admin-background-e2e@orf.local`。
  - [Setup-13] [api] 当前会话用户角色 应为 `admin`。
  - [Setup-14] [api] 当前会话用户状态 应为 `active`。
  - [Setup-15] [playwright] 打开 设置页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-admin-background-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `admin`。
  - [S0-4] [api] 当前会话用户状态 应为 `active`。
  - [S0-5] [prisma] ORF 业务系统中 应存在 邮箱为 `orf-admin-background-e2e@orf.local`、状态为 `active` 的管理员用户记录。
  - [S0-6] [prisma] 管理员用户的默认团队成员关系角色 应为 `admin`。
  - [S0-7] [playwright] 当前页面 应为 设置页面。
  - [S0-8] [playwright] 当前页面 应显示 `视觉设置`。
  - [S0-9] [playwright] 当前页面 应显示 `侧边栏背景设置`。
  - [S0-10] [api] 当前管理员读取侧边栏背景列表结果 应成功。
  - [S0-11] [api] 当前侧边栏背景配置 应等于 背景配置快照中的侧边栏背景配置。

- Action：被测业务动作。
  - [Action-1] [api] 基于背景配置快照生成新的侧边栏背景配置。
  - [Action-2] [api] 当前管理员提交新的侧边栏背景配置。
  - [Action-3] [playwright] 刷新 设置页面。

- S1：Action 后状态。
  - [S1-1] [api] 背景配置修改结果状态码 应为 200。
  - [S1-2] [api] 背景配置修改结果 应包含 新的侧边栏背景配置。
  - [S1-3] [api] 重新读取的侧边栏背景配置 应等于 新的侧边栏背景配置。
  - [S1-4] [api] 重新读取的侧边栏背景配置 应不等于 背景配置快照中的侧边栏背景配置。
  - [S1-5] [playwright] 当前页面 应为 设置页面。
  - [S1-6] [playwright] 当前页面 应显示 `侧边栏背景设置`。
  - [S1-7] [api] 当前会话 应为 已登录。
  - [S1-8] [api] 当前会话用户邮箱 应为 `orf-admin-background-e2e@orf.local`。
  - [S1-9] [api] 当前会话用户角色 应为 `admin`。
  - [S1-10] [api] 当前会话用户状态 应为 `active`。

- Clean：恢复 B。
  - [Clean-1] [api] 若已记录背景配置快照，恢复登录页背景和侧边栏背景配置。
  - [Clean-2] [api] 注销当前登录会话。
  - [Clean-3] [playwright] 离开当前 ORF 前端页面。
  - [Clean-4] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-5] [api] 撤销管理员登录身份的残留登录会话。
  - [Clean-6] [api] 删除邮箱为 `orf-admin-background-e2e@orf.local` 的管理员登录身份。
  - [Clean-7] [prisma] 删除邮箱为 `orf-admin-background-e2e@orf.local` 的管理员默认团队成员关系。
  - [Clean-8] [prisma] 删除邮箱为 `orf-admin-background-e2e@orf.local` 的管理员用户。
  - [Clean-9] [api] 登录页背景和侧边栏背景配置 应等于 背景配置快照。
  - [Clean-10] [api] 邮箱为 `orf-admin-background-e2e@orf.local` 的管理员登录身份 应不存在。
  - [Clean-11] [prisma] 邮箱为 `orf-admin-background-e2e@orf.local` 的管理员用户 应不存在。
