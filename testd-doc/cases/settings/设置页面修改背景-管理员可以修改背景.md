# 设置页面修改背景-管理员可以修改背景

## 1. 测试目标

验证：管理员可以在系统设置中切换登录页背景和系统默认 AppShell 皮肤。

实现说明：

- 当前实现：`/settings` 承载个人设置，普通成员和管理员均可通过设置图标切换本人 AppShell 皮肤。
- 当前实现：`/system/settings` 承载系统设置，仅管理员可通过系统管理访问。
- 当前实现：系统设置页包含 `登录页面背景设置` 和 `AppShell 皮肤设置`，分别对应系统级 `login_background` 和兼容场景 `app_background`。
- 当前实现：管理员可以上传系统候选背景，从背景列表中选择图片，并将选中图片设为默认背景。
- 当前实现：系统背景上传、设置默认背景和保存切换规则的写接口仍要求管理员权限。
- 当前用例类型：管理员系统背景正向用例。
- 当前代码状态：已生成独立 testd 用例。

边界：

- 覆盖对象：管理员在系统管理中上传候选背景，并切换登录页背景和系统默认 AppShell 皮肤。
- 不覆盖对象：普通成员个人背景、管理员个人背景、普通成员访问系统设置的权限拒绝、图片上传文件校验、背景图片渲染效果。
- 依赖对象：[设置页面修改背景](设置页面修改背景.md) 的个人设置背景定义。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：独占管理员身份、管理员用户、默认团队成员关系、系统背景配置快照，以及打开后的系统设置页面。
- Action 产物：管理员上传的登录页候选背景和 AppShell 皮肤候选背景，分别成为系统级 `login_background` 和 `app_background` 的当前默认背景。
- Clean 产物：系统背景列表与配置恢复为 Setup 记录快照，删除独占管理员身份、用户和成员关系，并清空页面运行态和 session。
