## 1. 测试目标

验证：当前权限模型下，普通成员不能进入设置页面修改系统背景；直接访问或调用背景写接口都会被拒绝，背景配置保持不变。

实现说明：

- 当前实现：设置入口和背景写接口要求管理员权限。
- 当前用例类型：权限防护用例。
- 未来调整条件：若产品允许普通成员修改个人背景偏好，应先调整前端可见性和后端权限。

边界：

- 覆盖对象：普通成员不可修改设置背景。
- 不覆盖对象：管理员上传图片、设置默认背景、切换规则保存、图片文件校验。
- B 基础数据：预置普通成员账号 "orf-member-e2e@orf.local"，角色为 member，状态为 active。
- Clean 产物：背景列表和背景配置保持 B 阶段记录值。

## 2. 状态模型

- B：基准状态。
  - [api] 前端服务 应可用。
  - [api] 后端服务 应可用。
  - [api] 前端登录页入口 应可访问。
  - [api] 当前会话查询接口 应可访问。
  - [prisma] ORF 数据库 应可连接。
  - [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [api] Ory/Kratos Admin/Public API 应可访问。
  - [api] 应存在 邮箱为 `orf-member-e2e@orf.local` 的普通成员测试身份。
  - [api] 普通成员测试身份 的密码凭据 应可用。
  - [prisma] 应存在 名称为 `ORF Member E2E`、角色为 `member`、状态为 `active` 的普通成员测试用户。
  - [api] 记录当前 `login_background` 和 `sidebar_background` 的背景列表与配置。
  - [api] 当前会话 应为 未登录。
  - [playwright] 当前浏览器 应不存在 Ory session cookie。
  - [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [playwright] 创建全新的浏览器上下文，或清空当前上下文的 cookies/localStorage/sessionStorage。
  - [playwright] 打开 登录页，使用普通成员测试邮箱和密码登录。
  - [playwright] 打开 悬赏大厅或登录后默认可访问页面。

- S0：Action 前状态。
  - [api] 当前会话 应为 邮箱为 `orf-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [playwright] 主导航 应可见。
  - [playwright] 当前用户显示 应为 `ORF Member E2E`。
  - [playwright] 侧边栏 `设置` 入口 应不可见。
  - [playwright] 悬赏大厅 应可访问。
  - [api] 以当前普通成员会话读取侧边栏背景列表接口 应成功。

- Action：被测业务动作。
  - [playwright] 打开 设置页面。
  - [api] 以当前普通成员会话尝试调用背景配置修改接口修改 `sidebar_background` 配置。
  - [api] 以当前普通成员会话尝试调用默认背景设置接口设置默认背景。
  - [api] 若当前没有可用背景图片，则跳过默认背景设置接口尝试。

- S1：Action 后状态。
  - [playwright] 直接访问设置页面后 当前页面 应不为 设置页面。
  - [playwright] 当前页面 应为 悬赏大厅或其他当前用户可访问页面。
  - [playwright] 页面中不显示 `视觉设置`、`登录页面背景设置` 或 `侧边栏背景设置`。
  - [api] 背景配置修改接口响应状态码 应为 403 或等价权限错误。
  - [api] 默认背景设置接口响应状态码 应为 403 或等价权限错误。
  - [api] 再次读取 `login_background` 和 `sidebar_background` 的背景列表与配置，与 B 阶段记录一致。
  - [playwright] 普通成员 应保持 已登录状态。
  - [playwright] 普通成员 应可继续访问 悬赏大厅。

- Clean：恢复 B。
  - [api] 调用退出登录接口撤销本次登录产生的 Ory session。
  - [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [api] `login_background` 和 `sidebar_background` 背景列表与配置 应等于 B 阶段记录值。
  - [api] 普通成员测试身份 应仍存在。
  - [prisma] 预置普通成员账号和 `member` 成员关系 应仍存在。
