## 1. 测试目标

验证：本用例独占普通成员不能进入系统设置修改系统背景；直接访问当前系统视觉设置页或调用系统背景写接口都会被拒绝，系统背景配置保持不变。

实现说明：

- 当前实现：`/settings` 已承载个人设置，`/system/settings` 承载系统设置，系统背景写接口仍要求管理员权限。
- 当前用例类型：旧权限防护用例，当前禁用；步骤仍按拆分前行为记录，待迁移。
- 目标契约：普通成员应能进入个人设置 `/settings` 修改个人背景偏好，但不能进入系统设置 `/system/settings` 或修改系统背景。
- 迁移要求：本用例应迁移为校验普通成员不可访问 `/system/settings`，并新增普通成员个人背景正向用例。

边界：

- 覆盖对象：普通成员不可修改系统设置背景。
- 不覆盖对象：普通成员修改个人背景、管理员上传图片、设置默认背景、切换规则保存、图片文件校验。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：独占普通成员身份/用户/成员关系、修改前 `login_background` 和 `sidebar_background` 背景列表与配置快照，以及登录后的悬赏大厅页面。
- Action 产物：普通成员直接访问系统设置页和调用系统背景写接口产生的权限拒绝响应；不应产生系统背景配置变更。
- Clean 产物：背景配置恢复为 Setup 记录快照，删除独占普通成员身份、用户和成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询接口 应可访问。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos Admin/Public API 应可访问。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory session cookie。
  - [B-10] [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 记录当前 `login_background` 和 `sidebar_background` 的背景列表与配置为 `runtime.backgroundSnapshot`。
  - [Setup-2] [api] 准备邮箱为 `orf-member-background-permission-e2e@orf.local` 的普通成员登录身份，并设置固定测试密码。
  - [Setup-3] [prisma] 准备邮箱为 `orf-member-background-permission-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户和默认团队成员关系。
  - [Setup-4] [api] 撤销普通成员登录身份可能残留的 Ory session。
  - [Setup-5] [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [Setup-6] [playwright] 打开 登录页。
  - [Setup-7] [playwright] 在邮箱输入框输入普通成员测试邮箱。
  - [Setup-8] [playwright] 在密码输入框输入普通成员测试密码。
  - [Setup-9] [playwright] 点击 `Sign In` 登录操作。
  - [Setup-10] [api] 当前会话 应为 普通成员已登录。
  - [Setup-11] [playwright] 打开 悬赏大厅。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱 `orf-member-background-permission-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [S0-2] [prisma] ORF 业务系统中 应存在 邮箱为 `orf-member-background-permission-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户。
  - [S0-3] [playwright] 主导航 应可见。
  - [S0-4] [playwright] 当前用户入口 应可见。
  - [S0-5] [playwright] 侧边栏 `设置` 入口 应不可见。
  - [S0-6] [playwright] 当前页面 应为 悬赏大厅。
  - [S0-7] [api] 以当前普通成员会话读取侧边栏背景列表接口 应成功。

- Action：被测业务动作。
  - [Action-1] [playwright] 直接打开 设置页面。
  - [Action-2] [api] 以当前普通成员会话尝试调用背景配置修改接口修改 `sidebar_background` 配置。
  - [Action-3] [api] 以当前普通成员会话尝试调用默认背景设置接口设置默认背景；若当前没有可用背景图片，则记录为跳过。

- S1：Action 后状态。
  - [S1-1] [playwright] 直接访问设置页面后 当前页面 应为 悬赏大厅。
  - [S1-2] [playwright] 页面中不显示 `视觉设置`。
  - [S1-3] [playwright] 页面中不显示 `登录页面背景设置`。
  - [S1-4] [playwright] 页面中不显示 `侧边栏背景设置`。
  - [S1-5] [api] 背景配置修改接口响应状态码 应为 403 或等价权限错误。
  - [S1-6] [api] 默认背景设置接口响应状态码 应为 403 或等价权限错误；无背景可设置时 应记录为跳过。
  - [S1-7] [api] 再次读取 `login_background` 和 `sidebar_background` 的背景列表与配置，应等于 `runtime.backgroundSnapshot`。
  - [S1-8] [api] 普通成员 应保持 已登录状态。

- Clean：恢复 B。
  - [Clean-1] [api] 若已记录 `runtime.backgroundSnapshot`，恢复 `login_background` 和 `sidebar_background` 背景列表与配置。
  - [Clean-2] [api] 退出 当前登录态。
  - [Clean-3] [playwright] 停止 当前页面运行态。
  - [Clean-4] [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [Clean-5] [api] 撤销普通成员登录身份的 Ory session。
  - [Clean-6] [api] 删除 普通成员 Ory 身份。
  - [Clean-7] [prisma] 删除 普通成员默认团队成员关系。
  - [Clean-8] [prisma] 删除 普通成员用户。
  - [Clean-9] [api] `login_background` 和 `sidebar_background` 背景列表与配置 应等于 `runtime.backgroundSnapshot`。
  - [Clean-10] [api] 邮箱为 `orf-member-background-permission-e2e@orf.local` 的普通成员 Ory 身份 应不存在。
  - [Clean-11] [prisma] 邮箱为 `orf-member-background-permission-e2e@orf.local` 的普通成员用户 应不存在。
