## 1. 测试目标

验证：本用例独占普通成员不能进入设置页面修改系统背景；直接访问或调用背景写接口都会被拒绝，背景配置保持不变。

实现说明：

- 当前实现：设置入口和背景写接口要求管理员权限。
- 当前用例类型：权限防护用例。
- 未来调整条件：若产品允许普通成员修改个人背景偏好，应先调整前端可见性和后端权限。

边界：

- 覆盖对象：普通成员不可修改设置背景。
- 不覆盖对象：管理员上传图片、设置默认背景、切换规则保存、图片文件校验。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：独占普通成员身份/用户/成员关系、修改前 `login_background` 和 `sidebar_background` 背景列表与配置快照，以及登录后的悬赏大厅页面。
- Action 产物：普通成员直接访问设置页和调用背景写接口产生的权限拒绝响应；不应产生背景配置变更。
- Clean 产物：背景配置恢复为 Setup 记录快照，删除独占普通成员身份、用户和成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 记录当前登录页背景和侧边栏背景配置快照。
  - [Setup-2] [api] 准备邮箱为 `orf-member-background-permission-e2e@orf.local`、使用固定测试密码的普通成员登录身份。
  - [Setup-3] [prisma] 准备邮箱为 `orf-member-background-permission-e2e@orf.local`、状态为 `active` 的普通成员用户记录。
  - [Setup-4] [prisma] 准备普通成员用户的默认团队成员关系，角色为 `member`。
  - [Setup-5] [api] 撤销普通成员登录身份可能残留的登录会话。
  - [Setup-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-7] [playwright] 打开 ORF 登录页。
  - [Setup-8] [playwright] 在邮箱输入框输入普通成员固定测试邮箱。
  - [Setup-9] [playwright] 在密码输入框输入普通成员固定测试密码。
  - [Setup-10] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-11] [api] 当前会话 应为 已登录。
  - [Setup-12] [api] 当前会话用户邮箱 应为 `orf-member-background-permission-e2e@orf.local`。
  - [Setup-13] [api] 当前会话用户角色 应为 `member`。
  - [Setup-14] [api] 当前会话用户状态 应为 `active`。
  - [Setup-15] [playwright] 打开 悬赏大厅。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-member-background-permission-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `member`。
  - [S0-4] [api] 当前会话用户状态 应为 `active`。
  - [S0-5] [prisma] ORF 业务系统中 应存在 邮箱为 `orf-member-background-permission-e2e@orf.local`、状态为 `active` 的普通成员用户记录。
  - [S0-6] [prisma] 普通成员用户的默认团队成员关系角色 应为 `member`。
  - [S0-7] [playwright] 主导航 应可见。
  - [S0-8] [playwright] 当前用户入口 应可见。
  - [S0-9] [playwright] 侧边栏 "设置" 入口 应不可见。
  - [S0-10] [playwright] 当前页面 应为 悬赏大厅。
  - [S0-11] [api] 当前普通成员读取侧边栏背景列表结果 应成功。

- Action：被测业务动作。
  - [Action-1] [playwright] 直接访问 ORF 设置页面。
  - [Action-2] [api] 当前普通成员尝试修改 `sidebar_background` 配置。
  - [Action-3] [api] 在存在可用侧边栏背景时，当前普通成员尝试设置默认背景。

- S1：Action 后状态。
  - [S1-1] [playwright] 直接访问设置页面后，当前页面 应为 悬赏大厅。
  - [S1-2] [playwright] 当前页面 应不显示 `视觉设置`。
  - [S1-3] [playwright] 当前页面 应不显示 `登录页面背景设置`。
  - [S1-4] [playwright] 当前页面 应不显示 `侧边栏背景设置`。
  - [S1-5] [api] 背景配置修改结果状态码 应为 403 或等价权限错误。
  - [S1-6] [api] 默认背景设置结果状态码 应为 403 或等价权限错误；无背景可设置时 应记录为跳过。
  - [S1-7] [api] 重新读取的 `login_background` 和 `sidebar_background` 背景列表与配置 应等于 `runtime.backgroundSnapshot`。
  - [S1-8] [api] 当前会话 应为 已登录。
  - [S1-9] [api] 当前会话用户邮箱 应为 `orf-member-background-permission-e2e@orf.local`。
  - [S1-10] [api] 当前会话用户角色 应为 `member`。
  - [S1-11] [api] 当前会话用户状态 应为 `active`。

- Clean：恢复 B。
  - [Clean-1] [api] 若已记录 `runtime.backgroundSnapshot`，恢复 `login_background` 和 `sidebar_background` 背景列表与配置。
  - [Clean-2] [api] 注销当前登录会话。
  - [Clean-3] [playwright] 离开当前 ORF 前端页面。
  - [Clean-4] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-5] [api] 撤销普通成员登录身份的残留登录会话。
  - [Clean-6] [api] 删除邮箱为 `orf-member-background-permission-e2e@orf.local` 的普通成员登录身份。
  - [Clean-7] [prisma] 删除邮箱为 `orf-member-background-permission-e2e@orf.local` 的普通成员默认团队成员关系。
  - [Clean-8] [prisma] 删除邮箱为 `orf-member-background-permission-e2e@orf.local` 的普通成员用户。
  - [Clean-9] [api] `login_background` 和 `sidebar_background` 背景列表与配置 应等于 `runtime.backgroundSnapshot`。
  - [Clean-10] [api] 邮箱为 `orf-member-background-permission-e2e@orf.local` 的普通成员 登录身份 应不存在。
  - [Clean-11] [prisma] 邮箱为 `orf-member-background-permission-e2e@orf.local` 的普通成员用户 应不存在。
