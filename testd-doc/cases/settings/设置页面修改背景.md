# 设置页面修改背景

## 1. 测试目标

验证：普通成员和管理员都可以在个人设置中切换自己的 侧边栏皮肤。

实现说明：

- 当前实现：`/settings` 承载个人设置，普通成员和管理员均可通过用户菜单中的 "个人设置" 入口访问。
- 当前实现：`/system/settings` 承载系统设置，仅管理员可在系统管理中访问。
- 当前实现：个人 侧边栏皮肤通过 `/api/settings/personal/backgrounds` 和 `/api/settings/personal/preferences` 管理；用户可以上传候选皮肤，也可以从皮肤列表中选择并设为自己的 侧边栏皮肤。
- 当前实现：系统背景写接口仍要求管理员权限，个人设置页不修改 `login_background` 或系统级 `topbar_background` 配置。
- 当前用例类型：个人背景正向用例，按角色参数化执行；`member` 和 `admin` 都应通过同一状态链。
- 当前代码状态：已生成独立 testd 用例，覆盖 `member` 和 `admin` 两个角色。

边界：

- 覆盖对象：普通成员和管理员通过用户菜单进入个人设置，上传候选皮肤，并切换选中皮肤为本人 侧边栏皮肤。
- 不覆盖对象：管理员系统管理背景配置、登录页背景配置、系统背景上传文件校验、个人背景删除、个人默认进入页面、主题和通知偏好。
- 依赖对象：[设置页面修改背景-管理员可以修改背景](设置页面修改背景-管理员可以修改背景.md) 的系统管理背景配置定义。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：当前角色对应的独占登录身份、用户记录、默认团队成员关系、系统背景配置快照、当前用户个人设置快照，以及登录后的悬赏大厅页面。
- Action 产物：当前用户通过个人设置上传两个候选皮肤，并将其中一个候选皮肤设为本人 侧边栏皮肤。
- Clean 产物：当前用户个人设置恢复为 Setup 记录快照，系统背景配置保持 Setup 记录快照，删除独占登录身份、用户和成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 记录当前系统 `login_background` 和 `topbar_background` 背景列表与配置快照。
  - [Setup-2] [api] 准备当前角色对应邮箱、使用固定测试密码的登录身份。
  - [Setup-3] [prisma] 准备当前角色对应邮箱、状态为 `active` 的用户记录。
  - [Setup-4] [prisma] 准备当前用户的默认团队成员关系，角色为当前用例参数角色。
  - [Setup-5] [api] 记录当前用户个人设置和个人背景目录快照。
  - [Setup-6] [api] 撤销当前用户登录身份可能残留的登录会话。
  - [Setup-7] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-8] [playwright] 打开 ORF 登录页。
  - [Setup-9] [playwright] 在邮箱输入框输入当前用户固定测试邮箱。
  - [Setup-10] [playwright] 在密码输入框输入当前用户固定测试密码。
  - [Setup-11] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-12] [api] 当前会话 应为 已登录。
  - [Setup-13] [api] 当前会话用户邮箱 应为 当前用户固定测试邮箱。
  - [Setup-14] [api] 当前会话用户角色 应为 当前用例参数角色。
  - [Setup-15] [api] 当前会话用户状态 应为 `active`。
  - [Setup-16] [playwright] 打开 悬赏大厅。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 当前用户固定测试邮箱。
  - [S0-3] [api] 当前会话用户角色 应为 当前用例参数角色。
  - [S0-4] [api] 当前会话用户状态 应为 `active`。
  - [S0-5] [prisma] ORF 业务系统中 应存在 当前用户固定测试邮箱、状态为 `active` 的用户记录。
  - [S0-6] [prisma] 当前用户的默认团队成员关系角色 应为 当前用例参数角色。
  - [S0-7] [playwright] 主导航 应可见。
  - [S0-8] [playwright] 用户菜单 应可见。
  - [S0-9] [playwright] 用户菜单中的 "个人设置" 操作 应可见。
  - [S0-10] [playwright] 当前页面 应为 悬赏大厅。
  - [S0-11] [api] 当前用户读取个人背景列表和个人偏好结果 应成功。
  - [S0-12] [api] 当前系统 `login_background` 和 `topbar_background` 背景列表与配置 应等于 系统背景配置快照。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击 用户菜单中的 "个人设置" 操作。
  - [Action-2] [playwright] 在个人设置的 侧边栏皮肤上传入口上传本用例第一个个人 侧边栏皮肤图片。
  - [Action-3] [playwright] 在个人设置的 侧边栏皮肤上传入口上传本用例第二个个人 侧边栏皮肤图片。
  - [Action-4] [playwright] 在 侧边栏皮肤列表中选择本用例第一个个人 侧边栏皮肤图片。
  - [Action-5] [playwright] 点击 "保存" 操作，将本用例第一个个人 侧边栏皮肤图片保存为本人 侧边栏皮肤。

- S1：Action 后状态。
  - [S1-1] [playwright] 当前页面 应为 个人设置页面。
  - [S1-2] [playwright] 当前页面 应显示 `个人设置`。
  - [S1-3] [playwright] 当前页面 应显示 `侧边栏`。
  - [S1-4] [api] 当前用户个人背景列表 应包含 本用例第一个个人 侧边栏皮肤图片。
  - [S1-5] [api] 当前用户个人背景列表 应包含 本用例第二个个人 侧边栏皮肤图片。
  - [S1-6] [api] 当前用户个人背景偏好 `backgrounds.sidebar_background.fixedBackgroundId` 应为 本用例第一个个人 侧边栏皮肤图片。
  - [S1-7] [playwright] 侧边栏皮肤区域 应显示 本用例第一个个人 侧边栏皮肤图片为 当前背景。
  - [S1-8] [api] 当前系统 `login_background` 和 `topbar_background` 背景列表与配置 应等于 系统背景配置快照。
  - [S1-9] [api] 当前会话 应为 已登录。
  - [S1-10] [api] 当前会话用户邮箱 应为 当前用户固定测试邮箱。
  - [S1-11] [api] 当前会话用户角色 应为 当前用例参数角色。
  - [S1-12] [api] 当前会话用户状态 应为 `active`。

- Clean：恢复 B。
  - [Clean-1] [api] 若已记录当前用户个人设置快照，恢复当前用户个人设置和个人背景目录。
  - [Clean-2] [api] 若已记录系统背景配置快照，恢复系统 `login_background` 和 `topbar_background` 背景列表与配置。
  - [Clean-3] [api] 注销当前登录会话。
  - [Clean-4] [playwright] 离开当前 ORF 前端页面。
  - [Clean-5] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-6] [api] 撤销当前用户登录身份的残留登录会话。
  - [Clean-7] [api] 删除当前用户固定测试邮箱对应的登录身份。
  - [Clean-8] [prisma] 删除当前用户固定测试邮箱对应的默认团队成员关系。
  - [Clean-9] [prisma] 删除当前用户固定测试邮箱对应的用户记录。
  - [Clean-10] [api] 系统 `login_background` 和 `topbar_background` 背景列表与配置 应等于 系统背景配置快照。
  - [Clean-11] [api] 当前用户固定测试邮箱对应的登录身份 应不存在。
  - [Clean-12] [prisma] 当前用户固定测试邮箱对应的用户记录 应不存在。
