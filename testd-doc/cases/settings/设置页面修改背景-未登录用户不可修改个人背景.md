# 设置页面修改背景-未登录用户不可修改个人背景

## 1. 测试目标

验证：未登录用户不能修改个人 侧边栏皮肤；直接调用个人背景偏好写接口会被拒绝，并且系统背景配置保持不变。

实现说明：

- 当前实现：个人背景写接口 `/api/settings/personal/preferences` 要求已登录且状态为 active 的用户。
- 当前用例类型：反向认证用例。
- 当前代码状态：生成独立 testd 用例。

边界：

- 覆盖对象：未登录用户不可写入个人 侧边栏皮肤偏好。
- 不覆盖对象：已登录普通成员和管理员修改个人背景、系统管理背景配置、图片上传文件校验、个人背景删除、个人默认进入页面、主题和通知偏好。
- 依赖对象：[设置页面修改背景](设置页面修改背景.md) 的个人设置背景定义。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何业务 fixture。
- Setup 产物：系统背景配置快照、未登录浏览器运行态。
- Action 产物：未登录用户直接提交个人背景偏好写请求的结果。
- Clean 产物：系统背景配置恢复为 Setup 记录快照，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 记录当前系统 `login_background` 和 `topbar_background` 背景列表与配置快照。
  - [Setup-2] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-3] [playwright] 打开 ORF 登录页。
  - [Setup-4] [api] 当前会话 应为 未登录。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 未登录。
  - [S0-2] [playwright] 当前页面 应为 登录页。
  - [S0-3] [api] 当前系统 `login_background` 和 `topbar_background` 背景列表与配置 应等于 系统背景配置快照。

- Action：被测业务动作。
  - [Action-1] [api] 未登录用户直接提交个人 侧边栏皮肤偏好。

- S1：Action 后状态。
  - [S1-1] [api] 保存个人 侧边栏皮肤偏好结果状态码 应为 401 或等价未认证错误。
  - [S1-2] [api] 当前会话 应为 未登录。
  - [S1-3] [api] 当前系统 `login_background` 和 `topbar_background` 背景列表与配置 应等于 系统背景配置快照。

- Clean：恢复 B。
  - [Clean-1] [api] 若已记录系统背景配置快照，恢复系统 `login_background` 和 `topbar_background` 背景列表与配置。
  - [Clean-2] [api] 注销当前登录会话。
  - [Clean-3] [playwright] 离开当前 ORF 前端页面。
  - [Clean-4] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-5] [api] 系统 `login_background` 和 `topbar_background` 背景列表与配置 应等于 系统背景配置快照。
