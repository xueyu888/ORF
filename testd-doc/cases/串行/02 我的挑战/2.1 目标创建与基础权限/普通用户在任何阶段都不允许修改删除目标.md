# 普通用户在任何阶段都不允许修改删除目标

## 1. 测试目标

验证：角色为 `member` 的普通用户作为目标当前挑战者时，在我的挑战页面可查看处于 `goalSetting`、`resultClaiming`、`orfReestimate`、`goalFrozen` 四个 ORF 阶段的目标；普通用户在页面中点击任一阶段目标的“编辑”或“删除”操作时，页面操作结果均为权限不足，目标不进入编辑态且不会被删除；普通用户通过接口请求修改或删除这些目标时，系统均返回权限不足，目标标题、阶段、流转状态和数据库记录保持不变。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [prisma] ORF 数据库 应可连接。
  - [B-4] [api] 当前会话 应为 未登录。
  - [B-5] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的目标标题前缀 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN` 对应的目标及其派生数据。
  - [Setup-2] [api] 记录 成员角色的当前权限配置。
  - [Setup-3] [api] 设置 成员角色权限不包含 `objective.delete`。
  - [Setup-4] [api] 准备邮箱为 `orf-member-target-mutation-forbidden-e2e@orf.local`、使用固定测试密码的普通用户登录身份。
  - [Setup-5] [prisma] 准备 角色为 `member`、状态为 `active`、名称为 `ORF Member Target Mutation Forbidden E2E` 的本用例普通用户。
  - [Setup-6] [prisma] 准备 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-GOAL-SETTING`、阶段为 `goalSetting`、流转状态为 `candidate`、当前挑战者包含本用例普通用户的目标。
  - [Setup-7] [prisma] 准备 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-RESULT-CLAIMING`、阶段为 `resultClaiming`、流转状态为 `open`、当前挑战者包含本用例普通用户的目标。
  - [Setup-8] [prisma] 准备 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-ORF-REESTIMATE`、阶段为 `orfReestimate`、流转状态为 `reestimating`、当前挑战者包含本用例普通用户的目标。
  - [Setup-9] [prisma] 准备 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-GOAL-FROZEN`、阶段为 `goalFrozen`、流转状态为 `frozen`、当前挑战者包含本用例普通用户的目标。
  - [Setup-10] [playwright] 使用 本用例普通用户账号 登录 ORF。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 已登录。
  - [S0-2] [api] 当前会话用户邮箱 应为 `orf-member-target-mutation-forbidden-e2e@orf.local`。
  - [S0-3] [api] 当前会话用户角色 应为 `member`。
  - [S0-4] [api] 当前会话用户名称 应为 `ORF Member Target Mutation Forbidden E2E`。
  - [S0-5] [api] 当前普通用户的目标内容编辑权限 应为 未授权。
  - [S0-6] [api] 当前普通用户的目标删除权限 应为 未授权。
  - [S0-7] [prisma] 应存在 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-GOAL-SETTING`、阶段为 `goalSetting`、流转状态为 `candidate` 的目标。
  - [S0-8] [prisma] 应存在 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-RESULT-CLAIMING`、阶段为 `resultClaiming`、流转状态为 `open` 的目标。
  - [S0-9] [prisma] 应存在 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-ORF-REESTIMATE`、阶段为 `orfReestimate`、流转状态为 `reestimating` 的目标。
  - [S0-10] [prisma] 应存在 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-GOAL-FROZEN`、阶段为 `goalFrozen`、流转状态为 `frozen` 的目标。
  - [S0-11] [prisma] 应不存在 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-MODIFIED` 的目标。

- Action：被测业务动作。
  - [Action-1] [playwright] 普通用户打开 我的挑战。
  - [Action-2] [playwright] 普通用户点击 本用例所有阶段目标的 "编辑" 操作。
  - [Action-3] [playwright] 普通用户点击 本用例所有阶段目标的 "删除" 操作。
  - [Action-4] [api] 普通用户请求 将本用例所有阶段目标标题修改为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-MODIFIED`。
  - [Action-5] [api] 普通用户请求 删除本用例所有阶段目标。

- S1：Action 后状态。
  - [S1-1] [playwright] 页面 应进入 我的挑战。
  - [S1-2] [playwright] "我的挑战" 视图 应处于选中状态。
  - [S1-3] [playwright] 我的挑战列表 应显示目标 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-GOAL-SETTING`。
  - [S1-4] [playwright] 我的挑战列表 应显示目标 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-RESULT-CLAIMING`。
  - [S1-5] [playwright] 我的挑战列表 应显示目标 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-ORF-REESTIMATE`。
  - [S1-6] [playwright] 我的挑战列表 应显示目标 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-GOAL-FROZEN`。
  - [S1-7] [playwright] 本用例所有阶段目标的编辑页面操作结果 应为 权限不足。
  - [S1-8] [playwright] 本用例所有阶段目标的标题编辑输入框 应不可见。
  - [S1-9] [playwright] 本用例所有阶段目标的删除页面操作结果 应为 权限不足。
  - [S1-10] [playwright] 删除目标确认框 应不可见。
  - [S1-11] [api] 本用例所有阶段目标的标题修改请求结果 应为 权限不足。
  - [S1-12] [api] 本用例所有阶段目标的删除请求结果 应为 权限不足。
  - [S1-13] [api] 当前普通用户的目标内容编辑权限 应仍为 未授权。
  - [S1-14] [api] 当前普通用户的目标删除权限 应仍为 未授权。
  - [S1-15] [prisma] 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-GOAL-SETTING` 的目标阶段 应仍为 `goalSetting`，流转状态 应仍为 `candidate`。
  - [S1-16] [prisma] 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-RESULT-CLAIMING` 的目标阶段 应仍为 `resultClaiming`，流转状态 应仍为 `open`。
  - [S1-17] [prisma] 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-ORF-REESTIMATE` 的目标阶段 应仍为 `orfReestimate`，流转状态 应仍为 `reestimating`。
  - [S1-18] [prisma] 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-GOAL-FROZEN` 的目标阶段 应仍为 `goalFrozen`，流转状态 应仍为 `frozen`。
  - [S1-19] [prisma] 应不存在 标题为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN-MODIFIED` 的目标。
  - [S1-20] [prisma] 标题前缀为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN` 的本用例目标数量 应为 `4`。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的目标标题前缀 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN` 对应的目标及其派生数据。
  - [Clean-2] [api] 注销当前普通用户登录会话。
  - [Clean-3] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-4] [api] 删除 本用例普通用户登录身份。
  - [Clean-5] [prisma] 删除 本用例普通用户。
  - [Clean-6] [api] 恢复 成员角色为 Setup 前记录的权限配置。
  - [Clean-7] [prisma] 应不存在 标题前缀为 `E2E-TARGET-MEMBER-MUTATION-FORBIDDEN` 的目标。
  - [Clean-8] [api] 邮箱为 `orf-member-target-mutation-forbidden-e2e@orf.local` 的普通用户登录身份 应不存在。
  - [Clean-9] [prisma] 邮箱为 `orf-member-target-mutation-forbidden-e2e@orf.local` 的普通用户 应不存在。
  - [Clean-10] [api] 当前会话 应为 未登录。
