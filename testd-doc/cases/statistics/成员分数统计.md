# 成员分数统计

## 1. 测试目标

- [playwright] 成员积分排行榜 应显示 多个普通成员的积分汇总。
- [prisma] 多个普通成员 对 目标 的测试积分流水 应存在。
- [playwright] 页面积分汇总 应与数据库积分汇总一致。

边界：

- 覆盖对象：成员积分排行榜展示。
- 不覆盖对象：积分结算公式、验收流程、时间范围算法、无分数空状态。
- B 基础数据：预置管理员账号 "zrx831@gmail.com"。
- B 基础数据：预置普通成员 "ORF Member E2E" 和 "m2"。
- Setup 产物：settled 目标。
- Setup 产物：两个普通成员 对 目标 的测试积分流水。
- Clean 产物：本用例创建的测试积分流水。
- Clean 产物：目标 的原始状态。

- B：基准状态。
  - [api] 前端服务 应可用。
  - [api] 后端服务 应可用。
  - [api] 健康检查或等价探测 应通过。
  - [prisma] ORF 数据库 应可连接。
  - [api] Ory/Kratos Admin API 应可访问。
  - [api] Ory/Kratos Public API 应可访问。
  - [api] 应存在 邮箱为 "zrx831@gmail.com" 的管理员 Ory/Kratos 测试身份。
  - [prisma] 应存在 邮箱为 "zrx831@gmail.com"、角色为 admin、状态为 active 的管理员用户。
  - [prisma] 应存在 名称为 "ORF Member E2E"、角色为 member、状态为 active 的普通成员用户。
  - [prisma] 应存在 名称为 "m2"、角色为 member、状态为 active 的普通成员用户。
  - [prisma] 应存在 一个属于管理员团队且可构造成员分数统计起点的目标。
  - [prisma] 应不存在 reason 为 "E2E-SCORE-STATS: 成员分数统计" 的测试积分流水。
  - [api] 当前会话 应为 未登录。
  - [playwright] 当前浏览器 应不存在 登录 cookie。
  - [playwright] 当前浏览器 storage 应不包含 登录态。
