# 成员分数统计

## 1. 测试目标

验证：统计页面可以展示本用例独占成员的积分汇总，并且页面汇总结果与数据库积分流水一致。

边界：

- 覆盖对象：成员积分排行榜展示。
- 不覆盖对象：积分结算公式、验收流程、时间范围算法、无分数空状态。
- B 基础状态：仅要求系统服务、数据库、schema、Ory/Kratos 和当前浏览器会话可用于开测，不要求存在任何业务 fixture。
- Setup 产物：独占管理员身份/用户/成员关系、两个独占普通成员身份/用户/成员关系、标题为 `E2E-MEMBER-SCORE-STATS: 目标前置` 的 settled 目标，以及两个普通成员对目标的测试积分流水。
- Action 产物：无新增业务资源，只打开统计页面并切换全部时间范围。
- Clean 产物：删除本用例创建的测试积分流水、独占目标、管理员和普通成员身份、用户与成员关系，并清空页面运行态和 session。

## 2. 状态模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的 reason 为 `E2E-SCORE-STATS: 成员分数统计` 的测试积分流水。
  - [Setup-2] [prisma] 删除可能残留的标题为 `E2E-MEMBER-SCORE-STATS: 目标前置` 的本用例目标及其派生数据。
  - [Setup-3] [api] 准备邮箱为 `orf-admin-score-stats-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-4] [prisma] 准备邮箱为 `orf-admin-score-stats-e2e@orf.local`、角色为 `admin`、状态为 `active` 的管理员用户和默认团队成员关系。
  - [Setup-5] [api] 准备邮箱为 `orf-score-stats-member-one-e2e@orf.local`、使用固定测试密码的第一个普通成员登录身份。
  - [Setup-6] [prisma] 准备邮箱为 `orf-score-stats-member-one-e2e@orf.local`、角色为 `member`、状态为 `active` 的第一个普通成员用户和默认团队成员关系。
  - [Setup-7] [api] 准备邮箱为 `orf-score-stats-member-two-e2e@orf.local`、使用固定测试密码的第二个普通成员登录身份。
  - [Setup-8] [prisma] 准备邮箱为 `orf-score-stats-member-two-e2e@orf.local`、角色为 `member`、状态为 `active` 的第二个普通成员用户和默认团队成员关系。
  - [Setup-9] [prisma] 创建标题为 `E2E-MEMBER-SCORE-STATS: 目标前置` 的本用例独占目标。
  - [Setup-10] [prisma] 记录 本用例独占目标。
  - [Setup-11] [prisma] 设置本用例目标为 `settled`，挑战者包含两个普通成员，目标结算总积分为 `100`。
  - [Setup-12] [prisma] 创建两个普通成员对本用例目标的测试积分流水，积分分别为 `70` 和 `30`。
  - [Setup-13] [api] 撤销管理员登录身份可能残留的登录会话。
  - [Setup-14] [api] 撤销第一个普通成员登录身份可能残留的登录会话。
  - [Setup-15] [api] 撤销第二个普通成员登录身份可能残留的登录会话。
  - [Setup-16] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-17] [playwright] 打开 ORF 登录页。
  - [Setup-18] [playwright] 在邮箱输入框输入管理员固定测试邮箱。
  - [Setup-19] [playwright] 在密码输入框输入管理员固定测试密码。
  - [Setup-20] [playwright] 点击 `Sign In` 登录操作。
  - [Setup-21] [api] 当前会话 应为 管理员的已登录会话。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱 `orf-admin-score-stats-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [prisma] 本用例目标 应为 `settled`。
  - [S0-3] [prisma] 数据库中 应存在 第一个普通成员对本用例目标的测试积分流水，积分为 `70`。
  - [S0-4] [prisma] 数据库中 应存在 第二个普通成员对本用例目标的测试积分流水，积分为 `30`。

- Action：被测业务动作。
  - [Action-1] [playwright] 打开 统计页面。
  - [Action-2] [playwright] 点击 `全部时间` 时间范围操作。

  - [S1-1] [playwright] 当前页面 应为 统计页面。
  - [S1-2] [playwright] 成员积分排行榜 应显示第一个普通成员的积分汇总。
  - [S1-3] [playwright] 成员积分排行榜 应显示第二个普通成员的积分汇总。
  - [S1-4] [prisma] 数据库中 第一个普通成员对本用例目标的测试积分流水 应保持为 `70`。
  - [S1-5] [prisma] 数据库中 第二个普通成员对本用例目标的测试积分流水 应保持为 `30`。
  - [S1-6] [api] 当前会话 应仍为 管理员的已登录会话。
