# 成员提出指标

## 1. 测试目标

验证：参与目标的普通成员可以在目标评估阶段提出成员建议指标；提交后该指标在接口、数据库和页面中可见。

边界：

- 覆盖对象：参与目标的普通成员提出指标。
- 不覆盖对象：非参与成员不可提出指标、管理员新增指标、指标采纳、指标编辑、指标删除、重估窗口关闭后的限制。
- B 基础数据：预置普通成员账号 "orf-member-e2e@orf.local"，角色为 member，状态为 active。
- Setup 产物：flowStatus 为 reestimating、挑战者包含普通成员、重估窗口未关闭的目标。
- Clean 产物：本用例创建的测试指标和目标原始状态。

## 2. 状态模型

- B：基准状态。
  - [api] 前端和后端服务 应为 可用。
  - [api] 前端登录页入口 应可访问。
  - [api] 当前会话查询接口 应可访问。
  - [prisma] ORF 数据库 应为 可连接。
  - [api] Ory/Kratos Admin/Public API 应为 可访问。
  - [api] Ory/Kratos 中 应存在 邮箱为 `orf-member-e2e@orf.local` 的普通成员测试身份。
  - [prisma] 应存在 邮箱为 `orf-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户。
  - [prisma] 应存在 一个可构造为成员提出指标起点的目标。
  - [prisma] 应不存在 标题为 `E2E-RESULT-PROPOSE: 成员提出指标` 的测试指标。
  - [api] 当前会话 应为 未登录。
  - [playwright] 浏览器 应不存在 登录 cookie。
  - [playwright] 浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [playwright] 清空 浏览器状态。
  - [prisma] 选择 一个可构造成员提出指标起点的目标。
  - [prisma] 记录 目标 的原始状态。
  - [prisma] 设置 目标 flowStatus 为 `reestimating`。
  - [prisma] 设置 目标 挑战者列表包含普通成员。
  - [prisma] 设置 目标 重估窗口为未关闭。
  - [playwright] 打开 登录页。
  - [playwright] 在 Email 输入框 输入 普通成员邮箱。
  - [playwright] 在 Password 输入框 输入 普通成员密码。
  - [playwright] 点击 `Sign In` 登录操作。
  - [api] 当前会话 应为 普通成员已登录。
  - [playwright] 打开 挑战工作台。

- S0：Action 前状态。
  - [api] 当前会话 应为 邮箱 `orf-member-e2e@orf.local` 的普通成员已登录。
  - [playwright] 当前页面 应为 挑战工作台。
  - [playwright] 目标 面板 应可见。
  - [playwright] 目标 的 `提出指标` 操作 应可点击。
  - [prisma] 目标 flowStatus 应为 `reestimating`。
  - [prisma] 目标 的挑战者列表 应包含 普通成员。
  - [prisma] 目标 应不存在 标题为 `E2E-RESULT-PROPOSE: 成员提出指标` 的指标。

- Action：被测业务动作。
  - [playwright] 点击 目标 的 `提出指标` 操作。
  - [playwright] 提出指标弹窗 应可见。
  - [playwright] 在 `指标标题` 输入框 输入 测试指标标题。
  - [playwright] 在 `衡量指标` 输入框 输入 测试衡量指标。
  - [playwright] 在点击 `提交指标` 前注册 新增指标接口响应捕获。
  - [playwright] 点击 `提交指标` 操作。
  - [api] 记录 新增指标接口返回的指标。

- S1：Action 后状态。
  - [api] 新增指标接口响应 应成功。
  - [api] 新增指标接口返回的指标 应属于 目标。
  - [api] 新增指标接口返回的指标标题 应为 测试指标标题。
  - [api] 新增指标接口返回的指标来源 应为 `memberProposed`。
  - [api] 新增指标接口返回的指标提出人 应为 普通成员。
  - [prisma] 目标 应存在 标题为测试指标标题、来源为 `memberProposed` 的指标。
  - [playwright] 目标 面板 应显示 测试指标标题。
  - [api] 当前会话 应仍为 普通成员已登录。

- Clean：恢复 B。
  - [prisma] 删除 本用例创建的测试指标。
  - [prisma] 恢复 目标 在 Setup 前记录的原始状态。
  - [api] 退出 当前登录态。
  - [playwright] 清空 浏览器状态。
  - [api] Ory/Kratos 中 应仍存在 普通成员测试身份。
  - [prisma] 应仍存在 邮箱为 `orf-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户。
