# 管理员新增指标

## 1. 测试目标

验证：由当前用例独占准备的管理员可以在当前用例独占目标中新增管理员定义指标；新增后该指标在接口、数据库和页面中可见。

边界：

- 覆盖对象：管理员新增指标。
- 不覆盖对象：普通成员不可新增指标、成员提出指标、指标编辑、指标删除、指标冻结后的新增限制。
- 原 legacy B 依赖：预置管理员账号 `zrx831@gmail.com`，以及默认团队中任意允许管理员新增指标的目标。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体管理员账号、目标或指标。
- Setup 产物：邮箱为 "orf-admin-create-result-e2e@orf.local" 的管理员身份、用户和 admin 成员关系；标题为 "E2E-ADMIN-CREATE-RESULT: 目标前置"、`flowStatus` 为 `open`、阶段为 `resultClaiming` 的本用例指标目标；运行时记录的 `runtime.resultTarget`。
- Action 产物：标题和衡量指标均为 "E2E-RESULT-CREATE: 管理员新增指标"、来源为 `managerDefined` 的测试指标。
- Clean 产物：删除本用例指标、目标及其派生数据，删除本用例独占管理员身份、用户、成员关系与 session。
- 原状态恢复：目标和指标均为当前用例独占资源，Clean 直接删除，不恢复任何共享目标状态。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例测试指标。
  - [Setup-2] [prisma] 删除可能残留的本用例目标及其派生数据。
  - [Setup-3] [api] 准备邮箱为 `orf-admin-create-result-e2e@orf.local`、使用固定测试密码的管理员登录身份。
  - [Setup-4] [prisma] 准备邮箱为 `orf-admin-create-result-e2e@orf.local`、角色为 `admin`、状态为 `active` 的管理员用户和默认团队成员关系。
  - [Setup-5] [prisma] 创建标题为 `E2E-ADMIN-CREATE-RESULT: 目标前置`、流转状态为 `open`、阶段为 `resultClaiming` 的本用例指标目标。
  - [Setup-6] [prisma] 记录 本用例指标目标。
  - [Setup-7] [api] 撤销管理员登录身份可能残留的登录会话。
  - [Setup-8] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-9] [playwright] 打开 ORF 登录页。
  - [Setup-10] [playwright] 在邮箱输入框输入管理员固定测试邮箱。
  - [Setup-11] [playwright] 在密码输入框输入管理员固定测试密码。
  - [Setup-12] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-13] [api] 当前会话 应为 管理员的已登录会话。
  - [Setup-14] [playwright] 打开 挑战工作台。
  - [Setup-15] [playwright] 切换到 "所有挑战" 视图。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-admin-create-result-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 挑战工作台。
  - [S0-3] [playwright] 本用例指标目标面板 应可见。
  - [S0-4] [playwright] 本用例指标目标的 "新增指标" 操作 应可点击。
  - [S0-5] [prisma] 本用例指标目标 应允许 管理员新增指标。
  - [S0-6] [prisma] 本用例指标目标 应不存在 标题为 `E2E-RESULT-CREATE: 管理员新增指标` 的指标。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击 本用例指标目标的 "新增指标" 操作。
  - [Action-2] [playwright] 新增指标内联标题编辑器 应可见。
  - [Action-3] [playwright] 在新增指标内联标题编辑器输入 测试指标标题。
  - [Action-4] [playwright] 提交新增指标内联标题编辑器。
  - [Action-5] [api] 记录 新增指标结果中的测试指标。

- S1：Action 后状态。
  - [S1-1] [api] 新增指标结果 应成功。
  - [S1-2] [api] 新增指标结果中的指标 应属于本用例目标，标题、衡量指标和来源正确。
  - [S1-3] [prisma] 本用例指标目标 应存在 标题为 `E2E-RESULT-CREATE: 管理员新增指标`、来源为 `managerDefined` 的指标。
  - [S1-4] [playwright] 本用例指标目标面板 应显示 测试指标标题。
  - [S1-5] [api] 当前会话 应仍为 管理员的已登录会话。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除 本用例创建的测试指标。
  - [Clean-2] [prisma] 删除 本用例指标目标及其派生数据。
  - [Clean-3] [api] 注销当前登录会话。
  - [Clean-4] [playwright] 离开当前 ORF 前端页面。
  - [Clean-5] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-6] [api] 撤销管理员登录身份的残留登录会话。
  - [Clean-7] [api] 删除邮箱为 `orf-admin-create-result-e2e@orf.local` 的管理员登录身份。
  - [Clean-8] [prisma] 删除管理员用户的默认团队成员关系。
  - [Clean-9] [prisma] 删除邮箱为 `orf-admin-create-result-e2e@orf.local` 的管理员用户。
  - [Clean-10] [prisma] 应不存在 标题为 `E2E-RESULT-CREATE: 管理员新增指标` 的测试指标。
  - [Clean-11] [prisma] 应不存在 标题为 `E2E-ADMIN-CREATE-RESULT: 目标前置` 的测试目标。
  - [Clean-12] [prisma] 应不存在 邮箱为 `orf-admin-create-result-e2e@orf.local` 的管理员用户。
