# 非参与的普通成员在执行中不支持删除行动项

## 1. 测试目标

验证：当前普通成员不是本用例执行中目标的正式挑战者时，当前普通成员进入“我的挑战”页面并筛选“执行中”后，看不到本用例目标，也看不到本用例目标下已有行动项的删除入口；页面、接口和数据库都不会产生删除结果，本用例目标下的行动项及其子行动项仍然保留。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除 本用例残留的执行中测试行动项及其子行动项。
  - [Setup-2] [prisma] 删除 本用例残留的执行中行动项目标及其派生数据。
  - [Setup-3] [api] 准备邮箱为 `orf-member-delete-task-active-forbidden-e2e@orf.local`、使用固定测试密码的非参与普通成员登录身份。
  - [Setup-4] [prisma] 准备邮箱为 `orf-member-delete-task-active-forbidden-e2e@orf.local`、角色为 `member`、状态为 `active` 的非参与普通成员用户和默认团队成员关系。
  - [Setup-5] [api] 准备邮箱为 `orf-member-delete-task-active-challenger-e2e@orf.local`、使用固定测试密码的目标挑战成员登录身份。
  - [Setup-6] [prisma] 准备邮箱为 `orf-member-delete-task-active-challenger-e2e@orf.local`、角色为 `member`、状态为 `active` 的目标挑战成员用户和默认团队成员关系。
  - [Setup-7] [prisma] 创建标题为 `E2E-TASK-DELETE-ACTIVE-FORBIDDEN: 目标前置`、流转状态为 `frozen`、阶段为 `goalFrozen` 的本用例执行中行动项目标。
  - [Setup-8] [prisma] 记录 本用例执行中行动项目标。
  - [Setup-9] [prisma] 设置本用例执行中行动项目标的挑战者账号身份包含目标挑战成员且不包含非参与普通成员。

  - [Setup-11] [prisma] 创建标签为 `执行中非参与成员不可删除子任务`、归属于本用例执行中测试行动项的本用例执行中测试子行动项。
  - [Setup-12] [prisma] 记录 本用例执行中测试行动项和测试子行动项。
  - [Setup-13] [api] 撤销非参与普通成员登录身份可能残留的登录会话。
  - [Setup-14] [api] 撤销目标挑战成员登录身份可能残留的登录会话。

  - [Setup-17] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-18] [playwright] 打开 ORF 登录页。
  - [Setup-19] [playwright] 在邮箱输入框输入非参与普通成员固定测试邮箱。
  - [Setup-20] [playwright] 在密码输入框输入非参与普通成员固定测试密码。
  - [Setup-21] [playwright] 点击 "Sign In" 登录操作。
