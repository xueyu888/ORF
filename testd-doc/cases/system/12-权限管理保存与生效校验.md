# 权限管理保存与生效校验

## 1. 测试目标

验证：系统管理-权限管理页面中，修改角色权限并保存后，重新进入页面仍保留已保存配置；取消 `member` 角色的 `comment.manage` 权限后，普通成员对其他用户评论的管理操作不可用；授予 `member` 角色的 `comment.manage` 权限后，普通成员对其他用户评论的管理操作可用。
