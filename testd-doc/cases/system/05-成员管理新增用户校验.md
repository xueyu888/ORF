# 成员管理新增用户校验

## 1. 测试目标

验证：系统管理-成员管理页面中，新增用户弹窗展示正常；输入有效姓名、邮箱和角色后新增用户成功并展示在成员列表中；姓名或邮箱为空、邮箱格式错误或邮箱已存在时新增失败并提示；取消或关闭弹窗后成员列表数据保持不变。
