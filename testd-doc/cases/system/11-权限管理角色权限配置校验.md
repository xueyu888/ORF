# 权限管理角色权限配置校验

## 1. 测试目标

验证：系统管理-权限管理页面中，切换成员和管理员角色后展示对应角色的权限配置；修改角色权限后影响该角色下所有用户的权限范围；权限数量与当前角色已允许的权限数量一致。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 准备邮箱为 `orf-system-permissions-config-admin-e2e@orf.local`、使用固定测试密码的权限配置管理员测试认证身份。
  - [Setup-2] [prisma] 准备姓名为 "ORF Permissions Config Admin E2E"、邮箱为 `orf-system-permissions-config-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的权限配置管理员测试用户。
  - [Setup-3] [api] 设置权限配置管理员测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-4] [api] 准备邮箱为 `orf-system-permissions-config-member-a-e2e@orf.local`、使用固定测试密码的权限配置普通成员 A 测试认证身份。
  - [Setup-5] [prisma] 准备姓名为 "ORF Permissions Config Member A E2E"、邮箱为 `orf-system-permissions-config-member-a-e2e@orf.local`、角色为 `member`、状态为 `active` 的权限配置普通成员 A 测试用户。
  - [Setup-6] [api] 准备邮箱为 `orf-system-permissions-config-member-b-e2e@orf.local`、使用固定测试密码的权限配置普通成员 B 测试认证身份。
  - [Setup-7] [prisma] 准备姓名为 "ORF Permissions Config Member B E2E"、邮箱为 `orf-system-permissions-config-member-b-e2e@orf.local`、角色为 `member`、状态为 `active` 的权限配置普通成员 B 测试用户。
  - [Setup-8] [api] 记录修改前的 `member` 角色权限配置。
  - [Setup-9] [api] 记录修改前的 `member` 角色已允许权限数量。
  - [Setup-10] [api] 撤销邮箱为 `orf-system-permissions-config-admin-e2e@orf.local` 的权限配置管理员测试认证身份的残留登录会话。
  - [Setup-11] [api] 撤销邮箱为 `orf-system-permissions-config-member-a-e2e@orf.local` 的权限配置普通成员 A 测试认证身份的残留登录会话。
  - [Setup-12] [api] 撤销邮箱为 `orf-system-permissions-config-member-b-e2e@orf.local` 的权限配置普通成员 B 测试认证身份的残留登录会话。
  - [Setup-13] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-14] [playwright] 打开 ORF 登录页。
  - [Setup-15] [playwright] 在邮箱输入框输入 `orf-system-permissions-config-admin-e2e@orf.local`。
  - [Setup-16] [playwright] 在密码输入框输入权限配置管理员测试固定密码。
  - [Setup-17] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-18] [api] 当前会话 应为 邮箱为 `orf-system-permissions-config-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [Setup-19] [playwright] 打开 权限管理页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-system-permissions-config-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 权限管理页面。
  - [S0-3] [playwright] 权限管理页面的 "成员" 角色切换操作 应可见。
  - [S0-4] [playwright] 权限管理页面的 "管理员" 角色切换操作 应可见。
  - [S0-5] [playwright] 权限管理页面的 `comment.manage` 权限开关 应可见。
  - [S0-6] [api] 修改前的 `member` 角色权限配置 应已记录。
  - [S0-7] [prisma] 邮箱为 `orf-system-permissions-config-member-a-e2e@orf.local` 的权限配置普通成员 A 测试用户 应存在。
  - [S0-8] [prisma] 邮箱为 `orf-system-permissions-config-member-b-e2e@orf.local` 的权限配置普通成员 B 测试用户 应存在。

- Action：被测业务动作。
  - [Action-1] [playwright] 选择 "成员" 角色切换操作。
  - [Action-2] [playwright] 记录成员角色页面已允许权限数量。
  - [Action-3] [playwright] 选择 "管理员" 角色切换操作。
  - [Action-4] [playwright] 记录管理员角色页面已允许权限数量。
  - [Action-5] [playwright] 选择 "成员" 角色切换操作。
  - [Action-6] [playwright] 切换 `comment.manage` 权限开关。
  - [Action-7] [playwright] 点击 "保存角色权限" 操作。
  - [Action-8] [api] 重新读取 `member` 角色权限配置。

- S1：Action 后状态。
  - [S1-1] [playwright] 选择成员角色后，权限列表 应展示 `member` 角色权限配置。
  - [S1-2] [playwright] 成员角色页面已允许权限数量 应等于 修改前的 `member` 角色已允许权限数量。
  - [S1-3] [playwright] 选择管理员角色后，权限列表 应展示 `admin` 角色权限配置。
  - [S1-4] [playwright] 管理员角色页面已允许权限数量 应等于 系统权限定义总数。
  - [S1-5] [playwright] 管理员角色页面的 `comment.manage` 权限开关 应为 只读已允许状态。
  - [S1-6] [api] `member` 角色权限保存结果 应成功。
  - [S1-7] [api] 重新读取的 `member` 角色权限配置 应等于 Action 保存的新权限配置。
  - [S1-8] [api] 权限配置普通成员 A 的权限范围 应等于 重新读取的 `member` 角色权限配置。
  - [S1-9] [api] 权限配置普通成员 B 的权限范围 应等于 重新读取的 `member` 角色权限配置。
  - [S1-10] [api] 权限配置管理员测试用户的权限范围 应包含 系统权限定义中的全部权限。
  - [S1-11] [playwright] 保存后成员角色页面已允许权限数量 应等于 重新读取的 `member` 角色已允许权限数量。
  - [S1-12] [api] 当前会话 应仍为 邮箱为 `orf-system-permissions-config-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
