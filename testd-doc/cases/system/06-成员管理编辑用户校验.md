# 成员管理编辑用户校验

## 1. 测试目标

验证：系统管理-成员管理页面中，点击编辑用户按钮后可打开编辑用户弹窗并显示用户信息；修改用户名、邮箱或角色后保存成功并同步更新成员列表；姓名为空、邮箱为空、邮箱格式错误或邮箱已存在时保存失败并提示；取消或关闭弹窗后用户信息保持不变。
