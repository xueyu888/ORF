# 成员管理注册申请审核校验

## 1. 测试目标

验证：系统管理-成员管理页面中，注册申请可通过或拒绝；点击通过后注册申请状态更新为启用；点击拒绝后展示确认弹窗，确认后状态更新为已拒绝，取消后状态保持不变。
