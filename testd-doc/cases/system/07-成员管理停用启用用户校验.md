# 成员管理停用启用用户校验

## 1. 测试目标

验证：系统管理-成员管理页面中，停用和启用用户操作正常；点击操作按钮后展示确认弹窗；确认后用户状态正确更新，取消后状态保持不变；用户停用后无法正常登录系统。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

  - [Setup-6] [api] 准备邮箱为 `orf-system-members-status-disabled-e2e@orf.local`、使用固定测试密码的成员管理待启用测试认证身份。
  - [Setup-7] [prisma] 准备姓名为 "ORF Members Status Disabled E2E"、邮箱为 `orf-system-members-status-disabled-e2e@orf.local`、角色为 `member`、状态为 `disabled` 的成员管理待启用测试用户。

  - [Setup-10] [api] 撤销邮箱为 `orf-system-members-status-admin-e2e@orf.local` 的成员管理停用启用管理员测试认证身份的残留登录会话。
  - [Setup-11] [api] 撤销邮箱为 `orf-system-members-status-active-e2e@orf.local` 的成员管理待停用测试认证身份的残留登录会话。
