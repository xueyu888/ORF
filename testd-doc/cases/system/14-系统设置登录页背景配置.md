# 系统设置登录页背景配置

## 1. 测试目标

验证：管理员可在系统管理-系统设置页面配置登录页背景并应用成功；上传背景图片后可用于系统设置配置；背景模式、触发方式、切换规则和切换间隔配置生效。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 对象存储服务 应可上传和读取系统背景图片。
  - [B-9] [api] 当前会话 应为 未登录。
  - [B-10] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-11] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 准备邮箱为 `orf-system-login-background-admin-e2e@orf.local`、使用固定测试密码的登录页背景配置管理员测试认证身份。
  - [Setup-2] [prisma] 准备姓名为 "ORF System Login Background Admin E2E"、邮箱为 `orf-system-login-background-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的登录页背景配置管理员测试用户。
  - [Setup-3] [api] 记录系统当前登录页背景配置。
  - [Setup-4] [api] 设置登录页背景配置管理员测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-5] [api] 撤销邮箱为 `orf-system-login-background-admin-e2e@orf.local` 的登录页背景配置管理员测试认证身份的残留登录会话。
  - [Setup-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-7] [playwright] 打开 ORF 登录页。
  - [Setup-8] [playwright] 在邮箱输入框输入 `orf-system-login-background-admin-e2e@orf.local`。
  - [Setup-9] [playwright] 在密码输入框输入登录页背景配置管理员测试固定密码。
  - [Setup-10] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-11] [api] 当前会话 应为 邮箱为 `orf-system-login-background-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [Setup-12] [playwright] 打开 系统设置页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-system-login-background-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 系统设置页面。
  - [S0-3] [playwright] 系统设置页面的皮肤设置模块 应可见。
  - [S0-4] [playwright] 系统设置页面的登录页背景设置入口 应可见。
  - [S0-5] [playwright] 系统设置页面的上传图片操作 应可见。
  - [S0-6] [playwright] 系统设置页面的保存皮肤设置操作 应可见。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击 系统设置页面的登录页背景设置入口。
  - [Action-2] [playwright] 上传登录页背景配置测试图片。
  - [Action-3] [playwright] 在系统设置页面的背景图片列表中选择登录页背景配置测试图片。
  - [Action-4] [playwright] 将登录页背景模式设置为 轮换。
  - [Action-5] [playwright] 将登录页背景触发方式设置为 定时。
  - [Action-6] [playwright] 将登录页背景切换规则设置为 随机。
  - [Action-7] [playwright] 将登录页背景切换间隔设置为 5 分钟。
  - [Action-8] [playwright] 点击 系统设置页面的保存皮肤设置操作。
  - [Action-9] [api] 注销当前登录会话。
  - [Action-10] [playwright] 移除当前浏览器中的残留登录态。
  - [Action-11] [playwright] 打开 ORF 登录页。

- S1：Action 后状态。
  - [S1-1] [api] 系统登录页背景配置的固定背景图片 应为 登录页背景配置测试图片。
  - [S1-2] [api] 系统登录页背景配置的背景模式 应为 轮换。
  - [S1-3] [api] 系统登录页背景配置的触发方式 应为 定时。
  - [S1-4] [api] 系统登录页背景配置的切换规则 应为 随机。
  - [S1-5] [api] 系统登录页背景配置的切换间隔 应为 5 分钟。
  - [S1-6] [api] 登录页背景配置测试图片 应存在于系统背景图片列表。
  - [S1-7] [playwright] ORF 登录页 应展示登录页背景配置测试图片。
  - [S1-8] [playwright] ORF 登录页的邮箱输入框 应可见。
  - [S1-9] [playwright] ORF 登录页的密码输入框 应可见。
  - [S1-10] [api] 当前会话 应为 未登录。

- Clean：恢复 B。
  - [Clean-1] [playwright] 离开当前 ORF 前端页面。
  - [Clean-2] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-3] [api] 恢复系统登录页背景配置为 Action 前记录的配置。
  - [Clean-4] [api] 删除登录页背景配置测试图片。
  - [Clean-5] [api] 撤销邮箱为 `orf-system-login-background-admin-e2e@orf.local` 的登录页背景配置管理员测试认证身份的残留登录会话。
  - [Clean-6] [api] 删除邮箱为 `orf-system-login-background-admin-e2e@orf.local` 的登录页背景配置管理员测试认证身份。
  - [Clean-7] [api] 恢复邮箱为 `orf-system-login-background-admin-e2e@orf.local` 的默认进入页面为 系统默认。
  - [Clean-8] [prisma] 删除邮箱为 `orf-system-login-background-admin-e2e@orf.local` 的登录页背景配置管理员测试用户的默认团队成员关系。
  - [Clean-9] [prisma] 删除邮箱为 `orf-system-login-background-admin-e2e@orf.local` 的登录页背景配置管理员测试用户。
  - [Clean-10] [api] 邮箱为 `orf-system-login-background-admin-e2e@orf.local` 的登录页背景配置管理员测试认证身份 应不存在。
  - [Clean-11] [prisma] 邮箱为 `orf-system-login-background-admin-e2e@orf.local` 的登录页背景配置管理员测试用户 应不存在。
