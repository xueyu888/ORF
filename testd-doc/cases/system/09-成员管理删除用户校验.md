# 成员管理删除用户校验

## 1. 测试目标

验证：系统管理-成员管理页面中，删除用户操作正常；点击删除按钮后展示确认弹窗；确认后用户从成员列表和数据库记录中移除；取消后用户数据保持不变。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 准备邮箱为 `orf-system-members-delete-admin-e2e@orf.local`、使用固定测试密码的成员管理删除用户管理员测试认证身份。
  - [Setup-2] [prisma] 准备姓名为 "ORF Members Delete Admin E2E"、邮箱为 `orf-system-members-delete-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的成员管理删除用户管理员测试用户。
  - [Setup-3] [api] 设置成员管理删除用户管理员测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-4] [api] 准备邮箱为 `orf-system-members-delete-target-e2e@orf.local`、使用固定测试密码的成员管理待删除测试认证身份。
  - [Setup-5] [prisma] 准备姓名为 "ORF Members Delete Target E2E"、邮箱为 `orf-system-members-delete-target-e2e@orf.local`、角色为 `member`、状态为 `active` 的成员管理待删除测试用户。
  - [Setup-6] [api] 准备邮箱为 `orf-system-members-delete-cancel-e2e@orf.local`、使用固定测试密码的成员管理取消删除测试认证身份。
  - [Setup-7] [prisma] 准备姓名为 "ORF Members Delete Cancel E2E"、邮箱为 `orf-system-members-delete-cancel-e2e@orf.local`、角色为 `member`、状态为 `active` 的成员管理取消删除测试用户。
  - [Setup-9] [api] 撤销邮箱为 `orf-system-members-delete-admin-e2e@orf.local` 的成员管理删除用户管理员测试认证身份的残留登录会话。
  - [Setup-10] [api] 撤销邮箱为 `orf-system-members-delete-target-e2e@orf.local` 的成员管理待删除测试认证身份的残留登录会话。
  - [Setup-11] [api] 撤销邮箱为 `orf-system-members-delete-cancel-e2e@orf.local` 的成员管理取消删除测试认证身份的残留登录会话。
  - [Setup-12] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-13] [playwright] 打开 ORF 登录页。
  - [Setup-14] [playwright] 在邮箱输入框输入 `orf-system-members-delete-admin-e2e@orf.local`。
  - [Setup-15] [playwright] 在密码输入框输入成员管理删除用户管理员测试固定密码。
  - [Setup-16] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-17] [api] 当前会话 应为 邮箱为 `orf-system-members-delete-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [Setup-18] [playwright] 打开 成员管理页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-system-members-delete-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 成员管理页面。
  - [S0-3] [playwright] 成员管理页面的用户列表 应显示 待删除测试用户。
  - [S0-4] [playwright] 成员管理页面的用户列表 应显示 取消删除测试用户。
  - [S0-5] [playwright] 待删除测试用户列表行的 "删除用户" 操作 应可见。
  - [S0-6] [playwright] 待删除测试用户列表行的 "删除用户" 操作 应可点击。
  - [S0-7] [playwright] 取消删除测试用户列表行的 "删除用户" 操作 应可见。
  - [S0-8] [playwright] 取消删除测试用户列表行的 "删除用户" 操作 应可点击。
  - [S0-10] [prisma] 邮箱为 `orf-system-members-delete-target-e2e@orf.local` 的成员管理待删除测试用户 应存在。
  - [S0-11] [prisma] 邮箱为 `orf-system-members-delete-cancel-e2e@orf.local` 的成员管理取消删除测试用户 应存在。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击 取消删除测试用户列表行的 "删除用户" 操作。
  - [Action-2] [playwright] 查看 删除用户确认弹窗。
  - [Action-3] [playwright] 点击 删除用户确认弹窗的取消操作。
  - [Action-4] [playwright] 点击 待删除测试用户列表行的 "删除用户" 操作。
  - [Action-5] [playwright] 查看 删除用户确认弹窗。
  - [Action-6] [playwright] 点击 删除用户确认弹窗的确认操作。

- S1：Action 后状态。
  - [S1-1] [playwright] 删除用户确认弹窗标题 应显示 删除用户确认信息。
  - [S1-2] [playwright] 删除用户确认弹窗 应显示 取消删除测试用户。
  - [S1-3] [playwright] 点击取消后，删除用户确认弹窗 应不可见。
  - [S1-4] [playwright] 点击取消后，成员管理页面的用户列表 应显示 取消删除测试用户。
  - [S1-5] [prisma] 点击取消后，邮箱为 `orf-system-members-delete-cancel-e2e@orf.local` 的成员管理取消删除测试用户 应仍存在。
  - [S1-7] [playwright] 删除用户确认弹窗 应显示 待删除测试用户。
  - [S1-8] [playwright] 确认删除后，删除用户确认弹窗 应不可见。
  - [S1-9] [playwright] 确认删除后，成员管理页面的用户列表 应不显示 待删除测试用户。
  - [S1-10] [prisma] 确认删除后，邮箱为 `orf-system-members-delete-target-e2e@orf.local` 的成员管理待删除测试用户 应不存在。
  - [S1-12] [api] 当前会话 应仍为 邮箱为 `orf-system-members-delete-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。

- Clean：恢复 B。
  - [Clean-1] [api] 注销当前登录会话。
  - [Clean-2] [playwright] 离开当前 ORF 前端页面。
  - [Clean-3] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-4] [api] 撤销邮箱为 `orf-system-members-delete-admin-e2e@orf.local` 的成员管理删除用户管理员测试认证身份的残留登录会话。
  - [Clean-5] [api] 撤销邮箱为 `orf-system-members-delete-target-e2e@orf.local` 的成员管理待删除测试认证身份的残留登录会话。
  - [Clean-6] [api] 撤销邮箱为 `orf-system-members-delete-cancel-e2e@orf.local` 的成员管理取消删除测试认证身份的残留登录会话。
  - [Clean-7] [api] 删除邮箱为 `orf-system-members-delete-admin-e2e@orf.local` 的成员管理删除用户管理员测试认证身份。
  - [Clean-8] [api] 删除邮箱为 `orf-system-members-delete-target-e2e@orf.local` 的成员管理待删除测试认证身份。
  - [Clean-9] [api] 删除邮箱为 `orf-system-members-delete-cancel-e2e@orf.local` 的成员管理取消删除测试认证身份。
  - [Clean-10] [api] 恢复邮箱为 `orf-system-members-delete-admin-e2e@orf.local` 的默认进入页面为 系统默认。
  - [Clean-11] [prisma] 删除邮箱为 `orf-system-members-delete-admin-e2e@orf.local` 的成员管理删除用户管理员测试用户的默认团队成员关系。
  - [Clean-12] [prisma] 删除邮箱为 `orf-system-members-delete-target-e2e@orf.local` 的成员管理待删除测试用户的默认团队成员关系。
  - [Clean-13] [prisma] 删除邮箱为 `orf-system-members-delete-cancel-e2e@orf.local` 的成员管理取消删除测试用户的默认团队成员关系。
  - [Clean-14] [prisma] 删除邮箱为 `orf-system-members-delete-admin-e2e@orf.local` 的成员管理删除用户管理员测试用户。
  - [Clean-15] [prisma] 删除邮箱为 `orf-system-members-delete-target-e2e@orf.local` 的成员管理待删除测试用户。

  - [Clean-17] [api] 邮箱为 `orf-system-members-delete-admin-e2e@orf.local` 的成员管理删除用户管理员测试认证身份 应不存在。
  - [Clean-18] [api] 邮箱为 `orf-system-members-delete-target-e2e@orf.local` 的成员管理待删除测试认证身份 应不存在。
  - [Clean-19] [api] 邮箱为 `orf-system-members-delete-cancel-e2e@orf.local` 的成员管理取消删除测试认证身份 应不存在。
  - [Clean-20] [prisma] 邮箱为 `orf-system-members-delete-admin-e2e@orf.local` 的成员管理删除用户管理员测试用户 应不存在。
