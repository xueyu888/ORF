## 1. 测试目标

验证：个人设置页面中，上传有效格式头像后用户头像更新成功；上传无效格式头像时上传失败；删除已上传头像后头像恢复为默认头像；未上传自定义头像时删除头像按钮不可用或删除操作受限制。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 准备邮箱为 `orf-default-page-avatar-manage-e2e@orf.local`、使用固定测试密码的个人设置头像管理测试认证身份。
  - [Setup-2] [prisma] 准备邮箱为 `orf-default-page-avatar-manage-e2e@orf.local`、姓名为 `ORF 默认页头像管理用户`、角色为 `member`、状态为 `active` 的个人设置头像管理测试用户。
  - [Setup-3] [api] 确保个人设置头像管理测试用户未上传自定义头像。
  - [Setup-4] [api] 设置个人设置头像管理测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-5] [api] 准备邮箱为 `orf-default-page-avatar-none-e2e@orf.local`、使用固定测试密码的个人设置无头像删除限制测试认证身份。
  - [Setup-6] [prisma] 准备邮箱为 `orf-default-page-avatar-none-e2e@orf.local`、姓名为 `ORF 默认页无头像限制用户`、角色为 `member`、状态为 `active` 的个人设置无头像删除限制测试用户。
  - [Setup-7] [api] 确保个人设置无头像删除限制测试用户未上传自定义头像。
  - [Setup-8] [api] 设置个人设置无头像删除限制测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-9] [mock] 准备本用例有效头像图片文件。
  - [Setup-10] [mock] 准备本用例无效格式头像文件。
  - [Setup-11] [api] 撤销邮箱为 `orf-default-page-avatar-manage-e2e@orf.local` 的个人设置头像管理测试认证身份的残留登录会话。
  - [Setup-12] [api] 撤销邮箱为 `orf-default-page-avatar-none-e2e@orf.local` 的个人设置无头像删除限制测试认证身份的残留登录会话。
  - [Setup-13] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-14] [playwright] 打开 ORF 登录页。
  - [Setup-15] [playwright] 在邮箱输入框输入 `orf-default-page-avatar-manage-e2e@orf.local`。
  - [Setup-16] [playwright] 在密码输入框输入个人设置头像管理测试固定密码。
  - [Setup-17] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-18] [api] 当前会话 应为 邮箱为 `orf-default-page-avatar-manage-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [Setup-19] [playwright] 打开 个人设置页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-default-page-avatar-manage-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 个人设置页面。
  - [S0-3] [playwright] 个人设置页面的当前用户头像 应显示 默认头像。
  - [S0-4] [playwright] 个人设置页面的上传头像操作 应可点击。
  - [S0-5] [playwright] 个人设置页面的删除头像操作 应不可点击。
  - [S0-6] [prisma] 邮箱为 `orf-default-page-avatar-manage-e2e@orf.local` 的个人设置头像管理测试用户 应不存在 自定义头像。

- Action：被测业务动作。
  - [Action-1] [playwright] 通过个人设置页面的上传头像操作选择本用例有效头像图片文件。
  - [Action-2] [playwright] 通过个人设置页面的上传头像操作选择本用例无效格式头像文件。
  - [Action-3] [playwright] 点击 个人设置页面的删除头像操作。
  - [Action-4] [api] 注销当前登录会话。
  - [Action-5] [playwright] 移除当前浏览器中的残留登录态。
  - [Action-6] [playwright] 打开 ORF 登录页。
  - [Action-7] [playwright] 在邮箱输入框输入 `orf-default-page-avatar-none-e2e@orf.local`。
  - [Action-8] [playwright] 在密码输入框输入个人设置无头像删除限制测试固定密码。
  - [Action-9] [playwright] 点击 "Sign In" 登录操作。
  - [Action-10] [playwright] 打开 个人设置页面。

- S1：Action 后状态。

  - [S1-5] [playwright] 删除头像后，个人设置头像管理测试用户的当前用户头像 应显示 默认头像。
  - [S1-6] [prisma] 删除头像后，邮箱为 `orf-default-page-avatar-manage-e2e@orf.local` 的个人设置头像管理测试用户 应不存在 自定义头像。
  - [S1-7] [api] 当前会话 应为 邮箱为 `orf-default-page-avatar-none-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [S1-8] [playwright] 无自定义头像用户的个人设置页面 应为 个人设置页面。
  - [S1-9] [playwright] 无自定义头像用户的个人设置页面的当前用户头像 应显示 默认头像。
  - [S1-10] [playwright] 无自定义头像用户的个人设置页面的删除头像操作 应不可点击。
  - [S1-11] [prisma] 邮箱为 `orf-default-page-avatar-none-e2e@orf.local` 的个人设置无头像删除限制测试用户 应不存在 自定义头像。
