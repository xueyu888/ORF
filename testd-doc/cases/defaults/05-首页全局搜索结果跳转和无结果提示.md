## 1. 测试目标

验证：首页（默认系统页）中，已登录用户在全局搜索中点击匹配结果后可以正常跳转；输入不存在关键词时系统展示无结果提示；清空搜索或关闭搜索弹窗后，搜索状态可以恢复正常。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 准备邮箱为 `orf-default-page-search-state-e2e@orf.local`、使用固定测试密码的默认系统页全局搜索状态测试认证身份。
  - [Setup-2] [prisma] 准备邮箱为 `orf-default-page-search-state-e2e@orf.local`、角色为 `admin`、状态为 `active` 的默认系统页全局搜索状态测试用户。
  - [Setup-3] [api] 设置默认系统页全局搜索状态测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-4] [prisma] 准备标题包含 `ORF全局搜索跳转E2E` 的全局搜索跳转测试目标。
  - [Setup-5] [prisma] 准备标题包含 `ORF全局搜索跳转E2E` 且属于全局搜索跳转测试目标的全局搜索跳转测试指标。
  - [Setup-6] [prisma] 准备标题包含 `ORF全局搜索跳转E2E` 且属于全局搜索跳转测试目标的全局搜索跳转测试任务。
  - [Setup-7] [prisma] 准备现象包含 `ORF全局搜索跳转E2E` 的全局搜索跳转测试反馈。
  - [Setup-8] [api] 撤销邮箱为 `orf-default-page-search-state-e2e@orf.local` 的默认系统页全局搜索状态测试认证身份的残留登录会话。
  - [Setup-9] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-10] [playwright] 打开 ORF 登录页。
  - [Setup-11] [playwright] 在邮箱输入框输入 `orf-default-page-search-state-e2e@orf.local`。
  - [Setup-12] [playwright] 在密码输入框输入默认系统页全局搜索状态测试固定密码。
  - [Setup-13] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-14] [api] 当前会话 应为 邮箱为 `orf-default-page-search-state-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [Setup-15] [playwright] 打开 首页（默认系统页）。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-default-page-search-state-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 首页（默认系统页）。
  - [S0-3] [playwright] 顶部导航栏的全局搜索入口 应可见。
  - [S0-4] [playwright] 顶部导航栏的全局搜索入口 应可点击。
  - [S0-5] [prisma] 标题包含 `ORF全局搜索跳转E2E` 的全局搜索跳转测试目标 应存在。
  - [S0-6] [prisma] 标题包含 `ORF全局搜索跳转E2E` 的全局搜索跳转测试指标 应存在。
  - [S0-7] [prisma] 标题包含 `ORF全局搜索跳转E2E` 的全局搜索跳转测试任务 应存在。
  - [S0-8] [prisma] 现象包含 `ORF全局搜索跳转E2E` 的全局搜索跳转测试反馈 应存在。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击 顶部导航栏的全局搜索入口。
  - [Action-2] [playwright] 在全局搜索输入框输入 `ORF全局搜索跳转E2E`。
  - [Action-3] [playwright] 点击 全局搜索结果列表中的 `ORF全局搜索跳转E2E 目标` 目标匹配结果。
  - [Action-4] [playwright] 打开 首页（默认系统页）。
  - [Action-5] [playwright] 点击 顶部导航栏的全局搜索入口。
  - [Action-6] [playwright] 在全局搜索输入框输入 `ORF不存在搜索结果E2E`。
  - [Action-7] [playwright] 清空 全局搜索输入框。
  - [Action-8] [playwright] 点击 全局搜索弹窗的关闭操作。

- S1：Action 后状态。
  - [S1-1] [playwright] 点击目标匹配结果后，当前页面 应进入 `ORF全局搜索跳转E2E 目标` 对应的挑战详情页。
  - [S1-2] [playwright] 输入 `ORF不存在搜索结果E2E` 后，全局搜索弹窗 应显示无结果提示。
  - [S1-3] [playwright] 清空全局搜索输入框后，全局搜索输入框的值 应为空。
  - [S1-4] [playwright] 清空全局搜索输入框后，全局搜索结果列表 应恢复展示默认可搜索入口。
  - [S1-5] [playwright] 点击关闭操作后，全局搜索弹窗 应不可见。
  - [S1-6] [playwright] 点击关闭操作后，顶部导航栏的全局搜索入口 应可见。
  - [S1-7] [api] 当前会话 应仍为 邮箱为 `orf-default-page-search-state-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
