## 1. 测试目标

验证：新建反馈页面中，已登录且具备反馈创建能力的用户填写有效反馈信息后，可以成功创建 issue；必填信息为空时，系统阻止创建并提示对应必填信息。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 准备邮箱为 `orf-default-page-feedback-create-e2e@orf.local`、使用固定测试密码的新建反馈创建测试认证身份。
  - [Setup-2] [prisma] 准备邮箱为 `orf-default-page-feedback-create-e2e@orf.local`、姓名为 `ORF Default Page Feedback Create E2E`、角色为 `admin`、状态为 `active` 的新建反馈创建测试用户。
  - [Setup-3] [api] 设置新建反馈创建测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-4] [prisma] 删除现象为 `ORF默认页反馈创建E2E-标题` 的残留反馈 issue。
  - [Setup-5] [api] 撤销邮箱为 `orf-default-page-feedback-create-e2e@orf.local` 的新建反馈创建测试认证身份的残留登录会话。
  - [Setup-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-7] [playwright] 打开 ORF 登录页。
  - [Setup-8] [playwright] 在邮箱输入框输入 `orf-default-page-feedback-create-e2e@orf.local`。
  - [Setup-9] [playwright] 在密码输入框输入新建反馈创建测试固定密码。
  - [Setup-10] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-11] [api] 当前会话 应为 邮箱为 `orf-default-page-feedback-create-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [Setup-12] [playwright] 打开 首页（默认系统页）。
  - [Setup-13] [playwright] 点击 顶部导航栏的新建反馈入口。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-default-page-feedback-create-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 新建反馈页面。
  - [S0-3] [playwright] 新建反馈表单 应可见。
  - [S0-4] [playwright] 新建反馈表单的标题输入框 应为空。
  - [S0-5] [playwright] 新建反馈表单的反馈描述输入区域 应为空。
  - [S0-6] [playwright] 新建反馈表单的处理人选择框 应已选择 `ORF Default Page Feedback Create E2E`。
  - [S0-7] [playwright] 新建反馈表单的分类选择框 应已选择 `技术问题`。
  - [S0-8] [playwright] 新建反馈表单的影响等级选择框 应已选择 `中`。
  - [S0-9] [playwright] 新建反馈表单的提交操作 应可点击。
  - [S0-10] [prisma] 现象为 `ORF默认页反馈创建E2E-标题` 的反馈 issue 应不存在。

- Action：被测业务动作。
  - [Action-1] [playwright] 在新建反馈表单的标题输入框输入 `ORF默认页反馈创建E2E-标题`。
  - [Action-2] [playwright] 点击 新建反馈表单的提交操作。
  - [Action-3] [playwright] 在新建反馈表单的反馈描述输入区域输入 `ORF默认页反馈创建E2E-描述内容`。
  - [Action-4] [playwright] 在新建反馈表单的处理人选择框选择 `ORF Default Page Feedback Create E2E`。
  - [Action-5] [playwright] 在新建反馈表单的分类选择框选择 `技术问题`。
  - [Action-6] [playwright] 在新建反馈表单的影响等级选择框选择 `高`。
  - [Action-7] [playwright] 点击 新建反馈表单的提交操作。

- S1：Action 后状态。
  - [S1-1] [playwright] 反馈正文为空提交后，系统 应提示 `请填写标题、正文、分类和处理人`。
  - [S1-2] [playwright] 当前页面 应为 新建反馈页面。
  - [S1-3] [playwright] 有效反馈信息提交后，当前页面 应为 新创建反馈 issue 的详情页。
  - [S1-4] [playwright] 新创建反馈 issue 详情页 应显示 `ORF默认页反馈创建E2E-标题`。
  - [S1-5] [playwright] 新创建反馈 issue 详情页 应显示 `ORF默认页反馈创建E2E-描述内容`。
  - [S1-6] [playwright] 新创建反馈 issue 详情页 应显示 分类为 `技术问题`。
  - [S1-7] [playwright] 新创建反馈 issue 详情页 应显示 影响等级为 `高`。
  - [S1-8] [prisma] 现象为 `ORF默认页反馈创建E2E-标题` 的反馈 issue 应存在。
  - [S1-9] [api] 当前会话 应仍为 邮箱为 `orf-default-page-feedback-create-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。

  - [Clean-6] [api] 删除邮箱为 `orf-default-page-feedback-create-e2e@orf.local` 的新建反馈创建测试认证身份。

  - [Clean-8] [prisma] 删除邮箱为 `orf-default-page-feedback-create-e2e@orf.local` 的新建反馈创建测试用户的默认团队成员关系。
  - [Clean-9] [prisma] 删除邮箱为 `orf-default-page-feedback-create-e2e@orf.local` 的新建反馈创建测试用户。
