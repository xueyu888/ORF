## 1. 测试目标

验证：个人设置页面基础元素正常展示，包括用户信息、上传头像、删除头像、默认进入页面、侧边栏默认状态、Toast 通知、皮肤列表和上传皮肤按钮；当前登录用户头像、用户名、邮箱、角色和状态展示正确。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 准备邮箱为 `orf-default-page-personal-settings-e2e@orf.local`、使用固定测试密码的个人设置页面测试认证身份。
  - [Setup-2] [prisma] 准备邮箱为 `orf-default-page-personal-settings-e2e@orf.local`、姓名为 `ORF 默认页个人设置用户`、角色为 `member`、状态为 `active` 的个人设置页面测试用户。
  - [Setup-3] [api] 为个人设置页面测试用户上传自定义头像。
  - [Setup-4] [api] 设置个人设置页面测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-5] [api] 撤销邮箱为 `orf-default-page-personal-settings-e2e@orf.local` 的个人设置页面测试认证身份的残留登录会话。
  - [Setup-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-7] [playwright] 打开 ORF 登录页。
  - [Setup-8] [playwright] 在邮箱输入框输入 `orf-default-page-personal-settings-e2e@orf.local`。
  - [Setup-9] [playwright] 在密码输入框输入个人设置页面测试固定密码。
  - [Setup-10] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-11] [api] 当前会话 应为 邮箱为 `orf-default-page-personal-settings-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [Setup-12] [playwright] 打开 首页（默认系统页）。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-default-page-personal-settings-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 首页（默认系统页）。
  - [S0-3] [playwright] 侧边栏底部的当前用户头像 应可见。
  - [S0-4] [playwright] 侧边栏底部的当前用户名 应显示 `ORF 默认页个人设置用户`。
  - [S0-5] [playwright] 侧边栏底部的用户菜单入口 应可见。
  - [S0-6] [playwright] 侧边栏底部的用户菜单入口 应可点击。
  - [S0-7] [playwright] 用户菜单中的 "个人设置" 操作 应不可见。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击 侧边栏底部的用户菜单入口。
  - [Action-2] [playwright] 点击 用户菜单中的 "个人设置" 操作。
