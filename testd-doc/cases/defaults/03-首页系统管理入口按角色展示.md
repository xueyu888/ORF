## 1. 测试目标

验证：首页（默认系统页）中，系统管理入口应按当前登录用户角色正确展示：管理员登录后系统管理入口可见且可点击，普通成员登录后系统管理入口不可见。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 准备邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local`、使用固定测试密码的默认系统页管理员测试认证身份。
  - [Setup-2] [prisma] 准备邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的默认系统页管理员测试用户。
  - [Setup-3] [api] 设置默认系统页管理员测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-4] [api] 准备邮箱为 `orf-default-page-admin-entry-member-e2e@orf.local`、使用固定测试密码的默认系统页普通成员测试认证身份。
  - [Setup-5] [prisma] 准备邮箱为 `orf-default-page-admin-entry-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的默认系统页普通成员测试用户。
  - [Setup-6] [api] 设置默认系统页普通成员测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-7] [api] 撤销邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local` 的默认系统页管理员测试认证身份的残留登录会话。
  - [Setup-8] [api] 撤销邮箱为 `orf-default-page-admin-entry-member-e2e@orf.local` 的默认系统页普通成员测试认证身份的残留登录会话。
  - [Setup-9] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-10] [playwright] 打开 ORF 登录页。
  - [Setup-11] [playwright] 在邮箱输入框输入 `orf-default-page-admin-entry-admin-e2e@orf.local`。
  - [Setup-12] [playwright] 在密码输入框输入默认系统页管理员测试固定密码。
  - [Setup-13] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-14] [api] 当前会话 应为 邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [Setup-15] [playwright] 打开 首页（默认系统页）。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local`、角色为 `admin`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 首页（默认系统页）。
  - [S0-3] [playwright] 侧边栏 应可见。
  - [S0-4] [playwright] 侧边栏的基础菜单入口 应可见。

- Action：被测业务动作。
  - [Action-1] [playwright] 查看 管理员登录后的 首页（默认系统页）侧边栏。
  - [Action-2] [playwright] 注销当前管理员登录会话。
  - [Action-3] [playwright] 移除当前浏览器中的残留登录态。
  - [Action-4] [playwright] 打开 ORF 登录页。
  - [Action-5] [playwright] 在邮箱输入框输入 `orf-default-page-admin-entry-member-e2e@orf.local`。
  - [Action-6] [playwright] 在密码输入框输入默认系统页普通成员测试固定密码。
  - [Action-7] [playwright] 点击 "Sign In" 登录操作。
  - [Action-8] [api] 当前会话 应为 邮箱为 `orf-default-page-admin-entry-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [Action-9] [playwright] 打开 首页（默认系统页）。
  - [Action-10] [playwright] 查看 普通成员登录后的 首页（默认系统页）侧边栏。

- S1：Action 后状态。
  - [S1-1] [playwright] 管理员登录后的侧边栏的系统管理入口 应可见。
  - [S1-2] [playwright] 管理员登录后的侧边栏的系统管理入口 应可点击。
  - [S1-3] [playwright] 普通成员登录后的侧边栏的系统管理入口 应不可见。
  - [S1-4] [api] 当前会话 应仍为 邮箱为 `orf-default-page-admin-entry-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。

- Clean：恢复 B。
  - [Clean-1] [api] 注销当前登录会话。
  - [Clean-2] [playwright] 离开当前 ORF 前端页面。
  - [Clean-3] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-4] [api] 撤销邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local` 的默认系统页管理员测试认证身份的残留登录会话。
  - [Clean-5] [api] 撤销邮箱为 `orf-default-page-admin-entry-member-e2e@orf.local` 的默认系统页普通成员测试认证身份的残留登录会话。
  - [Clean-6] [api] 删除邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local` 的默认系统页管理员测试认证身份。
  - [Clean-7] [api] 删除邮箱为 `orf-default-page-admin-entry-member-e2e@orf.local` 的默认系统页普通成员测试认证身份。
  - [Clean-8] [api] 恢复邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local` 的默认进入页面为 系统默认。
  - [Clean-9] [api] 恢复邮箱为 `orf-default-page-admin-entry-member-e2e@orf.local` 的默认进入页面为 系统默认。
  - [Clean-10] [prisma] 删除邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local` 的默认系统页管理员测试用户的默认团队成员关系。
  - [Clean-11] [prisma] 删除邮箱为 `orf-default-page-admin-entry-member-e2e@orf.local` 的默认系统页普通成员测试用户的默认团队成员关系。
  - [Clean-12] [prisma] 删除邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local` 的默认系统页管理员测试用户。

  - [Clean-14] [api] 邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local` 的默认系统页管理员测试认证身份 应不存在。
  - [Clean-15] [api] 邮箱为 `orf-default-page-admin-entry-member-e2e@orf.local` 的默认系统页普通成员测试认证身份 应不存在。
  - [Clean-16] [prisma] 邮箱为 `orf-default-page-admin-entry-admin-e2e@orf.local` 的默认系统页管理员测试用户 应不存在。
  - [Clean-17] [prisma] 邮箱为 `orf-default-page-admin-entry-member-e2e@orf.local` 的默认系统页普通成员测试用户 应不存在。
