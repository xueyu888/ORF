## 1. 测试目标

验证：个人设置页面中，上传有效格式 AppShell 自定义皮肤后，皮肤新增成功并展示在“我的 AppShell 皮肤”列表中；上传无效格式皮肤时上传失败；选择自定义皮肤后 AppShell 皮肤背景应用成功；删除自定义皮肤后皮肤从列表中移除；删除当前正在使用的自定义皮肤后 AppShell 皮肤背景恢复为系统默认皮肤。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 准备邮箱为 `orf-default-page-custom-skin-e2e@orf.local`、使用固定测试密码的个人设置自定义皮肤测试认证身份。
  - [Setup-2] [prisma] 准备邮箱为 `orf-default-page-custom-skin-e2e@orf.local`、姓名为 `ORF 默认页自定义皮肤用户`、角色为 `member`、状态为 `active` 的个人设置自定义皮肤测试用户。
  - [Setup-3] [api] 设置个人设置自定义皮肤测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-4] [api] 设置个人设置自定义皮肤测试用户 AppShell 皮肤偏好为 系统默认。
  - [Setup-5] [api] 删除个人设置自定义皮肤测试用户的残留自定义皮肤文件。
  - [Setup-6] [mock] 准备本用例有效格式自定义皮肤图片文件。
  - [Setup-7] [mock] 准备本用例无效格式自定义皮肤文件。
  - [Setup-8] [api] 撤销邮箱为 `orf-default-page-custom-skin-e2e@orf.local` 的个人设置自定义皮肤测试认证身份的残留登录会话。
  - [Setup-9] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-10] [playwright] 打开 ORF 登录页。
  - [Setup-11] [playwright] 在邮箱输入框输入 `orf-default-page-custom-skin-e2e@orf.local`。
  - [Setup-12] [playwright] 在密码输入框输入个人设置自定义皮肤测试固定密码。
  - [Setup-13] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-14] [api] 当前会话 应为 邮箱为 `orf-default-page-custom-skin-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [Setup-15] [playwright] 打开 个人设置页面。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-default-page-custom-skin-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 个人设置页面。
  - [S0-3] [playwright] 个人设置页面的“我的 AppShell 皮肤”区域 应可见。
  - [S0-4] [playwright] 个人设置页面的皮肤列表 应可见。
  - [S0-5] [playwright] 个人设置页面的上传皮肤操作 应可点击。
  - [S0-6] [playwright] 个人设置页面的设为我的背景操作 应可见。
  - [S0-7] [playwright] 个人设置页面的删除皮肤操作 应可见。
  - [S0-8] [api] 个人设置自定义皮肤测试用户的 AppShell 皮肤偏好 应为 系统默认。
  - [S0-9] [api] 个人设置自定义皮肤测试用户 应不存在 自定义皮肤文件。

- Action：被测业务动作。
  - [Action-1] [playwright] 通过个人设置页面的上传皮肤操作选择本用例有效格式自定义皮肤图片文件。
  - [Action-2] [playwright] 通过个人设置页面的上传皮肤操作选择本用例无效格式自定义皮肤文件。
  - [Action-3] [playwright] 点击 个人设置页面的使用系统默认操作。
  - [Action-4] [playwright] 选择 个人设置页面的已上传自定义皮肤卡片。
  - [Action-5] [playwright] 点击 个人设置页面的设为我的背景操作。
  - [Action-6] [playwright] 点击 个人设置页面的删除皮肤操作。
  - [Action-7] [playwright] 通过个人设置页面的上传皮肤操作再次选择本用例有效格式自定义皮肤图片文件。
  - [Action-8] [playwright] 点击 个人设置页面的使用系统默认操作。
  - [Action-9] [playwright] 选择 个人设置页面的新上传自定义皮肤卡片。
  - [Action-10] [playwright] 点击 个人设置页面的删除皮肤操作。

- S1：Action 后状态。
  - [S1-1] [playwright] 有效格式自定义皮肤上传后，个人设置页面的皮肤列表 应显示 已上传自定义皮肤。
  - [S1-2] [api] 有效格式自定义皮肤上传后，个人设置自定义皮肤测试用户 应存在 自定义皮肤文件。
  - [S1-3] [playwright] 无效格式自定义皮肤上传后，系统 应提示 `仅支持上传图片文件`。
  - [S1-4] [playwright] 无效格式自定义皮肤上传后，个人设置页面的皮肤列表 应仍显示 已上传自定义皮肤。
  - [S1-5] [api] 无效格式自定义皮肤上传后，个人设置自定义皮肤测试用户的自定义皮肤文件 应仍为 有效格式自定义皮肤上传后的文件。
  - [S1-6] [playwright] 选择自定义皮肤并设为我的背景后，AppShell 皮肤背景 应应用所选自定义皮肤。
  - [S1-7] [api] 选择自定义皮肤并设为我的背景后，个人设置自定义皮肤测试用户的 AppShell 皮肤偏好 应为 所选自定义皮肤。
  - [S1-8] [playwright] 删除当前正在使用的自定义皮肤后，个人设置页面的皮肤列表 应不显示 被删除的自定义皮肤。
  - [S1-9] [playwright] 删除当前正在使用的自定义皮肤后，AppShell 皮肤背景 应恢复为 系统默认皮肤。
  - [S1-10] [api] 删除当前正在使用的自定义皮肤后，个人设置自定义皮肤测试用户的 AppShell 皮肤偏好 应为 系统默认。
  - [S1-11] [playwright] 再次上传有效格式自定义皮肤后，个人设置页面的皮肤列表 应显示 新上传自定义皮肤。
  - [S1-12] [api] 点击使用系统默认后，个人设置自定义皮肤测试用户的 AppShell 皮肤偏好 应为 系统默认。
  - [S1-13] [playwright] 删除未设为当前背景的自定义皮肤后，个人设置页面的皮肤列表 应不显示 被删除的自定义皮肤。
  - [S1-14] [api] 删除未设为当前背景的自定义皮肤后，个人设置自定义皮肤测试用户 应不存在 自定义皮肤文件。
  - [S1-15] [api] 当前会话 应为 邮箱为 `orf-default-page-custom-skin-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。

  - [Clean-10] [prisma] 删除邮箱为 `orf-default-page-custom-skin-e2e@orf.local` 的个人设置自定义皮肤测试用户。
