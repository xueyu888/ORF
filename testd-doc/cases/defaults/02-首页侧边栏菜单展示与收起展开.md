## 1. 测试目标

验证：首页（默认系统页）中，已登录用户进入默认系统页后，侧边栏菜单应完整展示悬赏大厅、我的挑战、反馈、统计等基础入口，并且支持正常收起和展开。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询能力 应可用。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos 认证服务的管理和公共访问能力 应可用。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory 登录会话 cookie。
  - [B-10] [playwright] 当前浏览器 应不保留本地登录态。

- Setup：构造 S0。
  - [Setup-1] [api] 准备邮箱为 `orf-default-page-sidebar-e2e@orf.local`、使用固定测试密码的默认系统页测试认证身份。
  - [Setup-2] [prisma] 准备邮箱为 `orf-default-page-sidebar-e2e@orf.local`、角色为 `member`、状态为 `active` 的默认系统页测试用户。
  - [Setup-3] [api] 设置默认系统页测试用户默认进入页面为 首页（默认系统页）。
  - [Setup-4] [api] 设置默认系统页测试用户侧边栏默认状态为 展开。
  - [Setup-5] [api] 撤销邮箱为 `orf-default-page-sidebar-e2e@orf.local` 的默认系统页测试认证身份的残留登录会话。
  - [Setup-6] [playwright] 移除当前浏览器中的残留登录态。
  - [Setup-7] [playwright] 打开 ORF 登录页。
  - [Setup-8] [playwright] 在邮箱输入框输入 `orf-default-page-sidebar-e2e@orf.local`。
  - [Setup-9] [playwright] 在密码输入框输入默认系统页测试固定密码。
  - [Setup-10] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-11] [api] 当前会话 应为 邮箱为 `orf-default-page-sidebar-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [Setup-12] [playwright] 打开 首页（默认系统页）。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 `orf-default-page-sidebar-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 首页（默认系统页）。
  - [S0-3] [playwright] 侧边栏 应可见。
  - [S0-4] [playwright] 侧边栏的基础菜单入口 应可见。
  - [S0-5] [playwright] 侧边栏初始状态 应处于展开状态。

- Action：被测业务动作。
  - [Action-1] [playwright] 查看 首页（默认系统页）侧边栏菜单。
  - [Action-2] [playwright] 收起 首页（默认系统页）侧边栏。
  - [Action-3] [playwright] 侧边栏收起后 应处于收起状态。
  - [Action-4] [playwright] 展开 首页（默认系统页）侧边栏。

- S1：Action 后状态。
  - [S1-1] [playwright] 侧边栏的悬赏大厅入口 应可见。
  - [S1-2] [playwright] 侧边栏的我的挑战入口 应可见。
  - [S1-3] [playwright] 侧边栏的反馈入口 应可见。
  - [S1-4] [playwright] 侧边栏的统计入口 应可见。
  - [S1-5] [playwright] 侧边栏的悬赏大厅入口 应可点击。
  - [S1-6] [playwright] 侧边栏的我的挑战入口 应可点击。
  - [S1-7] [playwright] 侧边栏的反馈入口 应可点击。
  - [S1-8] [playwright] 侧边栏的统计入口 应可点击。
  - [S1-9] [playwright] 侧边栏展开后 应处于展开状态。
  - [S1-10] [playwright] 侧边栏展开后 侧边栏的悬赏大厅入口文本 应可见。
  - [S1-11] [playwright] 侧边栏展开后 侧边栏的我的挑战入口文本 应可见。
  - [S1-12] [playwright] 侧边栏展开后 侧边栏的反馈入口文本 应可见。
  - [S1-13] [playwright] 侧边栏展开后 侧边栏的统计入口文本 应可见。
  - [S1-14] [api] 当前会话 应仍为 邮箱为 `orf-default-page-sidebar-e2e@orf.local`、角色为 `member`、状态为 `active` 的已登录会话。

- Clean：恢复 B。
  - [Clean-1] [api] 注销当前登录会话。
  - [Clean-2] [playwright] 离开当前 ORF 前端页面。
  - [Clean-3] [playwright] 移除当前浏览器中的残留登录态。
  - [Clean-4] [api] 撤销邮箱为 `orf-default-page-sidebar-e2e@orf.local` 的默认系统页测试认证身份的残留登录会话。
  - [Clean-5] [api] 删除邮箱为 `orf-default-page-sidebar-e2e@orf.local` 的默认系统页测试认证身份。
  - [Clean-6] [api] 恢复邮箱为 `orf-default-page-sidebar-e2e@orf.local` 的默认进入页面为 系统默认。
  - [Clean-7] [api] 恢复邮箱为 `orf-default-page-sidebar-e2e@orf.local` 的侧边栏默认状态为 系统默认。
  - [Clean-8] [prisma] 删除邮箱为 `orf-default-page-sidebar-e2e@orf.local` 的默认系统页测试用户的默认团队成员关系。
  - [Clean-9] [prisma] 删除邮箱为 `orf-default-page-sidebar-e2e@orf.local` 的默认系统页测试用户。
  - [Clean-10] [api] 邮箱为 `orf-default-page-sidebar-e2e@orf.local` 的默认系统页测试认证身份 应不存在。
  - [Clean-11] [prisma] 邮箱为 `orf-default-page-sidebar-e2e@orf.local` 的默认系统页测试用户 应不存在。
