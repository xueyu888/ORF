# 用户增加行动项和子行动项

## 1. 测试目标

验证：有权限的普通成员可以在目标评估阶段新增行动项，并在该行动项下新增子行动项；新增后，行动项和子行动项在接口、数据库和页面中可见。

边界：

- 覆盖对象：有权限用户新增行动项和子行动项。
- 不覆盖对象：无权限用户不可新增、行动项编辑、行动项删除、子行动项编辑、子行动项删除、排序、完成状态切换。
- B 基础数据：预置普通成员账号 "orf-member-e2e@orf.local"，角色为 member，状态为 active。
- Setup 产物：允许新增行动项且挑战者包含普通成员的目标。
- Clean 产物：本用例创建的测试行动项和目标原始状态。

## 2. 状态模型

- B：基准状态。
  - [api] 前端和后端服务 应为 可用。
  - [api] 前端登录页入口 应可访问。
  - [api] 当前会话查询接口 应可访问。
  - [prisma] ORF 数据库 应为 可连接。
  - [api] Ory/Kratos Admin/Public API 应为 可访问。
  - [api] Ory/Kratos 中 应存在 邮箱为 `orf-member-e2e@orf.local` 的普通成员测试身份。
  - [prisma] 应存在 邮箱为 `orf-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户。
  - [prisma] 应存在 一个可构造成员新增行动项起点的目标。
  - [prisma] 应不存在 标题为 `E2E-TASK-CREATE: 用户增加行动项` 的测试行动项。
  - [api] 当前会话 应为 未登录。
  - [playwright] 浏览器 应不存在 登录 cookie。
  - [playwright] 浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [playwright] 清空 浏览器状态。
  - [prisma] 选择 一个可构造成员新增行动项起点的目标。
  - [prisma] 记录 目标 的原始状态。
  - [prisma] 设置 目标 flowStatus 为 `reestimating`。
  - [prisma] 设置 目标 挑战者列表包含普通成员。
  - [playwright] 打开 登录页。
  - [playwright] 在 Email 输入框 输入 普通成员邮箱。
  - [playwright] 在 Password 输入框 输入 普通成员密码。
  - [playwright] 点击 `Sign In` 登录操作。
  - [api] 当前会话 应为 普通成员已登录。
  - [playwright] 打开 挑战工作台。

- S0：Action 前状态。
  - [api] 当前会话 应为 邮箱 `orf-member-e2e@orf.local` 的普通成员已登录。
  - [playwright] 当前页面 应为 挑战工作台。
  - [playwright] 目标 面板 应可见。
  - [playwright] 目标 的 `新增行动项` 操作 应可点击。
  - [prisma] 目标 flowStatus 应为 `reestimating`。
  - [prisma] 目标 的挑战者列表 应包含 普通成员。
  - [prisma] 目标 应不存在 标题为 `E2E-TASK-CREATE: 用户增加行动项` 的行动项。

- Action：被测业务动作。
  - [playwright] 点击 目标 的 `新增行动项` 操作。
  - [playwright] 新建行动项弹窗 应可见。
  - [playwright] 在 `行动项标题` 输入框 输入 测试行动项标题。
  - [playwright] 在 `说明` 输入框 输入 测试行动项说明。
  - [playwright] 在点击 `保存行动项` 前注册 新建行动项接口响应捕获。
  - [playwright] 点击 `保存行动项` 操作。
  - [api] 记录 新建行动项接口返回的行动项。
  - [playwright] 在点击 `新增子行动项` 前注册 新建子行动项接口响应捕获。
  - [playwright] 点击 测试行动项 的 `新增子行动项` 操作。
  - [api] 记录 新建子行动项。

- S1：Action 后状态。
  - [api] 新建行动项接口响应 应成功。
  - [api] 新建子行动项接口响应 应成功。
  - [api] 新建行动项接口返回的行动项 应属于 目标。
  - [api] 新建行动项接口返回的行动项标题 应为 测试行动项标题。
  - [prisma] 目标 应存在 标题为测试行动项标题、执行人为普通成员的行动项。
  - [prisma] 测试行动项 应存在 标签为 `新子任务` 的子行动项。
  - [playwright] 目标 面板 应显示 测试行动项标题。
  - [playwright] 测试行动项 下 应显示 `新子任务` 子行动项。
  - [api] 当前会话 应仍为 普通成员已登录。

- Clean：恢复 B。
  - [prisma] 删除 本用例创建的测试行动项。
  - [prisma] 恢复 目标 在 Setup 前记录的原始状态。
  - [api] 退出 当前登录态。
  - [playwright] 清空 浏览器状态。
  - [api] Ory/Kratos 中 应仍存在 普通成员测试身份。
  - [prisma] 应仍存在 邮箱为 `orf-member-e2e@orf.local`、角色为 `member`、状态为 `active` 的普通成员用户。
