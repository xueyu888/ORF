# 用户增加行动项和子行动项

## 1. 测试目标

验证：由当前用例独占准备的普通成员可以在当前用例独占目标的重估阶段新增行动项，并在该行动项下新增子行动项；新增后，行动项和子行动项在接口、数据库和页面中可见。

边界：

- 覆盖对象：参与目标且有当前阶段权限的普通成员新增行动项和子行动项。
- 不覆盖对象：无权限用户不可新增、行动项编辑、行动项删除、子行动项编辑、子行动项删除、排序、完成状态切换。
- 原 legacy B 依赖：预置普通成员账号 `orf-member-e2e@orf.local`，以及默认团队中任意可改造为成员新增行动项起点的共享目标。
- B 基准：前端、后端、数据库、schema、Ory/Kratos 和当前浏览器可开测；不要求存在任何具体成员账号、目标、行动项或子行动项。
- Setup 产物：邮箱为 "orf-member-create-task-e2e@orf.local" 的普通成员身份、用户和 member 成员关系；标题为 "E2E-MEMBER-CREATE-TASK: 目标前置"、`flowStatus` 为 `reestimating` 且挑战者包含该成员的本用例行动项目标；运行时记录的 `runtime.taskTarget`。
- Action 产物：标题为 "E2E-TASK-CREATE: 用户增加行动项"、说明为系统默认说明、执行人为本用例普通成员的测试行动项；标签为 "新子任务" 的测试子行动项。
- Clean 产物：删除本用例行动项、子行动项、目标及其派生数据，删除本用例独占普通成员身份、用户、成员关系与 session。
- 原状态恢复：目标、行动项和子行动项均为当前用例独占资源，Clean 直接删除，不恢复任何共享目标状态。

## 2. 状态-动作模型

- B：基准状态。
  - [B-1] [api] 前端服务 应可用。
  - [B-2] [api] 后端服务 应可用。
  - [B-3] [api] 前端登录页入口 应可访问。
  - [B-4] [api] 当前会话查询接口 应可访问。
  - [B-5] [prisma] ORF 数据库 应可连接。
  - [B-6] [prisma] ORF 数据库 schema 应为 当前测试版本。
  - [B-7] [api] Ory/Kratos Admin/Public API 应可访问。
  - [B-8] [api] 当前会话 应为 未登录。
  - [B-9] [playwright] 当前浏览器 应不存在 Ory session cookie。
  - [B-10] [playwright] 当前浏览器 storage 应不包含 登录态。

- Setup：构造 S0。
  - [Setup-1] [prisma] 删除可能残留的本用例测试行动项。
  - [Setup-2] [prisma] 删除可能残留的本用例目标及其派生数据。
  - [Setup-3] [api] 准备邮箱为 "orf-member-create-task-e2e@orf.local" 的普通成员登录身份，并设置固定测试密码。
  - [Setup-4] [prisma] 准备邮箱为 "orf-member-create-task-e2e@orf.local"、角色为 member、状态为 active 的普通成员用户和默认团队成员关系。
  - [Setup-5] [prisma] 创建标题为 "E2E-MEMBER-CREATE-TASK: 目标前置"、流转状态为 reestimating、阶段为 orfReestimate 的本用例行动项目标。
  - [Setup-6] [prisma] 记录本用例行动项目标为 runtime.taskTarget。
  - [Setup-7] [prisma] 设置本用例行动项目标的挑战者包含普通成员。
  - [Setup-8] [api] 撤销普通成员登录身份可能残留的 Ory session。
  - [Setup-9] [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [Setup-10] [playwright] 打开 登录页。
  - [Setup-11] [playwright] 在邮箱输入框输入普通成员测试邮箱。
  - [Setup-12] [playwright] 在密码输入框输入普通成员测试密码。
  - [Setup-13] [playwright] 点击 "Sign In" 登录操作。
  - [Setup-14] [api] 当前会话 应为 普通成员已登录。
  - [Setup-15] [playwright] 打开 挑战工作台。

- S0：Action 前状态。
  - [S0-1] [api] 当前会话 应为 邮箱为 "orf-member-create-task-e2e@orf.local"、角色为 member、状态为 active 的已登录会话。
  - [S0-2] [playwright] 当前页面 应为 挑战工作台。
  - [S0-3] [playwright] 本用例行动项目标面板 应可见。
  - [S0-4] [playwright] 本用例行动项目标的 "新增行动项" 操作 应可点击。
  - [S0-5] [prisma] 本用例行动项目标 应允许 普通成员新增行动项。
  - [S0-6] [prisma] 本用例行动项目标 应不存在 标题为 "E2E-TASK-CREATE: 用户增加行动项" 的行动项。

- Action：被测业务动作。
  - [Action-1] [playwright] 点击本用例行动项目标的 "新增行动项" 操作。
  - [Action-2] [playwright] 新增行动项内联标题编辑器 应可见。
  - [Action-3] [playwright] 在新增行动项内联标题编辑器输入测试行动项标题。
  - [Action-4] [api] 在提交新增行动项内联标题前注册新建行动项接口响应捕获。
  - [Action-5] [playwright] 提交新增行动项内联标题编辑器。
  - [Action-6] [api] 记录新建行动项接口返回的行动项为 runtime.createdTask。
  - [Action-7] [playwright] 点击测试行动项的 "新增子行动项" 操作。
  - [Action-8] [playwright] 新增子行动项内联标题编辑器 应可见。
  - [Action-9] [playwright] 在新增子行动项内联标题编辑器输入测试子行动项标签。
  - [Action-10] [api] 在提交新增子行动项内联标题前注册新建子行动项接口响应捕获。
  - [Action-11] [playwright] 提交新增子行动项内联标题编辑器。
  - [Action-12] [api] 记录新建子行动项为 runtime.createdSubtask。

- S1：Action 后状态。
  - [S1-1] [api] 新建行动项接口响应 应成功。
  - [S1-2] [api] 新建子行动项接口响应 应成功。
  - [S1-3] [api] 新建行动项接口返回的行动项 应属于本用例目标，标题、说明和执行人正确。
  - [S1-4] [prisma] 本用例行动项目标 应存在 标题为 "E2E-TASK-CREATE: 用户增加行动项"、执行人为普通成员的行动项。
  - [S1-5] [prisma] 测试行动项 应存在 标签为 "新子任务" 的子行动项。
  - [S1-6] [playwright] 本用例行动项目标面板 应显示 测试行动项标题。
  - [S1-7] [playwright] 测试行动项下 应显示 "新子任务" 子行动项。
  - [S1-8] [api] 当前会话 应保持 普通成员已登录。

- Clean：恢复 B。
  - [Clean-1] [prisma] 删除本用例创建的测试行动项及其子行动项。
  - [Clean-2] [prisma] 删除本用例行动项目标及其派生数据。
  - [Clean-3] [api] 调用退出登录接口撤销当前登录会话。
  - [Clean-4] [playwright] 当前页面离开 ORF 前端应用。
  - [Clean-5] [playwright] 清空当前浏览器上下文的 cookies/localStorage/sessionStorage。
  - [Clean-6] [api] 撤销普通成员登录身份的残留 Ory session。
  - [Clean-7] [api] 删除邮箱为 "orf-member-create-task-e2e@orf.local" 的普通成员登录身份。
  - [Clean-8] [prisma] 删除普通成员用户的默认团队成员关系。
  - [Clean-9] [prisma] 删除邮箱为 "orf-member-create-task-e2e@orf.local" 的普通成员用户。
  - [Clean-10] [prisma] 应不存在 标题为 "E2E-TASK-CREATE: 用户增加行动项" 的测试行动项。
  - [Clean-11] [prisma] 应不存在 标题为 "E2E-MEMBER-CREATE-TASK: 目标前置" 的测试目标。
  - [Clean-12] [prisma] 应不存在 邮箱为 "orf-member-create-task-e2e@orf.local" 的普通成员用户。
