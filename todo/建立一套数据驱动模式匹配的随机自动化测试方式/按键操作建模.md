# 前端随机测试：键盘操作建模

## 1. 建模目标

前提：建模是为了对前端进行测试，因此只需要把"对前端的操作"进行建模就可以了。不需要关心数据如何从键盘到操作系统，再到浏览器。
最终数据到前端是由浏览器生成的 DOM（Document Object Model）事件。

键盘操作建模的目标：抽象出键盘输入的共同结构。
- 共性
- 分类
---

## 2. 总体模型

```text
KeyboardOperation                                      // 键盘操作
├── TextOperation                                      // 文本提交类操作
│   ├── InsertText(payload)                            // 输入一段文本
│   ├── PasteText(payload)                             // 粘贴一段文本
│   └── CommitCompositionText(payload)                 // 输入法提交文本，例如中文、日文、韩文
│
├── KeyOperation                                       // 按键类操作
│   ├── SingleKey(key)                                 // 单键输入
│   ├── ModifiedKey(modifierSet, key)                  // 修饰键 + 主键输入
│   ├── RepeatedKey(key, count)                        // 重复按同一个键
│   └── LongPressKey(key, duration)                    // 长按某个键
│
└── CompositeKeyboardOperation                         // 复合键盘操作
    └── KeySequence(operationList)                     // 多个键盘操作组成的序列
```

---

## 3. TextOperation：文本提交类操作

文本类操作只保留少量结构，差异主要放在 `payload` 里。

```text
TextOperation
├── InsertText(payload)                    // 模拟用户输入文本
├── PasteText(payload)                     // 模拟粘贴文本
└── CommitCompositionText(payload)         // 模拟输入法提交文本
```

推荐的 `payload` 参数空间：

```text
payload
├── emptyText                              // 空输入
├── asciiText                              // 英文、数字、普通标点
├── unicodeText                            // 中文、日文、韩文、emoji
├── whitespaceText                         // 空格、换行、Tab、连续空白
├── longText                               // 超长文本
├── structuredText                         // JSON、URL、HTML-like、路径、邮箱
└── malformedText                          // 异常格式文本，例如未闭合括号、非法结构
```

示例：

```text
InsertText("abc")
InsertText("你好")
InsertText("🙂🔥✅")
InsertText("\n")
PasteText("<script>alert(1)</script>")
PasteText("{\"name\":\"test\"}")
CommitCompositionText("中文输入")
```

---

## 4. KeyOperation：按键类操作

```text
KeyOperation
├── SingleKey(key)                         // 单独按下某个键
├── ModifiedKey(modifierSet, key)          // 修饰键组合，例如 Ctrl+A、Shift+Tab
├── RepeatedKey(key, count)                // 连续按某个键，例如连续 Backspace
└── LongPressKey(key, duration)            // 长按某个键，例如长按 ArrowDown
```

示例：

```text
SingleKey("Enter")
SingleKey("Backspace")
SingleKey("ArrowLeft")

ModifiedKey([PrimaryModifier], "A")
ModifiedKey([PrimaryModifier], "S")
ModifiedKey([Shift], "Tab")
ModifiedKey([Shift], "ArrowLeft")

RepeatedKey("Backspace", 5)
LongPressKey("ArrowDown", 1000ms)
```
---

### key：主键参数空间
```text
key
├── PrintableKey
├── EditingKey
├── NavigationKey
├── FocusKey
└── FunctionKey

key
├── PrintableKey                           // 可打印键：字母、数字、符号
│   ├── Letter
│   ├── Digit
│   ├── Symbol
│   └── Space
│
├── EditingKey                             // 编辑键：Backspace、Delete、Enter
│   ├── Backspace
│   ├── Delete
│   └── Enter
│
├── NavigationKey                          // 导航键：Arrow、Home、End、PageUp、PageDown
│   ├── ArrowUp
│   ├── ArrowDown
│   ├── ArrowLeft
│   ├── ArrowRight
│   ├── Home
│   ├── End
│   ├── PageUp
│   └── PageDown
│
├── FocusKey                               // 焦点相关键：Tab、Escape
│   └── Tab
│
├── ActionKey                              // 动作按键
│   ├── Escape
│   ├── Enter
│   └── Space
│
└── FunctionKey                            // 功能键：F1-F12
    └── F1-F12
```

示例：

```text
PrintableKey:
A, B, C, 1, 2, 3, -, =, /, .

EditingKey:
Backspace, Delete, Enter

NavigationKey:
ArrowLeft, ArrowRight, ArrowUp, ArrowDown, Home, End, PageUp, PageDown

FocusKey:
Tab, Escape

FunctionKey:
F1, F2, F3, ..., F12
```
---

### modifierSet：修饰键参数空间
```text
modifierSet
├── Shift                                     // Shift
├── PrimaryModifier                           // 主修饰键：Windows/Linux 为 Ctrl，macOS 为 Meta
├── Alt                                       // Alt
├── PrimaryModifier + Shift                   // 主修饰键 + Shift
├── PrimaryModifier + Alt                     // 主修饰键 + Alt
├── Alt + Shift                               // Alt + Shift
└── PrimaryModifier + Alt + Shift             // 复杂组合，建议低权重
```

其中：
```text
PrimaryModifier = platform === "macos" ? Meta : Ctrl
```

这样可以统一描述跨平台快捷键：

```text
Windows / Linux: Ctrl + C
macOS: Cmd + C

统一抽象为:
PrimaryModifier + C
```

## 5. CompositeKeyboardOperation：复合键盘操作

复合操作用于模拟更接近真实用户的连续行为，但仍然不引入业务语义。

```text
CompositeKeyboardOperation
└── KeySequence(operationList)                     // 一组键盘操作序列

```

示例：

```text
KeySequence([
  SingleKey("Tab"),
  InsertText("hello"),
  SingleKey("Enter")
])
```

这类结构可以覆盖：

```text
输入后删除
输入后提交
先全选再输入
Tab 切换焦点后输入
输入后按 Escape
方向键移动后继续输入
```
