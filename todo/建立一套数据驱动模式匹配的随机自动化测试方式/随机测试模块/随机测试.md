# CrawlJax
CrawlJax 是一个基于真实浏览器和 DOM 状态的前端 UI 自动探索工具。它会读取当前页面 DOM，按照用户配置的点击规则自动触发可交互元素，并通过比较交互前后的 DOM 变化来识别和记录页面状态迁移。

CrawlOverview 插件产出这些内容：
```
index.html       看总览
result.json      给程序读
config.json      看这次怎么跑的
CrawlPath*.json  看某条探索路径
doms/            看状态 DOM
screenshots/     看状态截图
states/          看单个状态详情页面
css/js/img/lib   报告页面资源
```
