# 前端随机测试：鼠标操作建模

## 1. 建模目标

前提：建模是为了对前端进行测试，因此只需要把"对前端的操作"进行建模就可以了。不需要关心数据如何从鼠标到操作系统，再到浏览器。
最终数据到前端是由浏览器生成的 DOM（Document Object Model）事件。

鼠标操作建模的目标：抽象出鼠标输入的共同结构。
- 共性
- 分类
---

## 2. 总体模型
```
MouseOperation                                      // 鼠标操作
├── PointOperation                                  // 指向 / 移动类操作
│   ├── MoveTo(target)                              // 移动到某个目标
│   └── Hover(target, duration)                     // 悬停在某个目标上
│
├── ClickOperation                                  // 点击类操作
│   ├── Click(target, button)                       // 单击
│   ├── DoubleClick(target)                         // 双击
│   ├── ContextClick(target)                        // 右键点击
│   ├── ModifiedClick(modifierSet, target, button)  // 修饰键 + 点击
│   └── RepeatedClick(target, button, count)        // 连续点击
│
├── DragOperation                                   // 拖拽类操作
│   ├── Drag(fromTarget, toTarget)                  // 从一个目标拖到另一个目标
│   └── DragWithDuration(fromTarget, toTarget, duration)
│
├── WheelOperation                                  // 滚轮类操作
│   ├── Scroll(direction, distance)                 // 垂直滚动
│   └── HorizontalScroll(direction, distance)       // 水平滚动，低权重
│
└── CompositeMouseOperation                         // 复合鼠标操作
    └── MouseSequence(operationList)                // 多个鼠标操作组成的序列
```
